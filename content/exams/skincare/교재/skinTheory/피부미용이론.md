## Chapter 01. 피부미용 개론·피부분석과 상담

### 1-1. 피부미용의 목적

- **피부미용(skin care)**: 피부를 건강하고 아름답게 유지·개선하기 위해 분석·상담·관리를 수행하는 일련의 행위 — 피부미용업(공중위생관리법 제2조)은 의료기기·의약품을 사용하지 않는 피부상태분석·피부관리·제모·눈썹손질 영업.
- 🎯 **관리 목표**: 피부 기능 정상화(보호·체온조절·분비·흡수·감각) + 미용적 개선(투명도·탄력·수분).
- **면역(免役)적 금지선**: 의료기기·의약품 사용 행위, 질병 치료 목적의 시술은 미용사 업무 범위 밖 — 의료법과의 경계가 단골 출제 지점.

### 1-2. 피부분석과 상담

- 🎯 **피부분석 절차**: 고객 상담(과거력·생활습관) → 육안 관찰 → 촉진(만져서 판단) → 기기 측정(우드램프·수분계) → 유형 판정 → 관리계획 수립.
- **기록**: 고객 카드(chart) — 개인정보·피부유형·관리 이력·사용 제품·부작용 여부 기록, 관리계획 차트는 실기 시험에서도 요구.
- **상담 원칙**: 효과를 과장하지 않음, 의료적 진단 표현 금지, 알레르기·민감 병력 반드시 확인.

## Chapter 02. 피부의 구조와 부속기관 ⭐빈출

### 2-1. 표피(epidermis) — 5층 구조

- 🎯 **표피 5층(밖→안)**: 각질층(stratum corneum) → 투명층(lucidum, 손바닥·발바닥에만 뚜렷) → 과립층(granulosum) → 유극층(spinosum) → 기저층(basale, 멜라닌세포·각질형성세포 모체).
- **각질형성세포(keratinocyte)**: 기저층에서 생성 → 위로 이동하며 각질화 → 약 28일(4주) 주기로 탈락(turnover). 연령 증가 시 주기 지연.
- **멜라닌세포(melanocyte)**: 기저층에 존재 — 멜라닌 생성, 자외선으로부터 DNA 보호. 멜라닌 과다 → 기미·주근깨·검버섯.
- **랑게르한스세포**: 표피의 면역 감시 세포(항원 제시). **메르켈세포**: 촉각 수용.

### 2-2. 진피(dermis)와 피하지방

- **진피**: 유두층(모세혈관·감각수용체 풍부) + 망상층(콜라겐·엘라스틴 섬유 — 탄력·지지). 콜라겐은 섬유아세포(fibroblast)가 생성, 노화 시 감소.
- 🎯 **피하지방(subcutaneous fat)**: 진피 아래 지방조직 — 체온 유지·충격 흡수·에너지 저장.
- **부속기관**: 피지선(피지 분비, 홀몬 영향 — 여드름 관련), 한선(에크린선=땀 분비 체온조절 / 아포크린선=겨드랑이·취기 관련), 모발·모낭, 입모근(세움털근), 손발톱.

### 2-3. 피부의 기능

- **보호**: 물리·화학·미생물 장벽(각질층 + 피부 산성막 pH 4.5~6.5 약산성).
- **체온조절**: 발한·혈관 확장/수축. **흡수**: 지용성 물질 위주 경피흡수. **감각**: 촉각·온각·통각 수용체. **비타민D 합성**: 자외선에 의해 피부에서 생성.

## Chapter 03. 피부 유형과 기능 ⭐빈출

### 3-1. 피부 유형 분류

- 🎯 **4대 유형**: 정상(수분·유분 균형, 모공 작음) / 건성(피지 부족, 각질·당김) / 지성(피지 과다, 모공 확장·번들거림·여드름 경향) / 복합성(T존 지성 + U존 건성·정상).
- **민감성**: 자극에 과민 반응 — 홍반·따가움, 유형과 별개의 피부 상태 개념.
- **판정 지표**: 수분량·피지량·모공·각질·탄력·색소침착.

### 3-2. 피부 pH와 산성막

- 🎯 **정상 피부 pH**: 약 4.5~6.5의 약산성 — 피지·땀·각질 대사물이 만드는 산성막(acid mantle)이 세균 증식을 억제.
- **알칼리화 요인**: 알칼리성 세정제 남용 → 산성막 파괴 → 세균 감염·건조 유발.

## Chapter 04. 클렌징과 딥 클렌징 ⭐빈출

### 4-1. 클렌징

- **목적**: 화장품 잔여물·피지·각질·외부 오염물 제거 — 관리의 첫 단계.
- 🎯 **포인트 메이크업 리무버(눈·입술) → 클렌징 크림/오일(1차) → 폼 클렌징(2차) → 토너 정리** 순서가 표준. 유성 메이크업은 유성 제품으로(지용성).
- **주의**: 클렌징 시간 과다·강한 마찰은 산성막 손상.

### 4-2. 딥 클렌징(각질 제거)

- 🎯 **방법 3종**: 물리적(스크럽·브러시·필링 패드 — 직접 마찰) / 화학적(AHA·BHA 등 각질 용해 성분) / 효소적(파파인·브로멜라인 효소 — 민감성에도 비교적 순함).
- **AHA**: 수용성 과일산(글리콜산·락트산) — 표피 각질 결합 완화. **BHA(살리실릭산)**: 지용성 — 모공 속 피지·각질 제거에 유리.
- **주의**: 민감성·염증 피부는 물리적 스크럽 금기, 시술 후 자외선 차단 필수.

## Chapter 05. 매뉴얼 테크닉 ⭐빈출

### 5-1. 기본 수기법

- 🎯 **에플라주(effleurage)**: 가볍게 쓰다듬는 경찰법 — 관리 시작·마무리, 진정·이완.
- 🎯 **페트리사주(petrissage)**: 반죽하듯 주무르는 율동법 — 근육 이완·혈액·림프 순환 촉진.
- **프릭션(friction)**: 원을 그리며 문지르는 마찰법 — 심부 자극.
- **타포트먼트(tapotement)**: 가볍게 두드리는 타격법 — 혈행 촉진·각성.
- **바이브레이션(vibration)**: 떨림법 — 진정·이완.

### 5-2. 수기 시 주의

- **방향**: 근육의 결·림프 흐름 방향(심장 방향)으로 — 안면은 아래→위(중력 반대) 리프팅 방향.
- **금기**: 염증·화농성 여드름·습진 부위, 수술 직후, 발열 시 마사지 금지.

## Chapter 06. 팩·마스크와 제모

### 6-1. 팩·마스크

- 🎯 **유형**: 크림팩(보습·영양, 건성용) / 클레이팩·머드팩(흡착·피지제거, 지성용) / 필오프팩(각질·노폐물 제거) / 시트마스크(수분·진정) / 모델링팩(석고계, 밀폐 효과).
- **작용**: 밀폐(occlusion) → 피부온도 상승 → 모공 확장 → 성분 흡수 촉진·노폐물 배출.
- **사용 빈도**: 일반적으로 주 1~2회 — 피부 상태에 따라 조절.

### 6-2. 제모(除毛)

- **피부미용업 범위**: 의료기기·의약품을 사용하지 않는 제모(왁싱·족집게·실 제모 등) — 레이저·전기제모(절연바늘)는 의료기기에 해당해 미용사 업무 범위 밖.
- 🎯 **왁싱**: 소프트왁스(시트로 제거, 넓은 부위) / 하드왁스(굳혀서 제거, 민감 부위) — 모발 성장 방향으로 도포, 반대 방향으로 제거.
- **주의**: 제모 후 자극 완화·소독, 당일 사우나·자외선 노출 자제 지도.

## Chapter 07. 신체 관리·림프

### 7-1. 신체 각 부위 관리

- **등·목·어깨**: 근육 긴장 완화 위주 — 페트리사주 중심.
- **팔·다리**: 말초→심장 방향 림프 배출(de-tox 컨셉), 부종 완화.
- **복부**: 시계 방향(결장 진행 방향) 마사지.

### 7-2. 림프계와 부종

- 🎯 **림프**: 조직액이 림프관으로 흡수된 액체 — 림프절에서 이물질·세균 여과, 면역 기능.
- **림프 드레나지**: 림프 흐름 방향(사지 말초 → 몸통 → 쇄골하 정맥각)으로 가벼운 압으로 유도 — 부종(림프 정체) 완화.
- **부종 원인**: 림프 순환 부전·염분 과다·장시간 같은 자세.

## Chapter 08. 피부와 영양·질환·광선·노화

### 8-1. 피부와 영양

- **비타민A**: 각질 정상화(부족 시 피부 건조·모공각화). **비타민C**: 콜라겐 합성·항산화·미백 보조. **비타민E**: 항산화·막 안정. **단백질**: 각질·콜라겐 원료. **수분**: 대사 기본.

### 8-2. 주요 피부 질환·트러블

- **여드름(acne)**: 피지선 과다 + 모낭각화 + P.acnes 증식 — 면포(화이트헤드·블랙헤드)→구진·농포 진행.
- **기미**: 이마·뺨 대칭 갈색 반점 — 여성호르몬·자외선 관련. **주근깨**: 유전적, 자외선에 심화. **검버섯(지루각화증)**: 노화성 양성 증식.
- **아토피·접촉피부염·백반증·건선** 등은 관리 금기 또는 의뢰 대상.

### 8-3. 광선·면역·노화

- 🎯 **UVA**: 진피 도달 — 탄력 저하·주름(광노화 주범), 창유리 투과. **UVB**: 표피 화상·홍반·색소침착, DNA 직접 손상. **UVC**: 오존층 차단, 인공 광원의 살균 이용.
- **광노화 vs 내인성 노화**: 자외선 누적이 주름·탄력저하의 최대 가외인자 — 자외선 차단이 노화 예방의 1차.
- **면역**: 랑게르한스세포·림프계 — 과민반응(알레르기) 시 접촉피부염.
