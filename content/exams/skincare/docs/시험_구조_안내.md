# 미용사(피부) 시험 구조 안내

> **문서 ID**: DOC-USR-15
> **범위**: exam:skincare · 판본: none
> **목적**: 시험 형식·합격 기준·앱 매핑 구조의 정확한 요약

## 필기시험

| 항목 | 내용 |
|------|------|
| 시행 방식 | CBT 상시검정 (주중 연중, 예약제) |
| 문항·시간 | 객관식 4지택일 **60문항 / 60분** |
| 과목 구조 | 통합 1과목 (출제기준 5개 주요항목 혼합 출제) |
| 합격 기준 | 100점 만점 **60점 이상** (36문) — 과목별 과락 없음 |
| 출제기준 비중(추정) | 피부미용이론 약 52% · 해부생리학 약 10% · 기기학 약 8% · 화장품학 약 10% · 공중위생관리학 약 20% |

본 앱의 `통합 모의고사`는 위 비중에 맞춰 과목별 문항을 배정(31/6/5/6/12)하고 60분 타이머로 실전 연습을 제공합니다.

## 실기시험

| 항목 | 내용 |
|------|------|
| 형식 | 작업형 (피부미용실무) — 약 2~3시간 |
| 주요 과제 | 고객 피부상태 분석 → 관리계획 차트 작성 → 얼굴/신부 관리 실습 |
| 응시 조건 | 필기 합격 후 2년 이내 응시 가능 |

본 앱의 `실기 서술 연습`은 관리계획 차트 작성·수기 순서 서술 등 **필답 가능한 범위**만 연습을 제공합니다. 실습 수기 자체는 앱 범위 밖이며, Q-Net 공개문제를 참조하세요.
