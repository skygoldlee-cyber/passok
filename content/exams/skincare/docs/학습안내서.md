## 시험 구조

| 구분 | 내용 |
|------|------|
| 시행 | 한국산업인력공단 (Q-Net) — 국가기술자격, 응시자격 제한 없음 |
| 필기 | CBT 상시검정(주중) — 객관식 4지택일 **60문항/60분**, 통합 1과목, 과락 없이 60점(36문) 이상 합격 |
| 실기 | 작업형 약 2~3시간 — 관리계획 차트 작성 + 피부미용 실습 (필기 합격 후 2년 내 응시) |
| 출제기준 | 5개 주요항목 — 피부미용이론·해부생리학·피부미용기기학·화장품학·공중위생관리학 |

## 과목 구성과 비중

- **피부미용이론 (과목1)** — 가장 큰 비중(절반 안팎). 피부 구조·유형·클렌징·수기법·팩·제모·신체 관리
- **해부생리학 (과목2)** — 안면골·표정근·삼차/안면신경·림프 순환 위주로 반복
- **피부미용기기학 (과목3)** — 갈바닉·고주파·우드램프 원리 + 의료기기 구분 금기
- **화장품학 (과목4)** — 화장품 정의·기능성·유화 제형·성분·표시
- **공중위생관리학 (과목5)** — 소독 방법 + 공중위생관리법(영업·면허·처분·벌칙)

## 권장 학습 경로

1. **교재리더 정독** — 과목1 피부미용이론부터 (최다 비중). `🎯` 표시가 빈출 핵심
2. **퀴즈 반복** — 문제은행을 과목별로 풀고 오답은 복습 뷰에 자동 수집
3. **모의고사** — 통합 60문/60분 실전 타이머로 마무리 점검
4. **실기 서술 연습** — 필기 합격 후 관리계획 차트·수기 순서 서술 문항으로 전환
