# 인물 설정표 — 서사·웹툰·문항 공통

> **문서 ID**: DOC-USR-27
> **범위**: exam:cosmetic · 판본: none

아크·복선·장면 공식 등 서사 운용 규칙은 `교재/docs/PASSMULA_이야기형교재_시리즈설정문서.md`(Series Bible)를 따릅니다.

## 설정 규칙

1. **역할·함정 배정 고정** — 각 인물의 주역 과목과 함정 유형은 고정입니다. 다른 함정이 필요하면 기존 인물에 덧붙이지 말고 신규 인물을 등록합니다.
2. **호칭** — 지문·대사 모두 직함 포함 표기("지연", "현우", "수진", "표 감독관")를 통일합니다. 감시원은 반드시 "표 감독관" — 이름 단독·다른 직함 사용 금지.
3. **함정 비트** — 인물의 실수는 항상 그 인물의 **고정 결점에서 나오는 자연스러운 실수**에 둡니다(민수=성급한 낙관, 현우=안 보이는 것 놓침, 수진=현장 응용 굳음). 억지·악의·무리수 금지 — 시나리오 문항의 대표 오답 보기 원천입니다.
4. **신규 인물 등록** — 반복 등장하는 명명 인물은 사용 전에 이 표에 등록합니다. 등록 없이 한 번 쓰고 버리는 인물은 배경 인물로 처리합니다.
5. **배경 인물** — 고객·직원·공무원 등은 장면에 필요 시 등장 가능하나, 고정 설정이 생기면 이 표에 등록해 재사용합니다.
6. **사실 무결성** — 인물이 실수로 틀린 내용을 말할 수 있으나, 정정 문장에는 반드시 정확한 법령·수치·분류가 나와야 하며 틀린 내용이 답처럼 남지 않게 합니다. ⚖️ 법령 원문·🔢 수치·기한·📊 표는 각색 대상이 아닙니다.
