> 🧠 **망각 곡선 이론이란?** — 외운 내용은 시간이 지날수록 잊혀지는데, 잊기 **직전**에 한 번 더 인출하면 기억이 다시 단단해져 다음 망각까지의 간격이 점점 길어집니다. 같은 시간에 몇 배나 오래 유지되는 간격 반복의 원리입니다. FSRS-6는 이 "망각 곡선"을 카드·진술마다 **난이도**(얼마나 어려운가)·**안정도**(기억이 며칠 지속되는가)·**기억률**(지금 꺼낼 확률) 세 수치로 추적하고, 기억률이 약 90% 아래로 떨어지는 시점을 다음 복습 기한으로 잡습니다 — "오늘 할 일"의 `복습 카드`가 그 결과입니다. 같은 카드라도 **난이도가 간격 속도를 가릅니다** — 어려운 카드는 간격이 천천히(예: 1→2→4→8일), 쉬운 카드는 빠르게(1→3→8→20일) 늘어납니다. 시험일을 설정하면 같은 계산을 **시험 당일**에도 적용합니다 — 다음 복습이 시험 이후라 시험날 기억률이 낮아질 카드를 찾아 `시험 전 최종 인출`로 알려주고, 복습 후 새 기한이 시험을 넘어가는 카드는 **시험 전날로 자동 당겨** 마지막 노출을 보장합니다.

![망각 곡선과 간격 반복 — 복습 시점마다 기억 곡선이 다시 세워지는 원리](images/망각곡선_간격반복_가로_각주.svg)

> 🧠 **단원 숙달 추적이란?** — FSRS가 "언제 다시 볼지"를 정한다면, **BKT(Bayesian Knowledge Tracing)**는 "지금 얼마나 아는지"를 추정합니다. 퀴즈·모의고사·드릴의 정오 판정을 **순서대로** 누적해 단원마다 숨은 숙달 확률 P(L)을 갱신합니다. 단순 정답률과 다른 점은 **찍기와 실수를 분리**한다는 것입니다 — 모르는데 운 좋게 맞힌 정답(추측)은 숙달을 크게 올리지 않고, 아는데 실수로 틀린 오답(슬립)은 크게 깎지 않습니다. 맞힐 때마다 "이번 기회에 새로 배웠을 확률"(학습 전이)도 함께 반영되므로, 연속 정답은 숙달을 빠르게 회복시킵니다. P(L)이 **90%**를 넘으면 그 단원은 "숙달 완료"로 간주하고, 낮은 단원일수록 학습 진단의 **취약 단원 랭킹**·**합격 갭 분석**에서 우선순위가 올라갑니다 — "몇 번 틀렸나"가 아니라 "지금 얼마나 아는가"로 정렬되는 이유입니다. 단, BKT는 망각을 다루지 않습니다 — 시간이 지나 잊는 것은 모델하지 않으므로, 복습 **시점**은 FSRS가, 숙달 **정도**는 BKT가 맡는 역할 분리입니다.

### 출제비중 기반 우선순위 등급

§2 과목별 표의 **우선순위** 열에 붙는 **S·A·B·C**는 각 섹션의 **학습 우선순위 등급**입니다.
`예상 비중`(기출 분석으로 추정한 출제 점유율)과 `중요도`(★ 5단계)를 함께 본 4단계 분류로,
시험 성적 등급이 아니라 **공부 시간을 어디에 쓸지 정하는 기준**입니다.

| 등급 | 조건 | 학습 전략 | 비중 |
|:----:|------|-----------|:----:|
| **S** | 예상 비중 ≥20% + ★★★★★ | 최우선 심화 학습, 완벽 암기 | 50% |
| **A** | 예상 비중 10~20% + ★★★★~★★★★★ | 핵심 위주 반복 학습 | 30% |
| **B** | 예상 비중 5~10% + ★★★~★★★★ | 요약 정리 + 문제은행 풀이 | 15% |
| **C** | 예상 비중 ≤5% + ★★~★★★ | 마지막에 훑기만 | 5% |

**표 읽는 법**

- **조건의 두 축**: `예상 비중`은 과목 안에서 그 섹션이 차지할 것으로 예상되는 출제 비율입니다 (예: 1.1 화장품법 = 1과목의 80~85%). `★`는 출제 빈도·법령 비중을 종합한 중요도로, 두 축이 모두 높아야 S·A입니다.
- **비중**: 같은 등급 섹션을 모두 합친 **시험 점유율**입니다 — S급 7개 섹션만 잡아도 시험의 약 절반을 커버합니다. 학습 시간 배분의 기준으로도 그대로 씁니다 (S급에 전체 시간의 절반가량, C급에 마지막 잔여).
- **⚠️ (과소 편차)**: §2 표에서 등급 옆에 붙은 ⚠️는 문제은행 문항 비중이 예상 비중보다 **낮은 섹션**입니다 — 문제 풀이만으로는 커버가 부족하므로 **교재 본문·참조자료로 반드시 보완**하세요. (예: 2.3 사용제한 원료 — 예상 25~30%인데 문제은행은 약 5%)
- **회독 연동**: 아래 회독별 전략이 이 등급을 그대로 사용합니다 — 1회독 S급 정독 → 2회독 A급 보완 → 3회독 B급 요약 → C급은 마지막 스캔.

**등급별 해석** (§2의 20개 섹션 기준)

- **S급 — 7개 섹션 · 시험의 약 50%**: 과목의 대표 구간입니다. 1회독부터 정독 대상이며, 단답형으로 답을 직접 꺼낼 수준까지 암기합니다. (1.1·2.1·2.3·3.3·3.4·4.2·4.6)
- **A급 — 7개 섹션 · 약 30%**: S 다음 가는 핵심 구간입니다. 개념 위주 반복 학습으로 객관식 정답률을 확보합니다. ⚠️가 붙은 A급(1.2·3.2·4.4·4.5)은 S급처럼 본문 보완이 필요합니다.
- **B급 — 5개 섹션 · 약 15%**: 보조 구간입니다. 요약표·숫자표로 정리하고 문제은행 풀이로 확인만 합니다.
- **C급 — 1개 섹션 · 약 5%**: 말단 구간(4.8 재고관리)입니다. 마지막 회독에 한 번 훑는 수준으로 충분합니다.

### 회독별 학습 전략 (출제비중 반영)

```text
1회독  구조 파악 + S등급 정독 (마인드맵 · 흐름도 · 본문)
   ↓
2회독  🎯 출제 + ⭐ 핵심 + A등급 보완 (과소 항목 집중)
   ↓
3회독  🔢 숫자 + 📊 비교표 + B등급 요약
   ↓
4회독  📝 확인문제 + 오답 역추적 (교재 원문 링크)
   ↓
시험 직전  🧠 30초 회상 카드 + 📋 체크리스트 + ⚠️ 편차 항목
```

> 💡 **앱 연동**: 교재리더에서 읽은 구간과 읽기 시간은 자동으로 기록되어, **1회독 진척률이 학습 계획에 반영**됩니다 — 남은 통독 기간만큼 카드 학습일이 예약되고, 읽기만 한 날도 학습일로 인정됩니다.
>
> ✅ **통독 완료는 따로 신고할 필요가 없습니다** — 별도의 "완료" 버튼이 없고, **앱 안에서 교재를 끝까지 읽는 행위 자체가 완료 신호**입니다. 리더가 과목별로 실제 머문 구간(청크 커버리지)을 누적하므로, 모든 구간을 지나치면 진척률 100%가 되는 순간 **알림창으로 완료를 통지**하고 통독 예약이 자동 해제되어 카드 학습일이 복원됩니다. 진행 상황은 학습 캘린더 계획 패널의 "교재 일독 N% 읽음 · 통독 N일 반영"에서 확인할 수 있습니다.
>
> ⚠️ 목차나 이어보기로 끝까지 점프해도 진척률은 오르지 않습니다 — **방문 기록이 아니라 체류 커버리지 기준**이라 실제로 구간을 지나야 인정됩니다. 종이책 등 앱 밖에서 읽는 경우는 기록되지 않습니다 — 통독 예약은 리더 사용 시작부터 적용되므로, 앱에서 통독하지 않을 계획이면 리더를 열지 않는 편이 계획상 유리합니다(통독일 차감 없이 카드 기간이 유지됨).

> **핵심 원칙:** 긴 설명을 처음부터 다시 읽기보다, **표·흐름도·숫자·문제를 통해 먼저 회상한 뒤 필요한 부분만 본문으로 돌아가는 방식**을 권장합니다.
> **편차 보정 원칙:** 문제은행 분포가 예상 비중보다 **과소한 항목은 교재 본문+참조자료로 보완**, **과다한 항목은 문제은행 풀이만으로 복습**합니다.
> **매일 학습 습관:** 매일 5분 데일리 챌린지로 연속 학습(🔥 스트릭)을 유지하고, 캘린더의 주간 목표 링으로 이번 주 진행을 확인하세요. 스트릭 복구권·마스터리 레벨 등 상세 기능은 [사용자 매뉴얼](doc:user_manual)을 참조하세요.

### 🔁 주간 배분·학습 진단 진행 흐름

시험일을 설정하면 **주간 배분**이 주차별 과목 배분을 만들고, 학습 기록이 **학습 진단**에 쌓여 다시 배분 가중으로 되먹는 순환입니다. 학습 진단은 별도 "시작" 절차가 없습니다 — 퀴즈·복습·드릴·모의고사 기록이 표본을 채우면 진단 카드가 자동으로 채워집니다.

```mermaid

    C --> D["④ 매일 실행<br/>과목 칩 → 카드 학습 → 퀴즈 → 오답 원인 태깅"]
```

**단계별 상세**

| 단계 | 앱이 하는 일 | 사용자가 할 일 |
|:---:|---|---|
| **① 시험일 설정** | D-day로 주차별 학습일을 역산하고, 필요량÷일일 목표 비율로 **여유/압축/긴급** 등급 판정. 90일 미만이면 권장 준비 기간 경고 (계획은 정상 생성) | 대시보드 '오늘 할 일' 큐의 `시험일 설정` 또는 캘린더에서 입력 |
| **② 교재 1회독** | 실제로 머문 구간(청크)만 진척으로 누적하고, 남은 통독 예상 학습일을 카드 학습일에서 차감 — 주차 표에 "통독 N일" 표기. 읽기만 한 날도 학습일·스트릭 인정 | 표준형 또는 이야기형으로 가볍게 구조 파악 (마인드맵·흐름도 위주) |
| **③ 주간 배분** | 과목별 남은 카드·퀴즈에 **출제 비중 × 약점 가중**(최근 퀴즈 정답률·헷갈림 카드·오답 원인·취약 단원·밀린 FSRS 복습)을 곱해 주차 배분. 먼저 끝낸 과목의 배정은 남은 과목으로 자동 재배분 | 이번 주 과목 칩의 `실적/배정` 확인. `약점` 배지 과목 우선 |
| **④ 매일 실행** | 칩 클릭 → 해당 과목 플래시카드 즉시 시작. 퀴즈 오답에 원인 태그를 달면 분류표에 축적 | 카드 목표(기본 50장)·퀴즈 목표(기본 10문) 채우기 + 오답 원인 태깅 |
| **⑤ 학습 진단** | 6개 진단 카드가 기록을 종합 — 진단 결과가 다음 주차 배분의 약점 가중에 반영. 합격선 미달이면 목표 상향 권고(계획 필요량 기반 권장치)와 "목표 상향" 버튼 | 취약 단원·오답 패턴 확인 → 권장 학습법 실천 |
| **⑥ 주간 판정·재배분** | 주간 목표 달성 시 다음 주차로 자동 진행. 미달 시 칩 ⓘ로 배정 근거를 확인하고 보강 동선 안내 | 주간 리포트로 복기 — 과목별 실적/배정 준수 확인 |

> 📏 **권장 준비 기간 90일의 근거**: 문제은행 1,937문 1회전을 학습일당 약 30문 페이스로 소화하려면 약 64학습일이 필요하고, 이를 주 5일 학습 기준으로 달력일로 환산한 값입니다 (64×7/5 ≈ 90일). 시험일이 90일 미만이면 전량 1회전이 물리적으로 어려워 경고가 표시됩니다.
>
> 🗓️ **13주 타임라인** — 90일 ≈ 64학습일 ≈ 13주(주 5일 기준):
> - **1~2주차(10학습일) — 교재 통독**: `readThroughDays`가 학습일에서 주차 순차 차감되어 주차 표에 "통독 N일"로 표기. 읽기만 한 날도 학습일·스트릭 인정
> - **3~13주차(~54학습일) — 카드·퀴즈·복습 본격 기간**: 주간 배분 추종 + FSRS 복습 큐 소진 + 오답 원인 태깅이 돌아가는 구간
> - 통독을 먼저 끝내면 차감이 해제되어 본격 기간이 앞당겨지고, 통독을 건너뛰면 처음부터 13주 전체가 카드·퀴즈 기간이 됩니다

**데이터가 쌓이는 순서**

```text
첫 주  : 카드·퀴즈 기록 축적 → 진단 카드가 하나씩 활성화 (표본 부족 시 중립 가중치)
2~3주차: 오답 원인·취약 진술 누적 → 주간 배분이 약점을 강하게 반영
중반   : 모의고사 1회 이상 → 성적 추이·합격 예측·과목별 균형(레이더) 활성화
후반   : 합격 갭이 0에 수렴하도록 일일 목표·배분이 자동 조정되는 흐름 확인
```

> 💡 **왜 이 순서인가**: 시험일이 배분의 기준선을 정하고, 교재 1회독이 전체 지형을 잡으며, 그 뒤의 카드·퀴즈 실행이 진단의 표본을 만듭니다. 진단 없는 초반엔 출제 비중 중심의 중립 배분, 표본이 쌓인 후반엔 약점 중심의 개인화 배분으로 자연히 이동합니다.

### 시험 직전 D-5 학습 플랜

> **목표**: 시험 5일 전부터 당일까지, 누적 학습 데이터로 최종 인출·보강
> **전략**: "복습 큐 → 취약 인출 → 함정표 스캔 → (잔여) 모의고사" 인출 우선 4층 구조 — 정독보다 인출(회상·풀이)이 기억 정착에 우월하고, FSRS 복습 카드는 망각 직전이라 한 장당 효용이 가장 큽니다
> **과목 순서**: 출제 비중 × 학습 진단 합격 갭 가중 — 데이터 부족 시 폴백 비중 1과목 10% / 2과목 25% / 3과목 25% / 4과목 40%
>
> 📌 **매일 고정 골격** — 순서를 바꾸지 마세요
> 1. **FSRS 복습 큐 소진** — 대시보드 "오늘 할 일"의 `복습 카드` 먼저 (비협상)
> 2. **취약 인출** — 리뷰 탭 오답·혼동 카드 + O/X 드릴 취약 편성 + 큐의 `시험 전 최종 인출` 항목(표시되면 — 다음 복습이 시험 이후로 잡힌 카드)
> 3. **함정표·숫자표 회상 점검** — 항목을 보고 핵심을 먼저 인출, 막힌 것만 원문 확인
> 4. **잔여 시간** — 미학습 카드(D-2까지)·문제은행 추가 풀이

**📅 D-5 — 합격 갭 최상위 과목 집중**

1. **고정 골격 ①**: FSRS 복습 큐 소진
2. 앱: **학습 진단 → "합격 갭 분석" 카드**로 취약 과목 순위 확인 → 최상위 과목(데이터 부족 시 과목4, 비중 40%)의 `핵심정리 문항` 회상 점검 — 막히는 영역은 문제은행에서 해당 주제 검색해 근거 확인
3. 오늘 주간 배분의 해당 과목 카드·퀴즈 소화 → 부족하면 문제은행 1회전, 시간 부족 시 해설의 **🎯 기출 표시 문항** 위주 (교재 리더 "기출 핵심 요약" 카드로도 확인 가능)

**📅 D-4 — 취약 상위 과목 인출**

1. **고정 골격** 순서 — FSRS 복습 큐 → 취약 인출
2. 합격 갭 상위 과목(폴백: 2·3과목)의 `핵심정리 문항` 회상 점검
3. `2과목 원료·사용제한원료 핵심암기`는 배합한도를 보고 수치를 먼저 인출 — 막힌 항목만 원문 확인 (3과목은 청정도 등급 수치·미생물 기준·안전용기 제외 대상이 빈출)
4. 오답엔 원인 태그(개념·숫자·함정) — 마지막 주말 학습 진단의 정확도가 올라갑니다

**📅 D-3 — 잔여 과목 + 암기 자료 총정리**

1. **고정 골격** 순서
2. 남은 과목(폴백: 1과목) `핵심정리 문항` 회상 점검 — 벌칙/과태료 구간, 등록 vs 신고, 기한(30일/90일/15일) 표 중심
3. **두음법 암기 총정리**(앱 문서함) 1회전 (두음법 Part 1 + 중요 숫자 Part 2)
4. 앱: **훈련소 → 암기 · 실무 훈련 → 계산 연습** (배합 한도 × g 계산 유형) + **원료 배합 챌린지**

**📅 D-2 — 통합 모의고사 + 오답 정리**

1. **통합 실전 모의고사** 1회 — 실제 시험 시간대에 응시, 타이머 사용 (100문항 120분). D-1이 아닌 D-2에 배치해 피로 회복 시간을 확보합니다
2. 오답 원인 태깅 → 학습 진단에 자동 반영 → 틀린 주제를 문제은행에서 10~20제 추가 풀이
3. 각 과목 핵심요약의 **혼동 함정표 + 숫자 체크리스트** 회상 점검
4. **두음법 암기 총정리** 2회전 — 연상 문장까지 회상되는지 확인

**📅 D-1 — 최종 인출 세션**

1. **고정 골격 ①②**: 밀린 복습 잔여 + 오답·혼동 카드 전량 재검 — 시험 직전 복습이 당일 기억률을 직접 끌어올립니다. 큐의 `시험 전 최종 인출` 항목이 있으면 최우선으로 소화 — 기억률이 가장 낮은 카드부터 출제됩니다
2. 앱: **학습 진단 → "합격 갭 분석"** 최종 확인 — 취약 과목 핵심요약의 **혼동 함정표**만 재학습
3. 저녁: **두음법 암기 총정리** 숫자 파트(Part 2) 2회전 + 각 과목 **숫자 체크리스트** 회상 점검
4. 새 문제·미학습 카드 금지 — 인출 검증만 (인지 부하·불안 관리)

**📅 시험 당일**

1. 핵심요약 4종의 **"시험 직전 1분 요약표" + 숫자 체크리스트**만 회상 (과목당 5~10분)
2. 새 문제 풀이 금지 — 이미 본 것만 복습
3. 앱: **데일리 챌린지**로 가볍게 워밍업 — 주간 배분은 무시하고 이미 본 카드·문제만
