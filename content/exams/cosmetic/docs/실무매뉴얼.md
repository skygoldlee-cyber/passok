# 맞춤형화장품 조제관리사 실무매뉴얼

> **문서 ID**: DOC-USR-21
> **범위**: exam:cosmetic · 판본: none
> **관련 SPEC ID**: DA-19

> PassOK Formula OS 실무 도구 사용 안내 — 시험 합격 후 현장에서 바로 쓰는 처방·조제·법규 도구

## 1. 시작하기

실무 모드 전환 후 사이드바의 **실무** 구역에서 각 도구를 사용합니다. 상세 기능별 레퍼런스는 `실무 매뉴얼`(Formula OS, doc:formula_manual)을 참조하세요.

## 2. 사업 유형 선택

화면 상단의 **사업 유형**을 먼저 선택합니다 — 유형에 따라 표시되는 작업이 달라집니다.

| 유형 | 주요 작업 |
|---|---|
| 맞춤형화장품 판매업 | 고객 상담 → 처방 설계 → 조제 기록 → 원료 관리 → 법규 점검 |
| 화장품제조업 | 레시피·원료·제조 기록 중심 |
| 책임판매업 | 표시사항·광고 문구 점검 중심 |

## 3. 대표 작업 흐름

1. **고객 상담** — 피부 상태·요구 기록
2. **처방 설계** — 성분 선택 → 배합 비율 설정
3. **조제 기록** — 조제일·사용 원료·LOT 기록 (의무 보관)
4. **법규 점검** — 표시사항·광고 문구·금지 성분 검토
5. **원료 관리** — 재고·유통기한 추적

## 4. 광고·표시 점검

- 광고 문구 사전으로 의약품 오인 표현·과대광고 위험 문구를 사전 점검합니다
- 금지·제한 성분은 조제 기록 작성 시 자동 경고됩니다

## 5. 무료와 Pro 경계

조제 기록 저장·내보내기 등 실무 데이터 기능은 Pro입니다. 자세한 기능 표는 `실무 매뉴얼`을 참조하세요.
