# 화장품법의 이해 핵심요지 (자체 편집)

> **성격**: 맞춤형화장품조제관리사 과목1「화장품법의 이해」대비 자체 편집 요지 — 법령이 아닌 학습 요약 문서
> **기반자료**: 식품의약품안전처 「맞춤형화장품조제관리사 교수학습가이드(개정 4판)」(2025) 학습가이드 ChapterⅠ — 저작권 고지에 따라 **사실·수치·기준만 추출하여 자체 문장으로 재구성**, 원문 미수록
> **주의**: 조문·수치·비율은 법령 개정에 따라 변경 가능 — 실제 판정은 당해연도 정본 기준 (법령 원문은 동 과목 ref_md의 화장품법·시행령·시행규칙·개인정보보호법 문서 참조)

## 1. 화장품의 정의와 유형

- 화장품 정의: 인체를 청결·미화하여 매력을 더하고 용모를 밝게 변화시키거나, 피부·모발 건강을 유지·증진하기 위하여 인체에 바르고 문지르거나 뿌리는 등의 방법으로 사용되는 물품으로서 **인체에 대한 작용이 경미한 것** (법 제2조제1호)
- **유형 13종** (「화장품 사용할 때의 주의사항 및 알레르기 유발성분 표시에 관한 규정」 별표1 제1호):
  1. 3세 이하의 영유아용 제품류 — 영유아용 샴푸·린스·로션·크림·오일·인체세정용·목욕용 (그 외 세부유형을 두지 않음)
  2. 목욕용 제품류 — 목욕 오일·정제·캡슐, 목욕 소금류, 버블 배스
  3. 인체 세정용 제품류 — 폼·바디 클렌저, 액체·화장 비누, 외음부 세정제, 물휴지 (식품접객업 손닦기용 물티슈·장례식장·의료기관 시체 닦는 용도 제외)
  4. 눈 화장용 제품류 — 아이브로·아이라이너·아이섀도·마스카라·아이메이크업리무버·속눈썹용 파마
  5. 방향용 제품류 — 향수·콜롱(부항률이 향수보다 낮음)
  6. 두발 염색용 제품류 — 헤어틴트·헤어컬러스프레이(일시적 착색)·염모제·탈염탈색제(멜라닌 산화 백색화)
  7. 색조 화장용 제품류 — 볼연지·파우더·파운데이션·베이스·픽서티브·립제품·페인팅·분장 (스티커형·침습적 문신염료 제외)
  8. 두발용 제품류 — 컨디셔너·트리트먼트·팩·린스·토닉·에센스·포마드·스프레이·무스·왁스·젤·크림·로션·오일·샴푸·파마·스트레이트너·흑채
  9. 손발톱용 제품류 — 베이스·언더코트·네일폴리시·에나멜·탑코트·네일 크림·리무버
  10. 면도용 제품류 — 애프터·프리셰이브 로션·셰이빙 크림·폼
  11. 기초화장용 제품류 — 화장수·마사지크림·에센스·오일·파우더·바디제품·팩·마스크·눈주위제품·로션·크림·손발피부연화·클렌징류
  12. 체취 방지용 제품류 — 데오도런트
  13. 체모 제거용 제품류 — 제모제·제모왁스

## 2. 기능성화장품

- 심사 대상 — 심사 제출자료: ① 기원·개발경위 ② 안전성 ③ 유효성·기능 ④ 자외선차단지수·A차단등급 근거(자외선차단 품목만) ⑤ 기준·시험방법(검체 포함)
- **보고서 제출 대상**(심사 면제): ①식약처 고시 품목과 성분·함량·효능·용법·기준·시험방법 동일 ②기심사 품목과 원료 종류·규격·함량 + 효능·효과 + 기준·시험방법 + 용법·용량 + 제형 모두 동일 (자외선차단지수 측정값 −20% 이내면 같은 효능·효과로 간주, pH 기준 제외, 1~3호·8~11호는 액제·로션·크림을 같은 제형으로 간주) ③자외선차단 + 미백·주름개선 성분 혼합 품목 중 동일 사항 충족
- **SPF 표시**: 측정 평균값(소수점 이하 절사)으로부터 **−20% 범위 정수** 표시. SPF 50 이상은 "50+" (예: 평균 23 → 19~23 정수)
- **PA 표시**: PFA 2이상~4미만 PA+(낮음) / 4~8 PA++(보통) / 8~16 PA+++(높음) / 16이상 PA++++(매우 높음)

## 3. 영업의 종류·등록·신고

- 영업 3종 (법 제2조의2): **화장품제조업**(화장품 전부·일부 제조 — 1차 포장만 해당. 위탁제조·1차 포장 포함, 2차 포장·표시만 공정은 2017.2.4.부터 등록 제외) / **화장품책임판매업**(품질·안전 관리하며 유통·판매 또는 수입대행형 거래 알선·수여 — 직접제조 유통, 위탁제조 유통, 수입 유통, 수입대행형 전자상거래 알선) / **맞춤형화장품판매업**(내용물에 다른 내용물·고시 원료 추가 혼합 판매, 소분 판매 — **고형 비누 단순 소분은 신고 대상 제외**)
- 등록·신고 요건: 제조업 — 결격사유 없음 + 작업소(쥐·해충·먼지 차단시설, 작업대·제조시설·기구, 분진제거시설)+보관소+시험실·품질검사 시설·기구. 책임판매업 — 결격사유 없음 + 품질관리·책임판매후 안전관리 기준 + 책임판매관리자 선임. 맞춤형판매업 — 결격사유 없음 + 혼합·소분 공간을 다른 용도 공간과 분리·구획(위해 우려 없으면 면제) + 조제관리사 선임
- 등록·신고처: 제조소·판매업소 소재지 관할 **지방식품의약품안전청장**
- 결격사유(제조·책임판매·맞춤형판매 공통): 정신질환자(전문의가 적합 인정 시 제외), 피성년후견인·미복권 파산선고자, 마약류 중독자, 화장품법·보건범죄단속법 위반 금고 이상 실형 종료 후 **2년** 미경과·집행유예자, 등록 취소 후 **2년** 미경과

## 4. 영업자 준수사항과 관리자

- 제조업자 준수사항 (규칙 제11조): 책임판매업자 지도·감독·요청 준수, 제조관리기준서·제품표준서·제조관리·품질관리기록서 작성·보관, 위해 없는 위생 관리, 시설·기구 정기 점검, 원료입고~완제품출고 시험·검사, 위탁 시 수탁자 관리·감독. 제조업자는 품질관리 필요 서류를 책임판매업자에게 제출(제조업자=책임판매업자 동일 또는 계약상 영업비밀 해당 시 제외)
- 책임판매업자 준수사항 (규칙 제12조): 품질관리·안전관리기준 준수, 제품표준서·품질관리기록서 보관, 수입품은 수입관리기록서 작성·보관, **제조번호별 품질검사** 후 유통(제조업자=책임판매업자 동일, 시험기관 위탁 품질검사 실시, 수입품 제조국 기준 상호인증·실사 인정 시 제외), 안전성 정보 수집·보고
- 맞춤형판매업자 준수사항 (규칙 제12조의2): 혼합·소분 전 **품질성적서 확인**, 손 소독·세정(일회용 장갑 착용 시 예외), 포장용기 오염 확인, 장비·기구 위생점검·세척, **판매내역서 작성·보관(제조번호·사용기한·판매일자·판매량)**, 사용시 주의사항 설명, 부작용 사례 식약처 보고
- 책임판매관리자 업무(규칙 별표1·별표2): 품질관리·안전확보 업무 총괄 + 적정 수행 확인 + 필요 시 책임판매업자에 문서 보고 + 관계자에 문서 연락·지시 + **품질관리·제조업자 관리 기록 작성 후 제조일(수입일)부터 3년 보관**
- 위탁제조 확인: 책임판매업자는 제조·품질관리 범위·방법·자료제공 계약 + 적정 제조 확인·기록 + 개선 필요 시 문서 지시 + 결과 보고 요구·평가·방문 확인
- 안전성 정보 보고: 유해사례(인과관계 불필요), 중대한 유해사례(사망·생명위협·입원·불구·선천기형 등), 실마리정보(signal). **신속보고 = 중대한 유해사례·외국 정부 조치 → 인지일로부터 15일 이내 / 정기보고 = 나머지 → 반기 종료 후 1월 이내** (2인 이하 화장비누 직접제조 책임판매업자 정기보고 면제)
- 안정성시험 자료 보존: **레티놀·아스코빅애씨드·토코페롤·과산화화합물·효소 0.5% 이상 함유 제품 → 사용기한 만료일부터 1년**

## 5. 화장품의 품질 요소

- **안전성(safety)**: 피부·신체 안전 보장 성질 — 건강한 피부의 불특정 다수가 장기 반복 사용하므로 핵심. 관리 수단: 안전용기·포장, 원료 사용기준, 유통 안전관리 기준
- **안정성(stability)**: 물리·화학 조건에서 성분 상태 유지 — 물리적 변화(분리·침전·응집·겔화·휘발·고화·연화·균열), 화학적 변화(변색·분리·변취·오염·결정석출). 확인: 장기보존시험·가속시험·가혹시험. 사용기한 = 제조일부터 적절 보관 상태에서 고유 특성 유지하며 안정적으로 사용 가능한 최소한의 기한
- **유효성(efficacy)**: 사용으로 피부에 직·간접 유도되는 물리·화학·생물학·심리적 효과 (미백·주름개선·자외선차단·탄력·세정·유연)
- 어린이 안전용기·포장: **만 5세 미만** 개봉 어려운 용기·포장 (「어린이보호포장대상공산품의 안전기준」). 대상 — 아세톤 함유 네일 리무버·폴리시 리무버, 개별포장 탄화수소류 **10% 이상**+운동점도 **21센티스톡스(40℃) 이하** 비유화 액제(어린이용 오일 등), 메틸살리실레이트 **5% 이상** 액제. 예외 — 일회용, 펌프·방아쇠 분무, 에어로졸
- 영유아·어린이 사용 화장품: **영유아 3세 이하, 어린이 4~13세**. 표시·광고로 영유아·어린이용 특정 시 안전성 자료 작성(제품·제조방법 설명 + 안전성평가 + 효능 증명 자료). 보관기간 — 사용기한 표시품: 최종 제조·수입품 사용기한 만료 후 1년 / 개봉 후 사용기간 표시품: 제조연월일 후 3년
- 원료 관리 = 네거티브 시스템: 사용 불가 원료(안전기준 별표1) + 사용기준 지정 원료(별표2 — 보존제·색소·자외선차단제 등)만 규제, 나머지는 업자 책임 하 사용. 위해성평가 절차: **위험성 확인 → 위험성 결정(허용량 산출) → 노출평가(노출량 산출) → 위해도 결정** (기존 위해평가·과학자료 있으면 그 근거로 판단 가능). 지정 원료 사용기준 **5년** 주기 안전성 검토. 사용기준 지정·변경 신청 자격: 제조업자·책임판매업자·대학·연구소

## 6. 화장품의 사후관리 기준

- 회수 대상 위해화장품 등급 — **가등급**: 사용금지원료 사용, 사용한도 위반, 미지정 보존제·색소·자외선차단제 사용. **나등급**: 안전용기·포장 위반, 유통안전관리기준 위반(내용량·기능성 주성분 함량부적합 제외). **다등급**: 변패·병원미생물 오염, 이물 혼입·부착 위해 우려, 기능성 주성분 함량 기준부적합, 사용기한·개봉후 사용기간 위조·변조, 영업자 자체 위해 판단, 무등록 제조·유통(법 제16조제1항 위반)
- 회수 절차: 즉시 판매중지 등 조치 → **회수 인지일부터 5일 이내 회수계획서 지방식약청 제출** → 판매자·업무상 취급자에 회수계획 통보(방문·우편·전화·전보·이메일·팩스·언론공고 — 통보 사실 입증자료 **회수종료일부터 2년 보관**) → 폐기 시 폐기신청서 제출(관계공무원 참관) → 회수종료신고서 제출
- 폐업·휴업·재개 신고 (법 제6조): 지방식약청 신고 — **휴업 1개월 미만이거나 기간 내 휴업·재개 시 신고 불필요**
- 표시·광고: 기재사항 = 명칭·영업자 상호주소·전성분·용량/중량·제조번호·사용기한(개봉후 사용기간 시 제조연월일 병기)·가격(직판자)·기능성 글자/도안·사용시 주의사항·총리령 사항(바코드, 기능성 효능·용법, 성분명 사용 시 성분+함량, 인체세포조직배양액 함량, 천연·유기농 표시 시 원료함량, 수입품 제조국+제조사+소재지). 기능성 4품목(탈모완화·여드름완화·피부장벽가려움·튼살)에는 **"질병의 예방 및 치료를 위한 의약품이 아님"** 문구
- 부당 표시·광고 금지: 의약품 오인 표시·광고, 비기능성을 기능성으로 오인·심사와 다른 내용, 사실과 다른 기만·오인 표시·광고 (규칙 별표5). 표시·광고 실증: 시험결과(인체적용·인체외) 또는 조사결과 등 합리적 근거
- 영업 금지 대상(법 제15조): 무심사·무고고 보고 기능성화장품, 변패·병원미생물 오염·이물혼입, 사용불가원료 사용·안전관리기준 부적합, **코뿔소 뿔·호랑이 뼈 추출물 사용**, 비위생·미적합 시설 제조, 용기·포장 불량 위해 우려, 사용기한 위조·변조, **식품 형태·냄새·색깔·크기·용기·포장 모방으로 오용 우려**
- 유통·판매 금지: 동물실험 실시 화장품·그 원료 사용 제조·수입품 — 예외 6종(사용제한 원료 기준지정 필요, 위해평가 필요, 대체시험법 부재, 수출국 법령 요구, 다른 법령상 동물실험 원료, 대체 곤란 고시)
- 판매 금지: 무등록 제조·수입·유통, **샘플화장품 소비자 판매 금지**, 포장·기재사항 훼손·위조·변조(맞춤형판매 필요 시 제외), **내용물 소분 판매 금지**(맞춤형판매업자·고형비누 단순소분 판매자 제외)

## 7. 감독·행정처분·벌칙

- 감독 수단: 보고 명령, 출입·검사·질문·수거, 판매 모니터링 기관 지정, **소비자화장품안전감시원**(협회·소비자단체 추천 또는 안전관리 지식자 — 책임판매관리자 포함, **임기 2년 연임 가능**, 신고·출입검사 지원·회수폐기 확인·홍보 — 반기 교육), 시정명령, 검사명령, 회수·폐기명령, 위해화장품 공표(표제·제품명·제조번호·사용기한·회수사유·방법·영업자 명칭·전화·주소)
- 행정처분: 등록 취소·영업소 폐쇄·제조수입판매금지·업무정지 — 등록취소·폐쇄 해당: 거짓·부정 등록·신고, 결격사유 해당, 업무정지 중 영업(광고정지 제외). 기능성화장품 인정 취소: 거짓·부정 심사·보고. 처분 기준 = 시행규칙 별표7 (일반기준·개별기준)
- **수출용 예외**: 국내 미판매 수출 전용 제품은 법 제4조·8조·9조·10조·11조·12조·14조·15조제1호·제5호·16조제1항제2·3호·제2항 적용 제외, 수입국 규정 준수
- 벌칙·과태료: **3년 이하 징역 또는 3천만원 이하 벌금**(법 제36조, 병과 가능) / **1년 이하 징역 또는 1천만원 이하 벌금**(제37조, 병과 가능) / 200만원 이하 벌금(제38조). 과태료 100만원 이하: 기능성화장품 변경심사 미실시, 생산·수입실적·원료목록 미보고, **책임판매관리자·조제관리사 교육 미이수**, 폐업신고 미실시. 양벌규정: 법인·개인의 업무상 위반 시 행위자 + 법인·개인 병과(방지 주의·감독 시 면제)

## 8. 개인정보 보호법

- 개인정보 정의(법 제2조): ①성명·주민번호·영상 등으로 개인 식별 ②단독으로는 불가 + 다른 정보와 쉽게 결합 식별(입수 가능성·시간·비용·기술 고려) ③가명처리 정보(가명정보). 처리 = 수집·생성·연계·기록·저장·가공·검색·정정·복구·이용·제공·공개·파기 등
- 원칙: 목적 명확 + 최소 수집, 처리 사항 공개·권리 보장, 익명 가능 시 익명→불가 시 가명 처리. 정보주체 권리(제4조): 알림·동의 선택·열람·전송 요구·정지·정정삭제·파기 요구·피해구제·자동화 결정 거부권
- 동의 없이 수집·이용 가능(제15조): 법령 규정·의무, 계약 이행 필요, 급박한 생명·신체·재산 이익, 개인정보처리자 정당한 이익(권리 우선 시), 공중위생 긴급, 목적과 합리적 관련 이용(시행령 14조의2 — 관련성·예측가능성·부당침해 여부·암호화 등)
- **동의 시 고지 사항 4개**: 수집·이용 목적 / 수집 항목 / 보유·이용 기간 / 동의 거부권·불이익. 동의는 항목별 구분하여 각각 명확히 — 구분 필수 대상: 수집이용 동의, 제3자제공 동의, 목적외 이용·제공 동의, 제공받은 자의 목적외 동의, 민감정보 동의, 고유식별정보 동의, 홍보·판매권유 목적 동의
- 정보주체 이외 출처 수집 시 고지 의무(법 제17조): 규모 기준 — **민감·고유식별 5만명 이상 또는 개인정보 100만명 이상** 처리자 → 수집 출처·목적·근거·파기까지 보관 등 모든 사항을 **제공받은 날부터 3개월 이내** 통지(연 2회 이상 정기 제공이면 3개월 이내 또는 동의 기산 연 1회 이상, 서면·이메일·전화·문자·알림창)
- 제3자 제공·위탁: 위탁 문서 필수사항 — 목적외 처리금지, 기술·관리 보호조치, 위탁 목적·범위, 재위탁 제한, 접근제한, 관리현황 점검, 의무위반 손배책임. 위탁자는 업무내용·수탁자를 홈페이지 지속 게재(불가 시 사업장 게시·신문·간행물 연2회 이상·계약서). 수탁자는 위탁범위 초과 이용·제공 금지, 재위탁은 위탁자 동의 필요, 위탁업무 위반 손배 시 수탁자=처리자 소속직원 간주
- 영업양도(제27조): 이전 사실·양수자 성명·주소·연락처·거부 방법을 사전 서면 통지 → 양수자는 지체 없이 수신 사실 통지 후 이전 목적 범위 내 이용·제공 가능(처리자 간주)
- 국외이전(제28조의8): 원칙 금지 — 예외 ①별도 동의(이용목적·보유기간·거부방법·효과 사전고지) ②법률·조약·국제협정 특별규정 ③계약 체결·이행 필요 + 처리방침 공개 또는 전자우편 등 통지 ④보호위 인증·서면 지킴이 약속 등
- 파기(제21조): 보유기간 경과·목적달성·가명처리 기간경과로 불필요해지면 **지체 없이 파기**(복구·재생 불가 조치, 전자파일은 영구 삭제, 기술적으로 곤란 시 법 제58조의2 수준 처리). 다른 법령상 보존 필요 시 **다른 개인정보와 분리 저장·관리**
