# 유통화장품 안전관리 핵심요지 (자체 편집)

> **성격**: 맞춤형화장품조제관리사 과목3「유통 화장품 안전관리」대비 자체 편집 요지 — 법령이 아닌 학습 요약 문서
> **기반자료**: 식품의약품안전처 「맞춤형화장품조제관리사 교수학습가이드(개정 4판)」(2025) 학습가이드 ChapterⅢ + 「우수화장품 제조 및 품질관리기준(CGMP) 해설서」(2024) — 저작권 고지에 따라 **사실·수치·기준만 추출하여 자체 문장으로 재구성**, 원문 미수록
> **주의**: 기준 수치는 고시 개정에 따라 변경 가능 — 실제 판정은 당해연도 정본 기준 (CGMP·시행규칙 별표 원문은 동 과목 ref_md 문서 참조)

## 1. 작업장 위생관리

- **구역 구분 3단계**: 분리(별개 건물·장소) / 구획(벽·칸막이·에어커튼 — 교차오염·혼입 방지) / 구분(선·간격으로 혼동 방지)
- 작업소 요건: 제품 보호 + 청소 용이 + 혼동 위험 최소화. 바닥·벽·천장은 매끄러운 표면 + 소독제 부식 저항, 모서리는 틈 없이 둥글게 처리. 외부 연결 창문은 개폐 불가 또는 오염 차단. 수세실·화장실은 접근 쉬우나 생산구역과 분리. 조명 파손 대비 제품 보호 절차. 배수관 역류 금지·청결
- 공기 조절: 온도·습도·공중미립자·풍량·풍향·기류 자동 제어 — 기류가 미립자·미생물을 부유시켜 제품 부착 위험. 방식: **센트럴 방식**(도관으로 4요소 일괄 제어 — 화장품에 가장 적합) / 환기+센트럴 겸용(비용 유리) / 팬코일·패키지 에어컨(기류 제어는 약하나 적합). CGMP 청정도 등급 설정 구역은 정기 모니터링
- 위생 처리: 필터 규정 주기 청소·교체, 유출수·고인물·파손 용기 지체 없이 제거, 제조·포장 구역에서 기류 오염 유발 청소는 작업 중 금지, 청소 용구는 지정 장소 건조 보관, 위생처리 기록 보관·사용 전 검사(청소완료 표시서)
- 방충·방서: 벌레 유인물 제거 + 빛 외부 누출 차단. 외부업체 운영 시 업체 평가·모니터링 보고서 수령·이상 대책
- 환경 미생물 평가: 공기 중 — 낙하균 측정·충돌법(slit-to-agar·impinger·andersen 샘플러)·여과형 샘플러 / 표면부착 — **면봉 시험법(swab)·콘택트 플레이트·린스 정량법**(설비 내면). 면봉·콘택트는 전수 채취 불가, 린스는 내부 표면용

## 2. 세제와 소독제

- 오염물질: 오일·지방·왁스·안료·탄닌·규산·탄산염(석회)·금속 산화물·검댕·부식물 + 미생물 — 물리·화학 메커니즘으로 제거. 고착·숙성 오염은 연마제 함유 세제
- 세제 요구조건: 세정력·표면 보호·무잔류 건조·사용·계량 편리·적절 기포·인체·환경 안전·저장 안정성. 구성 성분: 계면활성제(음이온·비이온)+살균제(4급 암모늄·양성계면활성제·알코올·알데히드·페놀 유도체)+금속이온봉쇄제+유기폴리머+용제+연마제+표백
- **세척제 pH 분류**: 무기산·약산성 **0.2~5.5**(무기염·금속complex — 염산·황산·인산·초산·구연산; 금속산화물 효과적, 독성 주의) / 중성 **5.5~8.5**(기름때·소입자 — 약한 계면활성제, 낮은 독성·부식성) / 약알칼리 **8.5~12.5**(기름·지방·입자 — 수산화암모늄·탄산·인산나트륨; 비누화·가수분해 촉진) / 부식성 알칼리 **12.5~14**(찌든 기름 — 수산화나트륨·칼륨·규산나트륨; 독성·부식)
- **이상적 소독제 조건**: 사용기간 활성 유지 / 무취 / 광범위 항균 스펙트럼 / **미생물 99.9% 이상 사멸**
- **물리적 소독**: 스팀 **100℃ 30분**(바이오필름 파괴, 잔류물·습기 발생) / 직열(전기 가열 테이프 — 파이프용, 일반적이지 않음)
- **화학적 소독제 표**:
  | 소독제 | 농도·시간 | 특징 |
  |---|---|---|
  | 염소 유도체(차아염소산 나트륨·칼슘·리튬, 염소가스) | **200ppm·30분** | 우수·찬물 단독 사용 / 냄새, pH↑ 효과↓, 금속 부식, 광열 민감 |
  | 양이온 계면활성제(4급 암모늄) | **200ppm(제조사 권장)** | 세정 겸용·부식無·무향·안정 / **포자 무효**, 경수·음이온 세정제로 불활성화, 중성~약알칼리 최적 |
  | 아이오도포(비이온+아이오딘) | **12.5~25ppm·10분** | 잔류 효과·무毒 / 포자 무효·얼룩·사용 후 세척 |
  | 알코올(이소프로필·에탄올) | **IPA 60~70%·에탄올 60~95%·15분** | 세척 불요·속건·단독 / **포자 무효·화재폭발 위험** |
  | 페놀·염소화페놀 | **1:200 용액** | 세정·탈취 / 불안정(**2~3시간 이내 사용**)·세척 필요 |
  | 인산 용액 | 제조사 지시 | 스테인리스 적합·저온·단시간 / 알칼리에서 효과↓ |
  | 과산화수소 | 35%액의 1.5%·30분 | 유기물 유효 / 고농도 폭발성 |
- 주의: 소독제는 내성균 방지로 주기적 교체, 알코올 인화성, MSDS 구비, 보호구 착용

## 3. 작업자 위생관리

- 기준: 위생관리 기준·절차 수립, 신규 위생교육+기존 정기교육, **질병·노출 피부상처 직원은 회복·의사소견 전까지 제품 접촉 격리**, 작업복·모자·신발 착용 + 필요 시 마스크·장갑
- 비출입 대상: 방문객·미교육 직원·무권한 직원 — 불가피 시 안내자 동행 필수, 소속·성명·목적·입퇴장 시간·동행자 기록
- 혼합·소분 위생 규정: 위생복·마스크 착용, 피부 외상 직원 혼합·소분 금지, **혼합 전후 손 소독·세정**(일회용 장갑 착용 시 세정 생략 가능 — 별표 기준)
- 손 위생: 손바닥 피지선 없음·외인성 오염 대상 — 고형비누·핸드워시·핸드새니타이저. 세정 시기: 화장실 후·식사 전·외출 후·오염 시
- 리필 용기 관리: 펌프·노즐형 용기는 세척 곤란 → 재사용 제한. 매장 전용용기는 책임판매업자로부터 **용기-내용물 적합성 검토 결과** 확인. 소비자 제공용기는 동일 내용물 리필 권장 + 재질 정보 사전 확인 + 품질 영향 안내(판매내역서 비고 기록 가능). 리필 전 잔여물·건조·파손 확인. 유성화장품 용기는 물 헹굼 효과↓ → 70% 에탄올 소독·UV 살균(플라스틱 UV 부적합 주의)
- 복장 청결 판단: 규정 작업복 착용 + 청정도 적합 모자·신발·마스크·장갑 + 작업복 상태 점검

## 4. 설비 및 기구 관리

- 설비 요건: 사용목적 적합·청소 가능·위생관리 가능 / 제품·세척소독제와 화학반응 없음 / 배수 용이 설계 / 미사용 호스·부속품은 건조·오염보호 / **접촉면은 내용물과 반응성·친화성 저해 재질 배제**(W/O형 내용물에 친수성 재질 등)
- 설비 세척 원칙: ①무위해 용제(물 최적) ②가능하면 세제 미사용 ③증기 세척 우수 ④분해 가능 설비는 분해 세척 ⑤세척 후 반드시 **판정** ⑥판정 후 건조·밀폐 보존 + 세척 유효기간 설정
- 세척 대상 구분: 물질(화학물·미립자·미생물, 동일·이종제품, 분해성·안정성, 불용·가용, 검출 난이) × 설비(설비·배관·용기·호스·부속품, 경질·연질 표면, 크기·세척 난이)
- **세척 확인 3법**: ①육안 확인(판정 자격자 선임) ②천으로 닦아 잔류물 확인(흰천·검은천) ③린스액 화학분석 + 표면균 시험(면봉·콘택트·린스)
- 위생 처리 대상 설비: 탱크·펌프·혼합교반·호스·이송파이프·칭량장치·게이지미터·충전기 — 작업 후 세척, 절차에 따라 위생 처리·기록
- 유지관리: 정기 점검·기록, 결함·정비 설비 표시, 세척 설비 오염 방지, 승인자만 접근, 계측장비 정기 교정·성능점검·기록. 예방적 유지보수 — 절차서·연간계획·점검체크시트(외관 더러움·녹·이상소음, 작동, 기능측정 회전수·전압·투과율·감도, 청소, 부품교환)
- **전자저울 점검**: 수평 매일 가동 전 육안 / 점검 월 1회 표준분동 — **직선성 ±0.5%·정밀성 ±0.5%·편심오차 ±0.1% 이내**
- 이력·폐기: 설비 가동일지(번호·명칭·설치장소·연월·생산시간·조업·정지·가동률), 설비 이력카드(기본정보+유지보수 이력+부품교체 이력), 내구연한 종료 시 폐기

## 5. 원료 및 내용물의 관리

- **입고 기준**: 구매요구서+공급업체 성적서+현품 일치 확인 / 모든 원료는 책임판매업자 기준 검증자료 공급 / 제조번호 없으면 관리번호 부여 / 표기 오류·용기손상·봉인파손·오염 육안검사 / 승인 전 불출 절차서 — **적합·부적합·검사중 상태 표시**, 각각 구획 보관(부적합은 잠금장치 가능), 결함 시 입고보류→격리→폐기·반송
- 입고 검사 순서: 입고차량검사(청결·시건·타코메타 냉장냉동)→원료 육안검사→수불일지 작성
- **유통화장품 안전관리 기준**(안전기준 제6조) — 비의도적 오염물 검출 허용한도:
  | 항목 | 한도 |
  |---|---|
  | 납 | 점토 원료 분말 50 ㎍/g, 그 외 **20 ㎍/g** |
  | 니켈 | 눈화장 35, 색조 30, 그 외 **10 ㎍/g** |
  | 비소 | **10 ㎍/g** |
  | 수은 | **1 ㎍/g** |
  | 안티몬 | **10 ㎍/g** |
  | 카드뮴 | **5 ㎍/g** |
  | 디옥산 | **100 ㎍/g** |
  | 메탄올 | **0.2%(v/v)**, 물휴지 0.002%(v/v) |
  | 포름알데하이드 | **2000 ㎍/g**, 물휴지 **20 ㎍/g** |
  | 프탈레이트류(DBP·BBP·DEHP 총합) | **100 ㎍/g** |
  - 별표1 사용불가 원료 비의도 검출 → 규칙 제17조 위해평가 후 위해 여부 결정
- 미생물 한도: 영유아·눈화장 총호기성생균 500개/g(mL) 이하, 물휴지 세균·진균 각 100개/g(mL), 기타 1,000개/g(mL), 대장균·녹농균·황색포도상구균 불검출
- **내용량 기준**: 제품 3개 평균 ≥ 표기량 **97%** — 미달 시 6개 추가 → 9개 평균 97% 이상(화장비누는 건조중량, 특수품은 대한민국약전). **유리알칼리 0.1% 이하(화장비누)**. 액상 pH 기준(영유아용 제품류 등 — 물 미함유·즉시 세정 제외)
- 기능성 주원료 함량: 심사·보고 기준 적합
- **보관 기준**: 품질 영향 없는 조건 + 보관기한 설정 / **바닥·벽 비접촉 + 선입선출(FIFO) 가능 보관** / 원자재·시험중·부적합품 구획(혼동 없는 시스템 예외) / 기한 경과 시 재평가 후 사용제한. 환경: 출입제한·오염방지·방충방서·온습도
- **출고 기준**: FIFO + 절차·책임자·문서화 + 기준 충족 시만 불출 — 단 사용기한 짧은 후입고품·특별사유는 선출고 가능(관리시스템 필요)
- **폐기**: 품질책임자가 폐기·재작업 승인, 폐기 대상 별도 보관·신속 처리. 기준일탈 → 지정 절차 처리·기록 → 폐기처분/재작업/반품. **재작업(reprocessing)**: 부적합품을 적합 범위로 재처리(충전량 부족→재충전, 로트착인 불량→재착인) — 품질보증책임자가 원인조사 지시
- 폐기 절차: 부적합 라벨 → 격리 → 분리수거 카드 → 폐기물 보관소 운반·분리수거 확인 → 폐기물 대장 → 인계

## 6. 사용기한·변질 판정

- 사용기한 = 제조일부터 적절 보관 상태에서 고유 특성 유지하며 안정 사용 가능한 최소 기한. 원료는 공급처 기한 준수 + 자체 재시험 기간·최대보관기한 설정(미지정 원료 — 색소 등 — 는 자체 설정). 개봉 후 사용기간(PAO) 동일 원칙
- **안정성시험 3종**: 장기보존시험(저장조건 장시간 — 물리화학·미생물·용기 적합성) / 가속시험(단기 가속조건 영향) / 가혹시험(분해과정·산물 — 운반·진열 중 가혹 조건) + 광안정성 시험. 개봉 후 안정성시험 = PAO 설정용
- 변질 판단: 검체는 오염·변질 방지 채취 + 원상 포장 + 채취 표시 — 용기에 명칭/코드·제조번호·채취일 기재. 반복 재보관·재사용 지양. 관능검사 우선 + 필요 시 이화학 검사

## 7. 포장재의 관리

- 정의: 포장에 사용되는 모든 재료(운송 외부포장 제외, 라벨·봉함 포함). 1차 = 내용물 직접접촉 용기 / 2차 = 1차 수용 포장+보호재+표시
- 재질 특성: **유리**(투명·착색·내성·기체비투과) / **플라스틱**(열가소성 PET·PP·PS·PE·ABS, 열경화성 페놀·멜라민·에폭시 — 가공·착색·경량·내수성 / 열약·흠집·가스·수증기 투과·용제 약) / **금속**(철·스테인리스·놋쇠·알루미늄·주석 — 튜브·뚜껑·에어로졸·립케이스 — 강도·불투과)
- 입고: 규격서 성적서 확인(용기 종류·재질)+관능검사(재질·용량·치수·외관·인쇄·이물·위생)+유통기한. 관리 흐름: 중요도→공급자→발주→입고→식별표시→합격판정→보관→불출→보관환경→사용기한→재고관리→재평가→재보관
- 보관·출고·폐기 = 원료 기준 동일(FIFO, 구획, 재평가, 품질책임자 승인, 부적합라벨→격리→분리수거→대장)
- 포장재 변질 판단: 재질별 특성 기준(외관·인쇄·물성) 관능 + 필요 시 물성 검사
