> **성격**: 맞춤형화장품조제관리사 과목4「맞춤형화장품의 이해」대비 자체 편집 요지 — 법령이 아닌 학습 요약 문서

## 1. 맞춤형화장품의 정의와 범위

- 정의: 맞춤형화장품판매업소에서 **조제관리사 자격증 소지자**가 고객 개인별 피부 특성·색·향 취향에 따라 ①제조·수입된 화장품의 내용물에 **다른 화장품의 내용물 또는 식약처 고시 원료(색소·향료 등 단일·혼합 원료)를 추가 혼합**한 화장품 ②제조·수입된 내용물을 **소분**한 화장품 (**고형 비누 단순 소분은 맞춤형화장품에서 제외**)
- 혼합·소분 범위: 내용물+내용물 혼합 / 원료+내용물 혼합 / 내용물 소분 — **원료+원료의 혼합은 맞춤형이 아니라 '화장품 제조'에 해당**
- 혼합·소분용 내용물 제한: 책임판매업자로부터 혼합·소분 목적으로 공급받은 것이어야 함 — 소비자 판매 목적 완제품·홍보용 비매품(시험·사용 목적 제조·수입품)은 사용 불가
- **혼합 사용 불가 원료** (안전기준 제5조): ①별표1 사용불가 원료 ②별표2 사용제한 원료(단, 원료 품질유지 목적 보존제 포함 원료는 예외, 맞춤형 추가용 색소·향·기능성 원료 및 그 조합은 허용) ③기능성화장품 효능·효과 원료 — 단 **책임판매업자가 해당 원료 포함 기능성화장품으로 심사·보고한 경우 사용 가능**(혼합·소분 결과물이 기심사·보고 기능성화장품이어야 함)
- 판매업자 준수사항(규칙 제12조의2): 시설·기구 정기점검 / 혼합·소분 안전관리기준(품질성적서 확인, 손 소독·세정 — 일회용 장갑 착용 시 예외, 포장용기 오염 확인, 장비·기구 위생점검·세척, 기한 확인) / 사용기한 초과 설정 금지(과학적 근거 시 예외) / 잔여 내용물 밀폐·비의도 오염 방지 / 미리 혼합·소분 보관·판매 금지 / 판매내역서 작성·보관 / 부작용 사례 식약처 보고

## 2. 맞춤형화장품의 안전성·유효성·안정성

- 안전성: 성분은 사용불가 지정 원료가 아니어야 하고 지정 사용목적·한도 적합. 위해 우려 성분은 위해평가로 확보. 비의도 오염물질은 사례별(case-by-case) 검토. 고려 항목: 피부자극·감작, 광자극·광감작, 안점막자극(두피·안면 제품), 전신독성 + 대상(영유아·민감피부)·피부투과 증가 성분·성분간 반응
- 위해성 표현: 화학적 위해요소는 위해지수·안전역으로 표현 + 국내외 평가 종합 / 미생물적은 생육 예측·용량-반응 모델로 판단 / 신속 필요 시 단순화 평가 가능
- 유효성: 화장품의 피부 효과 — 기능성화장품은 심사·보고 효능 기준
- 안정성: 일반시험·물리화학시험·미생물시험·용기적합성시험으로 평가 — 혼합 시 안정성 저해 요인: 부적절 저장·기한 초과, 도구·용기 위생·적합성, **원료 투입 순서 변경**(용해불량·침전·부유물 — 휘발성 원료는 유화 직전, 열불안정 원료는 냉각 공정 투입: 알코올·향료·첨가제), 믹서 회전 속도 부족, 미세 기포 미제거(비중·점도·안정성 영향)

## 3. 피부의 생리 구조

- **표피(epidermis)**: 바깥층, 지속 재생 — 두께 0.04mm(눈꺼풀)~1.6mm(손바닥). 세포: 각질형성세포 + **멜라닌형성세포(melanocytes)** + **랑게르한스세포(면역)** + 머켈세포(감각)
- **진피(dermis)**: 표피 아래, 콜라겐·엘라스틴 ECM + 진피섬유아세포(합성) + 혈관·땀샘·피지샘·신경 — **두께는 표피의 15~40배**(등 최대 5mm). 노화: 교원·탄력섬유 감소·변성, 히알루론산 감소, 혈관 손상, 상처치유·면역 저하
- **피하지방층(hypodermis)**: 최심층, 망상조직+지방세포 — 열손실 방어·충격흡수·에너지 저장·염증 조절
- 기능: 장벽(수분 손실 방지·미생물·유해물질 차단 — 상처 시 미생물 혈류 침투), 방수·유연(피지), 수분균형, 색소(멜라닌 — 피부색·UV 방어), 감각(진피 수용체: 압력·진동·열·냉·통증), 체온조절(혈관 수축·확장 + 에크린선 발한 — 자율신경)
- 피부타입(MED — 최소홍반량 기준 분류) + 피지 분비량에 따른 분류
- 화장품 연계: 부작용은 피부 세포생물학적 특성과 연관 — 표피 장벽 투과, 멜라닌형성세포(색소침착), 랑게르한스세포(알레르기성 접촉피부염)

## 4. 모발·두피의 생리 구조

- **모발 구조**: 모근(피부 내부 — 모낭·모유두) + 모간(피부 외부). 모근부: 모구부(세포분열→모발 생성), 모유두(혈액·영양 공급), 내·외모근초(성장주기·형태), 모모세포(germinal matrix — 성장 시작점·멜라닌 생성·주기 조절). 모간부: **모표피(cuticle — epicuticle·exocuticle·endocuticle) / 모피질(cortex) / 모수질(medulla)**
- 모낭 수: 태아 9~12주 형성 — 출생~사망까지 거의 불변, 전신 400~500만 개, 두발 평균 약 10만 개
- **성장주기**: 성장기(anagen) **3~6년·전체 모발 약 88%** — 모근 2~3년 성장, 속도 0.2~0.5mm/일·1~1.5cm/월 → 퇴행기 → 휴지기 → 탈락
- 두피: 모낭·피지선 밀집·혈관 풍부 — 외피+두개피+두개피하조직 3층. 기능: 보호(멜라닌·산성막·각질층), 호흡(피부 경유 1~3%), 분비배설(한선 땀·피지선 피지), 체온유지(입모근 모공 개폐)
- **탈모 종류**: 남성형(M자·회전형 — 이마·정수리, **DHT 원인**, 부신·난소 호르몬도 영향, 여성은 정수리 중심 반원형) / 원형(급격 탈락 원형·타원형 — 스트레스·자가면역, 모낭 염증) / 스트레스성·감염성·성장관련·질환·화학노출·상처·지루성·산후 휴지기·노인성. 원인: 유전(AR 유전자 상염색체 유전), 호르몬(DHT·에스트로겐·갑상선·코티솔), 스트레스(휴지기 탈모), 식습관(단백질·비타민D·A·E·C·아연·철 결핍), 모발 공해(파마·드라이·염색 — 열·알칼리 손상), 노화·질환
- **비듬**: 표피 탈락물 쌀겨 모양 — 두피 피지 과다·호르몬 불균형·세포 과다증식·**말라쎄지아(malassezia furfur) 진균 분비물 자극** — 가려움 동반, 심하면 지루성 피부염
- 제품 원리: 염모제 = 암모니아로 모표피 손상 → 과산화수소가 멜라닌 파괴(탈색) + 염료 착색. 기능성 연계 — 탈모완화 별표9, 모발색상변화 별표6, 체모제거 별표7

## 5. 피부·모발 상태 분석

- 피부 보습도: **corneometer 수분함유도, TEWL(경피수분손실량), 전기적 저항·정전·전도(impedance·capacitance·conductance), 광학(NMR·라만·적외선), 웨어러블**
- 주름: 시각·영상, Replica 분석, 3차원 표면 형태, 초음파
- 탄력: 음압 가압 후 회복도 측정기. 색소: 멜라닌 측정·UV/우즈램프(표면 변화) vs 깊은 분석
- 모발: 굵기·손상·탈염탈색 분석 — **모발검사(trichoscopy) 특수현미경, trichology 형태학**, 뿌리·색소·세균·성장주기·유전자 분석. 탈모·두피 상태(홍반·지루성) 분석

## 6. 관능평가

- 정의: 인간 오감으로 화장품 품질 평가 — 외관·색상, 향취, 사용감 검사. 유효성 평가 방법 중 하나 — 통계 기반 복수 평가자로 신뢰성 확보
- 2종류: **기호형**(좋고 싫음 주관 판단) / **분석형**(표준품·한도품 비교로 합격·불량 선별, 식별력 조사)
- 평가 대상: 향취·색상·광택·젤라틴성·매끈함·두께·청량감·미끄러짐·수분감·끈적임·유연감·피막형성·펴짐·유동성
- 절차: 유화품은 표준견본 대비 표면 매끄러움·점성·유백색 육안 / 색조품은 슬라이드글라스 또는 사용부위 도포 색상 대조 / 향취는 비커·손등 / 사용감 = 발림·무게감·밀착·청량감
- **사용시험**: 맹검(blind use — 상품명·디자인·표시 정보 미제공) / 비맹검(concept use — 정보 제공 후 인식·효능 일치 조사) / 전문가 패널(시험계획서·관능기준 교육 — spider profile·PCA 주요인분석 보고)
- 표준견본: 제품(개별포장)·제품색조·제품내용물(외관·성상·냄새·사용감)·레벨부착위치·충전위치(액면)·원료색조·원료·향료

## 7. 제품 상담 — 효과·부작용·원료 제한

- 맞춤형화장품 효과: 개인 피부 특성·취향 맞춤 — 전문 상담 기반 제조
- **부작용 종류**: 피부 — 발진·자극·감작(알레르기성 접촉피부염), 광자극·광감작 / 눈 — 육안 소견 없는 따가움·시림 vs 자극(결막·각막) / 알레르기 유발 성분은 사용시 주의사항 규정 별표2
- 발생 시 대처: **즉시 사용 중단** → 조제관리사·전문의 상담 → 판매업자는 유해사례를 **지체 없이 식약처 보고**(신속보고 15일: 중대 유해사례·외국 조치 / 정기보고 반기 1월)
- 원료·내용물 제한: §1 사용 불가 원료 참조 — 기능성 원료는 기심사·보고 품목만

## 8. 제품 안내 — 사용법·주의사항

- 사용법 안내: 조제관리사와 상담해 제조 → 내용물·원료 설명 청취 → **이상 증상 시 즉시 중단** → 사용기한·개봉 후 사용기간 준수
- 주의사항: 공통(이상 시 전문의 상담, 상처부위 자제, 어린이 손 미달·직사광선 회피 보관) + 유형별(별표1 문구) + 기능성(염모제·탈염탈색제·치오글라이콜릭애씨드 제모제) + 알레르기 유발성분(별표2)
- 리필(소분) 관리: 동일 제조번호 내용물 사용 권장(혼용 시 이력 추적 제조번호 표시), 개봉 내용물은 소분장치 전량 충전 판매, 벌크용기 개봉일자 표시, **기한 경과 내용물은 소분 판매 금지 → 책임판매업자 반납 폐기 또는 자체 폐기업체**, 소비자 직접 리필 시 이용법 안내 부착

## 9. 혼합·소분

- 제형(기능성화장품 기준·시험방법): 로션제(유화 점액상), 액제(용제 용해 액상), 크림제(유화 반고형), 침적마스크제(지지체 침적), 겔제(고분자+액체 반고형), 에어로졸제(분사제 압력 분출), 분말제
- 혼합 시 안정성 저해 요인: §2 참조
- 혼합·소분 장소 위생: 판매장소와 **구분 또는 구획**(구분=간격·선·그물망, 구획=벽·칸막이·에어커튼 — **기계 혼합·소분 시 구분·구획 간주**), 환기시설, 작업대·바닥·벽·천장·창문 청결, 손·장비 세척 시설, 방충·방서 정기점검
- 장비·도구: 사용 전후 세척, 무잔류·표면 이상 없는 세제, 건조 보관, **자외선 살균기는 한 층 비겹침 배치 + 램프 청결**
- 시설기준 권장: 혼합·소분 공간 구분·구획 + 혼입·미생물 오염 방지 시설 + 주기적 점검·관리 (CGMP 제3장 7·8·9조 참고)

## 10. 조제관리사 위생 + 충진·포장

- 조제관리사: 작업자 위생관리 항목 수행 + 위생 환경 모니터링(작업자·환경·장비도구 점검표 활용 기록)
- **충전기 종류**: 피스톤 방식(대용량 액상 — 샴푸·린스·컨디셔너), 파우치 충전기(1회용 견본), 파우더 충전기(페이스파우더), 카톤 충전기(테이핑 박스), 액체 충전기(스킨·토너·앰플), 튜브 충전기(폼클렌징·선크림) — 충전은 1차 포장 작업
- 포장: 제품 특성 적합 포장재 선택(용기-내용물 상용성), 기재·표시 사항 확인(맞춤형은 조제 정보·사용법 포함), 포장 공정 위생 유지
