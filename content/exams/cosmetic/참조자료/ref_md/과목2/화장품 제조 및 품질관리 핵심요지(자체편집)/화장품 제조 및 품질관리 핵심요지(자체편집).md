# 화장품 제조 및 품질관리 핵심요지 (자체 편집)

> **성격**: 맞춤형화장품조제관리사 과목2「화장품 제조 및 품질관리」대비 자체 편집 요지 — 법령이 아닌 학습 요약 문서
> **기반자료**: 식품의약품안전처 「맞춤형화장품조제관리사 교수학습가이드(개정 4판)」(2025) 학습가이드 ChapterⅡ — 저작권 고지에 따라 **사실·수치·기준만 추출하여 자체 문장으로 재구성**, 원문 미수록
> **주의**: 원료 한도·기준은 고시 개정에 따라 변경 가능 — 실제 판정은 당해연도 정본 기준 (별표 원문은 동 과목 ref_md의 안전기준·CGMP·색소·기능성화장품 문서 참조)

## 1. 원료의 분류와 특성

- 기능별 3분류: **부형제**(유탁액 기제 — 물·오일·왁스·유화제 등 가장 큰 부피) / **유효성분**(효능 부여 — 기능성 고시 원료 등) / **첨가제**(변질 방지 — 보존제·산화방지제 등)
- **수성 원료**(친수성기): 정제수(이온교환+역삼투 정제→자외선 살균 — 금속이온은 산화촉진·변색변취·성분작용 저해 → EDTA 등 금속이온봉쇄제 병용), 에탄올(추출용매·청량감·수렴·가용화·기포방지·점도감소 — 변성제 첨가 변성에탄올 사용), 폴리올(−OH 2개 이상: 글리세린·프로필렌글라이콜·부틸렌글라이콜 — 가용화·보습)
- **유성 원료**(비극성/친유성): 오일(식물·동물·광물성 — 밀폐제·유연·광택, 동물성은 색·냄새로 드묾, 광물성은 미네랄오일·파라핀·페트롤라툼 — 불증발·불산화, 유성감↑ 혼합), 실리콘오일(−Si−O−Si−: 사이클로메티콘 등), 왁스(고급지방산+고급알코올 에스터: 칸데릴라·비즈·카나우바·라놀린 — 경도조절·피막·보조유화), 고급지방산(라우릭·미리스틱·팔미틱·스테아릭·이소스테아릭·올레익 — NaOH·KOH·트리에탄올아민 병용 시 비누화), 고급알코올(C≥6: 세틸·스테아릴 — 경도·점도·유화안정화)
- **계면활성제**: 분자 내 극성+비극성 공존(양친매성) — 계면 흡착해 계면장력·자유에너지 저하. 기능별: 유화제·가용화제·분산제·세정제. 이온성별: 음이온·양이온·양쪽성·비이온
- **보습제**: 습윤제(humectant — 주변 수분 흡수, 글리세린) / 밀폐제(피막형성 — 수분 증발 억제) / 연화제 / 장벽대체제
- 고분자: 수용성은 점증 효과, 기원별 천연·반합성·합성
- 색재: 유기합성(타르)·천연색소·무기안료 — 진주광택 안료는 광학 특수효과
- 보존제: 미생물 성장 억제·감소 — 「화장품 안전기준 등에 관한 규정」 별표2 고시 품목만 사용 가능

## 2. 제조 원리 — 가용화·유화·분산

- **HLB**: 친수-소수 균형 지표. 용도별 범위 — 1~3 소포제 / 4~6 W/O 유화제 / 7~9 분산제·습윤제 / 8~18 O/W 유화제·세정제·가용화제 / 13~15 세정제 / 10~18 가용화제 / **유성물질 수상 가용화 최적 HLB 15~18**
- **가용화**: 난용성 물질을 계면활성제 미셀 내부·표면 흡착으로 용해 — 미셀 형성 시작 농도 = **임계미셀농도(CMC)**. 영향 요인: 가용화제 종류·구조·HLB, 피가용화물 구조·분자량, 전해질·비전해질, 온도·농도·pH. 방법: 가용화제+피가용화물 선혼합 후 수상 가하거나 수상에 용해 후 피가용화물 투입. 활용: 스킨·에센스·토닉. 가용화제 = 주로 비이온성(폴리솔베이트80, PEG-40 수소화피마자유, 폴리글리세릴-10 올리에이트, 콜레스-24, 세테스-24)
- **유화**: 이질 액체 상호 분산 — O/W(유상 내상, 산뜻·친수성), W/O(수상 내상, 유분감·내수성 — 자외선차단), 다중유화(W/O/W·O/W/O — 제형 매력 있으나 안정성·제조 곤란으로 상품성 낮음). 입자 크기별 마이크로·나노에멀젼. 유화법: 전유화법(유상을 수상에 투입 — 유상 소량 시), 역전유화법(PIT), 그 외
- **분산계**(분산상+분산매): 에어로졸(액·고→기 — 헤어스프레이), 기포(기→액 — 거품), 유액(액→액 — 로션·크림), 현탁액(고→액 — 파운데이션·마스카라), 고상 분산(→고 — 스틱제형)

## 3. 제조공정

- 일반 흐름: 원재료 입고 → 칭량 → 가온용해/유화·중화(또는 혼합·분쇄·체질) → 냉각·숙성(기포제거·자극 감소) → 충전(1차포장) → 2차포장·표시
- 공정용어: 제조(칭량~포장·표시 일련), 제조소, 원료(벌크 투입 물질), 원자재(원료+자재), 자재·부자재(용기·포장재), 포장재(1차=내용물 직접접촉 / 2차)
- 제형별: **화장수·에센스** = 가용화 (알코올상 실온 혼합 → 수상 선투입 → 서서히 투입 → 여과·충전); **로션·크림·폼클렌징** = 유화 (유상 70℃ 용해 + 수상 70℃ → 호모믹서 유화 → 패들 저속 냉각·탈포 — 열약성 약제·향료는 50℃ 냉각 단계 투입); **마스크팩** = 분산 (분말+피막제 고속 호모믹서 분산); **립스틱** = 색소 오일 습윤→3단 롤밀 분쇄·분산→85℃ 왁스 용해 혼합→금형 급냉; **파우더** = 분체 혼합→분쇄→체질(탈크·카올린·마이카·세리사이트·실리카·Ca/Mg카보네이트), 향료 분무 혼합, 콤팩트는 압축성형
- 페이스파우더 조성: 탈크 주성분(70% 이상) + 백색안료(티타늄다이옥사이드 — 피복성) + 착색안료(적·황·흑 산화철) + 부착성분(징크스테아레이트) + 방부제·향료

## 4. 유형별 특성 요약

- 클렌징(메이크업리무버): 워터프루프·유성 기반 제품을 유성 용제로 용해·분산해 제거. 클렌징워터(액상·보습 다량), 오일(헹굼 시 O/W 유화), 로션(O/W — 크림보다 산뜻·클렌징력 낮음), 크림(O/W·W/O), 젤(고분자젤·액정 — 액정형 클렌징력 높음)
- 기초제품: 화장수(유연·수렴·세정·다층 — 수렴은 피지·발한 억제 추가), 크림(O/W 산뜻 / W/O 유분·내수성 / 다중), 로션(화장수~크림 중간, O/W·W/O — 발림성 좋고 기제용), 에센스(점성+고농축 유효성분), 팩(워시오프·필오프·석고·부착형)
- 색조제품: 페이스파우더(피부색 보정·땀피지 억제·화장지속), 파운데이션(리퀴드·크림·케이크), 립글로스(액상·크림 — 유성+색재 분산), 립밤(스틱·크림 — 보습·윤기)

## 5. 제조·품질관리 문서 (CGMP 4대 기준서 + 성적서)

- **4대 기준서**: 제품표준서·제조관리기준서·품질관리기준서·제조위생관리기준서 — CGMP 제29조 문서관리 규정에 따라 작성·관리
- **제품표준서**: 제품의 이력서 — 제품명·작성연월일·효능효과(기능성)+주의사항·원료명 분량(100% 처방 기준) 및 제조단위당 기준량·공정별 단위공정+기기+공정흐름도·이론생산량·수율·관리기준·주의사항·원자재/반제품/완제품 기준 및 시험방법·필요시설기기·보관조건·사용기한/개봉후사용기간·변경이력 — 제조업자 작성·보관, 책임판매업자 보관
- **제조관리기준서**: 제품표준서의 제조공정·시설기기·원료/완제품 관리기준을 실행 기준으로 구체화. 제조관리기록서(제조관리지시서+기록): 제조번호·제조단위·실사용원료 분량·공정별 작업내용·지시자
- **품질관리기준서·품질관리기록서**: 품질검사 기준·결과 기록 — 책임판매업자는 제조업자로부터 받은 제품표준서+품질관리기록서 보관, 수입품은 수입관리기록서
- **원료품질성적서**: 맞춤형판매업자는 입고 시 책임판매업자 제공 성적서 구비·확인 의무. 인정 기준 4유형 — ①제조업자 자가검사 또는 공인기관 성적서 ②책임판매업자 자가검사 또는 공인기관 ③원료업체 공인기관 ④원료업체 자가검사 중 대한화장품협회 '원료공급자 검사결과 신뢰 기준 자율규약' 적합분(신뢰 시 일부 시험항목 갈음 가능)
- 성적서 필수항목: 원료명·제조자·공급자명·수령일자·**제조번호/관리번호(맞춤형은 식별번호=제조번호 — 내용물 제조번호와 혼합·소분 기록 추적용)**·제조연월일·보관방법·사용기한·특성항목(성상·pH·비중·굴절률·중금속·비소·미생물 등)

## 6. 사용제한 원료·착향제 알레르기 성분

- 관리 체계 = 네거티브: 사용 불가(안전기준 별표1) + 사용제한(별표2 — 보존제·자외선차단제 등 지정·고시 품목만, 미지정 사용 불가) + 색소(색소종류·기준 별표1 — 사용부위·한도) + 기능성 원료(기능성화장품 심사규정 — 품목별 고시 원료·한도). 법 제8조: 위해 우려 원료는 총리령으로 위해요소 신속평가 → 사용불가 지정 또는 기준 지정, 지정 원료 기준 **5년 주기 안전성 검토**, 제조업자·책임판매업자·대학·연구소는 해제·지정·변경 신청 가능
- **착향제 알레르기 유발성분**: 2020.1.1.부터 표시 의무 — 「화장품 사용할 때의 주의사항 및 알레르기 유발성분 표시에 관한 규정」 별표2의 성분(25종) 함유 시 성분명 표시, 미함유 시 '향료' 표기. 표시 기준: **씻어내는 제품 0.01% 초과 / 씻어내지 않는 제품 0.001% 초과** 함유 시만
- 기능성화장품 효능 별 고시 원료·사용한도는 KFCC 별표 체계 (미백 나이아신아마이드, 주름개선 레티놀, 자외선보호, 모발색상변화, 체모제거 치오글리콜산, 여드름 살리실릭애씨드, 탈모 덱스판테놀 등 — ref_md KFCC_별표 시리즈 참조)

## 7. 용기·포장·보관·미생물 관리

- 안전용기·포장(규칙 제18조): 성인 개봉 용이 + 5세 미만 개봉 곤란. 대상 — 아세톤 함유 네일리무버, 탄화수소류 10%+운동점도 21cSt(40℃) 이하 비유화 액제, 메틸살리실레이트 5%+ 액제. 예외 — 일회용·펌프·방아쇠 분무·에어로졸
- 포장 규제(환경부령): 재질 표시(1차/2차·내외부), **포장공간비율** — 인체·두발 세정용 15% 이하, 기타 화장품 10% 이하(향수 제외), 종합제품 25% 이하(받침·완충재 특정 재질 20% 이하), **포장횟수 2차 이내**. **재포장 금지** — 대규모점포·매장면적 33㎡ 이상은 포장 완료품 재포장 제조·수입·판매 금지. 분리배출표시 의무(자원재활용법 제14조)
- 용기 적합성 평가 4축: ①재질 물질 종류·함량 ②용출 정도 ③원료·용출물 독성시험 ④오염도 + 반복사용 용기는 잔류물·열화도
- 사용기한 설정: 제조업자·수입자가 **품목별 안정성시험** 결과로 자체 설정 — 과학적·합리적 타당성 인정 시험이어야 하고, 외국 시험 결과도 적합하면 인정
- **유통화장품 미생물 한도**(안전기준 제6조): 총 호기성 생균 — **영유아용·눈화장용 500개/g(mL) 이하, 물휴지 세균·진균 각 100개/g(mL) 이하, 기타 1,000개/g(mL) 이하** / 대장균·녹농균·황색포도상구균 **불검출**
- CGMP 3대 요소: 인위적 과오 최소화 / 미생물·교차오염 품질저하 방지 / 고도 품질관리체계 — 맞춤형판매장도 혼합·소분품 미생물 기준 준수(주기적 샘플링 검사 권장)
- 보관·사용 품질문제: 사용 직전 개봉·사용 후 밀봉(낙하균 오염·산화 변색변취·제형 경화 — 매니큐어·마스카라·리퀴드아이라이너는 용기 내 잦은 펌핑으로 공기 유입 시 굳음), 깨끗한 손·도구 사용(물기는 세균 증식·유화제품 상분리), 직사광선·고온다습 회피(레티놀 등 광불안정·세균 증식)

## 8. 사용시 주의사항

- 공통사항(규칙 별표3): 이상증상·부작용 시 전문의 상담, 상처 부위 사용 자제, **어린이 손 닿지 않는 곳·직사광선 피해 보관**, 알갱이 눈 유입 시 물 세정
- 유형별: 제2단계 퍼머액(과산화수소 주성분 — 검은 머리카락 갈변 주의), 외음부세정제(3세 이하 사용금지·임신중 자제·프로필렌글라이콜 함유 시 과민 주의 표시), 체취방지용(제모 직후 금지), 속눈썹 파마(15℃ 이하 어두운 곳·개봉 후 폐기), 염모제·탈염탈색제·제모제(치오글라이콜릭애씨드 함유품만 표시 — 피부상태·사용전후 주의 세부 구분)
- **에어로졸(고압가스)**: 비가연성 — 40℃ 이상 보관금지·불속 폐기금지·잔가스 제거·밀폐보관금지. 가연성 — 여기에 +화기주의·불꽃향해 사용금지·화기 부근·사용 실내 금지·밀폐실내 사용 후 환기. 인체용 추가: 특정부위 장기간 사용금지·**인체에서 0.2m 이상 거리**(물 40% 이상+분사제 10% 이하 거품·겔 분출형은 예외)
- 고압가스 비사용 분무형 자외선차단제: 얼굴 직접 분사 금지 — 손에 덜어 바름
- 맞춤형판매 시 소비자 설명 의무: 혼합·소분 내용물·원료의 내용 및 특성 + 맞춤형화장품 사용 시 주의사항

## 9. 위해 판단·보고

- 회수 대상 위해화장품 = 법 제9조(안전용기포장)·제15조(영업금지)·제16조제1항(판매금지) 위반 + 위해 우려. 위해성 등급(규칙 제14조의2): **가등급**(사용불가원료·사용한도 위반·미지정 보존제색소자외선차단제) / **나등급**(안전용기 위반·유통안전기준 위반 — 내용량·기능성 주성분함량부적합 제외·식품모방) / **다등급**(변패·병원미생물·이물 위해우려·기능성 주성분부적합·기한 위변조·영업자 자체판단·무등록·무신고·조제관리사 미선임 판매·기재위반·훼손위변조)
- 회수 절차·기한(규칙 제14조의3): 즉시 판매중지·조치 → 인지일 **5일 이내 회수계획서** 제출(제조수입기록서·판매처별 판매량·판매일 기록 첨부) → 회수 통보(방문·우편·전화·전보·이메일·팩스·공고 — 입증자료 회수종료 후 **2년**) → **가등급 15일 이내 / 나·다등급 30일 이내** 회수 완료 → 통보받은 자는 반품+회수확인서 송부 → 폐기 시 폐기확인서 **2년** 보관 → 회수종료신고서
- 유해사례 보고 체계(안전성 정보관리 규정): 의사·약사·판매자·소비자·단체 → 별지1호(유해사례보고서)·2호(안전성정보보고서)로 식약처·책임판매업자·맞춤형판매업자에 보고 가능. 책임판매·맞춤형판매업자는 중대 유해사례·외국 조치 → **15일 이내 신속보고**, 나머지 → **반기 종료 후 1월 이내 정기보고**(별지3호). 맞춤형판매업자는 유해사례 지체 없이 식약처 보고
- 위해평가(위해평가 가이드라인): 인체 위해영향·확률을 과학적으로 예측 — **위험성 확인(내재적 독성) → 위험성 결정(허용량 산출) → 노출평가(노출량 산출) → 위해도 결정(종합 판단)**. 전신노출량(systemic exposure dosage) = mg/kg bw/day — 피부노출량 기준. 원칙: 사례별(case-by-case) 평가, OECD 프로토콜 독성자료 우선, 자료 부족 시 부족 명시·안전역 미산출, 피부흡수율은 매질 영향 포함 평가, 새 과학자료 시 재평가 가능
- 안전성 평가 시 고려: 특정 대상(영유아·민감피부), 피부투과 증가 성분(투과 강화제·유기용제·산성 성분), 성분 간 화학반응 가능성 — 알레르기성 유해사례는 공급자+고객 공동 관리, 자극성은 개발·제조자 노력
