엑셀은 다양한 데이터를 효과적으로 계산, 분석, 시각화할 수 있는 대표적인 스프레드시트 프로그램이다. 컴퓨터활용능력 2급 필기시험에서는 화면의 각 구성 요소 명칭과 역할, 기본 옵션 설정, 창 제어 단축키와 동작 원리가 자주 출제되므로 정확한 개념 이해가 필요하다.

**1. 프로그램 실행 및 화면 인터페이스의 이해**

엑셀은 [시작] 메뉴나 바탕화면의 바로 가기 아이콘을 더블클릭하여 실행하거나, [실행] 창(Windows 로고 키 + R)에서 'excel'을 입력하여 구동할 수 있다. 프로그램이 실행되면 상단부터 다음과 같은 기본 인터페이스가 제공된다.

- **빠른 실행 도구 모음**: 자주 사용하는 명령(저장, 실행 취소, 다시 실행 등)을 모아둔 곳으로, 사용자가 원하는 명령을 추가하거나 제거할 수 있으며 리본 메뉴 아래로 위치를 변경할 수 있다.
- **제목 표시줄**: 현재 열려 있는 통합 문서의 이름과 프로그램 이름이 표시되며, 창 조절 단축 단추가 위치한다.
- **리본 메뉴**: 엑셀의 다양한 기능이 탭(홈, 삽입, 페이지 레이아웃, 수식, 데이터 등)과 그룹으로 분류되어 있는 영역이다. 🔢 단축키 `Ctrl + F1`을 누르면 리본 메뉴를 화면에서 축소하거나 다시 표시할 수 있다. 리본 메뉴 탭을 더블클릭해도 동일하게 작동한다.
- **이름 상자**: 현재 선택된 셀의 주소(예: A1)가 표시되며, 특정 셀 범위를 선택하고 고유한 이름을 정의하거나 정의된 이름으로 바로 이동할 때 사용한다. 차트나 도형 등의 개체가 선택되어 있을 때는 해당 개체의 이름이 표시된다.
- **수식 입력줄**: 현재 활성화된 셀에 입력된 실제 데이터나 수식이 그대로 표시되는 곳이다. 셀에 수식 결과값이 보여도 수식 입력줄에는 계산식 원형이 나타나며, 여기서 직접 데이터를 입력하거나 편집할 수 있다.
- **워크시트와 상태 표시줄**: 행(숫자 1, 2, 3...)과 열(알파벳 A, B, C...)이 만나는 셀(Cell)들로 구성된 작업 영역이다. 하단의 상태 표시줄에는 현재 작업 모드(준비, 입력, 편집 등)가 표시되고, 셀 범위를 지정했을 때 평균, 개수, 합계 등의 자동 계산 결과가 나타난다. 상태 표시줄을 마우스 오른쪽 단추로 클릭하면 표시할 항목을 자유롭게 선택할 수 있다.

**2. 엑셀 기본 옵션 설정**

[파일] - [옵션] 메뉴에서는 엑셀의 기본 작업 환경을 사용자 정의할 수 있다. 시험에서는 각 탭에서 설정할 수 있는 세부 항목을 묻는 문제가 자주 출제된다.

| 옵션 범주 | 주요 설정 항목 및 특징 |
| --- | --- |
| **일반** | 새 통합 문서 생성 시 기본 글꼴, 글꼴 크기, 기본 보기 상태, 포함할 시트 수 설정 |
| **수식** | 계산 옵션(자동/수동), R1C1 참조 스타일 사용 여부, 수식 자동 완성, 오류 검사 규칙 설정 |
| **언어 교정** | 자동 고침 옵션(오타 자동 수정), 맞춤법 검사 기준, 대/소문자 무시 설정 |
| **저장** | 기본 파일 저장 위치, 자동 복구 정보 저장 간격(기본 10분, 1~120분 범위), 기본 저장 형식 설정 |
| **고급** | <Enter> 키를 누른 후 이동할 셀 방향(아래, 오른쪽, 위, 왼쪽), 채우기 핸들 사용 여부, 소수점 자동 삽입 |

⚠️ **시험 함정 포인트**
- 새 통합 문서를 만들 때 포함되는 시트 수의 기본값은 1개이며, [옵션]의 [일반]에서 변경할 수 있다. 단, 기존에 이미 생성된 통합 문서의 시트 수가 자동으로 바뀌는 것은 아니다.
- <Enter> 키 입력 후 이동 방향의 기본값은 '아래쪽'이지만, [옵션] - [고급]에서 '오른쪽', '위쪽', '왼쪽'으로 변경하거나 아예 이동하지 않도록 해제할 수도 있다.

**3. 프로그램의 메뉴 및 창 제어**

엑셀 작업을 효율적으로 수행하기 위해서는 창 제어와 관련된 기능 및 단축키를 명확히 구분해야 한다. 특히 여러 문서를 동시에 비교하거나 한 화면에서 긴 시트를 다룰 때 유용한 기능들이 자주 출제된다.

- **창 분할**: 워크시트가 방대하여 서로 멀리 떨어진 데이터를 한눈에 비교할 때 사용한다. 화면을 최대 4개(가로/세로) 영역으로 분할할 수 있으며, 분할선을 마우스로 드래그하여 크기를 조절할 수 있다. 창 분할은 인쇄 시에는 적용되지 않으며 화면 표시에만 영향을 미친다. 분할선을 더블클릭하면 해당 분할선이 제거된다.
- **틀 고정**: 데이터의 양이 많아 스크롤을 내리거나 오른쪽으로 이동하더라도 특정 행(주로 표 제목행)이나 열(주로 고유식별자 열)이 항상 화면에 표시되도록 고정하는 기능이다. 틀 고정은 현재 선택된 셀의 '왼쪽'과 '위쪽'을 기준으로 적용되므로 기준 셀의 위치 선정이 매우 중요하다. 창 분할과 마찬가지로 인쇄물에는 반영되지 않는다.
- **새 창과 모두 정렬**: [보기] - [창] - [새 창]을 실행하면 현재 작업 중인 통합 문서를 별도의 창으로 하나 더 열 수 있다. 이때 파일이 복사되는 것이 아니라 동일한 문서가 두 창에 연결되어 표시되므로, 한쪽 창에서 데이터를 수정하면 다른 창에도 실시간으로 반영된다. [모두 정렬] 기능을 통해 여러 창을 바둑판식, 가로, 세로, 계단식으로 배치할 수 있다.

🔢 **주요 창 제어 단축키**
- `Ctrl + F9`: 현재 통합 문서 창 최소화
- `Ctrl + F10`: 현재 통합 문서 창 이전 크기로 복원 또는 최대화
- `Ctrl + W` 또는 `Ctrl + F4`: 현재 작업 중인 통합 문서만 닫기 (엑셀 프로그램은 유지됨)
- `Alt + F4`: 엑셀 프로그램 전체 종료

⚠️ 틀 고정과 창 분할은 동시에 한 시트에서 병행하여 적용할 수 없다. 둘 중 하나의 기능만 활성화할 수 있다는 점을 반드시 기억해야 한다.

엑셀에서 작업한 데이터를 보관하고 유통하기 위해서는 통합 문서의 열기, 저장, 내보내기 등 파일 관리 체계를 명확히 이해해야 한다. 시험에서는 단축키, 저장 옵션의 세부 설정, 다양한 파일 형식의 차이점이 자주 출제된다.

**1. 파일 열기와 닫기**

새로운 작업 공간을 열 때는 새 통합 문서(단축키: 🔢 `Ctrl + N`)를 생성하며, 기존 문서를 불러올 때는 열기(단축키: 🔢 `Ctrl + O`)를 사용한다. 열기 창에서는 로컬 드라이브뿐 아니라 원드라이브(OneDrive)와 같은 클라우드 위치도 선택할 수 있으며, [최근 항목]에 표시된 파일 목록에서 압정 모양의 고정 아이콘을 클릭하면 자주 쓰는 파일을 목록 상단에 항상 고정해 둘 수 있다.

작업 중인 통합 문서를 종료할 때는 닫기(단축키: 🔢 `Ctrl + W` 또는 `Ctrl + F4`)를 실행한다. 이는 프로그램 창 자체를 닫는 프로그램 종료(단축키: 🔢 `Alt + F4`)와 구별해야 한다. 통합 문서를 닫을 때 저장되지 않은 수정 사항이 있다면 저장 여부를 묻는 대화상자가 반드시 나타난다.

⚠️ **함정 포인트**: 닫기(`Ctrl + W`)는 현재 작업 중인 통합 문서 창만 닫히고 엑셀 프로그램은 계속 실행된 상태로 유지되지만, 프로그램 종료(`Alt + F4`)는 엑셀 프로그램 자체가 완전히 종료된다.

**2. 파일 저장과 다른 이름으로 저장**

기존 파일에 덮어쓰는 저장은 🔢 `Ctrl + S`를 누르며, 작업 중인 문서를 새로운 이름, 새로운 경로 또는 다른 파일 형식으로 보관할 때는 다른 이름으로 저장(단축키: 🔢 `F12`)을 사용한다. 

[다른 이름으로 저장] 대화상자의 [도구] - [일반 옵션]에서는 파일의 보안 및 복구와 관련된 중요한 옵션을 설정할 수 있다.

* **백업 파일 항상 만들기**: 문서를 저장할 때마다 기존 버전을 확장자가 `.xlk`인 백업 파일로 자동 생성하여 보관한다.
* **열기 암호**: 암호를 정확히 입력하지 않으면 파일의 내용을 전혀 열어볼 수 없도록 암호화한다.
* **쓰기 암호**: 암호를 몰라도 '읽기 전용'으로 문서를 열람할 수는 있지만, 수정한 내용을 원본 파일에 덮어쓸 수는 없다(다른 이름으로 저장은 가능).
* **읽기 전용 권장**: 파일을 열 때 문서를 수정할 필요가 없다면 읽기 전용으로 열도록 확인 메시지를 띄우는 옵션이다.

| 주요 파일 형식 | 확장자 | 특징 |
| --- | --- | --- |
| Excel 통합 문서 | `.xlsx` | 엑셀 2007 이후의 기본 XML 기반 형식(매크로 저장 불가) |
| Excel 매크로 사용 통합 문서 | `.xlsm` | VBA 매크로 코드가 포함된 통합 문서 형식 |
| Excel 서식 파일 | `.xltx` | 반복되는 양식을 템플릿으로 저장한 형식 |
| CSV (쉼표로 분리) | `.csv` | 텍스트 데이터의 각 항목을 쉼표(,)로 구분한 범용 형식 |
| 텍스트 (탭으로 분리) | `.txt` | 각 열 데이터를 탭(Tab) 문자로 구분한 일반 텍스트 파일 |

⚠️ **함정 포인트**: 매크로(VBA)가 포함된 문서를 기본 형식인 `.xlsx`로 저장하면 포함된 모든 매크로 코드가 자동으로 제거되므로, 반드시 `.xlsm` 형식으로 저장해야 한다.

**3. 내보내기**

[파일] - [내보내기] 메뉴는 통합 문서를 인쇄물 형태의 전자 문서로 변환하거나 형식을 일괄 변환할 때 사용한다.

* **PDF/XPS 문서 만들기**: 엑셀이 설치되지 않은 환경에서도 누구나 동일한 글꼴과 레이아웃으로 열람하고 인쇄할 수 있도록 고정 레이아웃 문서(PDF 또는 XPS)로 발행한다. 원본 데이터의 계산식이나 시트 구조를 보호하면서 배포용 보고서를 만들 때 유용하다.
* **파일 형식 변경**: 통합 문서를 이전 버전 형식(`.xls`), 텍스트 파일, 서식 파일 등 다른 확장자로 간편하게 변환하여 내보낼 수 있다.

**4. 게시**

[파일] - [게시] 메뉴는 작성된 데이터를 클라우드 기반의 비즈니스 인텔리전스 도구인 Power BI로 내보낼 때 사용된다.

* **Power BI로 게시**: 통합 문서의 원본 데이터 모델과 워크시트 테이블을 Power BI 작업 영역으로 업로드하여 대화형 대시보드 및 시각화 보고서로 연결할 수 있도록 지원한다.
* 데이터를 단순히 공유하는 것을 넘어 실시간 비즈니스 리포트로 연동할 때 활용되며, 이를 위해서는 유효한 회사 또는 학교 계정의 Power BI 서비스 로그인이 필요하다.

워크시트(Worksheet)는 엑셀에서 데이터를 입력하고 계산을 수행하는 기본 작업 공간이며, 이러한 시트들의 모음을 통합 문서(Workbook)라고 한다. 시험에서는 시트 편집 작업의 제한 사항과 시트 보호 및 통합 문서 보호의 차이점을 구별하는 문제가 매우 자주 출제된다.

**워크시트의 기본 관리**
새로운 워크시트를 삽입하면 기본적으로 현재 선택된 시트의 왼쪽에 추가된다. 🔢 단축키는 `Shift` + `F11`이며, 시트 탭의 '+' 단추를 누르면 마지막 시트 뒤에 추가된다. 워크시트의 삭제는 시트 탭의 바로 가기 메뉴에서 수행할 수 있는데, 데이터가 들어 있는 시트를 삭제할 때는 영구히 삭제되므로 ⚠️ 실행 취소(`Ctrl` + `Z`)로 되돌릴 수 없다는 점에 각별히 유의해야 한다.
통합 문서 내의 워크시트는 숨기기가 가능하지만, ⚠️ 통합 문서에는 최소한 하나의 시트가 화면에 표시되어 있어야 하므로 모든 시트를 숨기거나 삭제할 수는 없다. 
시트 이름을 변경할 때는 시트 탭을 더블 클릭하거나 우클릭 메뉴를 이용한다. 🔢 시트 이름은 공백을 포함하여 최대 31자까지 지정할 수 있으나, 슬래시(/), 역슬래시(\), 물음표(?), 별표(*), 콜론(:), 대괄호([ ])와 같은 특수문자는 사용할 수 없다.

**시트의 이동·복사와 시트 그룹**
시트를 마우스로 드래그하면 원하는 위치로 이동할 수 있고, `Ctrl` 키를 누른 채 드래그하면 시트가 복사된다. 시트 탭 바로 가기 메뉴의 [이동/복사] 대화상자를 이용하면 현재 통합 문서뿐만 아니라 다른 통합 문서로도 이동 및 복사가 가능하다.
여러 시트를 한 번에 제어할 때는 연속된 시트는 `Shift` 키, 서로 떨어진 시트는 `Ctrl` 키를 누른 채 클릭하여 선택한다. 둘 이상의 시트가 선택되면 제목 표시줄의 파일명 옆에 **[그룹]** 표시가 나타난다.
시트가 그룹으로 묶인 상태에서 특정 셀에 데이터를 입력하거나 서식을 변경하면, ⚠️ 그룹에 포함된 모든 시트의 동일한 셀 위치에 작업 내용이 일괄 적용된다. 그룹 설정을 해제하려면 선택되지 않은 다른 시트 탭을 클릭하거나 시트 탭에서 마우스 오른쪽 단추를 누른 뒤 [시트 그룹 해제]를 선택한다.

**시트 보호와 통합 문서 보호의 비교**
두 기능은 보호 대상이 완전히 다르므로 시험에서 보기 지문으로 교차 출제되어 함정을 파는 대표적인 영역이다. 암호 설정은 두 기능 모두 선택 사항(생략 가능)이다.

| 구분 | 시트 보호 | 통합 문서 보호 |
| --- | --- | --- |
| **보호 대상** | 워크시트 내의 셀 데이터, 개체, 시나리오 등 | 통합 문서의 구조(시트 구성) 및 창 창틀 |
| **주요 제한 사항** | 셀 내용 수정, 서식 변경, 차트 등 개체 수정 방지 | 시트 삽입, 삭제, 이름 바꾸기, 이동/복사, 숨기기 방지 |
| **연동 설정** | [셀 서식]의 [보호] 탭에서 '잠금'이 체크된 셀에만 적용 | 시트 보호 여부와 상관없이 통합 문서 전체에 적용 |
| **주의점** | 시트 자체의 삭제나 이름 변경은 막지 못함 | 워크시트 내부 셀의 데이터를 편집하는 것은 허용됨 |

⚠️ [시트 보호]를 설정하더라도 해당 셀의 [셀 서식]-[보호] 탭에서 '잠금' 항목의 체크를 해제해 두었다면 그 셀은 자유롭게 수정할 수 있다. 또한 ⚠️ [통합 문서 보호]가 설정되어 있어도 시트 내부의 셀 데이터를 입력하거나 수정하는 작업은 얼마든지 가능하다는 점을 반드시 기억해야 한다.

**통합 문서의 공유 및 병합**
통합 문서 공유는 로컬 네트워크 환경에서 여러 사용자가 동일한 통합 문서를 동시에 열어 편집할 수 있도록 지원하는 기능이다. 공유된 통합 문서는 제목 표시줄에 **[공유]**라는 표시가 붙는다.
여러 사용자가 동시에 같은 셀을 수정하여 충돌이 발생하면 충돌을 해결할 수 있는 대화상자가 나타나며, 사용자는 변경 내용의 우선순위를 결정할 수 있다.
⚠️ 공유 통합 문서로 지정되면 기능상의 제약이 발생한다. 조건부 서식, 차트, 피벗 테이블 보고서, 셀 병합, 수식 나누기, 매크로 기록 등의 기능은 새로 작성하거나 편집할 수 없다.
공유 통합 문서를 병합하려면 먼저 각 문서가 동일한 통합 문서의 복사본이어야 하며, 변경 내용 기록(추적)이 유지되도록 설정되어 있어야 병합이 정상적으로 수행된다.


## 📚 Chapter 02. 데이터 입력


### 1. 데이터 입력

- 각종 데이터 입력
- 일러스트레이션 활용
- 이름, 메모 및 노트, 윗주 삽입

<!-- ai-draft: LLM 초안 — 검수 필요 -->

워크시트의 셀에는 문자, 숫자, 날짜, 시간, 수식 등 다양한 유형의 데이터를 입력할 수 있으며, 데이터 종류에 따라 기본 정렬 방식과 처리 규칙이 서로 다르다.

문자 데이터는 기본적으로 셀의 왼쪽에 정렬된다. 텍스트뿐만 아니라 한글, 영문, 특수문자, 그리고 숫자 앞에 작은따옴표(')를 입력한 데이터도 문자로 인식한다. 입력한 문자열이 셀 너비보다 길 경우, 오른쪽 인접 셀이 비어 있으면 연속하여 표시되지만 내용이 채워져 있다면 셀 너비만큼만 잘려서 표시된다. 

숫자 데이터는 기본적으로 셀의 오른쪽에 정렬된다. 음수는 마이너스(-) 기호를 붙이거나 괄호 ( )로 묶어서 입력할 수 있다. 셀 너비가 좁아 입력된 숫자를 모두 표시하지 못할 때는 지수 형식으로 바뀌거나 셀 전체가 '###'으로 표시된다. 

날짜와 시간 데이터 역시 오른쪽에 정렬되며, 계산이 가능한 일련번호로 저장된다. 날짜는 하이픈(-)이나 슬래시(/)로 연·월·일을 구분하여 입력하고, 시간은 콜론(:)으로 시·분·초를 구분한다. 한 셀에 날짜와 시간을 함께 입력할 때는 반드시 한 칸의 공백을 두고 입력해야 한다.

🔢 **데이터 입력 필수 단축키**
- 한 셀에 여러 줄 입력: `Alt` + `Enter`
- 선택한 여러 셀에 동일한 데이터 일괄 입력: 데이터 입력 후 `Ctrl` + `Enter`
- 오늘 날짜 입력: `Ctrl` + `;`
- 현재 시간 입력: `Ctrl` + `Shift` + `;`

| 데이터 종류 | 기본 정렬 | 주요 입력 특징 및 규칙 |
| --- | --- | --- |
| 문자 | 왼쪽 | 셀 너비 초과 시 오른쪽 셀 침범 가능, ' 접두사 시 문자로 변환 |
| 숫자 | 오른쪽 | 열 너비 부족 시 지수 형태 또는 '###' 표시 |
| 날짜/시간 | 오른쪽 | 날짜(-, /), 시간(:)으로 구분, 1900년 1월 1일을 일련번호 1로 처리 |
| 논리값/오류 | 가운데 | TRUE, FALSE 및 #N/A, #VALUE! 등 |

[삽입] 탭의 [일러스트레이션] 그룹을 이용하면 워크시트에 그림, 도형, SmartArt, 스크린샷 등을 배치하여 시각적 전달력을 높일 수 있다.
- 도형을 그릴 때 `Shift` 키를 누른 채 드래그하면 정사각형, 정원, 수평선, 수직선 등 정방향 개체가 그려진다.
- `Alt` 키를 누른 채 도형이나 그림을 드래그하면 셀 눈금선(Grid)의 모서리에 딱 맞추어(스냅) 크기나 위치가 조절된다.
- `Ctrl` 키를 누른 채 드래그하면 마우스 클릭 지점이 중심이 되어 개체가 확대·축소된다.

이름 정의는 자주 사용하는 셀 범위나 수식에 고유한 명칭을 붙이는 기능이다. 이름 상자에 직접 입력하거나 [수식] - [정의된 이름] - [이름 정의]를 통해 생성할 수 있다. 이름의 첫 글자는 반드시 문자, 밑줄(_), 역슬래시(\)로 시작해야 하며 숫자로 시작할 수 없다. 이름 내에 공백은 포함될 수 없으며, 대소문자는 구분하지 않는다. 이미 정의된 이름은 기본적으로 절대 참조($A$1 형태)로 지정되며, 수식 작성 시 셀 주소 대신 직관적인 이름을 사용할 수 있어 관리가 용이하다.

⚠️ **이름 정의 시 주의점**: 'A1', 'R1C1'처럼 실제 셀 주소와 동일한 형태의 이름은 사용할 수 없다.

메모와 노트는 셀 내용에 부가적인 설명이나 주석을 첨부할 때 사용한다. 최신 엑셀에서는 공동 작업용 스레드 대화 기능인 '메모'와 기존의 정적 주석 기능인 '노트'로 구분된다. 노트가 삽입된 셀의 오른쪽 상단에는 빨간색 삼각형 표시가 나타난다. 셀을 삭제하면 메모와 노트도 함께 삭제되지만, 셀의 데이터만 지울 경우([Delete] 키 사용) 메모나 노트는 삭제되지 않고 그대로 유지된다. 워크시트 인쇄 시 기본값은 인쇄되지 않는 상태이지만, [페이지 설정] 대화상자의 [시트] 탭에서 '시트 끝' 또는 '화면에 표시된 대로' 인쇄되도록 설정할 수 있다.

윗주(Phonetic)는 셀에 입력된 문자열 위에 보조 설명이나 독음(발음)을 달아주는 기능이다. 윗주는 오직 문자 데이터가 입력된 셀에만 삽입할 수 있으며, 숫자나 수식, 날짜 데이터에는 적용할 수 없다. 윗주를 입력했더라도 [홈] - [글꼴] 그룹에서 [윗주 필드 표시]를 활성화해야 화면에 나타난다. 셀의 내용을 수정하거나 삭제하면 윗주도 함께 변경되거나 삭제되며, 윗주의 개별 글자 서식을 부분적으로 바꿀 수는 없고 전체 서식만 변경 가능하다.


### 2. 데이터 편집

- 데이터 편집
- 찾기 및 바꾸기
- 영역 설정 방식 이해
- 데이터의 복사, 이동, 삭제
- 다양한 붙여넣기 옵션 사용

<!-- ai-draft: LLM 초안 — 검수 필요 -->

워크시트에 데이터를 입력한 후에는 이를 수정하거나 재배열하는 편집 작업이 빈번하게 발생한다. 데이터 편집은 셀의 내용을 수정하는 기본 조작부터 연속적인 영역 지정, 데이터의 복사 및 이동, 고급 붙여넣기 기능까지 다양하게 구성된다.

**데이터 편집의 기초와 영역 설정**
셀 데이터를 수정할 때는 셀을 더블클릭하거나 해당 셀을 선택한 뒤 🔢 `F2`를 누르면 편집 상태로 전환된다. 수식 입력줄에서 직접 수정하는 것도 가능하다. 셀 전체의 내용을 완전히 새로 입력하려면 셀 포인터가 위치한 상태에서 바로 새 값을 입력하면 기존 데이터가 지워지고 새 내용이 입력된다.

영역을 지정할 때 연속된 셀 범위는 마우스 드래그 또는 🔢 `Shift`를 누른 채 방향키나 끝 셀을 클릭하여 선택한다. 반면 서로 떨어져 있는 비연속적인 셀이나 범위를 동시에 선택할 때는 🔢 `Ctrl`을 누른 채 원하는 셀들을 차례대로 클릭해야 한다. 행 전체를 선택하려면 행 번호를, 열 전체를 선택하려면 열 문자를 클릭하며, 시트 전체를 한 번에 선택할 때는 행·열 머리글이 만나는 모서리의 [모두 선택] 단추를 누르거나 🔢 `Ctrl` + `A`를 사용한다.

**데이터의 복사, 이동, 삭제**
셀 데이터를 복사(🔢 `Ctrl` + `C`)하면 클립보드에 데이터가 저장되고, 대상 위치에서 붙여넣기(🔢 `Ctrl` + `V`)를 수행하면 원본은 그대로 유지된 채 복제된다. 이동(🔢 `Ctrl` + `X`)은 대상 위치에 붙여넣을 때 원본 셀의 내용이 지워지면서 자리가 바뀐다. 마우스 드래그를 이용할 수도 있는데, 선택 영역의 테두리를 그냥 드래그하면 ‘이동’이 되고, 🔢 `Ctrl`을 누른 채 드래그하면 ‘복사’가 수행된다.

데이터 삭제 시에는 무엇을 지우느냐에 따라 방식이 다르다. 셀을 선택하고 🔢 `Delete`를 누르면 셀 안의 ‘내용(값과 수식)’만 삭제되며, 적용되어 있던 서식이나 메모는 그대로 유지된다. 셀 서식이나 메모까지 완전히 초기화하려면 [홈] 탭 - [편집] 그룹의 [지우기] 메뉴에서 [모두 지우기]를 실행해야 한다.

⚠️ **주의:** 셀 내용을 지우는 것과 셀 자체를 화면에서 도려내는 ‘셀 삭제’는 구분해야 한다. 셀을 삭제(🔢 `Ctrl` + `-`)하면 해당 공간을 메우기 위해 주변 셀이 ‘왼쪽으로 밀기’ 또는 ‘위로 밀기’ 방식으로 이동한다.

**다양한 붙여넣기 옵션**
일반적인 붙여넣기는 값, 서식, 수식을 모두 가져오지만, [선택하여 붙여넣기](🔢 `Ctrl` + `Alt` + `V`)를 사용하면 특정 요소만 골라 붙여넣거나 연산을 수행할 수 있다.

| 선택하여 붙여넣기 옵션 | 주요 기능 및 특징 |
| --- | --- |
| **모두** | 원본 셀의 내용, 수식, 서식을 제한 없이 전부 붙여넣음 |
| **수식** | 서식은 제외하고 셀에 입력된 수식(또는 텍스트/숫자)만 붙여넣음 |
| **값** | 수식의 결과로 계산된 최종 값만 텍스트/숫자 형태로 변환하여 붙여넣음 |
| **서식** | 셀 안의 텍스트나 수식은 제외하고 글꼴, 색상, 테두리 등 서식만 복사함 |
| **연산 (더하기/빼기/곱하기/나누기)** | 복사한 셀의 값을 붙여넣을 대상 셀의 기존 값과 즉시 사칙연산 처리함 |
| **행/열 바꿈** | 가로로 나열된 데이터 범위를 세로로, 세로 데이터를 가로로 축을 반전시킴 |

⚠️ **시험 함정:** [선택하여 붙여넣기]의 ‘연산’ 기능을 이용하면 특정 셀에 입력된 수치(예: 1,000)를 복사한 뒤, 다른 여러 셀에 ‘곱하기’로 선택하여 붙여넣어 일괄적으로 1,000배를 곱한 결과를 만들어낼 수 있다.

**찾기 및 바꾸기**
특정 문자열이나 숫자를 검색할 때는 [찾기](🔢 `Ctrl` + `F`), 다른 내용으로 일괄 변경할 때는 [바꾸기](🔢 `Ctrl` + `H`)를 실행한다.
- **와일드카드 문자 활용:** 글자 수에 상관없이 임의의 문자열을 찾을 때는 별표(`*`), 단 한 글자의 임의 문자를 찾을 때는 물음표(`?`)를 사용한다. 만약 순수한 문자로서 `*`나 `?` 자체를 검색하고 싶다면 앞에 물결표(`~*`, `~?`)를 붙여야 한다.
- **검색 범위 및 서식 검색:** 워크시트뿐만 아니라 통합 문서 전체를 대상으로 범위를 확장하여 검색할 수 있다. 텍스트뿐만 아니라 글꼴, 채우기 색 등 특정 [서식]이 지정된 셀만을 조건으로 찾아내거나 다른 서식으로 바꾸는 것도 가능하다.
- **대/소문자 구분:** 기본적으로는 대소문자를 구분하지 않으나, 옵션에서 ‘대/소문자 구분’을 체크하면 정확히 일치하는 영문자만 검색된다. 수식 안의 텍스트를 찾을지, 수식의 결과값이나 메모 안의 텍스트를 찾을지도 옵션에서 지정할 수 있다.


### 3. 서식 설정

- 기본 서식 지정
- 사용자 지정 서식 지정
- 조건부 서식 지정
- 서식 파일/스타일 사용

<!-- ai-draft: LLM 초안 — 검수 필요 -->

서식 설정은 입력된 데이터의 실제 값을 변경하지 않고 화면에 표시되는 형태만을 제어하는 핵심 기능이다. 엑셀에서는 셀 단위로 서식을 부여하며, 데이터의 가독성을 높이고 시각적 분석을 돕기 위해 다양한 서식 지정 방식을 제공한다.

셀 서식의 기본은 글꼴, 맞춤, 표시 형식, 테두리, 채우기 등을 설정하는 것이다. 🔢 셀 서식 대화상자를 호출하는 단축키는 [Ctrl] + [1]로, 필기시험에 빈출되므로 반드시 기억해야 한다. 맞춤 탭에서는 텍스트의 가로·세로 정렬뿐만 아니라 '텍스트 줄 바꿈', '셀에 맞춤', '병합하고 가운데 맞춤' 등을 설정할 수 있다. 여기서 '셀에 맞춤'은 열 너비에 맞춰 글자 크기를 자동으로 줄여 표시하는 기능으로, 열 너비를 줄여도 데이터가 잘리거나 '###' 형태로 숨겨지지 않는다. ⚠️ 단, '셀에 맞춤'과 '텍스트 줄 바꿈'은 동시에 적용할 수 없으며, 셀 병합 시 여러 셀에 데이터가 들어있다면 가장 왼쪽 위의 셀 내용만 남고 나머지 셀의 데이터는 모두 삭제된다는 점에 주의해야 한다.

사용자 지정 서식은 기존 표시 형식으로 나타낼 수 없는 고유한 형태를 서식 코드로 직접 정의할 때 사용한다. 기본 구조는 **양수; 음수; 0; 텍스트**의 순서로 세미콜론(;)을 구분자로 하여 구역을 나눈다. 각 구역에는 조건이나 글꼴 색을 대괄호 `[ ]` 안에 지정할 수 있다. 

| 서식 코드 | 의미 및 특징 |
| :--- | :--- |
| `0` | 유효하지 않은 자릿수라도 반드시 0을 표시 (자릿수 고정) |
| `#` | 유효하지 않은 0은 표시하지 않고 생략 |
| `?` | 유효하지 않은 0 대신 공백을 표시하여 소수점 위치를 맞춤 |
| `,` | 천 단위 구분 기호로 사용되며, 서식 끝에 붙으면 1,000단위씩 생략 |
| `@` | 입력된 텍스트 자체를 의미 (예: `@ "귀하"` → 홍길동 입력 시 "홍길동 귀하") |
| `*` | 기호 바로 뒤에 오는 특정 문자를 셀의 남은 너비만큼 반복 채움 |

날짜 서식에서는 연도를 `yy` 또는 `yyyy`, 월을 `m`~`mmmm`, 요일을 `aaa`(월) 또는 `aaaa`(월요일)로 표현한다. ⚠️ 특히 시간의 분을 나타내는 `m`과 날짜의 월을 나타내는 `m`의 혼동에 유의해야 하며, 24시간을 초과하는 누적 시간을 표시할 때는 `[h]`와 같이 대괄호로 묶어야 시간 계산이 누적되어 표시된다.

조건부 서식은 셀 값이 특정 조건을 만족할 때에만 지정된 서식(글꼴, 채우기, 테두리 등)이 자동으로 적용되도록 하는 기능이다. 
- 단일 셀 값 기준뿐만 아니라 수식을 사용하여 조건을 지정할 수 있으며, 수식으로 조건을 작성할 때는 반드시 등호(`=`)로 시작해야 한다.
- 행 전체에 서식을 적용하고자 할 때는 수식 작성 시 열 문자에만 절대 참조를 걸어 `$A1>80`과 같은 혼합 참조 형태를 취해야 한다.
- 여러 개의 조건부 서식 규칙이 충돌하는 경우, 규칙 관리자 창에서 가장 위에 있는 규칙이 우선순위를 갖는다. ⚠️ 단, 조건부 서식으로는 글꼴 크기 변경, 셀 잠금, 텍스트 줄 바꿈 등의 서식은 변경할 수 없으며 오직 글꼴 스타일, 색, 테두리, 채우기 등만 변경 가능하다는 제약이 시험에 자주 출제된다.

반복되는 서식 작업의 효율을 높이기 위해 스타일과 서식 파일이 활용된다. '셀 스타일'은 글꼴, 크기, 맞춤, 테두리, 음영 등 여러 서식 요소를 하나의 묶음으로 정의해 둔 것이다. 정의된 셀 스타일을 수정하면 해당 스타일이 적용되어 있던 모든 셀의 서식이 자동으로 한 번에 갱신된다. 통합 문서 전체의 일관된 디자인을 유지할 때는 글꼴, 색, 효과가 세트로 구성된 '테마'를 적용한다. 

자주 사용하는 표 양식이나 계산 틀, 특정 서식 설정을 템플릿 형태로 저장해 둘 때는 서식 파일(`.xltx`)을 사용한다. 🔢 기본 템플릿으로 사용하려면 파일명을 `Book.xltx`로 지정하여 Excel의 `XLStart` 폴더에 저장해야 하며, 이렇게 설정하면 새 문서를 열 때마다 해당 서식이 기본 적용된 상태로 실행된다. 매크로가 포함된 서식 파일의 확장자는 `.xltm`이다.


## 📚 Chapter 03. 데이터 계산


### 1. 기본 계산식

- 셀 참조 방식 이해
- 수식 입력, 수식 편집
- 내장함수를 사용한 수식 입력
- 시트 및 통합 문서 간 수식 계산
- 오류 메시지 처리

<!-- ai-draft: LLM 초안 — 검수 필요 -->

스프레드시트에서 계산식은 데이터 분석과 자동화의 출발점이다. 엑셀의 모든 수식은 등호(`=`) 또는 연산 부호(`+`, `-`)로 시작해야 하며, 수식을 입력한 후 Enter를 누르면 결과값이 셀에 표시되고 실제 수식은 수식 입력줄에 나타난다.

**수식 입력과 편집**
셀에 수식을 입력할 때 일반적인 계산식뿐 아니라 셀 주소와 텍스트, 비교 연산자 등을 조합할 수 있다. 문자열을 연결할 때는 `&` 연산자를 사용하며, 수식 내에서 고정된 텍스트는 반드시 큰따옴표(`" "`)로 묶어야 한다. 이미 입력된 수식을 수정하려면 해당 셀을 더블클릭하거나 수식 입력줄을 클릭해도 되지만, 단축키 🔢 `F2`를 눌러 빠르게 편집 상태로 전환하는 방식이 시험에 자주 출제된다. 또한, 여러 셀을 블록 지정한 상태에서 수식을 입력하고 🔢 `Ctrl + Enter`를 누르면 선택한 모든 셀에 동일한 수식이 한 번에 입력된다.

**셀 참조 방식 이해**
수식을 복사하거나 채우기 핸들을 끌어 다른 셀에 적용할 때 참조하는 셀 주소가 변하는 방식에 따라 세 가지로 나뉜다.
* 상대 참조: `A1`과 같이 표기하며, 수식이 입력된 셀의 위치가 바뀌면 참조하는 셀의 위치도 상대적인 방향과 거리만큼 함께 변한다.
* 절대 참조: `$A$1`과 같이 열 문자와 행 번호 앞에 모두 `$` 기호가 붙는다. 수식을 어느 위치로 복사하더라도 참조하는 셀이 고정되어 변하지 않는다.
* 혼합 참조: `$A1`(열 고정) 또는 `A$1`(행 고정)과 같이 행이나 열 중 한쪽에만 `$` 기호가 붙는다. 가로 또는 세로 방향 중 한쪽으로만 참조 위치를 고정할 때 사용한다.
참조 형태를 변경할 때는 수식 입력줄이나 편집 상태에서 해당 셀 주소에 커서를 두고 🔢 `F4` 키를 누르면 '상대 참조 → 절대 참조 → 행 고정 혼합 참조 → 열 고정 혼합 참조' 순으로 순환 변경된다.

**시트 및 통합 문서 간 수식 계산**
수식은 현재 작업 중인 워크시트 내부의 셀뿐만 아니라 다른 워크시트나 다른 통합 문서의 셀도 참조할 수 있다.
* 다른 워크시트 참조: `시트이름!셀주소` 형태로 작성한다. 예를 들어 `Sheet2!A1`은 Sheet2 시트의 A1 셀을 가리킨다. ⚠️ 만약 시트 이름에 공백(띄어쓰기)이나 특수문자, 숫자로 시작하는 이름이 포함되어 있다면 `'1분기 매출'!A1`과 같이 시트 이름을 반드시 작은따옴표(`' '`)로 묶어야 한다.
* 다른 통합 문서(파일) 참조: `[파일명.xlsx]시트이름!셀주소` 형태로 작성한다. 경로까지 포함될 경우 파일명 앞에 드라이브와 폴더 경로가 함께 붙는다.

**내장함수를 사용한 수식 입력**
엑셀이 제공하는 내장함수는 `함수명(인수1, 인수2, ...)` 구조를 갖는다. 함수를 직접 입력할 수도 있고, 수식 탭의 '함수 삽입' 아이콘을 누르거나 단축키 🔢 `Shift + F3`을 눌러 함수 마법사를 호출해 인수를 단계별로 지정할 수도 있다. 함수 내에 또 다른 함수를 인수로 사용하는 것을 '중첩 함수'라고 하며, 엑셀에서는 최대 64개까지 함수를 중첩할 수 있다.

**오류 메시지 처리**
수식이나 인수에 문제가 발생하면 엑셀은 원인에 따라 고유한 오류 메시지를 반환한다. 시험에서는 오류 화면을 제시하고 발생 원인을 묻거나, 잘못된 수식에서 유발되는 오류를 찾는 문제가 반복 출제되므로 각 오류의 특징을 정확히 구분해야 한다.

| 오류 메시지 | 발생 원인 |
| --- | --- |
| `#####` | 열 너비가 좁아 숫자나 날짜를 모두 표시하지 못하거나, 날짜·시간 값이 음수일 때 |
| `#DIV/0!` | 숫자를 `0` 또는 빈 셀로 나누었을 때 |
| `#N/A` | 함수나 수식에서 참조하려는 값을 찾을 수 없을 때(주로 `VLOOKUP`, `MATCH` 등) |
| `#NAME?` | 함수 이름을 잘못 입력했거나, 정의되지 않은 이름, 따옴표가 누락된 텍스트를 수식에 썼을 때 |
| `#NULL!` | 교차하지 않는 두 영역의 교집합을 지정했을 때(교점 연산자인 공백을 잘못 사용한 경우) |
| `#NUM!` | 수식이나 함수에 잘못된 숫자 인수를 지정했거나, 결과값이 엑셀이 표현할 수 있는 범위를 벗어났을 때 |
| `#REF!` | 수식이 참조하던 셀이 삭제되거나 이동되어 참조 위치가 유효하지 않을 때 |
| `#VALUE!` | 잘못된 데이터 형식(예: 텍스트와 숫자의 사칙연산)을 연산에 사용했을 때 |

⚠️ `#####` 표시는 데이터 자체가 깨진 오류가 아니라 단순한 표시 너비 부족인 경우가 대부분이므로 열 너비를 넓혀주면 해결된다. 반면 `#REF!`는 행이나 열을 '삭제'했을 때 자주 발생하며, 수식 입력 오류인 `#NAME?`과 데이터 형식 오류인 `#VALUE!`의 차이를 묻는 지문이 자주 출제된다.


## 📚 Chapter 04. 데이터 관리


### 1. 기본 데이터 관리

- 데이터 정렬(기본, 사용자지정)
- 자동/고급 필터
- 텍스트 나누기
- 그룹 및 윤곽설정
- 중복된 항목 제거
- 데이터 유효성 검사

<!-- ai-draft: LLM 초안 — 검수 필요 -->

**데이터 정렬(기본, 사용자 지정)**

데이터 정렬은 많은 양의 데이터를 특정 기준에 따라 재배열하는 기능이다. [데이터] - [정렬 및 필터] - [정렬] 대화상자에서 실행하며, 값뿐만 아니라 셀 색, 글꼴 색, 조건부 서식 아이콘을 기준으로도 정렬할 수 있다.

🔢 정렬 기준은 최대 64개까지 추가할 수 있다.
정렬 방향은 기본적으로 위에서 아래로 행을 바꾸는 방식이지만, [옵션]을 통해 왼쪽에서 오른쪽(열 단위 정렬)으로 방향을 변경할 수도 있다.

오름차순 정렬 시 데이터 순서는 다음과 같이 결정된다.
숫자 → 텍스트(영문 소문자 → 대문자 → 한글) → 논리값(FALSE → TRUE) → 오류값 → 빈 셀

⚠️ 빈 셀은 오름차순이나 내림차순에 관계없이 항상 가장 마지막에 배치된다.
기본적으로 대/소문자를 구분하지 않으나, 정렬 옵션에서 대/소문자를 구분하도록 설정하면 오름차순 시 소문자가 대문자보다 먼저 정렬된다. 사용자가 '월, 화, 수…'나 직급 순서(부장, 과장, 대리 등)와 같이 특정한 순서대로 정렬하고자 할 때는 [사용자 지정 목록]에 등록하여 정렬 기준으로 적용한다.


**자동 필터와 고급 필터**

필터는 많은 양의 데이터 목록에서 지정한 조건에 만족하는 데이터(행)만 화면에 표시하고, 나머지 행은 숨기는 기능이다. 

| 구분 | 자동 필터 | 고급 필터 |
| :--- | :--- | :--- |
| **조건 설정** | 열 머리글의 드롭다운 목록에서 선택 | 워크시트 빈 영역에 조건 범위를 직접 작성 |
| **조건 결합** | 동일 열 내에서는 다중 선택 가능, 서로 다른 열은 AND 결합만 가능 | 동일 행(AND), 서로 다른 행(OR) 등 자유로운 결합 가능 |
| **결과 위치** | 원본 데이터 범위 위치에만 표시 | [현재 위치에 필터] 또는 [다른 장소에 복사] 선택 가능 |
| **고유 레코드** | 지원하지 않음 | [동일한 레코드는 하나만] 옵션 지원 |

자동 필터를 적용하면 각 열 머리글에 드롭다운 화살표 단추가 생기며, 필터가 적용된 열의 화살표는 깔때기 모양으로 변경된다. 
고급 필터의 조건 범위를 작성할 때는 첫 행에 원본 데이터의 열 레이블(필드명)을 정확히 입력해야 한다. 같은 행에 조건을 나란히 쓰면 AND 조건(모두 만족), 서로 다른 행에 엇갈려 쓰면 OR 조건(하나라도 만족)으로 처리된다. 만약 수식을 사용하여 조건을 지정할 경우, 조건 필드명은 원본 데이터의 필드명과 일치하지 않는 이름(예: '조건')을 사용하거나 비워두어야 한다.


**텍스트 나누기**

하나의 셀에 쉼표(,), 공백, 탭 등으로 묶여 입력된 데이터를 여러 셀(열)로 분리할 때 사용한다. [데이터] - [데이터 도구] - [텍스트 나누기]를 실행하면 텍스트 마법사가 실행된다.
분리 방식은 '구분 기호로 분리됨'과 '너비가 일정함' 중 하나를 선택할 수 있다. 텍스트 마법사 3단계에서는 분리할 각 열의 데이터 서식(일반, 텍스트, 날짜)을 지정할 수 있으며, 원하지 않는 열은 '열 가져오지 않음(건너뜀)'을 선택하여 추출 대상에서 제외할 수 있다.


**그룹 및 윤곽 설정**

많은 데이터를 일정한 계층 구조로 묶어 요약 정보를 쉽게 파악하도록 접거나 펼치는 기능이다. 윤곽은 데이터의 상하(행) 또는 좌우(열) 방향으로 설정할 수 있다.

🔢 윤곽은 행과 열 각각 최대 8개 수준까지 설정할 수 있다.
윤곽 기호는 데이터 왼쪽에 계층 단계(1, 2, 3...)와 축소/확대 기호(-, +) 형태로 표시된다. 숫자 '1' 버튼을 누르면 가장 상위 요약 정보만 나타나고, 번호가 커질수록 하위 상세 데이터가 펼쳐진다.
🔢 윤곽 기호를 숨기거나 다시 표시하는 바로 가기 키는 [Ctrl] + [8]이다.


**중복된 항목 제거**

목록에서 지정한 열(필드)의 데이터가 중복되는 행을 찾아, 첫 번째 항목만 남기고 나머지 중복된 행 전체를 한 번에 삭제하는 기능이다.
[데이터] - [데이터 도구] - [중복된 항목 제거]에서 기준이 될 열을 다중 선택할 수 있다. 예를 들어 '이름'과 '전화번호'를 모두 선택하면 두 열의 값이 완벽히 일치하는 행만 중복으로 판정되어 삭제된다.

⚠️ 중복된 항목 제거는 대소문자를 구분하지 않는다(대문자 'A'와 소문자 'a'를 동일한 값으로 판단). 또한 셀 하나만 지워지는 것이 아니라 해당 데이터가 포함된 '행 전체'가 영구 삭제되므로 주의해야 한다.


**데이터 유효성 검사**

셀에 데이터를 입력할 때 유효한 값만 입력되도록 규칙을 지정하여 입력 오류를 사전에 방지하는 기능이다.
제한 대상으로는 모든 값, 정수, 소수점, 목록, 날짜, 시간, 텍스트 길이, 사용자 지정(수식 입력)을 제공한다. '목록' 제한 대상을 선택하면 셀을 클릭했을 때 드롭다운 목록이 표시되어 목록 중에서 선택 입력하게 만들 수 있다.

- 설명 메시지: 셀을 마우스로 클릭(선택)했을 때 입력 안내 힌트를 띄운다.
- 오류 메시지: 유효성 조건에 맞지 않는 값을 입력하고 Enter를 쳤을 때 나타나며, 스타일에는 [중지], [경고], [정보] 세 가지가 있다. 
  - [중지]: 잘못된 값의 입력을 완전히 차단한다(취소 또는 다시 시도만 가능).
  - [경고], [정보]: 경고 창이 뜨지만 사용자의 선택에 따라 잘못된 값을 그대로 입력할 수 있다.

⚠️ 이미 데이터가 입력되어 있는 셀에 나중에 데이터 유효성 검사를 설정하더라도, 기존에 입력된 잘못된 데이터가 자동으로 삭제되거나 수정되지 않는다. 기존 잘못된 데이터는 [데이터 유효성 검사] - [잘못된 데이터]를 클릭하여 빨간색 타원으로 표시해 찾아내야 한다.


### 2. 데이터 분석

- 데이터 통합
- 데이터 표
- 부분합
- 목표값 찾기
- 시나리오 분석
- 피벗 테이블 및 피벗 차트

<!-- ai-draft: LLM 초안 — 검수 필요 -->

데이터 분석 기능은 방대한 양의 워크시트 데이터를 효율적으로 요약·집계하고, 다양한 조건 변화에 따른 결과를 예측하는 가상 분석(What-If 분석) 도구들을 포함한다. 시험에서는 각 기능의 실행 조건과 설정 옵션, 특징을 묻는 문제가 집중 출제된다.

**1. 데이터 통합**
데이터 통합은 서로 다른 위치나 시트, 심지어 다른 통합 문서에 분산된 데이터를 하나로 취합하는 기능이다.
- 계산 함수로 합계, 평균, 개수, 최댓값, 최솟값, 표준편차 등을 선택할 수 있다.
- 데이터의 형태가 다르더라도 '첫 행'과 '왼쪽 열' 기준 레이블을 일치시키면 레이블을 기준으로 통합할 수 있다.
- 텍스트 조건 검색 시 물음표(?), 별표(*)와 같은 와일드카드 문자를 사용할 수 있다.
- ⚠️ **주의**: '원본 데이터에 연결' 옵션은 통합할 데이터가 **다른 워크시트**나 **다른 통합 문서**에 있을 때만 체크할 수 있다. 동일한 워크시트 안의 데이터를 통합할 때는 이 옵션을 사용할 수 없다.

**2. 데이터 표**
수식에 포함된 특정 값(변수)이 바뀔 때 결과값이 어떻게 달라지는지 표 형태로 나열해 보여주는 기능이다.
- 변수의 개수에 따라 단일 변수(열 또는 행 방향) 표와 이중 변수(행과 열 방향 동시) 표로 구분된다.
- 결과 셀의 수식은 반드시 데이터 표의 범위 내에 포함되어 있거나 행/열 레이블의 교차점에 참조되어 있어야 한다.
- ⚠️ 데이터 표로 작성된 결과 영역은 배열 수식 형태(TABLE 함수)로 입력되므로, 표 내부의 일부 셀만 개별적으로 수정하거나 삭제할 수 없다.

**3. 부분합**
특정 항목을 기준으로 그룹화하여 각 그룹별 소계 및 총합계를 계산하는 기능이다.
- ⚠️ **필수 선행 작업**: 부분합을 실행하기 전, 그룹화할 기준 열을 반드시 **오름차순 또는 내림차순으로 정렬**해야 한다. 정렬하지 않고 실행하면 동일 항목이 흩어져 그룹마다 소계가 불필요하게 반복 생성된다.
- 부분합 실행 시 합계, 평균, 개수 등 다양한 요약 함수를 중첩 적용할 수 있다.
- 두 번째 이상의 함수를 추가할 때는 반드시 **[새로운 값으로 대치] 확인란을 해제**해야 기존 부분합이 유지되면서 누적된다.
- 부분합을 생성하면 좌측에 윤곽 기호(1, 2, 3...)가 생성되며, 하위 데이터를 접거나 펼쳐 원하는 수준의 요약만 표시할 수 있다.

**4. 목표값 찾기**
결과값은 이미 알고 있으나, 그 결과를 얻기 위해 필요한 하나의 입력값(원인)을 역으로 계산할 때 사용하는 기능이다.
- 수식 셀, 찾는 값, 값을 바꿀 셀 등 3가지 요소로 구성된다.
- ⚠️ '수식 셀'에는 반드시 수식이 입력되어 있어야 하며, '값을 바꿀 셀'은 다른 셀을 참조하는 수식이 아닌 순수 단일 상수값이어야 한다.
- 한 번에 하나의 변수(단일 셀)만 변경할 수 있다.

**5. 시나리오 분석**
다양한 변수 변화에 따른 결과값의 변화를 가상의 시나리오로 작성하여 비교하는 기능이다.
- 🔢 하나의 시나리오에는 최대 32개까지의 변경 셀을 지정할 수 있다.
- 시나리오를 작성하기 전 변경 셀과 결과 셀에 이름을 정의해 두면, 보고서 생성 시 셀 주소 대신 정의된 이름이 표시되어 가독성이 높아진다.
- 결과는 '시나리오 요약' 보고서나 '시나리오 피벗 테이블 보고서' 형태로 별도의 시트에 생성된다.
- ⚠️ 시나리오 요약 보고서는 원본 데이터와 실시간 연동되지 않으므로, 원본 데이터가 변경되어도 요약 보고서에 자동으로 반영되지 않는다(새로 만들어야 함).

| 구분 | 목표값 찾기 | 데이터 표 | 시나리오 관리자 |
| :--- | :--- | :--- | :--- |
| **목적** | 원하는 결과에 대한 입력값 역산 | 특정 변수 변화에 따른 결과표 작성 | 여러 상황에 따른 결과값 다각적 비교 |
| **변수 개수** | 1개 (단일 셀) | 1개 또는 2개 (행/열) | 최대 32개 |
| **결과 형태** | 기존 셀 값 직접 변경 | 배열 수식 형태의 표 | 별도 워크시트 보고서 |

**6. 피벗 테이블 및 피벗 차트**
방대한 데이터를 드래그 앤 드롭 방식으로 행, 열, 값, 필터 영역에 배치하여 자유롭게 요약·분석하는 대화형 보고서이다.
- 원본 데이터가 변경되어도 피벗 테이블에 자동으로 반영되지 않으므로, **[피벗 테이블 분석] - [데이터] - [새로 고침]**(단축키 🔢 **Alt + F5**)을 직접 실행해야 반영된다.
- 기본적으로 '값' 영역에 텍스트 데이터가 들어가면 '개수', 숫자 데이터가 들어가면 '합계'가 기본 요약 함수로 지정된다.
- 사용자가 직접 필드를 결합하여 사칙연산 등이 가능한 '계산 필드'를 추가할 수 있다. 단, 계산 필드는 다른 필드를 참조할 수 있지만 셀 주소(A1 등)는 직접 참조할 수 없다.
- 피벗 차트는 피벗 테이블과 항상 연동되어 작동한다. 피벗 차트에서 필드를 필터링하거나 배치 변경 시 피벗 테이블에도 즉시 반영된다.
- ⚠️ 피벗 차트에서는 분산형, 주식형, 거품형 차트 등의 일부 차트 종류를 사용할 수 없다. 또한, 피벗 테이블을 삭제하면 연동된 피벗 차트는 일반 표준 차트로 변경된다.


## 📚 Chapter 05. 차트 활용


### 1. 차트 작성

- 차트 작성 방법
- 차트 종류
- 차트 구성 요소

<!-- ai-draft: LLM 초안 — 검수 필요 -->

차트는 워크시트에 입력된 수치 데이터를 시각적으로 표현하여 데이터의 상호 관계나 변화 추세, 비교 결과를 한눈에 파악할 수 있도록 돕는 기능이다. 원본 데이터와 실시간으로 연결되므로 원본 데이터가 변경되면 차트의 내용도 자동으로 갱신된다.

**차트 작성 방법**

차트를 만들려면 먼저 차트에 반영할 데이터 범위를 지정해야 한다. 연속된 범위는 마우스 드래그로 선택하고, 서로 떨어져 있는 데이터 범위는 `Ctrl` 키를 누른 상태에서 각각 지정한다. 범위를 지정한 후 [삽입] 탭의 [차트] 그룹에서 원하는 차트 종류를 선택하면 기본 차트가 생성된다.

🔢 **차트 생성 단축키**
- `F11`: 현재 워크시트가 아닌 별도의 ‘Chart1’, ‘Chart2’와 같은 전용 차트 시트에 기본 차트를 생성한다.
- `Alt` + `F1`: 현재 작업 중인 워크시트에 포함된 차트(임베디드 차트)로 기본 차트를 생성한다.

차트 작성 시 기본적으로 숨겨진 행이나 열의 데이터는 차트에 표시되지 않는다. 숨겨진 데이터를 차트에 반영하려면 [차트 디자인] 탭의 [데이터 선택] 대화상자에서 [숨겨진 셀 및 빈 셀] 옵션을 변경해야 한다. 또한 이미 작성된 차트라도 데이터 범위를 마우스로 드래그하여 확장하거나 복사하여 붙여넣는 방식으로 계열을 쉽게 추가할 수 있다.

**차트 구성 요소**

차트는 여러 시각적 요소가 결합되어 완성된다. 시험에서는 각 구성 요소의 명칭과 설정 가능 여부를 묻는 문제가 자주 출제된다.

- **차트 영역과 그림 영역**: 차트 영역은 차트 전체를 둘러싼 외곽 영역이며, 그림 영역은 축과 데이터 계열이 실제로 그려지는 내부 영역을 뜻한다. 차트 영역의 서식을 변경하면 내부 요소 전체에 일괄 적용된다.
- **축(가로/세로/보조 축)**: 데이터의 기준을 나타낸다. 보통 가로(항목) 축에는 텍스트 항목이, 세로(값) 축에는 수치 눈금이 배치된다. 두 계열의 값 단위 차이가 클 때는 보조 세로(값) 축을 추가하여 이중 축 차트를 구성할 수 있다.
- **데이터 계열 및 레이블**: 데이터 계열은 워크시트의 실제 데이터 값을 막대, 선, 점 등으로 나타낸 그래픽 요소다. 데이터 레이블을 추가하면 각 요소 위에 실제 값, 항목 이름, 백분율 등을 직접 표시할 수 있다.
- **범례와 데이터 표**: 범례는 각 데이터 계열이 무엇을 나타내는지 색상이나 표식으로 구별해 주는 상자다. 기본 위치는 오른쪽이지만 위, 아래, 왼쪽 등으로 변경 가능하다. 데이터 표는 차트 하단에 원본 수치 표를 함께 보여주는 기능이다.
- **추세선**: 데이터의 변화 추세를 파악하기 위해 추가하는 선형, 다항식, 이동평균 등의 가늠선이다.

⚠️ **차트 구성 요소 주의점**
- 추세선은 2차원 차트(꺾은선형, 막대형, 분산형 등)에만 추가할 수 있으며, 3차원 차트, 원형, 도넛형, 방사형, 표면형 차트에는 추가할 수 없다.
- 원형 차트에는 가로(항목) 축이나 세로(값) 축, 눈금선이 존재하지 않는다.

**주요 차트 종류 및 특징**

데이터의 특성과 전달하려는 목적에 맞춰 적절한 차트 종류를 선택해야 한다.

| 차트 종류 | 주요 특징 및 출제 포인트 |
| --- | --- |
| 막대형(세로/가로) | 항목 간의 값 비교에 가장 적합한 차트다. 가로 막대형은 항목 이름이 길거나 계열 수가 많을 때 유용하다. |
| 꺾은선형 | 시간의 경과에 따른 데이터의 변동 추세를 연속적으로 나타낼 때 사용한다. 일정 간격의 시계열 데이터에 적합하다. |
| 원형 | 전체에 대한 각 부분의 비율을 파악하는 데 사용된다. **단 하나의 데이터 계열만** 표시할 수 있으며, 음수나 0은 표시할 수 없다. |
| 도넛형 | 원형 차트와 유사하게 비율을 나타내지만, **여러 데이터 계열**을 포함할 수 있다. 가운데 구멍의 크기(비율) 조절이 가능하다. |
| 분산형(XY) | 수치 데이터 간의 상관관계를 파악할 때 쓰인다. 가로 축이 항목이 아닌 수치 눈금으로 구성되며, 공학·과학 데이터 분석에 주로 쓰인다. |
| 방사형 | 가운데 중심점에서 뻗어 나오는 여러 축을 기준으로 데이터의 균형이나 특성을 한눈에 비교할 때 적합하다. |
| 거품형 | 분산형 차트의 확장 형태로, 세 번째 값 요소(거품 크기)를 추가하여 총 3개의 데이터(X, Y, 크기)를 한 번에 비교한다. |

⚠️ **혼동하기 쉬운 차트 비교**
- **원형 vs 도넛형**: 원형 차트는 무조건 1개의 데이터 계열만 표현할 수 있으나, 도넛형 차트는 동심원 형태로 2개 이상의 다중 데이터 계열을 표현할 수 있다.
- **꺾은선형 vs 분산형**: 꺾은선형의 가로 축은 일정한 간격의 ‘항목’을 나열하지만, 분산형의 가로 축은 ‘수치(값)’로 이루어져 데이터의 불규칙한 간격을 그대로 반영한다.
- **혼합형 차트 제한**: 2차원 차트에서 서로 다른 종류를 혼합하여 사용할 수 있으나, 3차원 차트나 원형, 도넛형, 방사형 등은 다른 차트와 혼합하여 작성할 수 없다.


### 2. 차트 편집

- 차트 종류 변경
- 차트 구성 요소 편집

<!-- ai-draft: LLM 초안 — 검수 필요 -->

차트 편집은 이미 생성된 차트의 종류를 바꾸거나 차트를 구성하는 세부 요소를 추가, 삭제, 서식 변경하여 가독성을 높이는 작업이다. 시험에서는 차트 종류 변경 시의 제약 조건과 각 구성 요소의 특징 및 서식 설정 방법이 자주 출제된다.

**차트 종류 변경**

작성된 차트는 언제든지 다른 차트 종류로 변경할 수 있다. 차트 영역을 선택한 후 [차트 디자인] 탭의 [차트 종류 변경]을 클릭하거나, 차트의 마우스 오른쪽 단추 메뉴를 이용한다. 

차트 전체의 종류를 일괄적으로 변경할 수도 있고, 특정 데이터 계열만 선택하여 다른 차트 종류로 지정하는 '혼합(콤보) 차트'를 만들 수도 있다. 혼합 차트는 서로 다른 성격의 데이터(예: 판매 수량과 매출액)를 하나의 차트에 동시에 나타낼 때 유용하며, 값의 단위 차이가 큰 경우 특정 계열을 '보조 축'으로 지정하여 표현한다.

⚠️ **혼합 차트 적용 시 주의사항**
- 혼합 차트는 2차원 차트에서만 구성할 수 있다. 3차원 차트는 계열별로 종류를 다르게 지정할 수 없다.
- 원형, 도넛형, 거품형, 방사형, 주식형 등 일부 차트는 다른 차트 종류와 혼합하여 작성할 수 없다.

---

**차트 구성 요소 편집**

차트는 차트 영역, 그림 영역, 데이터 계열, 축, 범례, 제목, 눈금선 등 다양한 독립된 요소로 이루어져 있다. 차트 우측 상단의 [차트 요소(➕)] 단추를 누르거나 [차트 디자인] 탭의 [차트 요소 추가]를 통해 각 요소를 손쉽게 삽입하거나 제거할 수 있다.

- **차트 영역과 그림 영역**: 차트 영역은 차트 전체를 둘러싼 외곽 영역이며, 그림 영역은 축으로 둘러싸인 실제 데이터가 그래프로 그려지는 영역이다. 3차원 차트에서는 그림 영역을 선택할 수 없다. 차트 영역의 서식을 변경하면 내부 요소 전체에 기본 글꼴이나 배경 등이 상속되지만, 개별 요소의 서식을 따로 변경하면 개별 서식이 우선 적용된다.
- **데이터 레이블**: 데이터 계열이나 특정 데이터 요소의 실제 값, 항목 이름, 계열 이름 등을 차트 위에 텍스트로 표시하는 기능이다. 전체 계열에 한 번에 레이블을 붙일 수도 있고, 특정 데이터 요소(막대 하나)만 다시 클릭하여 하나의 요소에만 레이블을 표시할 수도 있다. 레이블 위치는 위쪽, 아래쪽, 안쪽 끝, 가운데 등으로 자유롭게 변경된다.
- **축(가로/세로 축) 서식**: 데이터의 범위를 나타내는 축 서식에서는 최솟값, 최댓값, 주 단위, 보조 단위를 수동으로 고정할 수 있다. 값의 단위가 너무 크면 '표시 단위'(천, 백만, 십억 등)를 지정하여 축 레이블의 숫자를 간소화하고 단위를 별도로 표시할 수 있다. 또한 데이터의 편차가 극단적으로 클 때 사용하는 '로그 눈금 간격' 설정도 지원한다.
- **범례(Legend)**: 각 데이터 계열이 어떤 항목인지를 색상이나 표식으로 구분해 주는 요소이다. 범례의 위치는 상/하/좌/우/위쪽 등으로 이동할 수 있으며, 범례 자체를 삭제하더라도 원본 워크시트 데이터나 차트의 계열 데이터는 삭제되지 않는다. 또한 범례 내에서 특정 범례 항목만 선택하여 개별 삭제하는 것도 가능하다.
- **추세선(Trendline)**: 데이터의 변화 추세를 파악하기 위해 계열에 추가하는 선으로 선형, 로그, 다항식, 이동 평균 등 다양한 유형을 제공한다. 추세선은 하나의 계열에 둘 이상 추가할 수 있다.

⚠️ **추세선 추가가 불가능한 차트**
추세선은 2차원 차트 중에서도 연속적인 흐름을 표현할 수 있는 차트에만 적용된다. 3차원 차트, 원형, 도넛형, 방사형, 표면형 차트 등에는 추세선을 추가할 수 없다.

- **데이터 표**: 차트 아래쪽에 워크시트의 원본 수치 데이터를 격자 표 형태로 함께 표시하는 기능으로, 범례 표식을 함께 나타내도록 설정할 수 있다.

| 차트 구성 요소 | 주요 편집 기능 및 특징 | 시험 출제 포인트 |
| --- | --- | --- |
| **차트 제목 / 축 제목** | 수식 입력줄에 `=A1`과 같이 입력하여 특정 셀과 연동 가능 | 셀 연동 시 반드시 등호(=)를 먼저 입력해야 함 |
| **데이터 레이블** | 값, 백분율(원형 차트), 계열 이름, 항목 이름 표시 | 전체 계열 또는 특정 데이터 요소 단독 지정 가능 |
| **축(값 축)** | 최솟값, 최댓값, 주 단위, 보조 단위, 표시 단위 설정 | 주 단위를 변경해도 보조 눈금선의 간격은 자동 유지되지 않음 |
| **범례** | 위, 아래, 왼쪽, 오른쪽, 대각선 등 위치 지정 및 테두리 서식 | 범례 항목 삭제 시 차트 계열은 유지됨 |
| **추세선** | 특정 데이터 계열의 경향성 파악 (선형, 지수, 이동평균 등) | 3차원, 원형, 도넛형, 방사형 차트에는 추가 불가 |
| **데이터 표** | 차트 하단에 원본 데이터 표를 표시 | 범례 표식 표시 여부 선택 가능 |

🔢 **단축키 및 작업 팁**
- 차트 구성 요소를 더블클릭하거나, 요소를 선택한 상태에서 `Ctrl` + `1`을 누르면 해당 요소의 작업창(서식 창)이 바로 열린다.
- 차트 크기를 워크시트 셀 눈금선에 딱 맞추어 조절하려면 `Alt` 키를 누른 채 마우스로 차트의 모서리 조절점을 드래그한다.

- 크기 조정
- 시트 옵션

<!-- ai-draft: LLM 초안 — 검수 필요 -->

페이지 레이아웃 설정은 작성한 워크시트의 출력 형태와 화면 표시 방식을 제어하는 기능이다. 인쇄물의 가독성을 높이고 통일된 서식을 부여하기 위해 다양한 도구와 옵션을 제공한다.

**테마 변경**
[페이지 레이아웃] 탭의 [테마] 그룹에서는 통합 문서 전체의 글꼴, 색, 효과를 한 번에 변경할 수 있다. 기본 제공 테마를 선택하거나 사용자가 직접 색과 글꼴을 조합하여 새로운 테마 파일(.thmx)로 저장해 재사용할 수 있다.
⚠️ 테마는 워크시트 단위가 아닌 통합 문서 전체에 일괄 적용된다. 특정 시트나 일부 셀 범위에만 다른 테마를 적용할 수는 없다.

**페이지 설정과 크기 조정**
[페이지 설정] 대화상자는 인쇄 방향, 용지 종류, 여백 등을 세부적으로 제어한다.
- **용지 및 여백 설정**: 용지 방향(가로/세로), 여백 크기(상/하/좌/우/머리글/바닥글)를 지정한다. '페이지 가운데 맞춤'의 가로와 세로 항목을 체크하면 데이터가 용지의 정중앙에 출력되도록 정렬할 수 있다.
- **크기 조정(배율 설정)**: 워크시트 내용이 용지보다 클 때 수동으로 배율을 축소하거나, 지정한 용지 매수에 맞추어 자동으로 축소·확대 인쇄되도록 설정한다.
🔢 배율은 최소 10%부터 최대 400%까지 1% 단위로 설정할 수 있다.
'자동 맞춤'에서 용지 너비와 높이를 각각 '1'로 지정하면 많은 양의 데이터가 축소되어 1페이지 안에 모두 인쇄된다. 단, 차트 시트에서는 배율 축소/확대 기능이 비활성화된다.

**시트 옵션**
화면 표시와 인쇄 출력을 분리하여 제어할 수 있는 기능이다.
- **눈금선과 행/열 머리글**: 워크시트의 셀 구분선(눈금선)과 행 번호·열 문자(머리글)는 기본적으로 화면에는 보이지만 인쇄되지는 않는다. 이를 출력물에 포함하려면 [시트 옵션] 그룹이나 [페이지 설정] 대화상자의 [시트] 탭에서 각각 '인쇄' 항목에 체크해야 한다.
- **인쇄 영역 및 인쇄 제목**: 특정 영역만 골라 인쇄하도록 '인쇄 영역'을 지정할 수 있다. 또한 데이터가 여러 페이지로 넘어갈 때 각 페이지 상단이나 좌측에 제목 행·열이 반복되도록 '반복할 행'이나 '반복할 열'을 설정한다.
- **기타 인쇄 옵션**: 흑백으로 인쇄, 간단하게 인쇄(도형·서식 제외), 메모 인쇄(시트 끝 또는 시트에 표시된 대로), 셀 오류 표시 방법(공백, --, #N/A 등)을 지정할 수 있다.
⚠️ [페이지 나누기 미리 보기] 상태나 [인쇄 미리 보기] 창에서 [페이지 설정] 대화상자를 호출하면 '인쇄 영역'과 '반복할 행/열' 설정 상자가 비활성화되어 수정할 수 없다. 이들 항목은 반드시 기본 워크시트 편집 화면에서 설정해야 한다.

**머리글/바닥글 도구 사용**
머리글과 바닥글은 인쇄 시 각 페이지의 상단과 하단 여백 영역에 자동으로 반복 출력되는 텍스트나 그래픽 정보를 말한다. 좌측, 가운데, 우측 3개 구역으로 나뉘어 입력할 수 있으며, 전용 제어 코드를 삽입하여 동적인 정보를 표시한다.

| 제어 코드 | 기능 및 표시 내용 |
| --- | --- |
| `&[페이지 번호]` | 현재 인쇄되는 페이지 번호 표시 |
| `&[전체 페이지 수]` | 전체 인쇄 대상 페이지의 총수 표시 |
| `&[날짜]` / `&[시간]` | 인쇄가 진행되는 현재 시스템 날짜 / 시간 표시 |
| `&[파일 이름]` / `&[시트 이름]` | 통합 문서의 파일명 / 현재 작업 중인 워크시트 이름 표시 |
| `&[파일 경로]` | 파일이 저장된 드라이브 및 폴더 경로 표시(단독 또는 파일 이름과 조합) |
| `&[그림]` | 로고나 서명 등의 이미지 삽입(삽입 후 [그림 서식] 도구로 크기 조정) |

머리글/바닥글 옵션 중 '짝수와 홀수 페이지를 다르게 지정'을 선택하면 양면 인쇄 시 책 형태의 레이아웃을 구성할 수 있다. '첫 페이지를 다르게 지정'을 사용하면 표지 역할을 하는 첫 페이지의 머리글/바닥글을 비워두거나 다른 내용으로 구성할 수 있다. '문서에 맞게 배율 조정'은 워크시트가 축소·확대 인쇄될 때 머리글/바닥글의 글꼴 크기도 비례하여 자동 조절되는 기능이다.

- 페이지 설정
- 인쇄 미리보기 설정
- 인쇄 옵션 설정
- 프린터 속성 설정

<!-- ai-draft: LLM 초안 — 검수 필요 -->

스프레드시트에서 작성한 방대한 데이터를 원하는 규격과 형태로 종이에 출력하려면 인쇄 환경을 세밀하게 제어해야 한다. 엑셀의 인쇄 작업은 크게 '페이지 설정', '인쇄 미리보기', '인쇄 옵션', 그리고 '프린터 속성'으로 나뉘며, 각 단계에서 지정할 수 있는 옵션의 차이를 묻는 문제가 자주 출제된다.

**페이지 설정(Page Setup)**

[페이지 레이아웃] 탭의 [페이지 설정] 대화상자는 크게 4개의 탭(페이지, 여백, 머리글/바닥글, 시트)으로 구성되어 있으며, 인쇄 결과물의 뼈대를 잡는 가장 핵심적인 메뉴다.

1. **페이지 탭**: 용지 방향(세로/가로)을 지정하고, 축소/확대 배율을 10%부터 최대 400%까지 설정할 수 있다. 너비와 높이를 각각 '1'로 지정하는 '자동 맞춤'을 선택하면 데이터 양에 상관없이 지정한 페이지 수에 맞춰 자동으로 확대/축소된다.
2. **여백 탭**: 상·하·좌·우 여백과 머리글·바닥글 여백을 설정한다. 특히 '페이지 가운데 맞춤'의 가로/세로 체크 상자를 이용하면 데이터가 용지의 정가운데에 출력되도록 정렬할 수 있다.
3. **머리글/바닥글 탭**: 매 페이지 상단이나 하단에 고정으로 출력될 텍스트나 정보를 지정한다. 페이지 번호(&[페이지 번호]), 전체 페이지 수(&[전체 페이지 수]), 현재 날짜(&[날짜]), 파일 이름(&[파일 이름]), 시트 이름(&[시트]) 등의 도구를 삽입할 수 있다. '짝수와 홀수 페이지를 다르게 지정'하거나 '첫 페이지를 다르게 지정'하는 옵션도 지원한다.
4. **시트 탭**: 반복 출력할 행/열이나 출력 세부 항목을 다룬다.
- **반복할 행/열**: 표의 제목 줄처럼 매 페이지마다 반복되어야 하는 행($1:$1 등)이나 열을 지정한다. ⚠️ [페이지 설정] 대화상자를 [인쇄 미리보기] 상태에서 열었을 때는 '인쇄 영역'과 '반복할 행/반복할 열'을 새로 설정하거나 수정할 수 없다는 점이 시험에 아주 자주 출제된다. 반드시 일반 시트 편집 상태에서 [페이지 레이아웃] 탭을 통해 열어야 한다.
- **인쇄 항목 제어**: 눈금선 출력 여부, 흑백으로 인쇄, 간단하게 인쇄(도형이나 차트 등 그래픽 요소를 제외하고 텍스트만 빠르게 인쇄), 행/열 머리글(A, B, C... 및 1, 2, 3...) 인쇄 여부를 선택한다.
- **셀 오류 표시**: 셀에 #N/A, #DIV/0! 등의 오류가 있을 때 이를 '<공백>', '--', '#N/A' 등으로 변경하여 인쇄하도록 지정할 수 있다.

| 탭 구분 | 핵심 설정 항목 | 시험 빈출 포인트 |
| :--- | :--- | :--- |
| **페이지** | 용지 방향, 배율(10~400%), 자동 맞춤 | 자동 맞춤 시 축소/확대 배율이 자동 계산됨 |
| **여백** | 상·하·좌·우 여백, 페이지 가운데 맞춤 | 가로/세로 중앙 정렬 지원 |
| **머리글/바닥글** | 페이지 번호, 날짜, 파일 경로, 그림 삽입 | 홀/짝수 페이지 다르게 지정 가능 |
| **시트** | 인쇄 영역, 반복할 행/열, 눈금선, 메모 | 미리보기 상태에서는 반복할 행/열 편집 불가 |

**인쇄 미리보기 설정**

🔢 단축키 [Ctrl] + [F2] 또는 [Ctrl] + [P]를 누르면 백스테이지(Backstage) 형태의 인쇄 화면으로 이동하며, 오른쪽 창에서 인쇄 미리보기가 표시된다.
미리보기 창의 오른쪽 하단에는 '여백 표시'와 '페이지 확대/축소' 아이콘이 위치한다. '여백 표시'를 켜면 마우스 드래그만으로 여백 크기와 각 열의 너비를 즉석에서 조절할 수 있다. 단, 미리보기 화면에서 셀의 데이터 내용 자체를 직접 수정할 수는 없다.

**인쇄 옵션 설정**

출력 범위와 매수를 결정하는 단계로, 인쇄 창 좌측의 드롭다운 메뉴를 통해 설정한다.
- **인쇄 대상**: 현재 작업 중인 시트만 출력하는 '활성 시트 인쇄', 파일 내 모든 시트를 출력하는 '전체 통합 문서 인쇄', 사용자가 마우스로 드래그한 특정 셀 범위만 출력하는 '선택 영역 인쇄' 중 하나를 선택할 수 있다.
- **페이지 범위**: 전체가 아닌 특정 페이지만 출력하고자 할 때 '시작 페이지'와 '끝 페이지' 번호를 입력한다.
- **한 페이지에 시트 맞춤**: 축소 배율을 일일이 계산하지 않고도 시트 전체를 한 페이지에 강제로 맞춰 인쇄하거나, 모든 열을 한 페이지에 맞추기, 모든 행을 한 페이지에 맞추기 옵션을 바로 적용할 수 있다.
- **한 면/양면 인쇄 및 한 부씩 인쇄**: 프린터 지원 여부에 따라 양면 인쇄를 선택할 수 있으며, 다중 복사 시 '1, 2, 3 - 1, 2, 3' 형태로 묶어 출력하는 '한 부씩 인쇄' 여부를 지정한다.

**프린터 속성 설정**

인쇄 화면 상단의 [프린터 속성] 링크를 클릭하면 현재 연결된 프린터의 고유 드라이버 설정 창이 열린다. 이는 엑셀 프로그램 고유의 기능이 아니라 Windows 운영체제 및 해당 프린터 하드웨어가 제공하는 제어 환경이다.
이곳에서는 컬러/흑백 인쇄 모드, 출력 해상도(인쇄 품질, dpi 단위), 급지 트레이 선택(용지 공급원), 양면 인쇄 세부 방향(긴 쪽으로 넘김/짧은 쪽으로 넘김), 용지 종류(일반 용지, 포토 용지 등)와 같은 하드웨어 종속적인 옵션을 설정한다. ⚠️ '기본 프린터'는 Windows 제어판의 [장치 및 프린터]에서 1대만 지정할 수 있으며, 네트워크에 연결되어 있더라도 엑셀 시트 설정과는 별개로 프린터 드라이버 차원에서 최종 출력 형식을 통제한다.

매크로는 반복적으로 수행하는 일련의 작업 명령과 순서를 기록해 두었다가, 필요할 때마다 한 번의 명령이나 바로 가기 키로 자동 실행하는 기능이다. 엑셀에서 매크로를 기록하면 사용자의 마우스 클릭과 키보드 입력 작업이 VBA(Visual Basic for Applications) 프로그래밍 언어 코드로 자동 변환되어 저장된다.

**매크로의 특징과 저장 위치**
매크로가 포함된 통합 문서는 일반 통합 문서 형식(.xlsx)으로 저장할 수 없으며, 반드시 매크로 사용 통합 문서(.xlsm) 또는 바이너리 통합 문서(.xlsb) 형식으로 저장해야 한다. 매크로 저장 위치는 세 가지 중 하나를 선택한다.
- 현재 통합 문서: 현재 작업 중인 파일 내에서만 해당 매크로를 사용한다.
- 새 통합 문서: 새로 만들어지는 빈 통합 문서에 매크로를 저장한다.
- 개인용 매크로 통합 문서: `PERSONAL.XLSB`라는 특수 파일에 저장되며, 엑셀을 실행할 때마다 백그라운드에 자동으로 열리므로 모든 통합 문서에서 해당 매크로를 공유하여 사용할 수 있다.

⚠️ 매크로를 실행하여 변경된 시트 내용이나 작업 결과는 [실행 취소(Ctrl + Z)]로 되돌릴 수 없으므로 실행 전 주의해야 한다.

**매크로의 생성(기록)**
매크로는 [개발 도구] 탭의 [코드] 그룹에서 [매크로 기록]을 클릭하여 생성한다. 기록 시작 시 나타나는 [매크로 기록] 대화상자에서 다음과 같은 속성을 설정한다.

| 설정 항목 | 설정 규칙 및 주의사항 |
| --- | --- |
| 매크로 이름 | 첫 글자는 반드시 문자(한글, 영문)로 시작해야 하며, 공백이나 특수문자는 사용할 수 없다. 단, 밑줄(_)은 사용 가능하다. |
| 바로 가기 키 | 기본적으로 Ctrl과 영문 소문자의 조합으로 지정한다. 대문자를 입력하면 자동으로 Ctrl + Shift + 대문자 형태로 지정된다. |
| 저장 위치 | '개인용 매크로 통합 문서', '새 통합 문서', '현재 통합 문서' 중 선택한다. |
| 설명 | 매크로에 대한 부가적인 주석을 남길 수 있으며, 실행에는 영향을 주지 않는다. |

🔢 매크로 바로 가기 키에 이미 엑셀에 내장된 단축키(예: Ctrl + C, Ctrl + V)를 할당하면, 기존 엑셀 단축키보다 사용자가 지정한 매크로 바로 가기 키가 우선 적용된다. 단, 바로 가기 키에는 숫자가 올 수 없다.

매크로를 기록할 때는 기본적으로 셀 주소가 고정되는 '절대 참조' 방식으로 기록된다. 활성 셀의 위치에 따라 상대적으로 작업을 수행하도록 만들려면 기록 전이나 도중에 [상대 참조로 기록]을 활성화해야 한다.

**매크로의 수정과 삭제**
매크로 기록 중에는 기존 매크로의 코드를 수정할 수 없으며, 작업이 끝나면 반드시 [기록 중지]를 눌러야 한다. 매크로 내용을 변경하거나 편집하려면 [매크로] 대화상자(단축키 🔢 Alt + F8)에서 해당 매크로를 선택한 뒤 [편집]을 클릭한다. 이때 Visual Basic Editor(VBE, 단축키 🔢 Alt + F11) 창이 열리며 모듈(Module) 내에 작성된 VBA 코드를 직접 수정할 수 있다. 더 이상 필요 없는 매크로는 [매크로] 대화상자에서 매크로를 선택하고 [삭제] 단추를 누르면 제거된다.

**매크로 실행 및 컨트롤 연계**
기록된 매크로는 지정된 바로 가기 키를 누르거나, [매크로] 대화상자(Alt + F8)에서 [실행]을 클릭하여 작동시킬 수 있다. 사용자의 편의를 높이기 위해 시트 내의 다양한 개체와 매크로를 연계할 수도 있다.
- 양식 컨트롤 단추: [개발 도구] - [삽입] - [양식 컨트롤]에서 [단추]를 선택하여 워크시트에 드래그하는 순간 자동으로 [매크로 지정] 대화상자가 표시된다. 실행할 매크로를 선택하고 확인을 누르면 클릭 한 번으로 매크로를 실행하는 단추가 완성된다.
- 도형 및 그래픽 개체: 직사각형, 원, 스마트아트 등 일반 도형이나 그림 개체도 매크로와 연결할 수 있다. 도형을 삽입한 후 마우스 오른쪽 단추로 클릭하여 바로 가기 메뉴에서 [매크로 지정]을 선택하면 원하는 매크로를 연결할 수 있다.

⚠️ 양식 컨트롤의 '단추'는 시트에 그릴 때 [매크로 지정] 창이 자동으로 나타나지만, 일반 '도형'은 자동으로 뜨지 않으므로 사용자가 마우스 우클릭 후 직접 [매크로 지정]을 실행해야 한다. 또한 ActiveX 컨트롤은 이벤트 프로시저 코드를 직접 작성하는 방식으로 연동하므로 단순 매크로 지정 방식과는 차이가 있다.
