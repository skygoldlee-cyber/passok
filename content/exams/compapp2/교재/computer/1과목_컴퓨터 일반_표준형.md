Windows는 그래픽 사용자 인터페이스(GUI)를 기반으로 선점형 멀티태스킹을 지원하며, PnP(Plug and Play) 기능을 통해 새로운 하드웨어를 연결하면 운영체제가 드라이버를 자동으로 인식하고 설정한다. 255자까지 긴 파일 이름을 지정할 수 있으며, 공백을 포함할 수 있으나 `\ / : * ? " < > |`의 9개 특수문자는 파일명에 사용할 수 없다.

마우스와 키보드는 Windows 조작의 기본이다. 연속된 여러 항목을 선택할 때는 Shift를 누른 채 클릭하고, 서로 떨어져 있는 비연속 항목을 선택할 때는 Ctrl을 누른 채 클릭한다. 열려 있는 창 사이를 전환할 때는 🔢 Alt + Tab(작업 목록 전환 창 표시)이나 🔢 Windows 로고 키 + Tab(작업 보기 실행)을 사용한다. 활성 창만 화면을 캡처할 때는 🔢 Alt + Print Screen을, 전체 화면 캡처는 🔢 Print Screen을 누른다. 

시작 메뉴는 설치된 앱 목록 확인 및 실행, 전원 관리(절전, 시스템 종료, 다시 시작), 사용자 계정 설정을 담당한다. 화면 하단(기본 위치)의 작업 표시줄은 현재 실행 중인 앱 아이콘과 알림 영역(트레이), 작업 표시줄 검색 상자, 작업 보기 단추 등으로 구성된다. 작업 표시줄은 상, 하, 좌, 우 네 방향으로 자유롭게 배치할 수 있으며, 화면의 최대 50%까지 크기를 조절할 수 있다. 작업 표시줄 잠금 상태에서는 크기나 위치를 변경할 수 없다.

바탕화면은 컴퓨터 작업의 시작 공간으로 바로 가기 아이콘과 파일, 폴더를 배치한다. 바탕화면 바로 가기 아이콘은 좌측 하단에 화살표 표시가 붙으며, 이를 삭제해도 원본 실행 파일은 삭제되지 않는다.

파일 탐색기(내 PC)는 파일과 폴더의 계층 구조를 관리하는 핵심 도구다. 🔢 Windows 로고 키 + E로 즉시 실행할 수 있다. 폴더 옵션에서는 파일 열기 방법(한 번 클릭해서 열기 또는 두 번 클릭해서 열기), 숨김 파일 및 폴더 표시 여부, 알려진 파일 형식의 파일 확장명 표시 여부 등을 지정할 수 있다.

파일 및 폴더의 복사, 이동, 삭제는 드래그 앤 드롭 동작 조건이 시험에 매우 자주 출제된다. 같은 드라이브 내에서 마우스로 끌어다 놓으면 '이동'이 되고, 서로 다른 드라이브 간에 끌어다 놓으면 기본적으로 '복사'가 된다. 강제로 동작을 고정하려면 단축키를 함께 사용해야 한다.

| 구분 | 마우스 드래그 동작 | 키보드 조합 단축키 |
| :--- | :--- | :--- |
| **복사** | 다른 드라이브로 드래그 (기본) | **Ctrl** + 드래그 |
| **이동** | 같은 드라이브로 드래그 (기본) | **Shift** + 드래그 |
| **바로 가기 만들기** | 마우스 오른쪽 단추로 드래그 후 선택 | **Ctrl + Shift** + 드래그 (또는 Alt + 드래그) |

파일이나 폴더의 이름을 바꿀 때는 해당 항목을 선택한 후 🔢 F2 키를 누른다.

휴지통은 삭제된 파일과 폴더가 임시 보관되는 장소로, 보관 중인 항목은 언제든지 원래 위치로 복원할 수 있다. ⚠️ 단, 휴지통 안에 들어 있는 상태에서는 파일을 직접 더블클릭하여 열거나 실행할 수 없으며, 반드시 복원한 후에 실행해야 한다. 또한 휴지통을 거치지 않고 영구 삭제되는 조건은 반드시 암기해야 한다.
- 🔢 Shift + Delete를 눌러 삭제한 경우
- 휴지통 속성에서 '파일을 휴지통에 버리지 않고 삭제할 때 즉시 제거'를 선택한 경우
- USB 메모리 등 이동식 디스크에서 파일을 삭제한 경우
- 네트워크 드라이브에서 공유된 파일을 삭제한 경우
- 휴지통 용량을 초과하는 대용량 파일을 삭제한 경우(단, 용량 초과 시 자동 영구 삭제 여부를 묻는 메시지가 나타남)

검색 기능은 작업 표시줄의 검색창이나 파일 탐색기 우측 상단 검색창을 활용한다. 와일드카드 문자인 `*`(모든 글자)와 `?`(해당 위치의 1글자)를 조합하여 조건 검색을 수행할 수 있다. 🔢 Windows 로고 키 + R을 누르면 '실행' 대화상자가 열리며, 명령어나 프로그램 이름을 직접 입력하여 즉시 실행할 수 있다.

Windows 보조프로그램에는 서식 없는 순수 텍스트만 작성·편집할 수 있는 메모장(확장자 .txt, 그림이나 표 삽입 불가), 캡처 및 스케치(화면 캡처), 그림판, 계산기 등이 제공된다.

인쇄 작업은 프린터 드라이버를 통해 제어된다. 여러 개의 인쇄 작업이 요청되면 스풀(SPOOL) 기능에 의해 하드디스크에 임시 저장된 뒤 백그라운드에서 순차적으로 인쇄되므로, 인쇄 중에도 다른 응용 프로그램을 계속 작업할 수 있다. 프린터 인쇄 대기열 창에서는 대기 중인 문서의 인쇄 순서를 변경하거나 일시 중지, 취소할 수 있다. ⚠️ 그러나 이미 프린터 본체 메모리로 전송되어 실제 출력이 진행 중인 문서는 인쇄 관리자에서 취소하더라도 즉각 멈추지 않고 잔여 버퍼 데이터가 출력된 후 중단된다. 기본 프린터는 여러 대 중 1대만 지정할 수 있으며, 인쇄 시 기본으로 선택되는 프린터를 뜻한다.

Windows의 [설정] 창은 운영체제의 전반적인 환경과 하드웨어, 소프트웨어를 제어하는 핵심 도구이다. Windows 10과 11에서는 과거 제어판에서 수행하던 대부분의 관리 작업이 [설정] 앱으로 통합 및 재편되었으므로, 각 범주별로 설정할 수 있는 세부 항목과 그 특징을 정확히 구분하여 암기해야 한다. 🔢 [설정] 창을 여는 기본 단축키는 [Windows 로고 키 + I]이다.

**시스템 설정**
컴퓨터의 가장 기본적인 하드웨어와 디스플레이, 전원 환경을 다룬다.
- 디스플레이: 화면 해상도, 방향(가로/세로), 야간 모드(블루라이트 차단), 다중 디스플레이(복제, 확장)를 지정한다.
- 소리: 출력 및 입력(마이크) 장치를 선택하고 볼륨을 조절한다.
- 알림 및 집중 지원: 앱과 시스템에서 보내는 알림 표시 여부와 방해 금지 시간대를 제어한다.
- 전원 및 배터리: 화면 꺼짐 시간, 절전 모드 진입 시간을 설정한다.
- 저장소(스토리지): 드라이브별 용량 사용 현황을 확인하며, 임시 파일이나 휴지통을 주기적으로 자동 비워주는 '저장 공간 센스(저장소 센스)'를 켤 수 있다.
- 정보: Windows 버전, 시스템 종류(32비트/64비트), 프로세서(CPU), 설치된 RAM 용량을 확인하고 컴퓨터 이름을 변경할 수 있다.

**Bluetooth 및 장치 설정**
PC에 연결되는 외부 주변기기를 관리한다. 마우스, 키보드, 펜, Bluetooth 오디오 기기를 페어링하거나 제거한다.
- 프린터 및 스캐너: 새 인쇄 장치를 추가하거나 기본 프린터를 지정한다. ⚠️ 네트워크 프린터를 설정할 때는 프린터의 포트와 고유 IP 주소를 확인해야 하며, 인쇄 스풀(Spool) 관련 기본 작업도 이 범주와 연계된다.
- 자동 실행: USB 메모리나 메모리카드 같은 이동식 미디어를 삽입했을 때 실행할 기본 동작을 설정한다.

**네트워크 및 인터넷 설정**
유선(이더넷) 및 무선(Wi-Fi) 연결, VPN, 모바일 핫스팟, 프록시 설정을 관리한다. 현재 연결된 네트워크 상태를 확인하고, 데이터 사용량을 모니터링하며, 문제 발생 시 '네트워크 초기화'를 통해 네트워크 어댑터를 공장 초기화 상태로 재설치할 수 있다.

**개인 설정**
사용자의 시각적 취향에 맞게 화면 요소를 꾸미는 영역이다.
- 배경(사진, 단색, 슬라이드 쇼), 색(라이트/다크 모드), 테마를 변경한다.
- 잠금 화면: PC가 잠겼을 때 표시할 배경 화면 및 상태 위젯을 지정한다.
- 작업 표시줄: 작업 표시줄 단추 하나로 표시(그룹화), 작업 표시줄 자동 숨기기, 모서리 아이콘(트레이 영역) 표시 여부를 설정한다. ⚠️ 작업 표시줄의 위치나 크기는 변경할 수 있으나, 작업 표시줄 자체를 삭제하는 것은 불가능하다.

**앱 설정**
설치된 응용 프로그램의 유지보수를 담당한다.
- 설치된 앱: 프로그램을 수정하거나 제거(삭제)한다.
- 기본 앱: 웹 브라우저, 전자 메일, 음악 플레이어 등 파일 형식(.확장자)이나 링크 유형별로 기본 실행할 앱을 지정한다.
- 시작프로그램: Windows가 부팅될 때 백그라운드에서 자동으로 실행될 앱을 켜거나 끌 수 있어 부팅 속도 최적화에 직결된다.

**계정 설정**
사용자 계정과 보안 인증 방식을 제어한다.
- 마이크로소프트(MS) 계정과 로컬 계정을 전환할 수 있다.
- 로그인 옵션: Windows Hello(얼굴 인식, 지문 인식, PIN), 보안 키, 일반 비밀번호 등 다양한 인증 수단을 등록한다.
- 가족 및 다른 사용자: 한 대의 PC를 여러 사람이 쓸 수 있도록 표준 사용자 계정이나 관리자 계정을 추가한다.

**시간 및 언어 설정**
표준 시간대, 시계 동기화, 지역 서식, 키보드 입력기 및 음성 언어 팩을 관리한다. 인터넷 시간 서버와의 자동 동기화를 켜면 시스템 시계의 오차를 자동으로 보정한다.

**게임 설정**
게임을 플레이하는 동안 화면을 캡처하거나 녹화하는 Xbox Game Bar 기능을 활성화하고, 게임 시 시스템 리소스를 게임에 우선 배정하여 프레임 레이트를 안정화하는 '게임 모드'를 켜거나 끌 수 있다.

**접근성 설정**
장애인이나 고령자 등 컴퓨터 사용에 어려움을 겪는 사용자를 배려하는 기능으로, 시험에 매우 빈출되는 영역이다.
- 시각: 텍스트 크기 확대, 마우스 포인터 색상 및 크기 변경, 화면의 텍스트를 음성으로 읽어주는 내레이터, 화면을 확대하는 돋보기, 시각적 대비를 극대화하는 대비 테마를 제공한다.
- 청각: 오디오를 모노로 전환하거나, 소리 알림 대신 화면이 깜빡이도록 시각적 신호로 대체한다.
- 상호작용(입력): 두 개 이상의 키를 동시에 누르기 힘든 사용자를 위해 [Shift], [Ctrl], [Alt] 키를 한 번 누른 상태로 고정시키는 '고정 키', 짧은 키 입력을 무시하는 '필터 키', [Caps Lock], [Num Lock], [Scroll Lock]을 누를 때 소리로 알려주는 '토글 키', 마우스 대신 숫자 패드로 커서를 이동하는 '마우스 키', 화면상에 키보드를 띄우는 화상 키보드 등을 제공한다.

**개인정보 및 보안 & Windows 업데이트 설정**
- 개인정보 및 보안: 앱이 카메라, 마이크, 위치 정보에 접근할 수 있는 권한을 개별 통제한다. 내장 백신 프로그램인 'Windows 보안(Microsoft Defender)'을 통해 바이러스 검사, 방화벽 상태 확인, 실시간 감시를 수행한다.
- Windows 업데이트: 운영체제의 최신 보안 패치와 기능 업데이트를 다운로드하여 설치한다. 업데이트 일시 중지, 사용 시간(재부팅 방지 시간대) 설정을 지원한다.

**컴퓨터의 기본 원리와 분류**
컴퓨터는 폰 노이만이 제안한 '프로그램 내장 방식'을 기반으로 동작한다. 이는 처리할 프로그램과 데이터를 주기억장치에 미리 저장해 두고 명령어를 순차적으로 읽어와 실행하는 원리이다. 컴퓨터는 정확한 데이터가 입력되어야 올바른 결과가 나온다는 GIGO(Garbage In, Garbage Out) 원칙을 따르며, 기본 기능으로는 입력, 기억, 연산, 제어, 출력의 5대 기능이 있다.

취급하는 데이터 형태에 따라 디지털 컴퓨터(이산적 데이터, 산술·논리 연산)와 아날로그 컴퓨터(연속적 물리량, 미·적분 연산), 두 방식을 결합한 하이브리드 컴퓨터로 분류한다. ⚠️ 디지털 컴퓨터는 프로그래밍이 필요하고 정밀도가 높은 반면, 아날로그 컴퓨터는 증폭 회로를 사용하여 연산 속도가 빠르지만 정밀도에 한계가 있어 프로그램이 불필요하다. 규모에 따라서는 슈퍼컴퓨터, 메인프레임, 미니컴퓨터, 마이크로컴퓨터(PC, 워크스테이션) 순으로 구분된다.

컴퓨터의 처리 속도는 🔢 ms($10^{-3}$) → $\mu$s($10^{-6}$) → ns($10^{-9}$) → ps($10^{-12}$) → fs($10^{-15}$) → as($10^{-18}$) 순으로 빨라지며, 성능 지표로는 클럭 주파수(Hz), 초당 백만 개 명령어를 처리하는 MIPS, 부동소수점 연산 능력을 나타내는 FLOPS 등이 쓰인다. 자료 표현 방식에서는 문자 코드가 자주 출제된다. BCD(6비트), 통신용으로 쓰이는 ASCII(7비트, 128자), 대형 컴퓨터용 EBCDIC(8비트, 256자)가 있으며, 전 세계 모든 문자를 2바이트(16비트) 이상으로 통일해 표현하는 코드는 유니코드(Unicode)이다.

**하드웨어 시스템 구성**
중앙처리장치(CPU)는 제어장치와 연산장치(ALU), 레지스터로 구성된다. 두 장치의 구성 요소를 구분하는 문제는 단골 출제 영역이다.

| 구분 | 주요 구성 레지스터 및 회로 | 주요 역할 |
| --- | --- | --- |
| 제어장치 | 프로그램 카운터(PC), 명령 레지스터(IR), 명령 해독기, 부호기 | 다음에 실행할 명령어 번지 기억(PC), 현재 실행 중인 명령어 보관(IR) 및 해석 |
| 연산장치 | 누산기(AC), 가산기, 보수기, 데이터 레지스터, 상태 레지스터 | 연산의 중간 결과 보관(누산기), 덧셈 수행(가산기), 뺄셈을 위한 보수 변환 |

기억장치는 주기억장치와 보조기억장치, 특수 기억장치로 나뉜다. 주기억장치인 ROM은 비휘발성으로 부팅 시 실행되는 BIOS(펌웨어)를 저장하고, RAM은 휘발성 메모리로 읽기/쓰기가 자유롭다. RAM 중 DRAM은 재충전(Refresh)이 필요하여 주기억장치로 쓰이고, SRAM은 속도가 빨라 CPU와 주기억장치 사이의 속도 차이를 극복하는 캐시 메모리(Cache Memory)로 쓰인다. 보조기억장치로는 자기디스크(HDD)와 반도체 기반의 고속·저전력 저장장치인 SSD가 있다. 그 외에 보조기억장치의 일부를 주기억장치처럼 쓰는 가상 메모리(Virtual Memory), 주소가 아닌 기억된 내용의 일부를 이용해 접근하는 연관(연상) 메모리가 있다.

입출력장치는 키보드, 마우스, 모니터, 프린터 등이 있으며, 장치 간 데이터 전송은 시스템 버스(데이터, 주소, 제어 버스)를 통해 이루어진다. 시스템에 예기치 않은 상황이 발생했을 때 CPU의 작업을 일시 중단하고 해당 상황을 먼저 처리하는 기법을 인터럽트(Interrupt)라고 하며, 하드웨어 고장 등의 외부 인터럽트, 0으로 나누기 등의 내부 인터럽트(트랩), 감시 프로그램 호출(SVC)인 소프트웨어 인터럽트로 구분된다.

**소프트웨어와 운영체제**
소프트웨어는 시스템 소프트웨어(운영체제, 컴파일러 등)와 응용 소프트웨어(한글, 엑셀 등)로 나뉜다. 시스템 소프트웨어의 핵심인 운영체제(OS)는 사용자와 하드웨어 사이의 인터페이스 역할을 하며, 목적은 처리 능력(Throughput) 향상, 반환 시간(Turn Around Time) 단축, 사용 가능도(Availability) 증대, 신뢰도(Reliability) 향상이다. 운영 방식에는 한 번에 모아서 처리하는 일괄 처리, 즉각 결과를 얻는 실시간 처리, 한 대의 컴퓨터로 여러 작업을 동시에 수행하는 다중 프로그래밍, CPU 시간을 쪼개어 여러 사용자에게 할당하는 시분할 시스템이 있다.

각종 유틸리티는 시스템 관리를 돕는 도구로, 디스크 조각 모음(최적화), 디스크 정리, 백신, 데이터 압축 프로그램 등이 대표적이다.

---

**PC 관리, 응급처치 및 업그레이드**
안정적인 PC 관리를 위해 직사광선과 습기, 정전기를 피하고 정기적으로 바이러스 검사를 수행해야 한다. 
- 시스템 부팅이 되지 않을 때는 전원 케이블 연결 상태, CMOS 셋업 설정값, RAM이나 그래픽 카드의 접촉 불량을 확인한다. 부팅 시 삑- 하는 비프음이 길게 반복되면 보통 메모리(RAM) 결착 오류이다.
- 부팅 과정에서 오류가 지속될 경우 최소한의 드라이버만 로드하는 '안전 모드'로 부팅하여 문제를 진단하거나 시스템 복원을 수행한다.
- ⚠️ PC 업그레이드 시 주의할 점: CPU 교체는 메인보드의 소켓 및 칩셋 지원 여부를 반드시 확인해야 한다. RAM을 증설하면 다중 작업 속도가 향상되며, 용량뿐 아니라 메인보드가 지원하는 규격(DDR 버전, 클럭 속도)을 맞춰야 한다. 장치 인식이나 호환성 문제를 해결하기 위해 메인보드의 BIOS ROM 데이터를 갱신하는 펌웨어 업데이트를 진행할 수도 있다. 드라이버 최신화나 운영체제 보안 패치는 소프트웨어적 업그레이드에 해당한다.

인터넷은 TCP/IP 프로토콜을 기반으로 전 세계의 수많은 컴퓨터와 네트워크가 하나로 연결된 거대한 컴퓨터 통신망이다. 미 국방성의 아르파넷(ARPANET)에서 시작되었으며, 중앙 통제 기구가 없는 분산 네트워크 구조를 띤다. 인터넷에 연결된 모든 컴퓨터는 고유한 식별 주소인 IP 주소를 부여받아 패킷 교환 방식으로 데이터를 주고받는다.

인터넷에 접속하여 웹 문서를 탐색할 수 있도록 돕는 소프트웨어를 웹 브라우저라고 하며, Microsoft Edge, Chrome 등이 대표적이다. 웹 브라우저 환경에서는 원활한 사용과 보안을 위해 다양한 설정 요소를 관리한다. '캐시(Cache)'는 재방문 시 로딩 속도를 높이기 위해 이미지 등 임시 인터넷 파일을 로컬 디스크에 저장하는 기능이며, '쿠키(Cookie)'는 사용자가 방문한 웹 사이트의 로그인 상태나 환경 설정 정보 등을 담고 있는 작은 텍스트 파일이다. ⚠️ 캐시는 데이터 재다운로드를 방지하여 속도를 향상시키지만 최신 웹 페이지 변경 사항을 즉시 반영하지 못할 때가 있으므로 주기적인 삭제가 필요하며, 쿠키는 개인정보 유출 위험이 있어 주의해야 한다. 🔢 브라우저에서 현재 페이지 새로 고침은 F5(또는 Ctrl + R), 캐시를 무시하고 완전히 새로 고치는 강력 새로 고침은 Ctrl + F5를 사용한다.

컴퓨터가 인터넷에 정상적으로 연결되려면 네트워크 속성에서 4가지 핵심 요소를 올바르게 설정해야 한다.
첫째, 'IP 주소'는 네트워크상에서 컴퓨터를 유일하게 구분하는 고유 주소이다. 현재 널리 쓰이는 IPv4는 32비트(8비트씩 4부분), 차세대 주소 체계인 IPv6는 128비트(16비트씩 8부분, 16진수 표기) 체계로 구성된다.
둘째, '서브넷 마스크(Subnet Mask)'는 IP 주소에서 네트워크 주소와 호스트 주소를 구별하기 위해 사용하는 마스크 값이다.
셋째, '기본 게이트웨이(Default Gateway)'는 서로 다른 네트워크 간에 데이터를 주고받을 때 다른 네트워크로 나가는 출입구 역할을 하는 장치(주로 라우터)의 주소이다. 게이트웨이가 잘못 설정되면 내부 네트워크끼리는 통신이 되지만 외부 인터넷 접속은 불가능하다.
넷째, 'DNS(Domain Name System) 서버'는 사용자가 입력한 문자 형태의 도메인 네임(예: www.korcham.net)을 컴퓨터가 이해하는 숫자 형태의 IP 주소로 상호 변환해 주는 서버이다.

웹 문서를 제작하고 제어하는 프로그래밍 언어도 시험에 단골로 출제된다. 'HTML'은 하이퍼텍스트와 멀티미디어를 표현하는 웹 문서의 표준 언어이다. 'XML'은 HTML의 한계를 극복하고 사용자가 새로운 태그를 직접 정의하여 데이터의 구조와 의미를 전달할 수 있도록 개발된 다목적 마크업 언어이다. 'CSS'는 HTML 문서의 레이아웃, 글꼴, 색상 등 전반적인 스타일을 일괄 지정할 때 사용한다. 'JavaScript'는 웹 브라우저 내에서 동작하며 동적인 대화형 웹 페이지를 제작할 때 쓰이는 객체 기반 스크립트 언어이다.

인터넷을 통해 제공되는 서비스는 웹 서핑(WWW) 외에도 파일 전송, 전자우편, 원격 접속 등 목적에 따라 전용 프로토콜을 사용한다.

| 인터넷 서비스 및 프로토콜 | 주요 특징 및 기능 |
| --- | --- |
| HTTP / HTTPS | 웹 문서를 전송하기 위한 기본 프로토콜. HTTPS는 SSL/TLS 암호화 기술을 적용하여 보안성을 강화함 |
| FTP (포트: 21) | 컴퓨터 간에 대용량 파일을 송수신하기 위한 파일 전송 프로토콜. 그림/실행 파일은 Binary, 텍스트는 ASCII 모드 사용 |
| SMTP (포트: 25) | 사용자가 작성한 전자우편(E-Mail)을 다른 서버로 전송(송신)하거나 서버 간에 전달할 때 사용 |
| POP3 (포트: 110) | 메일 서버에 도착한 전자우편을 사용자 로컬 컴퓨터로 가져올(수신) 때 사용하며, 수신 후 서버 메일은 기본 삭제됨 |
| IMAP (포트: 143) | 메일 서버에 이메일을 그대로 보관한 상태로 동기화하여 읽는 수신 프로토콜. 여러 장치에서 동일 메일함 접근 가능 |
| MIME | 텍스트만 전송 가능했던 전자우편 환경에서 이미지, 동영상, 압축 파일 등 다양한 멀티미디어 첨부 데이터를 지원하는 표준 규격 |
| Telnet / SSH | 원격지의 컴퓨터에 접속하여 명령을 수행할 수 있는 원격 접속 서비스. Telnet은 평문 전송(보안 취약), SSH는 암호화 전송 지원 |

⚠️ 전자우편 프로토콜의 송·수신 역할 혼동에 특히 주의해야 한다. 이메일을 '보낼 때'는 SMTP를, '받을 때'는 POP3나 IMAP을 사용한다. 또한, 전자우편의 헤더 중 '숨은 참조(Bcc)'로 지정된 수신자의 이메일 주소는 메일을 받은 다른 수신자들에게 공개되지 않는다는 점도 빈출 지문이다.

- 정보통신기술 관련 용어
- 모바일 기기 관련 용어
- 멀티미디어 관련 용어
- ICT 융합 관련 용어

<!-- ai-draft: LLM 초안 — 검수 필요 -->

최신 정보통신기술(ICT)은 컴퓨터활용능력 2급 필기에서 새로운 용어 위주로 출제 비중이 꾸준히 늘어나는 영역이다. 신기술의 단순 명칭 암기를 넘어 각 기술의 작동 원리와 적용 분야, 상호 간의 차이점을 명확히 구별해야 오답 함정을 피할 수 있다.

**1. 정보통신기술(ICT) 관련 핵심 용어**

네트워크와 컴퓨팅 자원을 효율적으로 다루기 위한 기술들이 주로 출제된다.
* **사물인터넷(IoT):** 사물에 센서와 통신 기능을 내장하여 인터넷에 연결하는 기술이다. 인간의 구체적인 개입 없이도 사물 간 협력하여 센싱, 네트워킹, 정보 처리 등 지능적 관계를 형성한다.
* **클라우드 컴퓨팅(Cloud Computing):** 하드웨어나 소프트웨어 같은 컴퓨팅 자원을 중앙 컴퓨터(서버)에 두고, 인터넷을 통해 언제 어디서나 필요한 만큼 대여하여 사용하는 방식이다.
* **빅데이터(Big Data):** 기존 데이터베이스 관리 도구로는 수집, 저장, 관리, 분석하기 어려운 방대한 양의 정형·비정형 데이터 집합이다. 데이터의 양(Volume), 생성 속도(Velocity), 다양성(Variety)의 '3V'가 핵심 요소다.
* **블록체인(Blockchain):** P2P(개인 간) 네트워크를 통해 거래 내역을 분산 저장하는 분산 원장 기술이다. 중앙 집중형 서버 없이 모든 참여자가 데이터를 공유하므로 위·변조가 매우 어렵다.

⚠️ **혼동 주의:** 사물인터넷(IoT)은 사물과 사물 간(M2M) 자율 통신을 전제로 하므로, 반드시 '사람의 직접적인 개입과 조작'이 있어야만 동작한다고 설명하면 오답이다.

**2. 모바일 기기 관련 기술과 용어**

스마트폰, 태블릿 등 휴대용 단말기와 관련된 근거리 무선 통신 기술이 집중 출제된다.
* **테더링(Tethering) 및 핫스팟(Hotspot):** 스마트폰의 모바일 데이터(LTE, 5G 등)를 다른 주변 기기(노트북, 태블릿)가 공유하여 인터넷을 쓸 수 있도록 스마트폰을 무선 공유기처럼 활용하는 기술이다.
* **블루투스(Bluetooth):** 2.4GHz ISM 대역을 이용해 약 10m 안팎의 근거리에서 디지털 기기를 무선으로 연결하는 기술이다.
* **NFC(Near Field Communication):** 13.56MHz 주파수를 이용하며, 10cm 이내의 매우 가까운 거리에서 데이터를 양방향 전송하는 비접촉식 근거리 무선 통신이다. 모바일 교통카드, 간편 결제 등에 널리 쓰인다.

| 기술 구분 | 통신 거리 | 주요 주파수 | 핵심 용도 및 특징 |
| :--- | :--- | :--- | :--- |
| **NFC** | 10cm 이내 (극근거리) | 13.56MHz | 전자 결제, 교통카드, 기기 간 간단한 페어링 |
| **블루투스** | 약 10m 내외 | 2.4GHz | 무선 이어폰, 스마트워치, 키보드·마우스 연결 |
| **RFID** | 수 cm ~ 수십 m | 다양(LF/HF/UHF) | 물류 유통 관리, 하이패스 (주로 단방향 인식) |

🔢 **암기 수치:** NFC 통신 거리는 **10cm 이내**, 주파수는 **13.56MHz**다. 통신 거리가 10m 이상이라는 지문은 단골 오답이다.

**3. 멀티미디어 관련 용어**

멀티미디어는 텍스트, 사운드, 그래픽, 동영상 등이 디지털 데이터로 통합된 형태를 말한다.
* **스트리밍(Streaming):** 인터넷에서 동영상이나 오디오 파일을 전체 다운로드 완료 후 재생하는 것이 아니라, 다운로드되는 데이터 흐름을 실시간으로 버퍼링하며 바로 재생하는 기법이다.
* **VOD(주문형 비디오)와 MOD(주문형 음악):** 사용자가 원하는 시간에 원하는 콘텐츠를 즉시 선택하여 시청하거나 감상할 수 있는 맞춤형 서비스다.
* **비손실 압축과 손실 압축:** 원본과 완전히 동일하게 복원되는 압축을 비손실(Lossless, ZIP, PNG, FLAC 등)이라 하고, 인간의 눈이나 귀가 감지하기 어려운 불필요한 데이터를 제거하여 높은 압축률을 얻는 방식을 손실(Lossy, JPG, MP3, MP4 등) 압축이라 한다.

**4. ICT 융합 기술 용어**

기존 산업과 정보통신기술이 결합하여 새로운 가치를 창출하는 융합 기술군이다.
* **메타버스(Metaverse):** 가상과 초월을 의미하는 '메타(Meta)'와 세계를 뜻하는 '유니버스(Universe)'의 합성어로, 가상현실(VR), 증강현실(AR) 기술을 통해 경제·사회·문화 활동이 이뤄지는 3차원 가상공간이다.
* **디지털 트윈(Digital Twin):** 현실 세계의 물리적 사물이나 환경을 가상 세계에 동일하게 컴퓨터 모델로 복제하고, 센서 데이터를 연동해 시뮬레이션함으로써 문제를 예측하고 최적화하는 기술이다.
* **인공지능(AI)과 딥러닝(Deep Learning):** 인간의 지능적 작업을 컴퓨터가 흉내 내는 기술이다. 특히 딥러닝은 인간의 뇌 신경망을 모방한 심층 인공신경망(ANN)을 기반으로 대량의 데이터에서 스스로 패턴을 학습한다.
* **핀테크(FinTech):** 금융(Financial)과 기술(Technology)의 합성어로, 모바일 송금, 간편 결제, 로보어드바이저 등 IT 기술을 접목한 혁신적 금융 서비스를 의미한다.

⚠️ **시험 함정:** 증강현실(AR)은 현실 배경에 가상의 이미지·정보를 겹쳐서 보여주는 방식(포켓몬 고 등)이고, 가상현실(VR)은 오로지 컴퓨터로 만든 100% 가상 환경만을 구현하는 방식이다. 두 개념을 뒤바꿔 기술하는 문제에 주의해야 한다.


### 3. 인공지능(AI) 기초 활용

- 인공지능(AI)의 이해
- 인공지능(AI)의 원리와 학습 개념
- 데이터와 기계학습의 이해
- 인공지능(AI)의 활용 사례
- 인공지능(AI)의 한계와 활용 시 유의사항

<!-- ai-draft: LLM 초안 — 검수 필요 -->

인공지능(AI; Artificial Intelligence)은 인간의 인지, 추론, 학습, 판단 등의 지적 능력을 컴퓨터 프로그램을 통해 모방하고 구현한 기술을 의미한다. 컴퓨터활용능력 시험에서는 인공지능, 기계학습(머신러닝), 심층학습(딥러닝) 간의 포함 관계를 구분하는 문제가 출제된다. 인공지능이 가장 넓은 범주이며, 그 안에 대량의 데이터를 바탕으로 규칙을 스스로 찾아내는 기계학습이 있고, 기계학습 중에서도 인간의 뇌 신경망 구조를 모방한 인공신경망 기반의 기술을 딥러닝이라고 부른다.

⚠️ **혼동 주의**: 인공지능이 머신러닝에 포함되는 것이 아니라, '인공지능 ⊃ 머신러닝 ⊃ 딥러닝'의 포함 관계를 갖는다.

기계학습은 컴퓨터가 프로그래머의 명시적인 규칙 코딩 없이도 데이터로부터 패턴을 학습하는 원리다. 학습에 사용하는 데이터의 형태와 목적에 따라 크게 세 가지 방식으로 분류된다.

| 학습 유형 | 개념 및 특징 | 대표 사례 및 알고리즘 |
| --- | --- | --- |
| 지도학습 (Supervised Learning) | 문제(입력 데이터)와 정답(레이블)을 함께 제공하여 학습시키는 방식 | 분류(스팸 메일 필터링, 이미지 판독), 회귀(주택 가격 예측) |
| 비지도학습 (Unsupervised Learning) | 정답(레이블) 없이 입력 데이터만 제공하여 숨겨진 패턴이나 군집을 찾는 방식 | 군집화(고객 세분화, 추천 시스템), 데이터 압축(차원 축소) |
| 강화학습 (Reinforcement Learning) | 에이전트가 환경과 상호작용하며 보상(Reward)을 극대화하는 방향으로 시행착오를 거치며 학습하는 방식 | 게임 AI(알파고), 자율주행 경로 제어, 로봇 보행 제어 |

기계학습과 딥러닝의 핵심 차이는 '특징 추출(Feature Extraction)'의 주체에 있다. 전통적인 기계학습은 사람이 직접 유의미한 특징을 정의하고 추출해 주어야 하지만, 딥러닝은 여러 층의 신경망(은닉층)을 거치며 데이터로부터 특징을 컴퓨터가 스스로 찾아낸다. 따라서 딥러닝은 비정형 데이터(이미지, 음성, 텍스트) 처리에 매우 강력하지만, 학습을 위해 방대한 양의 데이터와 높은 컴퓨팅 파워(GPU 등)를 필요로 한다.

인공지능은 다양한 산업과 실무에 널리 활용되고 있다.
- 자연어 처리(NLP): 챗봇, 기계 번역, 문서 요약 등 인간의 언어를 이해하고 생성하는 기술이다.
- 컴퓨터 비전: 얼굴 인식, 의료 영상 진단, 자율주행 차량의 사물 감지 등 시각 정보를 분석하는 기술이다.
- 생성형 AI(Generative AI): 대규모 언어 모델(LLM) 등을 기반으로 단순 분석을 넘어 텍스트, 이미지, 오디오, 소스 코드 등 새로운 콘텐츠를 스스로 만들어내는 인공지능이다.
- 업무 자동화(RPA + AI): 스프레드시트 데이터 입력, 송장 처리, 보고서 초안 작성 등 반복적이고 규칙적인 컴퓨터 작업을 지능적으로 자동화한다.

인공지능 기술은 업무 효율성을 극대화하지만, 명확한 한계와 위험 요소를 내포하고 있어 활용 시 각별한 주의가 요구된다.

⚠️ **인공지능 활용 시 유의사항 및 한계**
- 할루시네이션(환각 현상): 생성형 AI가 거짓된 정보나 사실이 아닌 내용을 마치 확실한 진실인 것처럼 그럴듯하게 꾸며내어 답변하는 현상이다. 따라서 AI가 생성한 결과물은 반드시 사용자가 사실 여부(팩트체크)를 직접 검증해야 한다.
- 데이터 편향성: AI 모델이 학습한 원천 데이터에 사회적 편견이나 특정 집단에 왜곡된 정보가 포함되어 있으면, 도출되는 판단과 예측 역시 불공정하고 편향된 결과를 낳는다.
- 설명 가능성의 한계(블랙박스 문제): 딥러닝 모델은 입력에 따른 출력 결과가 우수하더라도, 내부에서 어떤 추론 과정을 거쳐 그러한 결론에 도달했는지 논리적으로 명확히 설명하기 어렵다.
- 저작권 및 개인정보 침해: AI 학습 과정에서 타인의 저작물이나 비공개 개인정보를 무단 사용하는 문제, 사용자가 프롬프트(지시어)에 기업 기밀이나 민감한 개인정보를 입력하여 외부로 유출되는 위험이 있으므로 보안 규정을 준수해야 한다.

정보 사회가 고도화됨에 따라 컴퓨터 시스템을 안전하게 활용하고 디지털 자산을 올바르게 다루기 위한 윤리적·법적 기준의 중요성이 커지고 있다. 컴퓨터활용능력 시험에서는 정보 윤리의 기본 강령부터 저작권, 개인정보 보호, 그리고 최근 부각되는 인공지능 윤리까지 폭넓게 다룬다.

**1. 정보 윤리 기본**
정보 윤리는 정보 사회를 살아가는 구성원이 네트워크 공간에서 지켜야 할 올바른 행동 규범과 도덕적 기준을 뜻한다. 단순히 법률을 준수하는 소극적 태도를 넘어 타인의 권리와 인격을 존중하는 능동적 실천이 요구된다.
- **기본 원칙**: 정보 윤리의 4대 기본 원칙으로는 타인에게 피해를 주지 않는 '해악 금지의 원칙', 자신의 행동에 책임을 지는 '책임의 원칙', 정보 접근과 분배가 공평해야 한다는 '정의의 원칙', 인간의 자율성과 존엄성을 지키는 '인간 존중의 원칙'이 있다.
- **비도덕적 행위 유형**: 악성코드 유포, 불법 해킹, 허위 사실 유포, 악플(사이버 명예훼손 및 모욕) 등이 포함된다.
- ⚠️ 사이버 공간의 익명성과 비대면성은 정보 전달의 신속성을 돕지만, 책임 의식을 결여시켜 범죄와 윤리적 일탈을 쉽게 유발하는 요인이 된다. 인터넷 이용 시 '익명성이 보장되므로 모든 표현의 자유가 무제한 허용된다'는 보기는 대표적인 오답 함정이다.

**2. 저작권 보호**
저작권은 인간의 사상이나 감정을 표현한 창작물(저작물)에 대해 창작자가 가지는 배타적 권리다. 저작권법은 저작자의 권리와 이에 인접하는 권리를 보호하고 공정한 이용을 도모하여 문화 발전에 이바지함을 목적으로 한다.
- **저작권의 발생**: 저작권은 별도의 등록이나 절차를 밟지 않아도 창작한 순간부터 자동으로 발생한다(무방식주의). 
- **저작인격권과 저작재산권**: 저작인격권(공표권, 성명표시권, 동일성유지권)은 일신전속적 권리로 타인에게 양도하거나 상속할 수 없다. 반면, 저작재산권(복제권, 배포권, 2차적저작물작성권 등)은 전부 또는 일부를 양도하거나 상속할 수 있다.
- 🔢 **저작권 보호 기간**: 저작재산권은 원칙적으로 저작자가 생존하는 동안과 사망 후 70년간 존속한다.
- **소프트웨어 라이선스 구분**:
  - **상용 소프트웨어(Commercial)**: 정당한 대가를 지불하고 구입해야만 사용할 수 있는 프로그램이다.
  - **셰어웨어(Shareware)**: 정식 구매를 유도하기 위해 일정 기간(또는 기능)을 제한하여 무료 배포하는 프로그램이다.
  - **프리웨어(Freeware)**: 개인에 한해 기간 제한 없이 무료로 사용 가능한 프로그램이다(기업 이용 시 유료인 경우가 있으므로 주의).
  - **오픈소스 소프트웨어(OSS)**: 소스코드가 공개되어 있어 누구나 자유롭게 수정 및 재배포할 수 있는 소프트웨어다.

| 구분 | 주요 내용 | 양도/상속 가능 여부 |
| --- | --- | --- |
| 저작인격권 | 공표권, 성명표시권, 동일성유지권 | 불가능(일신전속권) |
| 저작재산권 | 복제권, 배포권, 공중송신권, 2차적저작물작성권 등 | 가능 |

**3. 개인정보 보호**
개인정보란 살아 있는 개인에 관한 정보로서 성명, 주민등록번호, 영상 등을 통해 개인을 알아볼 수 있는 모든 정보를 말한다. 특정 정보 하나만으로는 알 수 없더라도 다른 정보와 결합하여 쉽게 식별할 수 있는 정보도 포함된다.
- **수집 및 이용 원칙**: 개인정보처리자는 정보주체의 동의를 받아 필요한 최소한의 정보만을 적법하게 수집해야 한다. 목적 외 이용이나 제3자 무단 제공은 엄격히 금지된다.
- **민감정보와 고유식별정보**: 사상·신념, 건강, 성생활 등 사생활을 현저히 침해할 우려가 있는 정보(민감정보)나 주민등록번호, 여권번호, 운전면허번호(고유식별정보)는 원칙적으로 처리가 제한되며, 법령의 구체적 근거가 있거나 별도의 동의를 얻어야만 처리할 수 있다.
- ⚠️ 주민등록번호는 정보주체의 일반적인 동의만으로는 수집할 수 없으며, 반드시 법률에 구체적인 근거가 명시되어 있는 경우에만 처리가 가능하다.

**4. 인공지능(AI) 윤리**
생성형 AI와 지능형 시스템의 도입이 확산되면서 AI 개발과 활용 전반에 대한 윤리적 기준이 새로운 출제 요소로 자리 잡고 있다.
- **핵심 윤리 원칙**:
  - **인간 존엄성 및 투명성**: AI는 인간의 기본권을 침해하지 않아야 하며, AI가 내린 판단과 도출 결과는 인간이 이해하고 설명할 수 있어야 한다(설명 가능성).
  - **공정성과 편향 방지**: 학습 데이터의 왜곡으로 인해 특정 성별, 인종, 계층에 대한 차별적 결과를 도출하지 않도록 알고리즘의 공정성을 확보해야 한다.
  - **책임성**: AI 오작동이나 잘못된 의사결정으로 인해 발생한 피해에 대해 개발자와 운영 주체가 법적·윤리적 책임을 명확히 분담해야 한다.
  - **안전성과 프라이버시**: 방대한 데이터를 학습하는 과정에서 개인정보 침해나 저작권 무단 침해가 발생하지 않도록 철저한 데이터 정제 및 보호 장치를 마련해야 한다.

**컴퓨터 범죄의 유형과 예방 대책**

컴퓨터 범죄는 정보 통신망이나 컴퓨터 시스템을 악용하여 데이터와 프로그램을 위·변조하거나 유출, 파괴하는 행위를 말한다. 

주요 범죄 유형으로는 합법적인 사용자로 위장하여 시스템에 접근하는 스푸핑(Spoofing), 네트워크상에서 남의 패킷을 훔쳐보는 스누핑(Snooping) 및 스니핑(Sniffing)이 대표적이다. 또한 이메일이나 메신저를 통해 신뢰할 수 있는 기관을 사칭하여 금융 정보를 탈취하는 피싱(Phishing), 정상적인 도메인 주소를 입력해도 가짜 웹사이트로 접속을 유도하는 파밍(Pharming), 문자메시지(SMS) 내 인터넷 주소를 클릭하게 만들어 악성 앱을 설치하는 스미싱(Smishing)이 빈번하게 출제된다. 대량의 트래픽을 집중시켜 대상 서버를 마비시키는 분산 서비스 거부 공격(DDoS)과 시스템을 암호화하여 금전을 요구하는 랜섬웨어(Ransomware)도 핵심 유형이다.

이러한 범죄를 예방하기 위해서는 비밀번호를 주기적으로 변경해야 하며, 영문 대소문자, 숫자, 특수문자를 혼합하여 8자리 이상으로 설정하는 것이 안전하다. 운영체제 및 응용 소프트웨어의 최신 보안 패치를 즉시 적용하고, 정품 소프트웨어를 사용해야 한다. 중요한 데이터는 별도의 외장 매체나 클라우드에 주기적으로 백업하는 습관이 필수적이다.

**악성코드와 바이러스의 구분 및 특징**

컴퓨터 바이러스는 정상적인 프로그램이나 데이터에 침투하여 자신을 복제하고 시스템을 손상시키는 악성 소프트웨어의 일종이다. 시험에서는 악성코드의 동작 방식에 따른 차이점을 명확히 묻는다.

| 구분 | 주요 특징 및 동작 방식 | 자기 복제 여부 |
| :--- | :--- | :--- |
| **바이러스 (Virus)** | 다른 파일(숙주)에 기생하여 감염되며 데이터 파괴, 시스템 속도 저하 유발 | O (숙주 필요) |
| **웜 (Worm)** | 네트워크를 통해 스스로 복제본을 전파하며 시스템 과부하를 초래 | O (숙주 불필요) |
| **트로이 목마 (Trojan)** | 겉으로는 유용한 프로그램으로 위장하나 실행 시 백도어를 열어 해킹 유도 | X (단독 실행) |
| **랜섬웨어 (Ransomware)** | 사용자 문서 및 중요 파일을 암호화하여 접근을 막고 금전을 요구 | 유형별 상이 |
| **스파이웨어 (Spyware)** | 사용자 동의 없이 개인정보, 인터넷 방문 기록, 키보드 입력 정보 등을 수집 | X |

⚠️ **혼동 주의**: 트로이 목마는 다른 파일을 감염시키거나 스스로 증식(자기 복제)하지 않는다는 점이 바이러스 및 웜과의 결정적인 차이점이다.

바이러스 감염을 예방하고 치료하기 위해서는 신뢰할 수 있는 백신 프로그램을 설치하고 ‘실시간 감시’ 기능을 항상 켜두어야 한다. 백신 엔진은 항상 최신 버전으로 자동 업데이트하도록 설정하며, 출처가 불분명한 이메일의 첨부 파일은 실행하지 않고 즉시 삭제해야 한다.

**방화벽 및 Windows 보안 센터**

방화벽(Firewall)은 외부 네트워크(인터넷)와 내부 네트워크 사이에 위치하여 불법적인 침입을 차단하고 신뢰할 수 있는 트래픽만 통과시키는 하드웨어 또는 소프트웨어 보안 시스템이다. 

- 외부로부터 인가되지 않은 접근을 실시간으로 차단한다.
- 내부에서 외부로 나가는 패킷의 접근 규칙을 정의하고 기록(Log)을 유지한다.
- ⚠️ **시험 함정**: 방화벽은 외부 침입을 차단할 수 있지만, 내부 사용자의 불법적인 유출 행위나 이메일 첨부 파일 등으로 침투하는 악성 바이러스 감염 자체를 차단하지는 못한다. 따라서 방화벽과 백신 프로그램은 반드시 병행하여 운용해야 한다.

Windows에서는 'Windows 보안(Windows Defender)'이라는 통합 환경을 기본 제공한다. 이는 바이러스 및 위협 방지, 계정 보호, 방화벽 및 네트워크 보호, 앱 및 브라우저 컨트롤, 장치 보안 등의 상태를 한곳에서 점검하고 관리하는 도구다. 별도의 상용 백신이 설치되어 있지 않은 경우 Windows Defender 백신 기능이 자동으로 동작하여 시스템을 보호한다.

**기타 보안 기능**

운영체제 차원에서 시스템 무결성을 지키기 위한 핵심 기능은 다음과 같다.

- **사용자 계정 컨트롤(UAC)**: 시스템에 영향을 미치는 프로그램이 실행되거나 설정을 변경하려 할 때 화면을 어둡게 하고 사용자에게 승인을 묻는 대화상자를 띄운다. 이를 통해 악성코드가 관리자 권한을 가로채 백그라운드에서 임의로 설치되는 것을 방지한다.
- **BitLocker(드라이브 암호화)**: Windows Pro 이상 버전에서 제공하는 전체 디스크 암호화 기능이다. 노트북이나 외장 드라이브를 분실 또는 도난당하더라도 내부 데이터를 읽을 수 없도록 물리 드라이브 단위로 암호화한다.
- **파일 암호화 시스템(EFS)**: NTFS 파일 시스템 환경에서 개별 파일이나 폴더 단위로 암호화를 적용하여 다른 사용자 계정의 무단 접근을 방지한다.
- **시스템 복원**: 시스템 파일, 레지스트리, 설치된 프로그램 등을 이전의 안정적인 복원 지점으로 되돌리는 기능이다. 악성코드 감염이나 드라이버 충돌로 윈도우가 오작동할 때 유용하며, 사용자 개인 문서 파일(사진, 텍스트 등)은 복원 작업에 의해 삭제되거나 변경되지 않는다.
