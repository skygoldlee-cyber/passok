# 요양보호사 실무매뉴얼

> **문서 ID**: DOC-USR-20
> **범위**: exam:carework · 판본: none
> **관련 SPEC ID**: DA-18 · DA-19 · CO-13

> Care OS 요양보호사 실무 도구 사용 안내 — 시험 합격 후 현장에서 바로 쓰는 기록·계산·판단 도구

## 1. 시작하기

실무 모드 전환 후 사이드바의 **실무** 구역에서 각 도구를 사용합니다. 메뉴는 근무 흐름(오늘 → 교대 → 대상자·준비 → 기관·출력)으로 묶여 있습니다.

| 구역 | 메뉴 순서 | 용도 |
|---|---|---|
| 실무 | ① 홈 | 오늘 근무 요약·출력물 서명 설정·빠른 기록 |
| 오늘 | ② 요양일지 | 급여 활동 기록 자동 작성 |
| 오늘 | ③ 방문기록 | 면회·방문 예약·결과 기록 |
| 오늘 | ④ 사고보고 | 사고·낙상 보고서 작성·저장 |
| 교대 | ⑤ 인수인계 | 교대 인계서 생성·저장·공유 |
| 교대 | ⑥ 근무표 | 교대 근무일·근무조 배정 |
| 대상자·준비 | ⑦ 대상자 | 수급자 명부·입소서류·Excel 왕복 |
| 대상자·준비 | ⑧ 기관찾기 | 요양기관 검색·출력 기관명 설정 |
| 대상자·준비 | ⑨ 대처카드 | 상황별 대처 플로우카드 |
| 기관·출력 | ⑩ 평가점검 | 기관 평가 대비 체크리스트 |
| 기관·출력 | ⑪ 서식모음 | 정기 제출 서식 발급처 |
| 기관·출력 | ⑫ 본인부담금 | 등급·서비스별 본인부담금 산출 |

### 공통 — 공유·내보내기

문서가 있는 도구에는 **📤 공유·내보내기** 버튼이 하나씩 있습니다. 누르면 내보내기 메뉴가 열리고 방식을 고릅니다. 메뉴를 여는 순간 문서가 자동 생성·미리보기되므로 별도 생성 없이 바로 내보낼 수 있습니다. 명부·근무표·방문기록·평가점검표처럼 표 문서는 표 형태로 미리보기됩니다 — 미리보기가 그대로 인쇄·PDF·Word의 문서 구조가 됩니다.

| 메뉴 항목 | 표시 | 설명 |
|---|---|---|
| 📤 카카오톡 등으로 공유 | 모바일만 | 보낼 형식 선택(PDF·Word·Excel·전체) 후 OS 공유 시트로 첨부 |
| 🖨️ 인쇄·PDF 저장 | 항상 | 인쇄 대화상자 — 용지 출력·PDF 저장 |
| 📋 본문 복사 | 항상 | 문서 마크다운 클립보드 — 표는 줄막대 표기로 구조 유지 (가림 문서는 인명 가림) |
| 📄 PDF 파일 다운로드 | 항상 | 카톡 PC판 첨부용 PDF 파일 저장 |
| 📝 Word 파일 다운로드 | 항상 | 표·제목·목록이 그대로 살아있는 .docx — Word·한글에서 편집 가능 |
| 📊 Excel 내보내기 | Excel 지원 뷰 | 목록 데이터 .xlsx 저장 |

- PC에는 공유 시트 항목이 표시되지 않습니다 — 카톡 PC판에는 본문 복사 붙여넣기 + 다운로드한 파일(PDF·Word)을 드래그로 보내세요.
- 인쇄·PDF·Excel 등 내보내기 계열은 Pro 표기 기능입니다 (무료 체험 중 이용 가능).

## 2. 홈

실무 모드 첫 화면은 **홈**입니다 — 오늘 날짜·일지/방문/사고 건수 요약, 관찰 추세 "확인 권장" 배지, 6개 도구 빠른 기록 링크를 제공합니다. 아직 써보지 않은 도구에는 **"처음"** 표시가 붙습니다.

### 출력물 서명 설정

홈의 **출력물 서명** 카드에 세 성명을 한 번만 입력해 두면, 이후 모든 출력물 서명란에 자동 기입됩니다.

| 입력 | 기입되는 서명란 |
|---|---|
| 작성자(요양보호사) | 일지 작성자 · 사고보고 보고자 · 점검표 점검자 · 인수인계 인계자 |
| 확인자(시설장·기관장) | 일지 확인자 · 보고서 확인(시설장) · 점검표 기관장(확인) · 주간리포트 기관 검토 |
| 인수자(다음 근무자) | 인수인계 인수자 |

- 미입력 서명란은 기존처럼 수기 서명용 빈칸으로 출력됩니다. 날짜 슬롯(점검일·확인일)은 항상 빈칸입니다.
- 인수인계 화면의 인계자·인수자 입력란도 이 성명으로 기본 채워집니다.

## 3. 요양일지 — 급여 활동 기록 (오늘)

1. 일시·대상자·급여 종류(방문요양 등)를 입력합니다
2. 수행한 활동을 체크합니다 (신체활동·일상생활·인지활동 등)
3. **생성**을 누르면 서비스 제공기준 양식의 기록이 자동 작성됩니다
4. 저장하면 기록함에 누적됩니다 (무료 10건, 이후 Pro)

- 복사·인쇄·PDF·Excel 내보내기(.xlsx)·공유는 **📤 공유·내보내기** 메뉴에서 실행합니다 (Pro 표기)
- 저장된 일지는 인수인계서 작성 시 자동으로 병합됩니다
- **[AI 초안]** 버튼: 폼에 입력한 관찰 데이터를 AI에게 보내 초안을 생성합니다 — 설정에서 본인의 AI 키(BYOK)를 먼저 등록해야 하며, 전송 전에 가명처리된 내용을 미리 보고 확인해야 합니다. 결과는 초안이므로 검토·편집 후 사용하세요

### 관찰 기록 칩과 추세 확인
일지 폼 하단의 **식사량·수면·배변** 칩을 눌러 코드화 관찰을 남기면, 대상자별 연속 악화(예: 식사량 3회 연속 감소)가 **대상자 명부 카드에 "확인 권장" 배지**로 표시됩니다. 기록 요약·확인 권장 수준의 안내이며 의료적 판단이 아닙니다.

### 제공기록지 복사
**[제공기록지 복사]** 버튼은 공단 급여제공기록지 양식 텍스트를 클립보드에 복사합니다 — 기관 ERP·공단 앱에 그대로 붙여넣어 이중 입력을 줄입니다.

## 4. 방문기록 — 면회·방문 기록 (오늘)

1. 면회자·대상자·시간·면회 내용과 대상자 상태를 입력하고 **예약 등록**으로 저장합니다 (무료 10건, 이후 Pro)
2. 방문 후에는 해당 예약의 **결과 저장**으로 방문 결과를 기록합니다
3. 저장된 기록은 목록에 누적되며 기록함에서 확인·관리합니다

- 기록 복사·인쇄·PDF·Excel 내보내기(.xlsx)·기관에 공유는 Pro 표기 기능입니다

## 5. 사고보고 — 사고·낙상 보고서 (오늘)

사고 발생 시각·장소·대상자·경위·응급 조치·보고 경로를 입력하면 기관 양식의 사고·낙상 보고서가 작성됩니다.

- **기록 저장**으로 '저장된 보고서' 목록에 누적됩니다 (무료 10건, 이후 Pro)
- 복사·인쇄·PDF·Excel 내보내기(.xlsx)·기관에 공유는 Pro 표기 기능입니다

## 6. 인수인계 — 교대 기록 (교대)

인수인계서는 **기관의 기록 문서**입니다. 개인 카톡 공유보다 기록 저장이 먼저입니다.

1. 일시·근무조·인계자·인수자를 입력합니다 — 홈 서명 설정값이 기본 채워집니다
2. 상태 요약·미완료 작업·주의사항을 작성합니다
   - "당일 일지 병합" 체크 시 오늘 저장한 일지가 자동 요약됩니다
3. **📤 공유·내보내기**를 누르면 아직 저장되지 않은 문서가 기록에 자동 저장된 뒤 메뉴가 열립니다 — 저장본이 기관 기록이 됩니다
4. **기록 저장**으로 미리 저장해둘 수도 있습니다 — 같은 문서는 중복 저장되지 않습니다

### AI 초안
인수인계 폼에도 **[AI 초안]** 버튼이 있습니다 — 대상자·상태·주의사항을 기반으로 초안을 생성하며, 전송 전 가명처리 미리보기가 표시됩니다.

### 오늘 기록으로 채우기
**[오늘 기록으로 채우기]** 버튼은 근무 일자의 일지·사고·방문 기록을 대상자별로 자동 집계해 대상자·상태·주의사항 초안을 채웁니다. 내용을 검토·편집한 뒤 생성·저장하세요 — 자동 제출되지 않습니다.

## 7. 근무표 — 교대 근무표 (교대)

근무조(주간/야간 등)와 인원 배정을 입력해 **배정 등록**으로 저장합니다 (무료 30건).

- **Excel 내보내기(.xlsx)**: 배정 목록을 진짜 Excel 파일(.xlsx)로 저장합니다 — 셀 단위 편집·정렬 가능
- **Excel 가져오기**: CSV를 읽어 날짜+근무조+근무자 기준으로 병합합니다 — 신규 등록·기존 갱신 건수가 안내되고 한도 초과분은 제외됩니다
- CSV 헤더: `날짜,근무조,근무자,메모` — 근무조는 '주간(데이)'처럼 표시명 그대로 씁니다. 근무표 복사·인쇄·PDF·Excel 왕복은 Pro 표기 기능입니다

## 8. 대상자 — 수급자 명부·입소서류·CSV (대상자·준비)

1. 수급자 등록 시 상태(입소대기/입소중/재가이용)를 선택합니다 — 입소대기자도 동일 명부에서 관리됩니다
2. 폼 하단 체크리스트로 입소서류 14항목 수납 여부를 기록합니다 — 목록에 `서류 n/14` 표시
3. **명부 표 미리보기**: 저장된 명부가 표 형태 문서로 표시됩니다 — 공유·내보내기 메뉴에서 복사·인쇄·PDF·Word로 바로 출력합니다 (Pro 표기)
4. **Excel 내보내기(.xlsx)**: 명부+서류 현황을 Excel(.xlsx)로 저장합니다
5. **Excel 가져오기**: CSV·xlsx 파일을 읽어 성명 기준으로 병합합니다 — 신규 등록·기존 갱신 건수가 안내됩니다

- 수급자 저장은 무료 10건까지 — Excel 가져오기에서도 한도 초과분은 제외됩니다 (기존 성명 갱신은 한도 무관)
- CSV 헤더: `성명,상태,호실,생년월일,비상연락처,알레르기,주의사항,메모` + 서류 단명 열. 서류 수납은 ○·O·✓·x·1 등으로 표기하며, 앱에서 내보낸 파일을 그대로 다시 가져올 수 있습니다. CSV(UTF-8·CP949 자동 인식)와 .xlsx 파일 모두 읽을 수 있습니다 — 앱에서 내보낸 .xlsx를 그대로 다시 가져올 수 있습니다

### 대상자 연결과 이력
일지·사고·방문·인수인계 폼의 대상자 입력은 명부 자동완성을 지원합니다. 미등록 이름 입력 시 **"명부에 등록"** 버튼이 나타나 등록 즉시 기록이 연결됩니다. 명부 카드의 **"이력 N건"**을 펼치면 해당 대상자의 일지·방문·인수인계·사고 기록을 시간순으로 확인할 수 있습니다.

### 보호자 주간 리포트
명부 카드의 **[주간리포트]** 버튼은 해당 대상자의 최근 7일 일지·방문·사고 기록을 요약해 보호자용 리포트를 생성합니다 — 출력물에는 기관 검토(홈 서명 설정의 확인자)·발행일이 표기되고, 공유 시 인명·연락처가 가려집니다.

### 외부 명부 가져오기
롱텀 수급자목록·이지케어·케어포 등에서 내보낸 CSV도 헤더를 자동 인식해 가져옵니다(수급자명·생활실·연락처·특이사항 등 변형 컬럼 대응).

## 9. 기관찾기 — 출력물 기관명 설정 (대상자·준비)

데이터는 국민건강보험공단 장기요양기관 시설별 현황(2026.6.10 기준) 전국 6,252개 시설급여 기관이며, 결과 카드에 정원·요양보호사 인력 수가 표시됩니다.

1. 시설명·주소·전화로 장기요양기관을 검색합니다 (지역 필터 지원)
2. 결과 카드에서 **이 기관으로 설정**을 누르면 일지·인수인계·보고서 출력물 상단에 기관명이 표기됩니다
3. 설정된 기관은 `✓ 설정됨` 배지로 표시됩니다 — 미설정 시 상단 안내가 표시됩니다
4. 각 결과 카드의 **카카오맵**·**장기요양보험** 링크로 지도 위치와 공단 포털 기관 정보를 확인할 수 있습니다

## 10. 대처카드 — 상황별 대처 (대상자·준비)

8개 상황 카드: 배회·공격/거부·망상/환각(BPSD), 낙상, 욕창, 응급(의식/호흡/흉통), 감염 의심, 학대 의심.

- 각 카드는 **상황 인식 → 즉시 조치 → 보고 → 기록** 순서로 표시됩니다
- 학대 의심 시 신고의무: **1577-1389** (노인보호전문기관)

## 11. 평가점검 — 기관 평가 대비 (기관·출력)

인권·기록·감염·안전 4영역 20항목 체크리스트입니다. 진행률이 표시되고 선택 상태는 기기에 저장됩니다. `기준` 배지는 해당 항목의 평가 근거를 나타냅니다. 점검표는 **📤 공유·내보내기** 메뉴로 복사·인쇄·PDF·Word를 출력합니다 — 표 형태(영역·✔/□·항목·근거)로 나갑니다 (Pro 표기 기능).

### 증적 커버리지
점검표 상단의 **📋 증적 커버리지** 배너는 명부·일지·관찰·방문·인수인계·사고보고 6종 기록의 유무를 요약해 부족한 항목을 보여줍니다 — 기록 존재만 확인하며 품질 판단이 아닙니다.

## 12. 서식모음 — 정기 제출 서식 (기관·출력)

기관이 정부기관에 정기 제출하는 서식의 공식 발급처 모음입니다. 제출주기표(월·분기/연1회/수시)와 법령 별지 서식·공단·감염안전·지자체 서식 카드를 제공합니다. 지자체 서식은 시·군·구 노인복지과 양식을 사용하세요.

## 13. 본인부담금 계산 (기관·출력)

재가 서비스는 이용료의 15%, 시설은 20% 본인부담이며 감경 60%/40% 대상과 등급별 월 한도가 적용됩니다. 등급·이용 형태·이용 시간을 입력하면 예상 본인부담금이 계산됩니다. 한도 초과분은 전액 본인부담입니다.

## 14. 공유와 개인정보

**📤 공유·내보내기** 메뉴는 생성 문서를 외부로 내보내는 경로입니다. 수급자 데이터가 들어가는 문서(일지·인수인계·사고보고·명부·방문기록·근무표·주간리포트)는 공유·복사·PDF 파일에서 인명·연락처가 자동으로 가려진 본문으로 나갑니다 — 메뉴 항목에 "(인명 가림)" 표시로 확인할 수 있습니다. 기관의 개인정보 정책을 확인한 뒤 사용하세요 — 인쇄 출력물은 원문 그대로 나가므로 공유보다 보관에 주의가 필요합니다.

## 부록. 기관 워크스페이스 — 기관 기록 서버

> ⚠ 기관 워크스페이스(기관 가입·관리·서버 공유)는 현재 **비활성** 상태입니다 — 개인정보 처리위탁 준비 후 다시 열립니다. 아래 내용은 재개통 시 적용됩니다.

**요양보호사(가입)**
1. 설정 → 계정/로그인
2. 기관가입에서 관리책임자에게 받은 초대 코드 입력
3. 소속 기관·역할이 표시되면 연결 완료

**관리책임자(등록·관리)**
1. 설정 → 계정/로그인
2. 기관관리에서 기관 등록 → 8자리 초대 코드 발급
3. 요양보호사에게 코드 전달 → 멤버 목록에서 확인
4. 기관관리 메뉴는 관리책임자 확인 후에만 표시됩니다
