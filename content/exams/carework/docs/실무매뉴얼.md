## 1. 시작하기

실무 모드 전환 후 사이드바의 **실무** 구역에서 각 도구를 사용합니다. 메뉴는 근무 흐름(오늘 → 교대 → 대상자·돌봄 → 기관·행정 → 기관 → 기관·자료)으로 묶여 있습니다. 앱(플랫폼) 이름은 PassOK, 이 실무 도구 모드의 이름은 Care OS입니다 — 사이드바는 PassOK·PASSCARE, 실무 화면 헤더는 Care OS로 표시됩니다. 처음 실무 모드에 진입하면 **"기록 → 문서 생성 → 인쇄·공유" 3단계 안내**가 한 번 표시되고, "알겠어요"를 누르면 다시 나오지 않습니다.

| 실무 | ① 홈 | 오늘 근무 요약·다음 행동 안내·출력물 서명 설정·빠른 기록 |

### 공통 — 버튼 구성과 "더보기"

각 도구의 버튼은 **자주 쓰는 것만 크게** 보이고, 나머지는 **더보기**를 눌러 펼칩니다.

- 요양일지: 생성·공유·내보내기 → 더보기(AI 초안·저장·제공기록지 복사)
- 사고보고: 생성·공유·내보내기 → 더보기(저장·기관 공유(재개통 시))
- 인수인계: 생성·공유·내보내기 → 더보기(오늘 기록 채우기·AI 초안·저장)

### 공통 — 저장 확인·자동 기입·입력 보조

- **저장 확인**: 저장하면 결과 영역에 **"✓ 기기에 저장됨 · 방금"** 배지가 잠깐 뜹니다 — 저장됐는지 불안해할 필요가 없습니다.
- **자동 기입**: 사고보고·인수인계는 한 번 저장하면 장소·성명·시간대·근무조 같은 반복 입력이 다음 진입 시 자동으로 채워집니다 (빈 칸만 채움).
- **🎤 말로 입력**: 경위·조치·특이사항처럼 길게 쓰는 칸 옆의 🎤 버튼을 누르고 말하면 글자가 입력됩니다 (크롬·안드로이드 지원, 미지원 브라우저는 버튼이 보이지 않음).
- **삭제·초기화 확인**: 기록 삭제·목록 초기화·기본 양식 복원은 실행 전에 반드시 확인 창을 띄웁니다 — 실수로 지워지는 일이 없습니다.

![저장 확인 — 저장하면 "✓ 기기에 저장됨" 배지가 표시됩니다](images/manual-01-badge.webp)

### 공통 — 공유·내보내기

문서가 있는 도구에는 **📤 공유·내보내기** 버튼이 하나씩 있습니다. 누르면 내보내기 메뉴가 열리고 방식을 고릅니다. 메뉴를 여는 순간 문서가 자동 생성·미리보기되므로 별도 생성 없이 바로 내보낼 수 있습니다. 명부·근무표·방문기록·평가점검표처럼 표 문서는 표 형태로 미리보기됩니다 — 미리보기가 그대로 인쇄·PDF·Word의 문서 구조가 됩니다.

| 메뉴 항목 | 표시 | 인명 가림 | 설명 |
|---|---|---|---|
| 📤 카카오톡 등으로 공유 | 모바일만 | 적용 | 보낼 형식 선택(PDF·Word·Excel·전체) 후 OS 공유 시트로 첨부 |
| 🖨️ 인쇄·PDF 저장 | 항상 | **미적용(원문)** | 인쇄 대화상자 — 용지 출력·PDF 저장 |
| 📋 본문 복사 | 항상 | 적용 | 문서 마크다운 클립보드 — 표는 줄막대 표기로 구조 유지 |
| 📄 PDF 파일 다운로드 | 항상 | 적용 | 카톡 PC판 첨부용 PDF 파일 저장 |
| 📝 Word 파일 다운로드 | 항상 | 적용 | 표·제목·목록이 그대로 살아있는 .docx — Word·한글에서 편집 가능 |
| 📊 Excel 내보내기 | Excel 지원 뷰 | **미적용(원문)** | 목록 데이터 .xlsx 저장 — 성명·연락처가 그대로 나가니 주의 |

- PC에는 공유 시트 항목이 표시되지 않습니다 — 카톡 PC판에는 본문 복사 붙여넣기 + 다운로드한 파일(PDF·Word)을 드래그로 보내세요.
- **인쇄·PDF 저장(원문)** 과 **PDF 파일 다운로드(가림)** 는 이름이 비슷하지만 가림 적용이 다릅니다 — 외부에 전달할 땐 가림이 적용되는 다운로드·공유를 쓰세요.
- 인쇄·PDF·Excel 등 내보내기 계열은 유료 표기 기능입니다 (무료 체험 중 이용 가능).

> 📷 삽화 예정 [manual-01-share] — 공유·내보내기 메뉴 펼침 상태 (모바일 뷰포트 — PC는 항목 5개)

### 01 처음 쓰는 날

딱 한 번, **5분**만 설정하면 다음 날부터 바로 씁니다.

1. **휴대폰 첫 화면에 앱 놓기**
   - 안드로이드(크롬): 오른쪽 위 점 세 개 → **홈 화면에 추가**
   - 아이폰(사파리): 아래 공유 버튼 → **홈 화면에 추가**
   - 다음부터는 이 아이콘으로 여세요. **늘 같은 휴대폰·같은 앱**으로 열어야 기록이 보입니다.
2. **실무 모드로 바꾸기** — 처음 한 번 **3단계 안내**가 나옵니다. 읽고 **알겠어요**를 누르세요.

   ![첫 진입 3단계 안내](images/manual-01-guide.webp)
3. **우리 기관 정하기** — 메뉴 **기관찾기**에서 이름 검색 → **이 기관으로 설정** → **✓ 설정됨**. 서류 맨 위에 기관 이름이 찍힙니다.

   ![기관찾기 결과 카드 — ✓ 설정됨 표시](images/manual-13-finder.webp)
   > 방문요양 등 재가 기관은 아직 검색되지 않습니다. 이 단계는 건너뛰세요.
4. **내 이름 저장하기** — 홈 아래 **출력물 서명**에 내 이름·시설장·다음 근무자 이름을 넣고 **서명 저장**. 그림은 02번 2단계에 있습니다.
5. **글씨 크기 맞추기** — 홈의 **글자 크게**를 누르세요. 크롬·안드로이드에서는 입력칸 옆 **마이크 버튼**으로 말해서 쓸 수도 있습니다.

### 02 근무 시작할 때

홈에서 오늘 할 일을 보고, 요양일지로 하루를 시작합니다.

> 하루는 이 순서로 흘러갑니다: **홈 → 요양일지 → (일이 생기면) 사고보고·방문기록 → 인수인계**

1. **홈 열기** — 오늘 날짜와 기록 건수, 다음에 할 일이 보입니다. 글씨가 작으면 **글자 크게**를 누르세요.

   ![홈 화면 — 다음 할 일 안내와 글자 크게 버튼](images/manual-02-home.webp)
2. **내 이름 넣어 두기** (처음 한 번만) — 홈 아래 **출력물 서명**에 내 이름, 시설장 이름, 다음 근무자 이름을 넣고 **서명 저장**. 이제 일지·보고서·인수인계서의 서명란에 이름이 자동으로 들어갑니다.

   ![출력물 서명 카드 — 이름 세 칸과 서명 저장 버튼](images/manual-02-sign.webp)
3. **요양일지 쓰기** — 대상자 이름을 쓰면 명부에서 찾아 줍니다. 처음 보는 이름이면 명부에 등록하세요. 급여 종류와 시작·종료 시각을 고르고, 오늘 한 일을 체크합니다.

   ![요양일지 입력 화면 — 대상자 성명과 급여 종류 칸](images/manual-03-form.webp)
4. **식사·수면·배변 누르기** — 일지 아래 식사량·수면·배변 버튼을 눌러 두세요. 같은 분이 여러 번 연속으로 나빠지면 수급자 카드에 '확인 권장' 표시가 뜹니다 — 기록을 모아 보여 주는 표시이며 의료적 판단은 아닙니다.
5. **생성하고 저장하기** — **생성**을 누르면 일지가 완성됩니다. 이어서 **더보기 → 저장**. 저장한 일지는 퇴근할 때 인수인계서에 자동으로 모입니다. 대상자마다 반복하세요.

   ![더보기를 펼쳐 저장](images/manual-01-more.webp)

**다 했는지 확인**
- ☐ 홈에서 오늘 할 일 확인
- ☐ (처음 한 번) 서명 이름 저장
- ☐ 대상자별 요양일지 작성
- ☐ 식사·수면·배변 표시
- ☐ '저장됨' 확인

### 03 다음 근무자에게 넘길 때

인수인계서는 기관의 기록입니다. 카톡보다 저장이 먼저예요.

1. **인수인계 열기** — 메뉴 **인수인계**. 날짜와 근무조를 확인하세요. 인계자·인수자 이름은 홈의 서명 설정대로 이미 들어가 있습니다.
2. **오늘 기록 불러오기** — **더보기 → 오늘 기록으로 채우기**. 오늘 쓴 일지·사고·방문 기록이 대상자별로 모여 들어갑니다.
3. **꼭 읽고 고치기** — 아래 네 칸을 확인하세요. 자동으로 채워질 뿐 자동으로 넘어가지는 않습니다.

   ![인수인계서 — 대상자 상태·미완료 작업·주의사항·인계 확인](images/manual-06-handover.webp)
   - 대상자 상태 — 오늘 달라진 점
   - 미완료 작업 — 못 끝낸 일을 직접 적기
   - 주의사항 — 사고·낙상 등
   - 인계 확인 — 두 사람 이름
4. **저장하고 건네기** — **공유·내보내기**를 누르면 먼저 기록에 저장된 뒤 메뉴가 열립니다.
   - 종이로: 인쇄해서 다음 근무자에게 직접 건네기
   - 카톡으로: 대상자 이름·연락처는 자동으로 가려집니다

### 04 낙상이 났을 때

대처카드 → 사고보고서 → 인수인계, 5단계면 기록까지 끝납니다.

> **앱보다 사람이 먼저입니다**
> - 바로 일으키지 말고 의식·호흡·아픈 곳부터 확인하세요.
> - 의식이 없거나, 머리를 부딪혔거나, 피가 많이 나면 바로 119.
> - 시설장·기관 책임자에게 먼저 말로 알리세요. 기록은 그다음입니다.

1. **대처카드에서 '낙상' 열기** — 메뉴 **대처카드 → 낙상**. 카드의 순서대로 조치한 뒤, 맨 아래 **사고보고서 작성**을 누릅니다. (아래 화면은 '배회' 카드 예시이며, 낙상 카드도 버튼 위치는 같습니다.)

   ![대처카드 화면 — 맨 아래 사고보고서 작성 버튼](images/manual-09-card.webp)
2. **빈칸만 채우기** — 사고 유형 '낙상'과 기본 경위는 이미 들어가 있습니다. 장소·시각·조치 내용만 확인하고 채우세요.
   - 글자가 불편하면 칸 옆 **마이크 버튼**을 누르고 말하세요 — 말한 내용이 글자로 들어갑니다.
   - **사진은 3장까지** — 사진 추가로 현장·다친 부위를 찍어 두면 보고서에 그대로 붙습니다.
3. **저장하기** — **더보기 → 저장**. 화면에 '✓ 기기에 저장됨'이 뜨면 끝입니다.

   ![더보기를 펼쳐 저장](images/manual-01-more.webp)
4. **시설장에게 보고하기** — **공유·내보내기 → 인쇄**해서 드리거나, PDF로 저장해 보내세요. 사고 유형과 사진이 보고서에 그대로 나오고, 보고자·확인자 이름은 홈의 서명 설정대로 자동으로 들어갑니다.

   ![완성된 사고·낙상 보고서 — 사고 유형과 첨부 사진](images/manual-05-preview.webp)
   > ⚠ **사진은 가려지지 않아요** — 카톡 공유 때 이름은 자동으로 가려지지만 사진은 그대로 나갑니다. 얼굴이 나오지 않게 찍어 주세요.
5. **퇴근 전, 다음 근무자에게 넘기기** — 인수인계 → 더보기 → 오늘 기록으로 채우기. 오늘 사고가 주의사항에 들어갑니다. 읽어 보고 고친 뒤 저장하세요.

   ![인수인계서 — 특이 주의사항에 낙상 주의가 들어간 모습](images/manual-06-handover.webp)

**다 했는지 확인**
- ☐ 대상자 상태 확인·책임자 보고
- ☐ 사고보고서 저장 ('저장됨' 확인)
- ☐ 시설장에게 보고서 전달
- ☐ 가족 통지 여부 기록
- ☐ 인수인계서에 반영·저장

### 05 응급 상황일 때

> **119 — 앱보다 전화가 먼저.** 망설여지면 일단 거세요. 상담원이 무엇을 할지 알려 줍니다.

> **이럴 땐 바로 119**
> - 불러도 반응이 없어요
> - 숨을 안 쉬거나 이상하게 쉬어요
> - 가슴이 아프다며 식은땀을 흘려요
> - 목에 걸려 말도 기침도 못 해요

1. **119에 전화** — 기관 주소와 어르신 상태를 말하고, 상담원이 끊을 때까지 끊지 마세요.
2. **큰 소리로 도움 요청** — 한 사람을 정해서 "책임자 불러 주세요"라고 부탁하세요.
3. **상담원 안내대로** — 심폐소생술이나 막힌 것 빼기는 교육받은 대로, 상담원 말에 따라 하세요.
4. **상황이 끝난 뒤에 앱** — 대처카드(응급·질식) → 사고보고서 작성 → 저장 → 인수인계에 반영. 04번 낙상 안내와 같은 순서입니다.

> 이 안내는 응급 처치 교육을 대신하지 않습니다. 기관의 응급 대응 지침과 119 상담원 안내가 우선합니다.

### 06 보호자에게 보낼 때

주간리포트 한 장으로 한 주의 기록을 정리해 보냅니다.

> 보내기 전에 기관 방침을 확인하세요. 보호자에게 누가, 어떤 방법으로 보낼지는 기관마다 다릅니다. 시설장 확인 후 보내는 곳이 많습니다.

1. **주간리포트 만들기** — 메뉴 **수급자** → 해당 어르신 카드의 **주간리포트**. 최근 7일 일지·방문·사고 기록이 한 장으로 요약됩니다.

   ![수급자 카드 — 주간리포트 버튼](images/manual-08-client.webp)
2. **내용 확인하기** — 리포트 아래에 기관 검토(시설장 이름)와 발행일이 찍힙니다. 틀린 내용은 리포트가 아니라 원래 기록(일지 등)을 고친 뒤 다시 만드세요.
3. **보내기**
   - 휴대폰에서: 공유·내보내기 → 카카오톡 등으로 공유 → PDF 고르기 → 보호자 대화방
   - 컴퓨터에서: 공유·내보내기 → PDF 파일 다운로드 → 받은 파일을 카톡 PC 대화창에 끌어다 놓기

> **개인정보, 이것만 기억하세요**
> - 카톡 공유·PDF 파일에서는 이름·연락처가 ○○로 가려집니다.
> - 사진은 가려지지 않습니다. 다른 어르신이 찍힌 사진은 빼세요.
> - 인쇄물은 원래 이름 그대로 나옵니다. 보관에 주의하세요.

### 07 기록 지키기

기록은 인터넷이 아니라 이 휴대폰 안에 저장됩니다.

> **이럴 때 기록이 사라지거나 안 보여요**
> - 브라우저의 사용 기록·사이트 데이터 삭제
> - 휴대폰 초기화나 교체
> - 다른 휴대폰·컴퓨터에서 열기
> - 시크릿(비공개) 창에서 쓰기

1. **늘 같은 휴대폰, 같은 앱으로** — 홈 화면 아이콘으로 여세요(01번 1단계). 다른 기기에서 기록이 안 보이면 사라진 게 아니라 원래 휴대폰에 있는 것입니다.
2. **중요한 서류는 그날 바로 제출** — 사고보고서·인수인계서는 인쇄하거나 PDF로 그날 기관에 내세요. 기관에 낸 서류가 원본이 됩니다.
3. **날을 정해 Excel로 받아 두기** (Pro) — 각 화면의 공유·내보내기 → Excel 내보내기. 일주일에 한 번처럼 날을 정해 두세요.

   | 받아 둔 파일 | 새 휴대폰에서 |
   |---|---|
   | 수급자 명부 · 근무표 | Excel 가져오기로 다시 불러올 수 있음 |
   | 요양일지 · 방문기록 · 사고보고 | 보관용 — 다시 불러오기는 안 됨 |
4. **받은 파일은 조심해서 보관** — Excel 파일에는 어르신 이름·연락처가 그대로 들어 있습니다. 기관이 정한 곳에 두고, 개인 카톡방이나 개인 클라우드에 올려 두지 마세요.

> **휴대폰을 바꿔야 한다면** — 바꾸기 전에 Excel로 모두 받아 두기 → 새 휴대폰에서 01번 설정 → 명부·근무표는 Excel 가져오기로 다시 넣기.

> 이 안내는 앱 사용법입니다. 기록 보관 기간과 장소는 기관 지침과 관련 법령을 따르세요.

### 출력물 서명 설정

홈의 **출력물 서명** 카드에 세 성명을 한 번만 입력해 두면, 이후 모든 출력물 서명란에 자동 기입됩니다. **서명 이미지**를 올려두면 인쇄·PDF처럼 이미지가 들어가는 출력 경로에 서명이 기입됩니다 (텍스트 경로에는 성명만 기입).

| 입력 | 기입되는 서명란 |
|---|---|
| 작성자(요양보호사) | 일지 작성자 · 사고보고 보고자 · 점검표 점검자 · 인수인계 인계자 · 명부/근무표/방문기록 작성자 |
| 확인자(시설장·기관장) | 일지 확인자 · 보고서 확인(시설장) · 점검표 기관장(확인) · 주간리포트 기관 검토 |
| 인수자(다음 근무자) | 인수인계 인수자 |

미입력 서명란은 수기 서명용 빈칸으로 출력되고, 날짜 슬롯(점검일·확인일)은 항상 빈칸입니다. 인수인계 화면의 인계자·인수자 입력란도 이 성명으로 기본 채워집니다.

## 4. 요양일지 — 급여 활동 기록 (오늘)

1. 일시·대상자·급여 종류를 입력하고 수행한 활동을 체크합니다
2. **생성**을 누르면 서비스 제공기준 양식의 기록이 자동 작성됩니다
3. 저장하면 기록함에 누적되고(무료 10건, 이후 Pro), 인수인계서 작성 시 자동 병합됩니다

- 폼 하단 **식사량·수면·배변** 칩은 코드화 관찰 기록입니다 — 같은 대상자 연속 악화 시 명부 카드에 "확인 권장" 배지가 표시됩니다 (기록 요약 안내이며 의료적 판단 아님)
- **[AI 초안]**(더보기 안, 유료): 관찰 데이터를 AI에 보내 초안 생성 — 설정의 AI 키(BYOK) 필요, 전송 전 가명처리 내용 확인
- **[제공기록지 복사]**(더보기 안, 유료 표기): 공단 급여제공기록지 양식 텍스트를 클립보드에 복사 — 기관 ERP·공단 앱 붙여넣기용
- 복사·인쇄·PDF·Excel 내보내기·공유는 **📤 공유·내보내기** 메뉴 (유료 표기)

## 5. 방문기록 — 면회·방문 기록 (오늘)

1. 면회자·대상자·시간·면회 내용과 대상자 상태를 입력하고 **예약 등록**으로 저장합니다 (무료 10건, 이후 Pro)
2. 방문 후에는 해당 예약의 **결과 저장**으로 방문 결과를 기록합니다 — 결과 칸의 🎤로 말로 적을 수 있습니다
3. 결과 저장 시 **📷 사진 추가**로 전달 물품·대상자 상태 사진을 최대 3장까지 첨부할 수 있습니다 — 사진은 문서 말미 "첨부 사진" 칸에 나오고, 다시 열면 복원됩니다
4. 저장된 기록은 목록에 누적되며 기록함에서 확인·관리합니다

- 기록 복사·인쇄·PDF·Excel 내보내기(.xlsx)·기관에 공유(재개통 시)는 유료 표기 기능입니다

## 7. 인수인계 — 교대 기록 (교대)

인수인계서는 **기관의 기록 문서**입니다. 개인 카톡 공유보다 기록 저장이 먼저입니다.

1. 일시·근무조·인계자·인수자 입력 — 홈 서명 설정값·직전 저장값이 기본 채워집니다
2. 상태 요약·미완료 작업·주의사항 작성 — "당일 일지 병합" 체크 시 오늘 일지가 자동 요약됩니다
3. **오늘 기록으로 채우기**(더보기 안): 근무 일자의 일지·사고·방문 기록을 대상자별로 자동 집계 — 검토·편집 후 저장 (자동 제출 아님)
4. **📤 공유·내보내기** 시 미저장 문서는 기록에 자동 저장된 뒤 메뉴가 열립니다 — 무료 한도(10건) 초과로 자동 저장이 거절되면 Pro 안내

- **[AI 초안]**(더보기 안, 유료): 대상자·상태·주의사항 기반 초안 — 가명처리 미리보기 후 전송
- **기록 저장**(더보기 안)으로 미리 저장 가능 — 같은 문서는 중복 저장되지 않습니다

## 8. 근무표 — 교대 근무표 (교대)

근무조(주간/야간 등)와 인원 배정을 입력해 **배정 등록**으로 저장합니다 (무료 30건 한도 · 유료 표기 기능).

- **Excel 내보내기(.xlsx)**: 배정 목록을 진짜 Excel 파일(.xlsx)로 저장합니다 — 셀 단위 편집·정렬 가능
- **Excel 가져오기**: CSV·xlsx 파일을 읽어 날짜+근무조+근무자 기준으로 병합합니다 — 내보낸 .xlsx를 그대로 다시 가져올 수 있어 왕복이 됩니다. 신규 등록·기존 갱신 건수가 안내되고 한도 초과분은 제외됩니다
- CSV 헤더: `날짜,근무조,근무자,메모` — 근무조는 '주간(데이)'처럼 표시명 그대로 씁니다. 근무표 복사·인쇄·PDF·Excel 왕복은 유료 표기 기능입니다

## 9. 수급자 — 명부·입소서류·Excel (대상자·돌봄)

1. 수급자 등록 시 상태(입소대기/입소중/재가이용) 선택 — 입소대기자도 동일 명부, 무료 10건까지 (기존 성명 갱신은 한도 무관)
2. 폼 하단 체크리스트로 입소서류 14항목 수납 기록 — 목록에 `서류 n/14` 표시
3. **명부 표 미리보기**로 복사·인쇄·PDF·Word 출력 (유료 표기)
4. **Excel 내보내기(.xlsx)·가져오기**: 명부+서류 현황 왕복 — CSV(UTF-8·CP949 자동 인식)·xlsx, 성명 기준 병합

- CSV 헤더: `성명,상태,호실,생년월일,비상연락처,알레르기,주의사항,메모` + 서류 단명 열 (○·O·✓·x·1 표기) — 앱에서 내보낸 파일을 그대로 다시 가져올 수 있습니다
- 폼의 대상자 입력은 명부 자동완성 — 미등록 이름은 **"명부에 등록"**으로 즉시 연결
- 명부 카드 **"이력 N건"**: 해당 대상자의 일지·방문·인수인계·사고 기록 시간순 확인
- **[주간리포트]**: 최근 7일 기록을 보호자용 한 장으로 — 기관 검토(홈 서명의 확인자)·발행일 표기, 공유 시 인명 가림
- 롱텀 수급자목록·이지케어·케어포 등 외부 CSV도 헤더 자동 인식으로 가져올 수 있습니다 (수급자명·생활실·연락처·특이사항 등 변형 컬럼 대응)

## 11. 평가점검 — 기관 평가 대비 (기관·행정)

## 12. 기관양식 — 기관 자체 양식 (기관·행정)

실무 도구의 문서는 기관 자체 서식으로 바꿀 수 있습니다. **기관양식** 뷰의 **기본 양식** 목록에서 도구별로 두 가지 방법을 고릅니다.

### 사본 만들기

1. 도구 옆 **사본 만들기**를 누르면 기본 양식이 복사된 편집기가 열립니다.
2. 본문을 수정·추가하고 미리보기에서 확인한 뒤 저장합니다.
3. 저장하면 해당 도구가 만드는 문서(미리보기·인쇄·공유·PDF·Word)가 사본 서식으로 바뀝니다. 기본 양식은 그대로 남고, 사본을 삭제하면 기본으로 돌아갑니다.

### 파일로 만들기

1. **파일로 만들기**를 누르고 기관이 쓰는 양식 파일(Word·Excel·CSV·PDF)을 고릅니다.
2. 파일 내용이 편집기에 들어옵니다 — `{{기록표}}`처럼 데이터가 들어갈 자리가 필요하면 미리보기에서 위치를 확인해 넣습니다. 양식의 라벨(일시·인계자 등)이 도구가 채우는 키와 겹치면 편집기에서 `{{키}}` 표기를 안내합니다.
3. 저장하면 사본 만들기와 같이 도구 출력 서식으로 적용됩니다. 이미 사본이 있으면 내용이 바뀝니다.

![양식 편집기](images/manual-11-template.webp)

### 평가점검에 기관 점검표 올리기

평가점검 화면의 **기관 점검표 불러오기**로 기관 점검표 파일(Word·Excel·CSV)을 올리면 점검 항목 자체가 기관 내용으로 바뀝니다. 표의 "영역·항목·근거" 칸을 인식합니다.
1. 파일을 올리면 바로 적용되지 않고 **인식 결과(영역·항목 나누기)를 먼저 보여줍니다** — 나뉨이 잘못됐으면 취소하고, 맞으면 적용합니다.
2. (재개통 시) 기관에 등록된 사용자는 올린 점검표가 **기관 다른 멤버에게도 자동으로 적용**됩니다 — 기관 공유 경로가 비활성인 동안에는 본인 기기에만 적용됩니다.
3. **기본 점검표 복원**으로 원래 기본 점검표로 돌아갈 수 있고, 같은 파일을 다시 올리면 체크한 상태가 유지됩니다.

## 13. 본인부담금 계산 (기관·행정)

등급·이용 형태·이용 시간을 입력하면 예상 본인부담금이 계산됩니다.

- **기본 본인부담률**: 재가 서비스는 이용료의 15%, 시설은 20%입니다.
- **감경 적용 시 실제 부담률**: 감경 40% 대상이면 재가 9%·시설 12%, 감경 60% 대상이면 재가 6%·시설 8%입니다. 기초생활수급자는 본인부담이 면제(0원)됩니다.
- **월 한도액**은 재가급여에만 적용됩니다 — 한도 초과분은 전액 본인부담입니다. 시설급여는 월 한도 대신 등급별 1일 수가 기준이며, 식재료비 등 비급여는 별도 전액 부담입니다.
- 근거(당해연도 고시): 노인장기요양보험법 §40 · 제공기준 고시 §13 · 본인부담금 감경 고시.

## 16. 공유와 개인정보

**📤 공유·내보내기** 메뉴는 생성 문서를 외부로 내보내는 경로입니다. 수급자 데이터가 들어가는 문서(일지·인수인계·사고보고·명부·방문기록·근무표·주간리포트)는 공유·복사·PDF·Word 파일에서 인명·연락처가 자동으로 가려진 본문으로 나갑니다 — 메뉴 항목에 "(인명 가림)" 표시로 확인할 수 있습니다.

- **가림이 적용되지 않는 경로**: 인쇄·PDF 저장, Excel 내보내기 — 성명·연락처가 원문 그대로 나갑니다. 외부 전달 시에는 가림이 적용되는 경로를 사용하세요.
- **사진은 가려지지 않습니다**: 사고보고·방문기록에 첨부한 사진은 인명 가림 대상이 아니라 공유·PDF에 그대로 나갑니다 — 사진에 얼굴·성명·차량번호가 찍히지 않았는지 확인 후 공유하세요.
- 기관의 개인정보 정책을 확인한 뒤 사용하세요 — 인쇄 출력물은 원문 그대로 나가므로 공유보다 보관에 주의가 필요합니다.
