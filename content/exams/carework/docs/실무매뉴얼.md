### 공통 — 버튼 구성과 "더보기"

각 도구의 버튼은 **자주 쓰는 것만 크게** 보이고, 나머지는 **더보기**를 눌러 펼칩니다.

- 요양일지: 생성·공유·내보내기 → 더보기(AI 초안·저장·제공기록지 복사)
- 사고보고: 생성·공유·내보내기 → 더보기(저장·기관 공유(재개통 시))
- 인수인계: 생성·공유·내보내기 → 더보기(오늘 기록 채우기·AI 초안·저장)

![버튼 행](images/manual-01-more.webp)

### 공통 — 저장 확인·자동 기입·입력 보조

- **저장 확인**: 저장하면 결과 영역에 **"✓ 기기에 저장됨 · 방금"** 배지가 잠깐 뜹니다 — 저장됐는지 불안해할 필요가 없습니다.
- **자동 기입**: 사고보고·인수인계는 한 번 저장하면 장소·성명·시간대·근무조 같은 반복 입력이 다음 진입 시 자동으로 채워집니다 (빈 칸만 채움).
- **🎤 말로 입력**: 경위·조치·특이사항처럼 길게 쓰는 칸 옆의 🎤 버튼을 누르고 말하면 글자가 입력됩니다 (크롬·안드로이드 지원, 미지원 브라우저는 버튼이 보이지 않음).
- **삭제·초기화 확인**: 기록 삭제·목록 초기화·기본 양식 복원은 실행 전에 반드시 확인 창을 띄웁니다 — 실수로 지워지는 일이 없습니다.

![저장 배지 "✓ 기기에 저장됨 · 방금" + 🎤 버튼이 붙은 입력 칸](images/manual-01-badge.webp)

### 공통 — 공유·내보내기

문서가 있는 도구에는 **📤 공유·내보내기** 버튼이 하나씩 있습니다. 누르면 내보내기 메뉴가 열리고 방식을 고릅니다. 메뉴를 여는 순간 문서가 자동 생성·미리보기되므로 별도 생성 없이 바로 내보낼 수 있습니다. 명부·근무표·방문기록·평가점검표처럼 표 문서는 표 형태로 미리보기됩니다 — 미리보기가 그대로 인쇄·PDF·Word의 문서 구조가 됩니다.

| 메뉴 항목 | 표시 | 인명 가림 | 설명 |
|---|---|---|---|
| 📤 카카오톡 등으로 공유 | 모바일만 | 적용 | 보낼 형식 선택(PDF·Word·Excel·전체) 후 OS 공유 시트로 첨부 |
| 🖨️ 인쇄·PDF 저장 | 항상 | **미적용(원문)** | 인쇄 대화상자 — 용지 출력·PDF 저장 |
| 📋 본문 복사 | 항상 | 적용 | 문서 마크다운 클립보드 — 표는 줄막대 표기로 구조 유지 |
| 📄 PDF 파일 다운로드 | 항상 | 적용 | 카톡 PC판 첨부용 PDF 파일 저장 |
| 📝 Word 파일 다운로드 | 항상 | 적용 | 표·제목·목록이 그대로 살아있는 .docx — Word·한글에서 편집 가능 |
| 📊 Excel 내보내기 | Excel 지원 뷰 | **미적용(원문)** | 목록 데이터 .xlsx 저장 — 성명·연락처가 그대로 나가니 주의 |

- PC에는 공유 시트 항목이 표시되지 않습니다 — 카톡 PC판에는 본문 복사 붙여넣기 + 다운로드한 파일(PDF·Word)을 드래그로 보내세요.
- **인쇄·PDF 저장(원문)** 과 **PDF 파일 다운로드(가림)** 는 이름이 비슷하지만 가림 적용이 다릅니다 — 외부에 전달할 땐 가림이 적용되는 다운로드·공유를 쓰세요.
- 인쇄·PDF·Excel 등 내보내기 계열은 유료 표기 기능입니다 (무료 체험 중 이용 가능).

> 📷 삽화 예정 [manual-01-share] — 공유·내보내기 메뉴 펼침 상태 (모바일 뷰포트 — PC는 항목 5개)

## 2. 홈

실무 모드 첫 화면은 **홈**입니다 — 오늘 날짜·일지/방문/사고 건수 요약, 관찰 추세 "확인 권장" 배지, **다음 행동 안내**, 빠른 기록 링크 8종(요양일지→방문기록→사고보고→인수인계→근무표→수급자 명부→대처카드→평가점검, 사이드바와 같은 순서)을 제공합니다. 아직 써보지 않은 도구에는 **"처음"** 표시가 붙습니다.

- **다음 행동 안내**: 오늘 기록이 없으면 "요양일지 기록부터 시작하세요", 기록이 있으면 "근무 마무리는 인수인계로 넘기세요"로 다음 할 일을 알려줍니다.
- 저장된 기록 건수가 바로 보이니 "내가 오늘 뭘 했나"를 한눈에 확인할 수 있습니다.

![홈 상단 — 오늘 요약·다음 행동 안내·빠른 기록](images/manual-02-home.webp)

### 출력물 서명 설정

홈의 **출력물 서명** 카드에 세 성명을 한 번만 입력해 두면, 이후 모든 출력물 서명란에 자동 기입됩니다.

- **성명(텍스트)** 은 미리보기·인쇄·PDF·Word·본문 복사·공유 텍스트 — 모든 출력 경로에 기입됩니다.
- **서명 이미지**를 올려두면 인쇄·PDF처럼 **이미지가 들어가는 출력 경로**에서 서명란에 이미지가 기입됩니다 (텍스트 경로에는 성명만 기입).

| 입력 | 기입되는 서명란 |
|---|---|
| 작성자(요양보호사) | 일지 작성자 · 사고보고 보고자 · 점검표 점검자 · 인수인계 인계자 · 명부/근무표/방문기록 작성자 |
| 확인자(시설장·기관장) | 일지 확인자 · 보고서 확인(시설장) · 점검표 기관장(확인) · 주간리포트 기관 검토 |
| 인수자(다음 근무자) | 인수인계 인수자 |

- 미입력 서명란은 기존처럼 수기 서명용 빈칸으로 출력됩니다. 날짜 슬롯(점검일·확인일)은 항상 빈칸입니다.
- 인수인계 화면의 인계자·인수자 입력란도 이 성명으로 기본 채워집니다.

![출력물 서명 카드](images/manual-02-sign.webp)

## 3. 요양일지 — 급여 활동 기록 (오늘)

1. 일시·대상자·급여 종류(방문요양 등)를 입력합니다
2. 수행한 활동을 체크합니다 (신체활동·일상생활·인지활동 등)
3. **생성**을 누르면 서비스 제공기준 양식의 기록이 자동 작성됩니다
4. 저장하면 기록함에 누적됩니다 (무료 10건, 이후 Pro)

- 복사·인쇄·PDF·Excel 내보내기(.xlsx)·공유는 **📤 공유·내보내기** 메뉴에서 실행합니다 (유료 표기)
- 저장된 일지는 인수인계서 작성 시 자동으로 병합됩니다
- **[AI 초안]** 버튼(더보기 안, 유료): 폼에 입력한 관찰 데이터를 AI에게 보내 초안을 생성합니다 — 설정에서 본인의 AI 키(BYOK)를 먼저 등록해야 하며, 전송 전에 가명처리된 내용을 미리 보고 확인해야 합니다. 결과는 초안이므로 검토·편집 후 사용하세요

![일지 작성 폼](images/manual-03-form.webp)

### 관찰 기록 칩과 추세 확인
일지 폼 하단의 **식사량·수면·배변** 칩을 눌러 코드화 관찰을 남기면, 대상자별 연속 악화(예: 식사량 3회 연속 감소)가 **수급자 명부 카드에 "확인 권장" 배지**로 표시됩니다. 기록 요약·확인 권장 수준의 안내이며 의료적 판단이 아닙니다.

> 📷 삽화 예정 [manual-03-chips] — 관찰 칩 선택 → 명부 카드 "확인 권장" 배지 대응 (같은 대상자 3회 연속 감소 시드 필요)

### 제공기록지 복사
**[제공기록지 복사]** 버튼(더보기 안)은 공단 급여제공기록지 양식 텍스트를 클립보드에 복사합니다 — 기관 ERP·공단 앱에 그대로 붙여넣어 이중 입력을 줄입니다.

## 4. 방문기록 — 면회·방문 기록 (오늘)

1. 면회자·대상자·시간·면회 내용과 대상자 상태를 입력하고 **예약 등록**으로 저장합니다 (무료 10건, 이후 Pro)
2. 방문 후에는 해당 예약의 **결과 저장**으로 방문 결과를 기록합니다 — 결과 칸의 🎤로 말로 적을 수 있습니다
3. 결과 저장 시 **📷 사진 추가**로 전달 물품·대상자 상태 사진을 최대 3장까지 첨부할 수 있습니다 — 사진은 문서 말미 "첨부 사진" 칸에 나오고, 다시 열면 복원됩니다
4. 저장된 기록은 목록에 누적되며 기록함에서 확인·관리합니다

- 기록 복사·인쇄·PDF·Excel 내보내기(.xlsx)·기관에 공유(재개통 시)는 유료 표기 기능입니다

![방문 결과 패널](images/manual-04-result.webp)

## 5. 사고보고 — 사고·낙상 보고서 (오늘)

사고 발생 시각·장소·대상자·경위·응급 조치·보고 경로를 입력하면 기관 양식의 사고·낙상 보고서가 작성됩니다.

- **기록 저장**(더보기 안)으로 '저장된 보고서' 목록에 누적됩니다 (무료 10건, 이후 Pro)
- 복사·인쇄·PDF·Excel 내보내기(.xlsx)·기관에 공유(재개통 시)는 유료 표기 기능입니다
- 경위·조치 칸은 🎤 버튼으로 말로 입력할 수 있습니다
- **📷 사진 추가**: 현장·상해 부위 사진을 최대 3장까지 붙일 수 있습니다 — 선택한 사진은 자동으로 작게 줄어들어 저장되고, 출력물·PDF에 그대로 나옵니다. 사진 옆 ✕로 삭제하며 목록에는 📷 건수가 표시됩니다
- 대처카드에서 **📝 사고보고서 작성**을 눌러 열면 카드 상황에 맞는 사고 유형과 경위가 미리 기입됩니다 — 낙상 카드는 '낙상', 투약 사고는 '약물 관련'처럼 연결됩니다

![사고보고서 미리보기 — 본문과 하단 첨부 사진](images/manual-05-preview.webp)

## 6. 인수인계 — 교대 기록 (교대)

인수인계서는 **기관의 기록 문서**입니다. 개인 카톡 공유보다 기록 저장이 먼저입니다.

1. 일시·근무조·인계자·인수자를 입력합니다 — 홈 서명 설정값과 직전 저장값이 기본 채워집니다
2. 상태 요약·미완료 작업·주의사항을 작성합니다
   - "당일 일지 병합" 체크 시 오늘 저장한 일지가 자동 요약됩니다
3. **📤 공유·내보내기**를 누르면 아직 저장되지 않은 문서가 기록에 자동 저장된 뒤 메뉴가 열립니다 — 저장본이 기관 기록이 됩니다
   - 무료 저장 한도(10건)에 도달해 자동 저장이 거절되면 Pro 안내가 표시됩니다 — 기존 기록을 삭제하면 다시 저장할 수 있습니다
4. **기록 저장**(더보기 안)으로 미리 저장해둘 수도 있습니다 — 같은 문서는 중복 저장되지 않습니다

### AI 초안
인수인계 폼에도 **[AI 초안]** 버튼(더보기 안, 유료)이 있습니다 — 대상자·상태·주의사항을 기반으로 초안을 생성하며, 전송 전 가명처리 미리보기가 표시됩니다.

### 오늘 기록으로 채우기
**[오늘 기록으로 채우기]** 버튼(더보기 안)은 근무 일자의 일지·사고·방문 기록을 대상자별로 자동 집계해 대상자·상태·주의사항 초안을 채웁니다. 내용을 검토·편집한 뒤 생성·저장하세요 — 자동 제출되지 않습니다.

## 7. 근무표 — 교대 근무표 (교대)

- **Excel 내보내기(.xlsx)**: 배정 목록을 진짜 Excel 파일(.xlsx)로 저장합니다 — 셀 단위 편집·정렬 가능
- **Excel 가져오기**: CSV·xlsx 파일을 읽어 날짜+근무조+근무자 기준으로 병합합니다 — 내보낸 .xlsx를 그대로 다시 가져올 수 있어 왕복이 됩니다. 신규 등록·기존 갱신 건수가 안내되고 한도 초과분은 제외됩니다
- CSV 헤더: `날짜,근무조,근무자,메모` — 근무조는 '주간(데이)'처럼 표시명 그대로 씁니다. 근무표 복사·인쇄·PDF·Excel 왕복은 유료 표기 기능입니다

## 8. 대상자 — 수급자 명부·입소서류·CSV (대상자·돌봄)

1. 수급자 등록 시 상태(입소대기/입소중/재가이용)를 선택합니다 — 입소대기자도 동일 명부에서 관리됩니다
2. 폼 하단 체크리스트로 입소서류 14항목 수납 여부를 기록합니다 — 목록에 `서류 n/14` 표시
3. **명부 표 미리보기**: 저장된 명부가 표 형태 문서로 표시됩니다 — 공유·내보내기 메뉴에서 복사·인쇄·PDF·Word로 바로 출력합니다 (유료 표기)
4. **Excel 내보내기(.xlsx)**: 명부+서류 현황을 Excel(.xlsx)로 저장합니다
5. **Excel 가져오기**: CSV·xlsx 파일을 읽어 성명 기준으로 병합합니다 — 신규 등록·기존 갱신 건수가 안내됩니다

- 수급자 저장은 무료 10건까지 — Excel 가져오기에서도 한도 초과분은 제외됩니다 (기존 성명 갱신은 한도 무관)
- CSV 헤더: `성명,상태,호실,생년월일,비상연락처,알레르기,주의사항,메모` + 서류 단명 열. 서류 수납은 ○·O·✓·x·1 등으로 표기하며, 앱에서 내보낸 파일을 그대로 다시 가져올 수 있습니다. CSV(UTF-8·CP949 자동 인식)와 .xlsx 파일 모두 읽을 수 있습니다 — 앱에서 내보낸 .xlsx를 그대로 다시 가져올 수 있습니다

![명부 카드](images/manual-08-client.webp)

### 대상자 연결과 이력
일지·사고·방문·인수인계 폼의 대상자 입력은 명부 자동완성을 지원합니다. 미등록 이름 입력 시 **"명부에 등록"** 버튼이 나타나 등록 즉시 기록이 연결됩니다. 명부 카드의 **"이력 N건"**을 펼치면 해당 대상자의 일지·방문·인수인계·사고 기록을 시간순으로 확인할 수 있습니다.

### 보호자 주간 리포트
명부 카드의 **[주간리포트]** 버튼은 해당 대상자의 최근 7일 일지·방문·사고 기록을 요약해 보호자용 리포트를 생성합니다 — 출력물에는 기관 검토(홈 서명 설정의 확인자)·발행일이 표기되고, 공유 시 인명·연락처가 가려집니다.

### 외부 명부 가져오기
롱텀 수급자목록·이지케어·케어포 등에서 내보낸 CSV도 헤더를 자동 인식해 가져옵니다(수급자명·생활실·연락처·특이사항 등 변형 컬럼 대응).

## 11. 우리 서식 — 기관 자체 양식 (기관·행정)

실무 도구의 문서는 기관 자체 서식으로 바꿀 수 있습니다. **우리 서식** 뷰의 **기본 양식** 목록에서 도구별로 두 가지 방법을 고릅니다.

### 사본 만들기

1. 도구 옆 **사본 만들기**를 누르면 기본 양식이 복사된 편집기가 열립니다.
2. 본문을 수정·추가하고 미리보기에서 확인한 뒤 저장합니다.
3. 저장하면 해당 도구가 만드는 문서(미리보기·인쇄·공유·PDF·Word)가 사본 서식으로 바뀝니다. 기본 양식은 그대로 남고, 사본을 삭제하면 기본으로 돌아갑니다.

### 파일로 만들기

1. **파일로 만들기**를 누르고 기관이 쓰는 양식 파일(Word·Excel·CSV·PDF)을 고릅니다.
2. 파일 내용이 편집기에 들어옵니다 — `{{기록표}}`처럼 데이터가 들어갈 자리가 필요하면 미리보기에서 위치를 확인해 넣습니다. 양식의 라벨(일시·인계자 등)이 도구가 채우는 키와 겹치면 편집기에서 `{{키}}` 표기를 안내합니다.
3. 저장하면 사본 만들기와 같이 도구 출력 서식으로 적용됩니다. 이미 사본이 있으면 내용이 바뀝니다.

![양식 편집기](images/manual-11-template.webp)

### 평가점검에 기관 점검표 올리기

평가점검 화면의 **기관 점검표 불러오기**로 기관 점검표 파일(Word·Excel·CSV)을 올리면 점검 항목 자체가 기관 내용으로 바뀝니다. 표의 "영역·항목·근거" 칸을 인식합니다.
1. 파일을 올리면 바로 적용되지 않고 **인식 결과(영역·항목 나누기)를 먼저 보여줍니다** — 나뉨이 잘못됐으면 취소하고, 맞으면 적용합니다.
2. (재개통 시) 기관에 등록된 사용자는 올린 점검표가 **기관 다른 멤버에게도 자동으로 적용**됩니다 — 기관 공유 경로가 비활성인 동안에는 본인 기기에만 적용됩니다.
3. **기본 점검표 복원**으로 원래 기본 점검표로 돌아갈 수 있고, 같은 파일을 다시 올리면 체크한 상태가 유지됩니다.

## 12. 본인부담금 계산 (기관·행정)

등급·이용 형태·이용 시간을 입력하면 예상 본인부담금이 계산됩니다.

- **기본 본인부담률**: 재가 서비스는 이용료의 15%, 시설은 20%입니다.
- **감경 적용 시 실제 부담률**: 감경 40% 대상이면 재가 9%·시설 12%, 감경 60% 대상이면 재가 6%·시설 8%입니다. 기초생활수급자는 본인부담이 면제(0원)됩니다.
- **월 한도액**은 재가급여에만 적용됩니다 — 한도 초과분은 전액 본인부담입니다. 시설급여는 월 한도 대신 등급별 1일 수가 기준이며, 식재료비 등 비급여는 별도 전액 부담입니다.
- 근거(당해연도 고시): 노인장기요양보험법 §40 · 제공기준 고시 §13 · 본인부담금 감경 고시.

## 13. 기관찾기 — 출력물 기관명 설정 (기관·자료)

데이터는 국민건강보험공단 장기요양기관 시설별 현황(2026.6.10 기준) 전국 6,252개 **시설급여** 기관이며, 결과 카드에 정원·요양보호사 인력 수가 표시됩니다.

- **시설급여 기관만** 검색됩니다 — 방문요양 등 재가 기관은 현재 찾을 수 없고 기관명 직접 입력 경로도 아직 없습니다. 재가 소속 기관명 표기는 추후 지원 예정입니다.

1. 시설명·주소·전화로 장기요양기관을 검색합니다 (지역 필터 지원)
2. 결과 카드에서 **이 기관으로 설정**을 누르면 일지·인수인계·보고서 출력물 상단에 기관명이 표기됩니다
3. 설정된 기관은 `✓ 설정됨` 배지로 표시됩니다 — 미설정 시 상단 안내가 표시됩니다
4. 각 결과 카드의 **카카오맵**·**장기요양보험** 링크로 지도 위치와 공단 포털 기관 정보를 확인할 수 있습니다

## 15. 공유와 개인정보

**📤 공유·내보내기** 메뉴는 생성 문서를 외부로 내보내는 경로입니다. 수급자 데이터가 들어가는 문서(일지·인수인계·사고보고·명부·방문기록·근무표·주간리포트)는 공유·복사·PDF·Word 파일에서 인명·연락처가 자동으로 가려진 본문으로 나갑니다 — 메뉴 항목에 "(인명 가림)" 표시로 확인할 수 있습니다.

- **가림이 적용되지 않는 경로**: 인쇄·PDF 저장, Excel 내보내기 — 성명·연락처가 원문 그대로 나갑니다. 외부 전달 시에는 가림이 적용되는 경로를 사용하세요.
- **사진은 가려지지 않습니다**: 사고보고·방문기록에 첨부한 사진은 인명 가림 대상이 아니라 공유·PDF에 그대로 나갑니다 — 사진에 얼굴·성명·차량번호가 찍히지 않았는지 확인 후 공유하세요.
- 기관의 개인정보 정책을 확인한 뒤 사용하세요 — 인쇄 출력물은 원문 그대로 나가므로 공유보다 보관에 주의가 필요합니다.

> 📷 삽화 예정 [manual-15-mask] — 공유·내보내기 메뉴의 "(인명 가림)" 표시 — 개인정보 구분이 그림으로 보이는 위치

> ⚠ 기관 워크스페이스(기관 가입·관리·서버 공유)는 현재 **비활성** 상태입니다 — 개인정보 처리위탁 준비 후 다시 열립니다. 매뉴얼의 "기관 공유"는 모두 재개통 시 적용됩니다. 아래 내용은 재개통 시 안내입니다.

**요양보호사(가입)**
1. 설정 → 계정/로그인
2. 기관가입에서 관리책임자에게 받은 초대 코드 입력
3. 소속 기관·역할이 표시되면 연결 완료

**관리책임자(등록·관리)**
1. 설정 → 계정/로그인
2. 기관관리에서 기관 등록 → 8자리 초대 코드 발급
3. 요양보호사에게 코드 전달 → 멤버 목록에서 확인
4. 기관관리 메뉴는 관리책임자 확인 후에만 표시됩니다
