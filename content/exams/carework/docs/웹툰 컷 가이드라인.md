# 웹툰 컷 가이드라인 — 이야기 슬롯 → 말풍선 컷 자산 규약

> **문서 ID**: DOC-USR-26
> **범위**: exam:carework · 판본: none
> **관련 문서**: 적응형 학습 엔진 설계(DOC-USR-22 §5·§6), 인물 설정표(DOC-USR-23)

Nov 6, 2026 · @coteleaf

## 1. 컷의 정의와 주소 체계

- **컷(cut) 1개 = 스토리 슬롯 1개** — 이야기형 교재의 `<!-- story:slot:sNN -->` 블록이 웹툰 렌더(`webtoon-render.js`)에서 말풍선 씬 1개로 변환됩니다.
- **cutId = 슬롯 ID**(예: `s01`) — 런타임이 `concepts.storySlot` → 슬롯 블록을 조회해 렌더합니다. 비트 단위 분리(한 슬롯 → 여러 컷)는 개념 단위 세분 시 `s01-b2` 형태로 확장합니다.
- **concepts.cuts[]**: 개념이 참조하는 컷 목록. 현재는 storySlot 1:1(`["s01"]`) — 함정/교정 비트가 슬롯 안에 같이 있으므로 오답 시 슬롯 전체를 보여주면 됩니다.
- **items.cutOnWrong{optionIndex: cutId}**: 오답 보기 선택 시 보여줄 컷. 보기마다 다른 컷은 비트 세분 이후에 매핑합니다.

## 2. 슬롯(컷) 구조 규칙

한 슬롯은 세 비트로 구성됩니다 — 문항 변환 시 각 비트가 지문·오답·정답에 대응합니다(§5 비트→문항 표).

| 비트 | 내용 | 예(s01 식사) |
|------|------|------|
| 상황 | 장소·인물·과제 설정 | 최복순 어르신 댁 점심 지원 |
| 함정 | 미영의 초보 실수 | 「왜 제가 대신하죠?」— 대신 먹이려 함 |
| 원칙 | 박은정 선임의 교정 | 「스스로 드실 수 있게 돕는 거예요」 |

- 나레이션(`scene`)·대사(`line`)·화자(`speaker`) 비트는 렌더러가 자동 구분 — 작성자는 대사를 따옴표로 감싸면 됩니다.
- **수치·조문은 슬롯에 넣지 않습니다** — 정확한 수치는 표준형 본문의 몫이며, 슬롯은 상황·감정·행동만 담습니다(§11 리스크: 자산 간 수치 불일치 방지).

## 3. 인물 규약

「인물 설정표」(DOC-USR-23)가 정본입니다 — 미영(신입 요양보호사)·박은정(선임)·최복순(대상자, 무릎 통증만 — 편마비·당뇨 없음). 편마비 장면은 김순례(가칭) 확정 전까지 대상자를 특정하지 않습니다.

## 4. 검수표 (신규 슬롯/컷 추가 시)

- [ ] 함정 비트가 실제 흔한 실수인가 (문항의 대표 오답과 일치)
- [ ] 원칙 비트가 표준형 본문의 수치·조문과 어긋나지 않는가
- [ ] 슬롯이 한 장면으로 읽히는가 (장소·시간 도배 금지)
- [ ] 대상자 설정이 인물 설정표와 일치하는가
- [ ] 슬롯 ID가 concepts.storySlot/cuts[]와 연결됐는가
