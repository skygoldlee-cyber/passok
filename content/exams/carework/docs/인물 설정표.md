# 인물 설정표 — 서사·웹툰·문항 공통

> **문서 ID**: DOC-USR-23
> **범위**: exam:carework · 판본: none

이야기형 서사·웹툰 컷·선택형 시나리오 문항이 공유하는 인물 설정의 정본입니다. 새 장면이나 문항을 쓸 때 인물의 질환·ADL·가족 구성이 이 표와 어긋나면 안 됩니다 — 어긋남이 생기면 이 표를 먼저 고치고 모든 자산을 동기화합니다.

## 설정 규칙

1. **질환 배정 고정** — 최복순은 무릎 관절염만, 한정수는 경도인지장애(치매 초기)만 가집니다. 편마비·와상·당뇨·욕창 등 다른 상태의 장면이 필요하면 기존 인물에 덧붙이지 말고 신규 인물을 등록합니다.
2. **호칭** — 미영의 대사에서 멘토는 「선임님」, 서술 지문은 「박 선임」 또는 「박은정 선임」. 단독 「은정」 사용 금지, 의료인 등 타 인물은 「선생님」.
3. **함정 비트** — 미영의 실수는 「경험 없는 사람의 자연스러운 실수」에 둡니다(빨리 먹이기, 다그치기, 기록의 주관적 표현). 시나리오 문항의 대표 오답 보기 원천입니다.
4. **신규 인물 등록** — 편마비 대상 장면용으로 「김순례(가칭)」 어르신이 설계 문서(적응형 학습 엔진 설계, DOC-USR-22)에 예약돼 있습니다 — 도입 여부·이름 결정 전까지 편마비 장면은 어르신을 특정하지 않습니다.
5. **배경 인물** — 가족·간호사·의사 등은 장면에 필요 시 등장 가능하나, 고정 설정이 생기면 이 표에 등록해 재사용합니다.
