## 📚 Chapter 01. 업무 체크리스트 도구

> 식사·이동·배설·위생·체위 변경 등 업무별 확인 항목 — 시험의 요양보호 기술 지식을 현장 절차로 연결

**도구 명세 (초안)**

- **목적**: 업무별 표준 절차를 체크리스트로 제공, 누락 방지
- **입력**: 업무 선택 → 항목 체크 상태
- **출력**: 업무별 체크 진행률, 미완료 항목 목록
- **데이터**: 체크리스트 정의(pack 콘텐츠) + 진행 상태(localStorage)
- **시험 연계**: careprac Chapter 01·02 (신체활동·일상생활 지원)
- **단계**: 1단계 (콘텐츠만으로 구현 가능 — 뷰 로직 소량)

## 📚 Chapter 02. 상황별 대응 가이드 도구

> 낙상·식사 거부·배회·불안·응급 상황의 관찰→보고→대응 순서 안내

**도구 명세 (초안)**

- **목적**: 돌발 상황에서 표준 대응 절차를 즉시 확인
- **입력**: 상황 유형 선택
- **출력**: 상황별 관찰→보고→대응 절차 카드 (응급 시 기관 공식 절차·119 연결 안내)
- **데이터**: 상황별 절차 정의(pack 콘텐츠 — ref 기반 저작)
- **시험 연계**: caretheory Ch01(인권)·Ch04(상황별기술), careprac Ch03
- **단계**: 1단계 (정적 절차 카드 — 콘텐츠가 핵심)
- **주의**: 기관 공식 절차를 대체하지 않는 보조 안내로 명시

## 📚 Chapter 03. 관찰 기록·업무일지·인수인계 도구

> 관찰 사실을 기록 초안으로 변환 — 사업화 전략의 AI 업무일지 도구의 지식 토대이자 사전 검증 수단

**도구 명세 (초안)**

- **목적**: 버튼·템플릿 입력을 기관 양식의 기록 문장으로 조립 (AI 없이 결정론 조립부터 시작)
- **입력**: 대상자 상태 선택(식사량·수면·배변·활동·특이사항)
- **출력**: 기록 초안 텍스트(복사 가능) + 인수인계 요약
- **데이터**: 입력 항목·문장 템플릿(pack 콘텐츠) — AI 초안 생성은 후순위
- **시험 연계**: caretheory Ch04(기록·보고), careprac Ch03
- **단계**: 2단계 (규칙 기반 조립 먼저 → 이후 AI 초안 검토)
- **주의**: 공식 기록 확정은 담당자 수행 — 도구는 초안만 제공

**음성 입력 경로 (검토 확정 — 보조 입력)**

- **파이프라인**: MediaRecorder 녹음 → **온디바이스 whisper WASM** 전사 → 템플릿 문장 매핑 → 기록 초안
- **STT 선택**: `@huggingface/transformers` + ONNX (임베딩 파이프라인과 동일 스택) — 음성이 기기를 떠나지 않아 민감정보 국외이전 문제 구조적 소거, 오프라인 동작
- **기각 대안**: Web Speech API(오디오 → Google 전송, 전략 §6 충돌)·서버 STT(백엔드·비용·국외이전 고지 필요)
- **모델**: whisper-tiny는 한국어 부정확 → `base`(~75MB) 이상, `small`(~250MB) 실용 수준. 지연 로딩 + 캐시(SW/IndexedDB)로 초기 번들과 분리 — SHELL_ASSETS 예산 무관
- **제약**: iOS는 AAC 녹음 → 16kHz mono PCM 리샘플링 필요 · 30초 음성 전사 ~10–30초(모바일)
- **위치**: 버튼/템플릿 입력의 **보조 경로** — 어르신 앞 발화 부담·소음 환경으로 템플릿이 기본 (전략 §9 현장 발화 수용성은 시범 검증 대상)
- **단계**: 2단계 후반 — 템플릿 조립이 먼저, STT는 기능 플래그 뒤에

## 📚 Chapter 04. 의사소통·시나리오 훈련 도구

> 거부·반복 질문·정서 지원 대응 대화 패턴 — 이야기형(드라마·시뮬레이션) 콘텐츠와 결합

**도구 명세 (초안)**

- **목적**: 현장 대화 상황을 선택형 시나리오로 훈련
- **입력**: 시나리오 선택지
- **출력**: 선택에 따른 대응 전개·피드백
- **데이터**: 시나리오 트리(pack 콘텐츠 — 이야기형 서사 파이프라인 재사용)
- **시험 연계**: caretheory Ch01(인권)·Ch03(생활지원), careprac Ch03(인지활동)
- **단계**: 1~2단계 (story 패치 포맷으로 콘텐츠 저작 후 렌더 검토)
