### 환경 설정 및 문서 관리
스프레드시트 프로그램의 원활한 활용을 위해 프로그램 실행과 옵션 설정, 메뉴 및 기능 활용, 창 제어, 화면 인터페이스에 대한 이해가 요구됩니다. 파일 관리에서는 파일 열기와 닫기, 저장 및 다른 이름으로 저장과 저장 옵션, 내보내기, 게시 등의 기능을 다룹니다. 또한 통합 문서를 효율적으로 관리하기 위해 시트의 삽입, 삭제, 선택, 숨기기, 복사 및 이동, 그룹화, 이름 바꾸기 작업을 수행할 수 있어야 합니다. 아울러 통합 문서와 시트의 보호 기능을 적용하고, 통합 문서의 공유 및 병합 기능을 적절히 운용해야 합니다.

### 데이터 입력 및 편집
데이터 입력 단계에서는 각종 데이터의 입력과 더불어 일러스트레이션 활용, 이름, 메모 및 노트, 윗주 삽입 기능을 학습합니다. 데이터 편집 항목에는 데이터의 직접적인 편집, 찾기 및 바꾸기, 영역 설정 방식에 대한 이해, 데이터의 복사·이동·삭제, 그리고 다양한 붙여넣기 옵션의 활용이 포함됩니다. 서식 설정 과정에서는 기본 서식과 사용자 지정 서식, 특정 조건에 따라 서식을 부여하는 조건부 서식을 지정할 수 있어야 합니다. 또한 일관된 문서 작성을 위해 서식 파일과 스타일을 사용하는 방법을 익혀야 합니다.

### 데이터 계산
기본 계산식에서는 셀 참조 방식의 구조를 이해하고 수식의 입력과 편집, 내장함수를 사용한 수식 입력을 다룹니다. 시트 간 및 통합 문서 간에 연계되는 수식 계산 방법을 학습하며, 수식 작성 시 나타나는 오류 메시지를 확인하고 처리하는 능력을 기릅니다. 나아가 고급 계산식 영역에서는 사용자가 직접 정의하는 함수와 배열수식 입력 방식을 학습하여 보다 복잡한 계산 작업을 수행합니다.

### 데이터 관리 및 분석
기본 데이터 관리에서는 기본 및 사용자 지정 데이터 정렬, 자동 필터와 고급 필터, 텍스트 나누기, 그룹 및 윤곽 설정, 중복된 항목 제거, 데이터 유효성 검사 기법을 다룹니다. 외부 데이터 관리의 경우 외부 데이터를 가져오거나 외부 데이터베이스를 연계하여 이용하는 방식을 포함합니다. 데이터 분석 항목에서는 데이터 통합, 데이터 표, 부분합, 목표값 찾기, 시나리오 분석, 피벗 테이블 및 피벗 차트 기능을 통해 대량의 데이터를 체계적으로 요약·분석합니다.

### 차트 활용 및 출력 작업
차트 작성 항목에서는 차트를 작성하는 기본 방법과 차트의 종류, 차트를 이루는 구성 요소를 이해해야 합니다. 차트 편집에서는 이미 작성된 차트의 종류를 변경하거나 세부 구성 요소를 편집하는 작업을 다룹니다. 출력 작업의 경우 페이지 레이아웃 설정을 통해 테마 변경, 페이지 설정, 크기 조정, 시트 옵션, 머리글/바닥글 도구를 다루며, 인쇄 작업에서는 페이지 설정, 인쇄 미리보기 설정, 인쇄 옵션 및 프린터 속성 설정을 통해 문서를 알맞게 인쇄하도록 합니다.

### 매크로 활용
매크로 작성 영역에서는 매크로의 기본 개념을 정립하고 매크로를 직접 생성, 수정, 삭제하는 절차를 익힙니다. 작성된 매크로는 직접 실행하거나 컨트롤과 연계하여 편리하게 작동시킬 수 있습니다. 매크로 편집 항목에서는 기존 매크로의 내용을 편집하거나 VBA 모듈을 작성하고 편집하는 방법을 다룹니다.

### DBMS 파일 사용 및 관리

데이터베이스 일반 과목의 DBMS 파일 사용 항목은 데이터베이스 파일 관리와 인쇄 작업으로 구성됩니다. 데이터베이스 파일 관리에서는 데이터베이스의 개념, 구축 절차, 구성요소, 종류 및 구조를 이해하고, 키(Key)의 개념, 관계도(ERD)의 이해 및 작성, 관계형 모델, 정규화에 대한 이론적 기초를 다룹니다. 아울러 새 데이터베이스 파일 생성 및 데이터베이스 파일 관리 실무를 포함합니다. 인쇄 작업 세부항목에서는 페이지 설정, 인쇄 미리보기 설정, 인쇄 옵션 설정, 프린터 속성 설정에 관한 내용을 학습합니다.

### 테이블 활용

테이블 활용은 테이블 작성, 제약요건 설정, 데이터 입력 세부항목으로 구분됩니다. 테이블 작성에서는 테이블 생성과 삭제, 테이블 속성을 비롯하여 필드의 생성·변경·이동·삭제, 필드의 데이터 형식 및 일반·조회 속성을 다룹니다. 제약요건 설정에서는 제약 요건의 종류 및 의미, 기본 키의 설정 및 특징, 입력 마스크와 유효성 검사 규칙, 인덱스 설정 및 특징, 테이블 간 관계 설정을 포함합니다. 데이터 입력 단계에서는 직접적인 데이터 입력과 찾기/바꾸기, 레코드 삭제·요약·정렬뿐만 아니라 외부 데이터 가져오기, 데이터 내보내기, 데이터 수집 기능의 활용 방법을 다룹니다.

### 쿼리 활용

쿼리 활용 항목은 선택 쿼리 사용, 실행 쿼리 사용, SQL 명령문 사용으로 나누어집니다. 선택 쿼리 사용에서는 일반 선택 쿼리, 계산 쿼리, 매개 변수 쿼리의 작성 방법을 다루며, 실행 쿼리 사용에서는 테이블 만들기 쿼리, 추가 쿼리/삭제 쿼리, 업데이트 쿼리 및 크로스탭 쿼리를 학습합니다. SQL 명령문 사용 항목에서는 Insert, Select, Update, Delete 명령문의 작성과 실행을 다룹니다. 이에 더해 Where 절, Order By 절, Group By ~ Having 절의 구문 작성과 연산자 및 함수 활용, alias 사용법이 포함됩니다.

### 폼 및 보고서 활용

폼 활용은 기본 폼 작성, 컨트롤 사용, 기타 폼 작성 세부항목으로 구성되며, 보고서 활용은 기본 보고서 작성을 포함합니다. 기본 폼 작성에서는 폼 생성 및 삭제, 폼 각 영역의 이해 및 활용, 폼 속성, 연산자 및 함수 활용, 조건부 서식을 학습합니다. 컨트롤 사용에서는 컨트롤의 개념과 종류, 컨트롤의 생성·레이아웃·맞춤·위치·크기·표시여부 조정 및 속성 설정을 다루며, 기타 폼 작성에는 폼 분할, 여러 항목, 차트 만들기, 가져오기/내보내기가 포함됩니다. 기본 보고서 작성 항목에서는 보고서의 생성과 삭제, 보고서 속성 설정, 보고서 각 영역의 이해 및 활용을 다룹니다.

### 컴퓨터활용능력 1급 실기 검정 개요
컴퓨터활용능력 1급 실기시험의 직무분야는 경영·회계·사무(사무)이며, 적용기간은 2027년 1월 1일부터 2029년 12월 31일까지입니다. 직무내용은 컴퓨터와 주변기기를 이용하고 인터넷을 사용하는 사무환경에서 스프레드시트, 데이터베이스관리시스템 등의 응용 프로그램을 이용하여 필요한 정보를 수집, 분석, 활용하는 작업으로 규정되어 있습니다. 검정방법은 10문제 이내의 컴퓨터 작업형으로 시행되며, 시험시간은 90분이 주어집니다.

### 데이터베이스 보고서 및 모듈 활용
보고서 작성 영역에서는 그룹화 및 정렬, 요약 정보, 조건부 서식, 날짜 및 페이지 정보, 연산자 및 함수 활용을 다룹니다. 컨트롤 사용 시에는 컨트롤의 개념과 종류, 생성, 레이아웃, 맞춤, 위치, 크기, 표시여부 및 속성 설정을 평가하며, 레이블·업무 문서 양식·우편 엽서 보고서 작성과 페이지 설정, 가져오기 및 내보내기 기능이 포함됩니다. 모듈 활용 영역에서는 매크로의 개념, 매크로의 생성·수정·삭제, 매크로 함수 사용 및 컨트롤 연계뿐만 아니라 오브젝트 프로그래밍 개념에 기반한 이벤트 프로시저의 생성·수정·삭제와 실행 및 컨트롤 연계 작업을 요구합니다.

### 스프레드시트 실무: 응용 프로그램 준비 및 통합 문서 관리
스프레드시트 실무의 프로그램 환경 설정 단계에서는 정보 가공을 위한 응용 프로그램을 실행하고 환경 파악 및 옵션 설정을 수행할 수 있어야 합니다. 파일 관리 항목에서는 작업 파일의 열기와 닫기, 다양한 저장 옵션을 통한 저장, 공동작업을 위한 파일 배포 및 내보내기 능력을 다룹니다. 또한 통합 문서 관리하기를 통해 새로운 시트의 삽입, 시트 복사·이동·이름 바꾸기·그룹 설정 작업을 진행하며, 시트 보호 및 통합 문서의 보호, 공유, 병합 기능을 활용할 수 있어야 합니다.

데이터 입력하기에서는 업무에 필요한 데이터를 특성에 맞게 입력하고, 시각화를 위한 일러스트레이션 개체 삽입과 이름, 메모 및 노트, 윗주 기능을 사용해 기타 정보를 입력합니다. 데이터 편집 시에는 입력 데이터의 수정, 다양한 영역 설정, 복사하여 다른 형식으로 붙여넣기를 수행할 수 있어야 합니다. 아울러 데이터 가독성과 파악 용이성을 위한 기본 서식, 사용자지정 서식, 조건부 서식, 서식파일 및 스타일을 적용할 수 있어야 하며, 데이터 계산 작업을 위해 기본 계산식과 시트 및 통합 문서 간 수식을 활용할 수 있어야 합니다.

계산 결과의 정확성을 확보하기 위해 오류 메시지를 처리할 수 있어야 합니다. 효율적인 계산 작업을 진행할 때는 계산식에 함수를 활용하며, 복잡한 수식을 단순화하기 위해 사용자 정의 함수를 정의하여 사용할 수 있습니다. 또한 수식에 배열을 사용함으로써 일반적인 다른 수식으로는 처리할 수 없는 계산을 수행할 수 있습니다.

### 차트 활용

### 출력 작업
인쇄물을 출력하기 위해 페이지 레이아웃을 설정하며, 화면 보기 상태에서 인쇄물을 확인하고 필요에 따라 페이지 레이아웃을 변경할 수 있습니다. 인쇄 작업을 수행할 때는 인쇄물 출력을 위한 프린터 속성을 지정할 수 있습니다. 이와 함께 원활한 출력을 지원하는 다양한 인쇄 옵션을 설정하여 작업을 완료합니다.

### 매크로 활용

### DBMS 파일 사용 및 인쇄
효율적인 데이터 관리를 위해 새 데이터베이스 파일을 생성하고 데이터베이스 도구를 이용하여 해당 파일을 관리할 수 있습니다. 데이터베이스 작업물의 출력을 위해 페이지 설정과 인쇄 미리보기 설정을 진행할 수 있습니다. 또한 각 개체별로 다양한 인쇄 옵션을 지정하고, 인쇄물 출력을 위한 프린터 속성을 설정할 수 있습니다.

### 테이블 작성
데이터가 저장될 기본 공간인 테이블을 새롭게 생성할 수 있습니다. 테이블 구성 시에는 각 필드에 적합한 데이터 형식과 속성을 올바르게 설정해야 합니다. 아울러 테이블 내에서 원하는 데이터와 레코드를 찾아 관리하는 작업을 수행할 수 있습니다.

데이터 계산 작업을 위해 기본 계산식을 사용할 수 있어야 하며, 분산된 데이터 계산을 위한 시트 및 통합 문서 간 수식 사용과 오류 메시지 처리 능력이 요구됩니다. 데이터 관리 측면에서는 분산 데이터의 통합 관리를 위한 워크시트 관리, 기본 데이터 도구 사용, 데이터 형식과 사용자 입력을 제어하기 위한 데이터 유효성 검사 설정을 수행할 수 있어야 합니다. 더불어 데이터의 요약과 보고를 위한 데이터 분석 도구 사용 및 수식에 여러 값 집합을 적용해 결과를 확인하는 가상 분석 도구 활용을 평가합니다.

### 스프레드시트 실무: 차트 활용

데이터의 특성에 부합하는 차트 종류를 선택하여 차트를 작성하고, 데이터 내용에 맞춰 차트의 구성 요소를 변경할 수 있어야 합니다. 또한 작성된 차트의 크기를 조정하여 재배치할 수 있어야 하며, 차트에 표현하고자 하는 데이터 원본을 선택하여 반영하는 등 차트 편집 작업을 수행할 수 있어야 합니다.

### 차트 편집 및 서식 파일 활용
차트는 작성 목적과 필요에 따라 적합한 차트 종류로 변경할 수 있으며, 이미 작성된 차트의 서식 또한 유연하게 변경할 수 있습니다. 또한 동일하거나 유사한 형태의 차트 작업이 반복되는 경우에는 해당 차트를 서식 파일로 저장하여 효율적으로 재활용할 수 있습니다.

### 출력 작업 (페이지 레이아웃 및 인쇄 설정)
인쇄물 출력을 진행할 때에는 먼저 적절한 페이지 레이아웃을 설정하여 인쇄 형태를 구성할 수 있습니다. 화면 보기 상태에서 인쇄물 상태를 미리 확인하며 페이지 레이아웃을 필요에 맞게 변경할 수 있습니다. 또한 원활한 출력을 위해 프린터 속성을 알맞게 설정하고 다양한 인쇄 옵션을 지정하여 인쇄 작업을 수행할 수 있습니다.

### 매크로 작성 및 실행
반복적으로 수행되는 일련의 작업을 단순화하고 작업 효율을 높이기 위해 매크로를 작성할 수 있습니다. 이렇게 작성된 매크로는 시트 내의 컨트롤과 연계하여 손쉽게 실행할 수 있습니다.

### 1급 과목 및 항목 체계
1급 평가 영역은 컴퓨터 일반, 스프레드시트 일반, 데이터베이스 일반의 세 과목으로 구분됩니다. 컴퓨터 일반에서는 컴퓨터 시스템 활용, 디지털 정보 활용, 컴퓨터 시스템 보호 항목을 통해 운영체제·주변기기, 파일·폴더, 인터넷 정보, 보안 위협 대응 및 백업·복구 등을 다룹니다. 스프레드시트 일반에서는 기본 활용, 데이터 계산·분석, 매크로·고급 기능을 다루며, 데이터베이스 일반에서는 테이블 설계와 관계를 포함한 데이터베이스 구축과 폼·쿼리·보고서 작성을 포함한 데이터 입력·조회·분석 항목을 다룹니다.
