# 인물 설정표 — 서사·웹툰·문항 공통

> **문서 ID**: DOC-USR-28
> **범위**: exam:hazmat · 판본: none

이야기형 서사·선택형 시나리오 문항·학습 보조 콘텐츠가 공유하는 인물 설정의 정본입니다. 새 장면이나 문항을 쓸 때 인물의 역할·결점·함정 유형·시그니처 장치가 이 표와 어긋나면 안 됩니다 — 어긋남이 생기면 이 표를 먼저 고치고 모든 자산을 동기화합니다.
아크·복선·장면 공식 등 서사 운용 규칙은 `교재/docs/SAFECHEM_이야기형교재_시리즈설정문서.md`(Series Bible)를 따릅니다.

## 설정 규칙

1. **역할·함정 배정 고정** — 각 인물의 역할과 함정 유형은 고정입니다. 다른 함정이 필요하면 기존 인물에 덧붙이지 말고 신규 인물을 등록합니다.
2. **호칭** — 도현의 대사에서 멘토는 「선임님」, 지문은 「백 선임」. 점검관은 반드시 「남 소방위」, 기사는 「정 씨」로 통일합니다. 사업장명은 **SAFECHEM**(대문자).
3. **함정 비트** — 도현의 실수는 항상 *어림 기억*에서 나오는 자연스러운 실수에 둡니다(경계값·배수·기한의 어림). 김 반장의 위반은 *관행*에 둡니다. 억지·악의·무리수 금지 — 시나리오 문항의 대표 오답 보기 원천입니다.
4. **신규 인물 등록** — 반복 등장하는 명명 인물은 사용 전에 이 표에 등록합니다. 등록 없이 한 번 쓰고 버리는 인물은 배경 인물로 처리합니다.
5. **배경 인물** — 직원·작업자·공무원 등은 장면에 필요 시 등장 가능하나, 고정 설정이 생기면 이 표에 등록해 재사용합니다.
6. **사실 무결성** — 인물이 실수로 틀린 수치를 말할 수 있으나, 정정 문장에는 반드시 정확한 법령·수치·공식이 나와야 하며 틀린 수치가 답처럼 남지 않게 합니다. ⚖️ 법령 원문·🔢 수치·기한·배수·📊 표·화학식은 각색 대상이 아닙니다.
