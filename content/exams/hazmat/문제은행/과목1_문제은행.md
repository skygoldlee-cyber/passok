> **정답: ①** [교재: L188](<../교재/physchem/1과목_물질의 물리화학적 성질_표준형.md#L186>)

> **📖 교재 근거 ([교재: L188](<../교재/physchem/1과목_물질의 물리화학적 성질_표준형.md#L186>)):**
> * **수소와 산소의 화합물 (H₂O와 H₂O₂):**
> * 물(H₂O): 수소 2 g에 결합한 산소 질량 = 16 g
> * 과산화수소(H₂O₂ - 제6류 위험물): 수소 2 g에 결합한 산소 질량 = 32 g
> * 일정 질량의 수소(2 g)와 결합하는 산소의 질량비 = 16 : 32 = 1 : 2
> * **질소와 산소의 화합물 군:**
> **해설**: 배수 비례의 법칙은 반드시 두 가지 원소로만 구성된 화합물 쌍에서 성립한다. 수소와 산소의 두 가지 원소로 이루어진 H₂O와 H₂O₂는 일정 질량의 수소(2g)와 결합하는 산소의 질량비가 16:32(=1:2)로 간단한 정수비가 성립하므로 배수 비례의 법칙이 적용된다.

**Q2.**

> **정답: ①** [교재: L40](<../교재/physchem/1과목_물질의 물리화학적 성질_표준형.md#L40>)
>
> **📖 교재 근거 ([교재: L40](<../교재/physchem/1과목_물질의 물리화학적 성질_표준형.md#L40>)):**
> * **융해 (Melting)**: 고체가 열을 흡수하여 액체로 변하는 과정 (ΔH > 0, 흡열). 고체가 용융점에 도달했을 때 열에너지가 가역적으로 전달되며 상전이가 일어난다.
> * **응고 (Freezing)**: 액체가 열을 방출하여 고체로 변하는 과정 (ΔH < 0, 발열).
> * **기화 (Vaporization/Evaporation)**: 액체가 열을 흡수하여 기체로 변하는 과정 (ΔH > 0, 흡열).
> - *참고*: 물이 기화하여 생성된 수증기는 눈에 보이지 않는 무색투명한 기체 상태이며, 일상에서 관찰되는 김이나 구름은 대기 중에 분산된 미세한 액체 상태의 물방울이다.
> * **액화 (Liquefaction/Condensation)**: 기체가 열을 방출하여 액체로 변하는 과정 (ΔH < 0, 발열).
> **해설**: 융해, 기화, 고체에서 기체로의 승화 과정은 열을 흡수하는 흡열 과정(ΔH > 0)이며, 입자의 무질서도가 증가하여 계의 엔트로피가 증가(ΔS_계 > 0)한다. 반면 응고, 액화, 기체에서 고체로의 승화는 열을 방출하는 발열 과정(ΔH < 0)이고 계의 엔트로피는 감소한다.

**Q3.**

> **정답: ④** [교재: L396](<../교재/physchem/1과목_물질의 물리화학적 성질_표준형.md#L395>)
>
> **📖 교재 근거 ([교재: L396](<../교재/physchem/1과목_물질의 물리화학적 성질_표준형.md#L395>)):**
> * 결합 차수가 높을수록(단일 결합 < 이중 결합 < 삼중 결합) 결합 에너지는 증가하고 결합 길이는 짧아진다.
> * 예: 질소 분자(N≡N)는 삼중 결합으로 결합 해리 에너지가 매우 커 상온에서 대단히 안정한 불활성 거동을 보인다.
> **해설**: 결합 차수가 높아질수록(단일 결합 < 이중 결합 < 삼중 결합) 결합 에너지는 증가하고 결합 길이는 짧아진다. 따라서 결합 길이가 길어지고 에너지가 감소한다는 설명은 옳지 않다.

> **정답: ②** [교재: L53](<../교재/physchem/1과목_물질의 물리화학적 성질_표준형.md#L54>)

> **정답: ③** [교재: L737](<../교재/physchem/1과목_물질의 물리화학적 성질_표준형.md#L740>)

> **📖 교재 근거 ([교재: L737](<../교재/physchem/1과목_물질의 물리화학적 성질_표준형.md#L740>)):**
> *   **강산 + 강염기 생성 염**: 가수분해를 하지 않으며, 수용액은 **중성(pH = 7)**이다. (예: NaCl, KNO₃)
> *   **약산 + 강염기 생성 염**: 약산의 짝염기가 가수분해되어 OH⁻를 방출하므로 **염기성(pH > 7)**을 띤다.
> CH₃COONa(aq) → Na⁺ + CH₃COO⁻
> CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻
> **해설**: 약산과 강염기가 반응하여 생성된 아세트산나트륨(CH₃COONa)은 약산의 짝염기(CH₃COO⁻)가 물과 반응(가수분해)하여 OH⁻를 방출하므로 수용액이 염기성을 띤다. 강산과 강염기가 생성한 염은 가수분해를 하지 않아 중성이며, 염화암모늄은 약염기의 짝산이 가수분해하여 산성을 나타낸다.
