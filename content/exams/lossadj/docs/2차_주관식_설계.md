## 1. 2차 시험 개요

- **형식**: 주관식 서술형 (객관식 아님)
- **과목** (시행령 별표 2의2):
  - 가. 농작물재해보험 및 가축재해보험의 이론과 실무
  - 나. 농작물재해보험 및 가축재해보험 손해평가의 이론과 실무
- **1차 합격 후 2년 유효** — 1차만 대비하는 현 팩과 응시 주기가 다름.

## 1-1. 기출 유형 분석 (공식 문제지 실측 — 제3회 2017·제9회 2023)

공식 문제지 2개 회차(apfs.kr 자료실·Q-net 게시본) 구조 실측:

| 유형 | 배점 | 형식 | 예시 |
| --- | --- | --- | --- |
| 단답형(빈칸) | 5점 | ㉠~㉤ 답란 — 용어 정의·보장개시일·판정기준·할인율 수치 | "유량검정젖소 요건 ( ① )kg 이상" |
| 판정형 | 5점 | 손해내용별 "해당/미해당", 가입 "가능/불가능"+사유 | 지진 피해 손해내용 보상 여부 |
| 서술형 | 15점 | 정의·절차·법적특성 자유서술 | "손해보험계약의 유상계약성·쌍무계약성 기술" |
| 계산형 | 5~15점 | 계산과정+답+단위 필수, 소수처리 지시문 명시 | 수확량→피해율→보험금 3단계 산출 |
| 사례형 | 15점 | 조건1~3 제시 후 물음1~N 답하기 | 시나리오 기반 가입판정·보험금 산정 |

**실측 유의사항(문제지 명문)**: "계산문제는 반드시 계산과정, 답, 단위를 정확히 기재〈부분점수 없음〉", "계산과정에서 임의적인 반올림 또는 절사 금지", "농업재해보험ㆍ손해평가의 이론과 실무를 기준으로 답안 작성".

**공식 답안 비공개** — 모범답안·채점기준 일체 미공개 → 플랫폼용 모범답안·rubric은 자체 제작 필수.

**자료 확보처·라이선스**:
- 농업정책보험금융원 자료실(apfs.kr) — 「농업재해보험ㆍ손해평가의 이론과 실무」 이론서(zip) + 기출문제 게시. 이론서는 **"무단 도용·상업적 사용·배포 금지"** 명문 → ref_md 전재 불가, 참조 링크만 선언
- 기출문제 — 국가시험 문제지도 자유 재배포 대상 아님 → 유형 분석만 활용, 문항은 자체 제작
- 손해평가요령(고시) — 법령성 고시로 자유 이용 가능 → 계산형 문항의 산정식 근거로 직접 인용 가능(별표 1)

## 3. 콘텐츠 설계 제안

- **문항 저장**: `문제은행/2차_주관식_연습.md` — `### S` 헤딩으로 서술 문항 구분(기존 `### Q`와 분리). 파일명이 `과목N_` 접두가 아니므로 자동등록 대상에서 제외되어 빌드 미편입 (sync_textbook_files 규칙).
- **문항 포맷 (실측 기출 반영)**:

```markdown
### Sn. 제목
- **유형**: 단답형|판정형|서술형|계산형|사례형 · **배점**: 5|15점 · **근거**: 문서명 별표/조문
**문제**: (조건 표 + 지시문, 소수처리 지시 포함)
**모범답안**: (계산과정 단계별 + 최종답 + 단위)
**채점기준**: - [ ] 항목 (배점) ... — 자기채점 체크리스트
**흔한 오류**: (선택)
⚖️ [근거문서: LNN](<../참조자료/ref_md/...#LNN>)
```

- **유형 분류 (실측 5종)**: 단답형(빈칸 ㉠~㉤), 판정형(해당/미해당·가능/불가능), 서술형(정의·절차), 계산형(과정+답+단위), 사례형(조건+복수 물음)
- **근거 인용**: 기존 `#LNN` 체인 유지 — 손해평가요령 별표 1(보험금 산정식)·별표 2(조사방법)를 주 근거로 활용
- **모범답안 스키마**: 문항당 `rubric`(항목별 배점·필수 키워드), `modelAnswer`, `commonErrors` 필드 — 공식 채점기준 비공개이므로 전량 자체 제작
- **현황**: `2차_주관식_연습.md`에 파일럿 10제 수록 (계산형 5 + 단답형 2 + 서술형 2 + 판정형 1). 이론서 기반 수치는 `ref_md/과목5/농업재해보험 손해평가 핵심요지(자체편집)` — 공식 이론서(무단전재금지)에서 사실·수치만 추출한 자체 편집본

## 4. 채점 설계 제안

- **1단계(구현 완료)**: 자기채점 모드 — 서술 입력 후 모범답안·채점기준과 대조해 사용자가 체크리스트로 자가 평가. 구현 `src/written/written-practice.js`(`parseWrittenBank` 파서 + 자기채점 오버레이: 답안 textarea·모범답안/rubric 토글·항목 체크·⚖️ 인용 → 문제집 뷰어 `#LNN` 연동). 진행 저장 `STORAGE_KEYS.WRITTEN_PRACTICE`(시험 스코프·백업 대상), 카드 노출은 `exams.json` `features.writtenPractice` + `manifest.written[]` 선언 시에만 — 시험 뷰 "주관식 연습" 카드 → `WrittenPractice.openWritten`.
- **2단계(구현 완료)**: LLM 보조 채점 — `src/written/written-grading.js`. rubric+모범답안+수험생 답안 전달 → 항목별 충족(met)·피드백 JSON → 체크박스에 제안 반영(사용자 조정 가능)+결과 스냅샷 저장. 공급자 openai·anthropic·gemini(`llm_client.js` PROVIDERS 미러), 키는 `WRITTEN_AI_KEY` 디바이스 로컬(백업·동기 제외 — FORMULA_GEMINI_KEY 계약). 점수는 LLM 산출 불신·클라이언트 합산. 자기평가 완료는 여전히 사용자 수동.
- 학습 진도 연동: 서술 문항은 `isAnswered` 대신 "자기평가 완료" 플래그로 별도 추적 (구현됨 — 문항 id `Sn` 기준 `{a:답안, c:[체크인덱스], d:완료ts}`).
