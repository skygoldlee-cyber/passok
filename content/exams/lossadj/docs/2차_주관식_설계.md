# 손해평가사 2차(주관식) 설계 메모

> **문서 ID**: DOC-USR-10
> **범위**: exam:lossadj · 판본: none
> **관련 SPEC ID**: 해당 없음 (시험 팩 설계 메모 — 기능 명세 아님)
>
> **문서 성격**: lossadj 팩의 2차 시험(서술형) 지원 설계 초안 — 현재 플랫폼 런타임에는 미편입.
> **근거**: 시행령 별표 2의2(제12조의4 관련), 농업정책보험금융원 시행계획 공고.

## 1. 2차 시험 개요

- **형식**: 주관식 서술형 (객관식 아님)
- **과목** (시행령 별표 2의2):
  - 가. 농작물재해보험 및 가축재해보험의 이론과 실무
  - 나. 농작물재해보험 및 가축재해보험 손해평가의 이론과 실무
- **1차 합격 후 2년 유효** — 1차만 대비하는 현 팩과 응시 주기가 다름.

## 2. 현 플랫폼과의 갭

| 항목 | 현재 런타임 | 2차 요구사항 |
| --- | --- | --- |
| 문제 유형 | 4지선다·복수정답·단답형 | 서술형(장문 자유서술)·계산형(보험금 산정) |
| 채점 | 정답 매칭(결정론) | 키워드·논점 기반 부분점수 — 자동채점 불가 또는 LLM 채점 필요 |
| 모범답안 | 해설 문자열 | 채점기준표(rubric) + 모범답안 + 감점 요소 |
| 시험 흐름 | 과목별 N문항 객관식 | 과목별 서술 문항 + 시간제 |

## 3. 콘텐츠 설계 제안

- **문항 저장**: `문제은행/2차_주관식/` 별도 디렉터리, `### S` 헤딩으로 서술 문항 구분(기존 `### Q`와 분리).
- **모범답안 스키마**: 문항당 `rubric`(항목별 배점·필수 키워드), `modelAnswer`, `commonErrors` 필드.
- **근거 인용**: 기존 `#LNN` 체인 유지 — 손해평가요령 별표(보험금 산정식)를 주 근거로 활용.
- **유형**:
  - A형(서술): 개념·절차 서술 (예: "종합위험방식의 보험가액 산정방법을 서술하시오")
  - B형(계산): 별표 1 산정식 적용 수치 계산 (예: 피해율·보험금 계산)
  - C형(사례): 손해평가 시나리오 판단·처리절차 서술

## 4. 채점 설계 제안

- **1단계(근시일)**: 자기채점 모드 — 서술 입력 후 모범답안·채점기준과 대조해 사용자가 체크리스트로 자가 평가. 플랫폼 변경 최소.
- **2단계(후속)**: LLM 보조 채점 — rubric 전달 → 항목별 충족 여부·부분점수·피드백 생성 (ai:explain 계열과 동일한 로컬 키 계약).
- 학습 진도 연동: 서술 문항은 `isAnswered` 대신 "자기평가 완료" 플래그로 별도 추적.

## 5. 범위 외(Non-goals) — 현 단계

- 객관식 런타임에 2차 문항 편입 금지 (manifest의 `exams[]`/`integratedExam` 미등록 유지).
- 자동채점의 공식 인정 수준 정확도 요구 — 학습 보조 수준에서만 활용.
- 가축재해보험·양식수산물 영역 본문 — 현 파일럿은 농작물 중심.
