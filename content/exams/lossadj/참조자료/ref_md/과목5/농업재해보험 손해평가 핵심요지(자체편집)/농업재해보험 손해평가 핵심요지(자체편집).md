# 농업재해보험 손해평가 핵심요지 (자체편집)

> **문서 성격**: 법령·고시 아님 — 손해평가 실무 수치·기준의 자체 편집 요지
> **기반 자료**: 농업정책보험금융원「농업재해보험·손해평가의 이론과 실무」2026년 수정본(2026.3.31 등재, 2025.12.31 기준 법령·사업시행지침·약관 반영) — 원문은 "무단 도용·상업적 사용·배포 금지" 고지가 있어 본 문서는 수치·산식·기준 사실만 자체 문장으로 재구성한 요지이며 원문 표현을 수록하지 않음
> **용도**: lossadj 팩 2차(주관식) 연습 문항의 근거 + 손해평가 기준 학습 — 문제은행 `2차_주관식_연습.md`와 연동
> **주의**: 세부 적용은 연도별 업무방법서·약관의 정본이 우선. 본 요지는 시험 핵심 수치 위주의 발췌 편집본

## 1. 손해평가 기본 흐름

- 손해평가 절차: 손해발생 사실 확인 → 손해 조사(손해액 확정) → 보험가액 평가 → 보험금 산정
- 조사 시기 원칙: 피해사실 확인이 가능한 시기, 사고 접수 후 지체 없이 실시 (생육시기별로 조사 종류 구분)
- 조사 방법: 전수조사(목적물 전부 조사) 또는 표본조사(통계이론 기반 산정 표본만 조사) — 품목별 표본주수·표본구간표에 따라 표본 규모 산정

## 2. 과수원 조사 핵심 산식

| 조사 | 산식·기준 |
| --- | --- |
| 유과타박률 | 표본주의 피해유과수 합계 ÷ (피해유과수 + 정상유과수) — 표본주는 품목별 표본주수표대로 선정, 주당 동서남북 4개 가지 × 가지당 5개 이상 유과 표본 조사. 우박 피해·5종 한정 특약 가입건 대상 |
| 낙엽률 | 표본주의 낙엽수 합계 ÷ (낙엽수 + 착엽수) — 단감·떫은감, 수확연도 6월 1일 이후 적과종료 이전 낙엽피해 시 '5종 한정 특약' 가입건. 낙엽수는 잎이 떨어진 자리를 계수 |
| 과실침수율 | 침수된 착과(화)수 ÷ 전체 착과(화)수 → 침수주수 = 침수피해 나무수 × 과실침수율 |
| 미보상감수량 | (평년수확량 − 수확량) × 미보상비율 — 보상 손해 이외 원인으로 감소한 과실 비율 |
| 조사대상나무수 | 실제결과나무수 − 고사나무수 − 미보상나무수 − 수확완료나무수 − 수확불능나무수 |
| 조사대상면적 | 실제경작면적 − 고사면적 − 타작물 및 미보상면적 − 기수확면적 |

- 적과후 착과수 조사: 사과·배·단감·떫은감 가입 과수원 전체 대상, 통상적 적과·자연낙과(떫은감은 1차 생리적 낙과) 종료 시점에 실시

## 3. 벼 품목 판정 기준

- **경작불능**: 식물체 피해율 65% 이상 + 계약자가 경작불능보험금 신청 → 보험금 지급 후 계약 소멸. 식물체 피해율 65% 이상이면 수확감소보험금 지급하지 않음
- **수확불능(벼만)**: 제현율(精玄率, 조곡 대비 정미 비율)이 65%(분질미는 70%) 미만으로 정상 출하 불가 + 계약자가 수확불능보험금 신청
- 수확포기 인정 요건(하나 충족): ①당해연도 11월 30일까지 미수확 ②미수확 상태로 갈아엎음(로터리 등) ③수확물 전량이 시장 미유통 확인
- 실제경작면적이 보험가입면적 대비 10% 이상 차이 시 계약사항 변경 필요

## 4. 밭작물·기타 기준

- **병·해충 등급별 인정비율** (감자): 1급(역병·모자이크병 등) 90% / 2급(홍색부패병·시들음병 등) 70% / 3급(반쪽시들음병·탄저병 등) 50%
- 전수조사 수확량 산정 (콩·팥): 전체 종실중량 × (1 − 함수율) ÷ 0.86
- 종합위험 생산비보장 대상품목: 고추·브로콜리·배추(고랭지·월동·봄)·무(고랭지·월동·가을)·대파·쪽파·실파[1형]·메밀·시금치(노지)·양상추
- 옥수수 농업수입감소 피해율: (기준수입 − 실제수입) ÷ 기준수입 (100% 상한) — 기준가격과 수확기가격 비교 방식으로 손해액 분기 산출

## 6. 가축재해보험 손해평가 기준

- **특별약관 구조**: 일반조항 9개 + 부문별 13개(소 1·돼지 2·돼지가금공통 2·말 4·기타가축 3·축사 1) = 총 22개
- **협정보험가액 특별약관 대상**: 종빈우·종모돈·종빈돈·자돈(포유·이유)·종가금·유량검정젖소 등 기평가보험 특약
- **유량검정젖소 요건**: 대상농가 — 직전월 305일 평균유량 10,000kg 이상 + 평균체세포수 30만 이하 / 대상젖소 — 최근 산차 305일 유량 11,000kg 이상 + 체세포수 20만/ml 이하 → 요건 충족 시 시가 무관 협정보험가액 특약 가입 가능
- **계약 전 알릴의무 위반**: 보험자는 안 날로부터 1개월 내 + 계약체결일로부터 3년 내 해지 가능
- **계약 후 알릴의무**(전 축종 공통): 동일 위험 타보험 체결·양도·반경 10km 이내 가축전염병 발생 또는 원인불명 집단폐사·보험목적 건물 구조변경·15일 이상 수선·용도변경 위험변경·30일 이상 비움/휴업·이전·도난행방불명·구할 수 없는 상태 — 위반 시 안 날로부터 1개월 내 해지 가능

## 7. 보험금 산정 골격 (손해평가요령 별표 1 연계)

- 수확감소보장(옥수수 외): 보험가입금액 × (피해율 − 자기부담비율); 피해율 = (평년수확량 − 수확량 − 미보상감수량) ÷ 평년수확량
- 나무손해: 보험가입금액 × (피해율 − 자기부담비율); 피해율 = 피해주수 ÷ 실제결과주수
- 농업시설물·버섯재배사·부대시설: 재조달가액(특약 미가입 시 시가) 기준 손해액 − 자기부담금, 가입금액 내 보상
- 상세 산식 전문은 `손해평가요령` 별표 1·2 ref_md 원문 참조 (본 요지는 실무 해설 기준 보조)

## 8. 손해평가의 의의와 기능 (이론서 2권 제1장)

- 손해평가 = 보험대상 목적물에 피해 발생 시 피해 사실을 확인하고 평가하여 보험금을 결정하는 일련의 과정. 지급보험금 확정의 결정적 근거이므로 농업재해보험에서 가장 중요한 업무 중 하나
- 손해평가의 중요성 5가지: ①보험금 결정의 기초자료 ②보험가입자·제3자가 납득할 수 있는 공정성 요구 ③보험료율 조정의 기초(수급 실적별 인상·인하) ④과대평가 방치 시 보험수지 악화→보험료율 상승→가입 기피→제도 존립 위협 ⑤누적 결과는 재해통계·재해대책 기초자료
- 공정한 손해평가의 의의 3가지: 정당한 보상(마찰 축소·보험료율 현실화), 선의의 계약자 보호(부당 수급은 다수 가입자 부담), 보험사업 건전화(부당 보험금 증가→보험료 상승→사업 지속 불가)

## 9. 손해평가 체계 — 법령·주체·조사자

- 법적 근거: 농어업재해보험법 제11조(손해평가 등) — 손해평가인 위촉, 손해평가요령 고시, 교차손해평가, 정기교육(연 1회 이상), 자격요건. 요령 고시 전 금융위원회와 협의 의무
- 손해평가 주체: 농림축산식품부장관과 사업약정을 체결한 재해보험사업자(법 제8조). 손해평가 담당은 손해평가인(위촉) 또는 손해평가사·손해사정사(법 제11조)에게 위탁 가능
- 업무 위탁(법 제14조·시행령 제13조): 지역농협·지역축협·품목별/업종별 협동조합, 지역산림조합, 지구별·업종별 수협·수협은행, 보험업법상 손해사정업자, 민법 제32조 비영리법인
- 조사자 유형 3종 + 보조: 손해평가인(시행령 제12조 자격요건 충족, 재해보험사업자 위촉) / 손해평가사(농식품부장관→산업인력공단 위탁 자격시험 합격자) / 손해사정사(보험개발원 시험 합격 + 실무수습 + 금감원 등록) / 손해평가보조인(위탁받은 자가 운용)

## 10. 손해평가 과정 (사고접수 → 현지조사 → 전산입력)

1. **사고 발생 통지**: 보험가입자는 보험사고 발생 시 가입 대리점 또는 재해보험사업자에 지체 없이 통보
2. **사고 발생 보고 전산입력**: 기상청 자료·현지 방문으로 보험사고 여부 판단 → 사고접수대장 기록 + 전산 입력
3. **손해평가반 구성**: 생육시기·품목·재해종류에 따라 조사내용 결정 후 지체없이 구성 — 손해평가인·손해평가사·손해사정사로 구성, **5인 이내**, 부족 시 손해평가보조인 위촉 (요령 제8조)
4. **현지조사 실시**: 손해평가 단위별로 실시 (요령 제12조) — 농작물=농지별, 가축=개별가축별(벌은 벌통 단위), 농업시설물=보험가입 목적물별. "농지"는 하나의 보험가입금액에 해당하는 토지로 필지(지번)와 무관 — 방풍림·돌담·도로(농로 제외)·울타리·시설 등으로 구획된 하나의 경작지
5. **현지조사 결과 전산 입력**: 전산 또는 모바일 기기로 입력
- 현지조사 5단계: 영업점 도착 → 계약·기본서류 검토·현지조사서 수령 → 피해현장 방문해 보장재해 여부 심사 → 상황별 관련조사 선택 실시 → 결과 안내·서명확인 → 전산입력 또는 대리점 제출

## 11. 과수작물 손해평가 체계 (이론서 2권 제2장 2절)

- 적과전종합위험방식(사과·배·단감·떫은감) 시기별 조사: 피해사실 확인조사(사고접수 후 지체없이, 피해 명백 시 생략 가능) → 유과타박률(우박, 5종한정특약) → 낙엽률(단감·떫은감, 6.1 이후~적과 전) → 적과후 착과수 조사(전 과수원, 피해 무관) → 낙과피해조사(사고접수 후 지체없이, 전수 또는 표본) → 착과피해조사(수확 직전, 우박·일소·가을동상해) → 고사나무조사(수확완료 후~보험종기 전, 전수조사)
- 종합위험방식 보장 유형: 수확감소보장·과실손해보장·나무손해보장·해가림/비가림시설(인삼)·농업시설물·농업수입보장
- 과실피해분류: 낙과피해·착과피해 조사 시 보험약관의 과실피해분류기준에 따라 피해과실 구분

| 수확불능확인조사 (벼만) | 수확포기가 확인되는 시점 |
| 수확량조사 — 수량요소 (벼만, 표본) | 수확 전 14일 전후 |
| 수확량조사 — 표본조사 | 알곡이 여물어 수확 가능한 시기 |
| 수확량조사 — 전수조사 | 수확 시 |

## 13. 밭작물 손해평가 (종합위험 수확감소보장·생산비보장·작물특정 및 시설종합위험)

- 수확감소보장 대상품목: 고구마·옥수수·콩·양배추·양파·마늘·차·감자·팥·수박·단호박·참깨·당근·녹두·생강·가을무·가을배추(병충해보장형 포함)
- 조사 종류별 품목: 피해사실확인조사=전 품목(지체없이) / 재파종조사=마늘·당근·가을무·감자(가을재배) / 재정식조사=양배추·단호박·가을배추·양파 / 경작불능조사=전 품목(차 제외) / 수확량조사=수확직전 표본 또는 전수(차만 수확 중 전수조사)
- 미보상감수량 = (평년수확량 − 수확량) × 미보상비율

## 14. 농업수입감소보장방식 손해평가 (이론서 2권 제2장 6절)

- 농업수입안정보험: 농작물재해보험에 농산물 가격하락 손해까지 더해 보상 — 수입감소보험금 산출 가격은 **기준가격과 수확기가격 중 낮은 가격** 적용 (수확기가격 상승 시 기준가격으로 지급)
- 과수 대상: 포도(비가림시설보장)·복숭아·감귤(만감류)·단감
- 피해사실확인조사 대상재해: 자연재해·조수해·화재·**가격하락**·병충해(복숭아만)
- 손해액: 기준가격 ≥ 수확기가격 → (기준가격 − 수확기가격) × (평년수확량 − 피해수확량) + 기준가격 × 피해수확량 / 기준가격 < 수확기가격 → 기준가격 × 피해수확량
- 피해율 = (기준수입 − 실제수입) ÷ 기준수입 (100% 상한), 기준수입 = 평년수확량 × 기준가격

## 15. 가축재해보험 손해평가 (이론서 2권 제3장)

- 손해 평가 흐름: 손해발생 사실 확인 → 손해액·보험가액 평가 → 지급보험금 산정. 축종별 손해액 확정 방식 상이
- 계약 전 알릴의무: 청약서 질문사항을 사실대로 고지 — 위반 시 보험자는 **안 날로부터 1월 내 + 계약체결일로부터 3년 내** 해지 가능 (보험자가 알았거나 중과실로 몰랐으면 해지 불가)
- 특약 손해평가 — 소도체결함보장 특약:
  - 보험가액 = 정상도체 해당등급(사고소 등급)의 1두가격 / 손해액 = 정상도체 해당등급 1두가격 − 사고소 1두 경락가격
  - 1두가격 = 사고 전월 전국지육경매평균가격(원/지육kg, 축산물품질평가원 고시) × 사고소 도체중(kg)
  - 도체 결함: 근출혈·수종·근염·외상·근육제거·기타 (축산물품질평가사 판정); 폐기처분 시 보통약관 방식
- 지급보험금(특약): 가입금액 ≥ 가액 → 가입금액 한도 손해액 전액(단 가입금액>가액이면 가액 한도) / 가입금액 < 가액 → 손해액 × (가입금액 ÷ 가액) — 일부보험 비례보상 구조
- 보험가액 개념: 피보험이익의 평가액 — 손해보험 이득금지원칙의 판정기준. 전부보험(가액=가입금액)·초과보험(가입>가액→가액 한도)·일부보험(비례분담)·중복보험(동일방식=가입금액 비례분담 / 상이방식=독립책임액분담)

## 16. 품목별 표본주(구간)수 표준 (손해평가요령 별표 2의2)

- 과수 주요 11품목(사과·배·단감·떫은감·포도·복숭아·자두·밤·호두·무화과·감귤-만감류): 조사대상 50주 미만 → 표본 **5주**, 100주 미만 6주, 150주 미만 7주, 200주 미만 8주, 300주 미만 9주, 400주 미만 10주, 500주 미만 11주 … 1,000주 이상 → **17주**
- 인삼: 피해칸수 기준 — 300칸 미만 3칸 ~ 1,800칸 이상 10칸
- 참다래·블루베리: 주수 기준 (50주 미만 5주 ~ 800주 이상 10주) / 매실·대추·살구: 별도 주수 기준 (100주 미만 5주 ~ 1,000주 이상 16주)
- 오미자: 유인틀길이 기준 — 500m 미만 5구간 ~ 6,000m 이상 10구간
- 오디: 주수 (50주 미만 6주 ~ 600주 이상 13주) / 복분자: 가입포기수 (1,000포기 미만 8 ~ 3,000포기 이상 13) / 감귤(온주밀감류): 가입면적 (5,000㎡ 미만 4주 ~ 10,000㎡ 이상 8주)
- 표본주 선정: 품종별·수령별 조사 대상주수에 비례하여 배분, 특성이 고르게 반영되도록 선정 — 대표성 없으면 주변 나무로 대체, 필요 시 별표 기준 이상 선정 가능
- **거대재해 발생 시 표본주수는 별표 기준의 1/2 이하로 축소 가능**
- 유과(꽃눈) 표본조사: 표본주별 동서남북 4곳 가지에 가지별 5개 이상 유과 추출 → 피해유과수 ÷ (피해유과수 + 정상유과수)

## 17. 조사시기·대상 기본 원칙

- 적과후 착과수 조사시기: **통상적인 적과 및 자연 낙과 종료 시점** (떫은감은 1차 생리적 낙과 종료 시점) — 지역 기상여건을 감안한 시·군별 판정
- 착과 피해 조사시기: 착과수 조사 이후 품종별 피해 확인이 가능한 시기
- 수확전 사고·수확기 사고·수확후 조사 등 시기별 조사 유형이 품목·재해 조합별로 상이 — 별표 2(품목별·재해별·시기별 손해수량 조사방법)에 대응표로 규정
- 낙과수 조사: 표본주의 수관면적 내 낙과수 조사 — 표본주와 품종이 달라도 해당 표본주 낙과로 간주. 표본조사 불가 시 전수조사로 전환
- 피해 확인 시점의 원칙: 생물 특성상 조사 시점에 따라 피해율 변동 → 시기별 조사 기준을 정한 이유

## 18. 조사 구분·손해평가반 제척·재조사·검증조사·이의신청

- 조사의 구분 2축: 단계별=**본조사**(사고 신고된 보험목적물에 곧바로 실시하는 손해 평가 조사) / **재조사**(결과에 이의가 있어 다시 실시) / **검증조사**(결과 확인 목적의 임의추출 조사) — 범위별=**전수조사·표본조사**
- **재조사 요건**: 계약자가 손해평가 결과를 설명·통지받은 날로부터 **7일 이내**에 손해평가가 잘못되었음을 증빙하는 서류 또는 사진 등을 제출한 경우, 재해보험사업자가 **다른 손해평가반**으로 하여 재조사
- **검증조사** (요령 제11조): 재해보험사업자·사업관리위탁기관이 손해평가를 실시한 보험목적물 중 일정 수를 임의 추출해 확인. 농림축산식품부장관이 재해보험사업자로 하여금 실시하게 할 수 있고 결과 제출 의무. 차이 발생 시 정정, **현저한 차이 → 해당 손해평가반이 조사한 전체 보험목적물 재조사** 가능. 가입자가 정당한 사유 없이 거부 시 불가 사실 통지 후 검증조사결과 작성·제출. 위탁기관의 조치 요구 시 재해보험사업자는 특별한 사유 없는 한 이행
- **손해평가반 제척** (요령 제8조③) — 다음에 해당하는 자는 손해평가반 구성에서 배제: ①자기 또는 이해관계자(생계를 같이 하는 친족)가 가입한 계약의 손해평가 ②자기 또는 이해관계자가 **모집한** 계약의 손해평가 ③직전 손해평가일로부터 **30일 이내**의 보험가입자간 상호 손해평가 ④**자기가 실시한 손해평가에 대한 검증조사 및 재조사**
- **이의신청 2단계** (요령 제11조의8): ①손해평가결과에 이의 → 재해보험사업자에게 **재평가 요청**(사업자는 특별한 사정 없으면 수행) → ②재평가 후에도 미해결 → **농림축산식품부장관 또는 해양수산부장관이 정하는 기관**에 이의신청 (신청요건·절차는 장관이 정함)

## 19. 품목별 현지조사 종류표 (품목군 × 조사 종류)

- 공통조사: **피해사실확인조사**는 전 상품군 공통(사고접수 후 지체없이 — 피해 명백 시 생략 가능)
- 과수 종합위험 **수확감소보장**(복숭아·사과·밤·자두·매실·오미자·유자·호두·살구·감귤-만감류·배·단감·떫은감): 예찰조사·수확량조사·고사나무조사(나무손해특약 가입건)
- 과수 종합위험 **과실손해보장**(감귤-온주밀감류·오디·두릅·블루베리): 과실손해조사·고사나무조사(감귤-온주밀감류·무화과)
- 과수 **비가림과수 손해보장**(대추·포도[수입보장 포함]·이듬해 맺은 참다래): 예찰조사·수확량조사·비가림시설 손해조사(특별약관 가입건)
- **적과전종합위험방식Ⅱ**(사과·배·단감·떫은감): 적과전=예찰·피해사실확인(유과타박률·낙엽률·나무피해·미보상비율)·고사나무(특약) / 적과후=착과수조사·낙과피해조사(단감·떫은감은 낙엽률 포함)·착과피해조사·고사나무(특약)
- 수확전종합위험 **무화과**: 과실손해조사·고사나무조사(나무손해특약) / **복분자**: 경작불능조사·과실손해조사
- **벼**: 이앙·직파불능 / 재이앙·재직파 / 경작불능 / 수확량(수량요소·표본·전수) / 수확불능확인조사
- **감자·마늘·당근·가을무**: 재파종·경작불능·수확량(표본) / **양파·고구마·수박(노지)·녹두·생강·참깨·단호박·가을배추(병충해보장형 포함)**: 재정식(고구마 제외)·경작불능·수확량(표본) / **양배추**: 재정식·경작불능·수확량(표본)
- **차(茶)**: 수확량(표본) / **밀·콩·보리·팥·옥수수**: 경작불능·수확량(표본·전수)
- 생산비보장 품목: **고추·브로콜리·무·파·시금치(노지)** = 생산비보장 손해조사·재파종·재정식 / **배추·양상추** = 재정식·경작불능·생산비보장 / **메밀** = 재파종·경작불능·생산비보장
- **인삼**: 해가림시설 손해조사(시설)·수확량조사(작물) / **원예시설**: 시설하우스(단동·연동·유리온실·버섯재배사)=시설하우스 손해조사, 시설작물 26품목(수박·딸기·오이·토마토·참외·고추·호박·국화·장미·멜론·파프리카·상추·부추·시금치·배추·가지·파·무·백합·카네이션·미나리·쑥갓·느타리·표고·양송이·새송이·감자)=시설작물 손해조사

## 20. 가축 손해평가 세부 — 계약후 알릴의무·축사·특약
