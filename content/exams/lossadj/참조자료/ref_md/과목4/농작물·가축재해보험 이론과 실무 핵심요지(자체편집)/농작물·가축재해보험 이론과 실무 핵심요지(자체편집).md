# 농작물·가축재해보험 이론과 실무 핵심요지 (자체 편집)

> **성격**: 손해평가사 2차 과목1「농작물재해보험 및 가축재해보험의 이론과 실무」대비 자체 편집 요지 — 법령이 아닌 학습 요약 문서
> **기반자료**: 농업정책보험금융원 「농업재해보험·손해평가의 이론과 실무」 이론서 1권(2026년 수정본, 2025.12.31 기준 법령·약관) — 무단 전재·배포 금지 고지에 따라 **사실·수치·기준만 추출하여 자체 문장으로 재구성**, 원문 미수록
> **주의**: 품목·수치·비율은 연도별 사업시행지침·약관에서 변경 가능 — 실제 판정은 당해연도 정본 기준

## 1. 보험의 정의와 특성

- 보험 = 위험 결합(pooling)으로 불확실성을 확실성으로 전환하는 사회적 제도 — 다수의 동질적 위험을 모아 개별 실제손실(actual loss)을 평균손실(average loss)로 대체
- 정의의 4가지 관점: 경제적(위험 감소 — 위험 전가·위험 결합 수단) / 사회적(손실 분담 sharing of loss — "만인은 일인을 위하여, 일인은 만인을 위하여") / 법적(재무적 손실 보전을 목적으로 하는 계약) / 수리적(확률이론·통계 기반 예측·배분)
- 보험의 특성: ① 예기치 못한 손실의 집단화 — 계약자·피보험자의 **고의적 손실은 보상하지 않음** ② 손실의 집단화(the pooling of fortuitous losses)

## 2. 손해보험의 의의와 원리

- 손해보험 = 보험사고 발생 시 손해가 생긴 만큼 손해액을 산정하여 보험금을 지급하는 보험 (실손보상)
- 법적 근거: 상법은 정의 없음 / 보험업법 제2조는 '손해보험상품'을 "우연한 사건(질병·상해·간병 제외)으로 발생하는 손해에 금전 등을 지급할 것을 약속하고 대가를 수수하는 계약"으로 정의 — 생명보험을 제외한 대부분의 보험을 포괄
- 정책보험(농작물·가축재해보험)도 기본적으로 손해보험의 틀 — 이득금지원칙 적용, 보험가액이 보상한도 판정기준 (전부·초과·일부·중복보험 구분)

## 3. 농업경영위험과 재해보험의 필요성

- 농업경영위험 5종: **생산위험**(기후·병해충 → 생산량·품질 저하) / **가격위험**(농산물·투입재 가격변동) / **재무위험**(이자율·자금 접근성) / **제도적 위험**(세금·가격·소득지지·환경·식품안전·노동·토지 규제 변동) / **인적위험**(가족 구성원 사고·질병·사망)
- 농가 자구 노력: 영농다각화·계약재배·판매 다각화·선물/옵션 활용·재무관리·농외소득
- 농업은 기후·병해충 등 통제 어려운 변수 + 가격 불확실성 → 개별 농가가 관리 불가 → 국가 정책수단 필요. 미국·EU·일본 등 선진국은 보험료 국가지원 농업재해보험을 핵심 경영안정장치로 활용

## 4. 농업재해보험의 특징

- ① **주요 담보위험이 자연재해** — 민영 일반보험은 자연재해 피해를 보상하지 않음 (피해 규모 크고 전국 동시발생 → 민영 감당 곤란)
- ② **손해평가의 어려움** — 생물 특성상 시점별 피해 정도 상이, 재해 후 기상조건 따라 작황 변동, 광범위 동시발생·부패로 단기 집중 평가 필요 → 비용·인력 대규모 소요
- ③ **위험도 차별화 곤란** — 보험료율이 농가 단위가 아닌 **시·군 단위** 책정 구조
- ④ 정책보험 성격 — 정부 재정지원(보험료·운영비) + 국가재보험으로 운영

## 5. 농작물재해보험 도입 경과와 국가재보험

- 경과: 1975 국립농업경제연구소 타당성 연구 → 1982 논벼 재해보험 시업 설계 → 1986 수도작 5년 도상연습 → 1991 중단 → **1999 태풍 올가**(67명 사망·실종, 재산피해 약 1조 1,500억) → 2000 도입준비위원회 → **2001.3.1 농작물재해보험법 시행** → **2001.3.17 사과·배 2품목, 9개도 51개 시·군 판매 개시**
- 국가재보험: 2002 태풍 루사·2003 매미 연속 피해 → 민영사 대규모 적자·참여 포기 → **2005 국가재보험 도입(초과손해율 방식)** → 2017 손해율 구간별 **손익분담 방식** 부분 도입 → **2019 전면 도입**

## 6. 농작물재해보험 상품 체계

- 보장방식 크게: **적과전 종합위험방식Ⅱ**(과수 4종) / **종합위험방식**(수확감소보장·과실손해보장·나무손해보장·생산비보장·해가림/비가림시설·농업시설물·농업수입보장)
- 적과전 종합위험Ⅱ(사과·배·단감·떫은감): 보장개시일~**적과종료**까지 자연재해·조수해·화재 종합위험 → **착과감소보험금**(평년착과량 − 적과후착과량) / 적과후~종기까지는 **태풍(강풍)·집중호우·우박·화재·지진·가을동상해·일소피해** 특정위험만 → **과실손해보험금**
- 별표 미경과비율표: 적과전 특정위험 5종 한정보장 특약 미가입 시 착과감소보험금 보장수준 50%형 기준, 품목·판매개시 연도·이듬해 월별 비율(%)

## 7. 대상 품목과 가입자격 (2025년 기준)

- 보험 대상 농작물 **76개 품목** + 농업시설물(버섯재배사·농업용 시설물)
- 가입자격 요건 3중: ①사업 실시 지역 ②경작 규모 하한 ③**보험료 50% 이상 정책자금 지원 대상은 농업경영체 등록 필수**
- 규모 하한(농지 보험가입금액 기준): 사과·배·단감·떫은감·감귤·포도·복숭아·자두·살구·매실·참다래·대추·유자·무화과·밤·호두·마늘·양파·감자·고구마·고추·양배추·브로콜리·오미자·복분자·오디·인삼·수박(노지)·두릅·블루베리 = **200만원 이상** / 옥수수·콩·팥·배추·무·파·단호박·당근·시금치(노지)·양상추 = **100만원 이상** / 벼·밀·보리·메밀·귀리 = **50만원 이상**
- 면적 기준 품목: 비가림시설(포도·대추·참다래) **200㎡ 이상** / 농업용 시설물·버섯재배사·녹두·생강·참깨·종합위험 과수4종 **단지 300㎡ 이상** / 차·조사료용 벼·사료용 옥수수 **1,000㎡ 이상** / 농업수입안정보험 별도
- 지역 제한 품목(전국 아님): 녹두(전남 무안·신안), 생강(경북 안동·영주·봉화·예천, 충남 서산·태안), 참깨(경북 문경·예천), 유자(전남 고흥·완도·진도, 경남 거제·통영·남해), 무화과(전남 영암·신안·목포·무안·해남), 감자·메밀·배추·무 = 재배형태별 지역 한정

## 8. 계약 인수·관리 (농작물·가축 공통 원칙)

- 가축: 수용장소에서 사육하는 해당 가축은 **모두 가입 의무** — 위반 시 보험자는 안 날부터 1개월 내 해지 가능
- 소 가입 요건: **생후 15일령 ~ 13세 미만**, 귀표(개체식별 표지) 부착 필수 / 젖소 불임우(프리마틴 등)는 암컷, 거세우는 수컷으로 분류
- 포괄가입 간주(1년 이내 출하 예정 송아지·큰소): 신규가입자·**손해율 130% 초과**자는 이력제 현황 **전부 가입** / 손해율 130% 이하자는 **80% 이상 가입** 시 포괄가입 간주
- 인수 제외: 다른 계약(공제 포함) 있는 가축, 과거 병력·발육부진·발병 등 인수 부적절, 가축 증가분(출산·매입) 추가보험료 미납 가축
- 농작물 계약 관리: 보험가입지역별 품목 판매, 청약·약관 교부·설명 의무 등 계약관리 절차

## 9. 가축재해보험 사업 경과

- 1997 '소' 가축공제 시범사업 시작 — 납입 공제료의 **50%를 축산업발전기금에서 지원**
- 2007 민영보험사 참여 허가(KB컨소시엄, 경쟁체제 도입) → 2016 KB·한화·DB 추가(NH 포함 4개사) → 2017 현대해상 → 2023 삼성화재 → **민영보험사 6개사** 판매 체계

## 10. 가축재해보험 약관 구조와 보험의 목적

- 약관 = 보통약관 + 특별약관 **22개** (일반조항 9 + 부문별 13)
- 보험의 목적 = **6개 부문 16개 축종 + 축사**:
  - 소: 한우·육우·젖소 / 종모우 별도 부문 (한우·육우·젖소 분류)
  - 돼지: 종모돈·종빈돈·비육돈·육성돈(후보돈 포함)·자돈·기타 돼지
  - 가금(8축종): 닭·오리·꿩·메추리·타조·거위·칠면조·관상조
  - 말: 경주마·육성마·일반마·종빈마·종모마·제주마
  - 기타 가축(5축종): 사슴·양(염소 포함)·꿀벌·토끼·오소리
  - 축사: 가축사육건물 + 부속물(칸막이·대문·담·곳간)·부착물(게시판·간판·안테나)·부속설비(전기가스·급배수·냉난방·급이기·통풍)·기계장치(착유기·원유냉각기·케이지·부화기·분류기)

## 11. 축종별 세부 기준

- 돼지 사육단계: 포유기간 ~4주 / 이유자돈 4~8주 / 육성돈 8~22주 / 비육돈 22~26주 → 비육돈 약 180일 사육 후 도축
- 닭 분류: 종계(종란 생산)·육계(식육용)·산란계·토종닭
- 꿀벌 보험목적: **서양종(양봉) = 꿀벌 있는 소비(巢脾) 3매 이상 벌통 / 동양종(토종벌) = 봉군 있는 벌통** — 화재·풍재·수재·설해·지진 손해 보상
- 기타 가축 연령: 사슴(꽃사슴 만 2개월~15세, 엘크·레드디어·기타사슴 만 2개월~13세) / 양(산양·면양 만 3개월~10세)

## 12. 특별약관 — 협정보험가액

- 특약 총 22개 = 일반조항 9개(화재대물배상책임·구내폭발위험보장·협정보험가액(소·돼지·가금) 등) + 부문별 13개(소 1·돼지 2·돼지가금공통 2·말 4·기타가축 3·축사 1)
- **협정보험가액 특약** = 계약 체결 시 사업자와 계약자·피보험자가 협의해 평가한 보험가액을 보험기간 중 보험가액·보험가입금액으로 하는 **기평가보험** 특약
- 적용 대상 가축: 종빈우·종모돈·종빈돈·자돈(포유돈·이유돈)·종가금·유량검정젖소·기타 보험자 인정 가축
- 유량검정젖소 요건: 농가 — 직전월 305일 평균유량 10,000kg 이상 + 평균체세포수 30만 이하 / 개체 — 최근 산차 305일 유량 11,000kg 이상 + 체세포수 20만/ml 이하
