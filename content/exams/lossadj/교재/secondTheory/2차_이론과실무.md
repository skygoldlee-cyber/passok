## Chapter 01. 보험의 이해 — 정의·특성·손해보험

### 1-1. 보험의 정의와 특성

- 🧠 **보험** = 위험 결합(pooling)으로 불확실성을 확실성으로 전환하는 사회적 제도 — 다수의 동질적 위험을 모아 개별 **실제손실(actual loss)**을 **평균손실(average loss)**로 대체 🎯
- ⭐ 정의의 4가지 관점: **경제적**(위험 감소 — 위험 전가·위험 결합 수단) / **사회적**(손실 분담 — "만인은 일인을 위하여, 일인은 만인을 위하여") / **법적**(재무적 손실 보전 계약) / **수리적**(확률이론·통계 기반 예측·배분).
- 특성: 예기치 못한 손실의 집단화 — 계약자·피보험자의 **고의적 손실은 보상하지 않음** 🎯

### 1-2. 손해보험의 의의와 원리

- 손해보험 = 사고 발생 시 손해가 생긴 만큼 손해액을 산정하여 보험금을 지급하는 **실손보상** 보험.
- 법적 근거: 상법은 정의 규정 없음 / **보험업법 제2조** — '손해보험상품'을 "우연한 사건(질병·상해·간병 제외)으로 발생하는 손해에 금전 등을 지급할 것을 약속하고 대가를 수수하는 계약"으로 정의 → 생명보험 제외 대부분 포괄 🎯
- 🧠 정책보험(농작물·가축재해보험)도 손해보험 틀 — **이득금지원칙** 적용, 보험가액이 보상한도 판정기준 (전부·초과·일부·중복보험) ⭐

## Chapter 02. 농업재해보험의 특성과 필요성

### 2-1. 농업경영위험과 재해보험의 필요성

- 🎯 농업경영위험 5종: **생산위험**(기후·병해충 → 생산량·품질 저하) / **가격위험**(농산물·투입재 가격변동) / **재무위험**(이자율·자금 접근성) / **제도적 위험**(세금·가격·소득지지·환경·식품안전·노동·토지 규제) / **인적위험**(가족 사고·질병·사망).
- 농가 자구 노력: 영농다각화·계약재배·판매 다각화·선물/옵션·재무관리·농외소득.
- ⭐ 농업은 통제 어려운 자연 변수 + 가격 불확실성 → 개별 농가 관리 불가 → **국가 정책수단** 필요 — 미국·EU·일본은 보험료 국가지원 재해보험을 핵심 경영안정장치로 활용.

### 2-2. 농업재해보험의 특징

- ① **주요 담보위험이 자연재해** — 민영 일반보험은 자연재해를 보상하지 않음 (피해 크고 전국 동시발생 → 민영 감당 곤란) 🎯
- ② **손해평가의 어려움** — 생물 특성상 시점별 피해 상이, 재해 후 기상 따라 작황 변동, 광역 동시발생·부패로 단기 집중 평가 → 비용·인력 대규모 소요 🎯
- ③ **위험도 차별화 곤란** — 보험료율이 농가 단위가 아닌 **시·군 단위** 책정 ⭐
- ④ **정책보험** — 정부 재정지원(보험료·운영비) + 국가재보험으로 운영.

## Chapter 03. 농작물재해보험 제도 — 경과·상품·가입

### 3-1. 도입 경과와 국가재보험

- 경과: 1975 타당성 연구 → 1982 논벼 시업 → 1986 수도작 5년 도상연습 → 1991 중단 → **1999 태풍 올가**(67명 사망·실종, 재산피해 약 1조 1,500억) → 2000 도입준비위원회 → **2001.3.1 농작물재해보험법 시행** → **2001.3.17 사과·배 2품목, 9개도 51개 시·군 판매** 🎯
- 국가재보험: 2002 루사·2003 매미 연속 피해 → 민영사 대규모 적자·포기 → **2005 초과손해율 방식 도입** → 2017 손해율 구간별 **손익분담** 부분 → **2019 전면 도입** ⭐

### 3-2. 상품 체계 — 보장방식

- 🎯 보장방식 2대 축: **적과전 종합위험방식Ⅱ**(과수 4종: 사과·배·단감·떫은감) / **종합위험방식**(수확감소·과실손해·나무손해·생산비·해가림/비가림시설·농업시설물·농업수입보장).
- 적과전 종합위험Ⅱ: 개시일~**적과종료**까지 자연재해·조수해·화재 종합위험 → **착과감소보험금**(평년착과량 − 적과후착과량) / 적과후~종기는 **태풍(강풍)·집중호우·우박·화재·지진·가을동상해·일소피해** 특정위험만 → **과실손해보험금** ⭐
- 별표 **미경과비율표**: 적과전 특정위험 5종 한정보장 특약 미가입 시 착과감소보험금 보장수준 50%형 기준 — 품목·판매개시 월별 비율(%).

### 3-3. 대상 품목과 가입자격 (2025년 기준)

- 대상: 농작물 **76개 품목** + 농업시설물(버섯재배사·농업용 시설물).
- 🎯 가입자격 3중 요건: ①사업 실시 지역 ②경작 규모 하한 ③보험료 50% 이상 정책자금 지원 대상은 **농업경영체 등록 필수**.
- 가입금액 하한: 과수·감귤·고추·마늘·인삼 등 **200만원** / 옥수수·콩·팥·배추·무·파 등 **100만원** / 벼·밀·보리·메밀·귀리 **50만원**.
- 면적 하한: 비가림시설 **200㎡** / 시설물·버섯재배사·녹두·생강·참깨·종합위험 과수4종 **단지 300㎡** / 차·조사료용 벼·사료용 옥수수 **1,000㎡**.
- ⚠️ 지역 제한 품목: 녹두(전남 무안·신안), 생강·참깨(경북·충남 일부), 유자(전남·경남 남해안), 무화과(전남), 감자·메밀·배추·무(재배형태별).

## Chapter 04. 가축재해보험 제도 — 경과·약관·특약

### 4-1. 사업 경과

- 1997 '소' 가축공제 시범 — 공제료 **50% 축산업발전기금** 지원 → 2007 민영 참여(KB컨소시엄) → 2016 KB·한화·DB 추가(NH 포함 4사) → 2017 현대해상 → 2023 삼성화재 → **민영 6사** 판매 🎯

### 4-2. 약관 구조와 보험의 목적

- 🎯 약관 = 보통약관 + 특별약관 **22개**(일반조항 9 + 부문별 13).
- 보험의 목적 = **6개 부문 16축종 + 축사**:

| 부문 | 보험의 목적 |
| --- | --- |
| 소 | 한우·육우·젖소 (+종모우 별도 부문) |
| 돼지 | 종모돈·종빈돈·비육돈·육성돈(후보돈)·자돈·기타 돼지 |
| 가금(8) | 닭·오리·꿩·메추리·타조·거위·칠면조·관상조 |
| 말 | 경주마·육성마·일반마·종빈마·종모마·제주마 |
| 기타 가축(5) | 사슴·양(염소)·꿀벌·토끼·오소리 |
| 축사 | 사육건물 + 부속물·부착물·부속설비·기계장치 |

- ⚠️ 소: 수용장소 내 **전두 가입 의무**(위반 시 안 날 1개월 내 해지), 생후 15일령~13세 미만 + 귀표 필수 / 인수 제외 — 타 계약·병력·발육부진·추가보험료 미납.
- 포괄가입: 신규·손해율 130% 초과 → 전부 가입 / 130% 이하 → **80% 이상** 가입 시 포괄 간주.

### 4-3. 축종별 세부·특약

- 돼지 단계: 포유 ~4주 / 이유 4~8주 / 육성 8~22주 / 비육 22~26주 → 비육돈 약 **180일** 도축.
- 꿀벌: 서양종=소비(巢脾) **3매 이상** / 동양종=봉군 있는 벌통 — 화재·풍재·수재·설해·지진 보상.
- 기타 가축 연령: 꽃사슴 만2개월~15세 / 엘크·레드디어 만2개월~13세 / 양 만3개월~10세.
- 🧠 **협정보험가액 특약** = 계약 체결 시 협의 평가가액을 보험기간 중 가액·가입금액으로 하는 **기평가보험** — 대상: 종빈우·종모돈·종빈돈·자돈·종가금·유량검정젖소 ⭐

### 4-4. 핵심 용어

- **보통약관** 🎯 중요: 재해보험사업자가 미리 작성한 정형 계약조항 — 가축 16축종+축사 분류
- **특별약관** 🎯 중요: 보통약관을 변경·보충·배제하는 약관 — 총 22개
- **협정보험가액** 🎯 중요: 협의 평가가액을 보험기간 중 가액·가입금액으로 하는 기평가보험 특약
- **유량검정젖소** 🎯 중요: 농가 10,000kg·30만 + 개체 11,000kg·20만/ml 요건
- **포괄가입** 🎯 중요: 수용장소 내 가축 전두 가입 — 손해율 130% 기준, 80% 이상 시 간주
