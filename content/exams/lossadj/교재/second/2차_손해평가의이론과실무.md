## Chapter 01. 손해평가 개관 — 의의·기능·체계

### 1-1. 손해평가의 의의와 기능

- 🧠 **손해평가** = 보험대상 목적물에 피해 발생 시 피해 사실을 확인하고 평가하여 보험금을 결정하는 일련의 과정 — 지급보험금 확정의 결정적 근거이므로 농업재해보험의 핵심 업무 🎯
- ⭐ 손해평가의 중요성 5가지: ①보험금 결정의 기초자료 ②보험가입자·제3자 납득을 위한 공정성 ③보험료율 조정의 기초 ④과대평가 방치 시 보험수지 악화→보험료 상승→가입 기피→제도 존립 위협 ⑤누적 결과는 재해통계·재해대책 기초자료.
- 공정한 손해평가의 의의 3가지: **정당한 보상**(마찰 축소·보험료율 현실화) / **선의의 계약자 보호**(부당 수급은 다수 가입자 부담) / **보험사업 건전화**(부당 보험금→보험료 상승→사업 지속 불가).

### 1-2. 손해평가 체계와 주체

- 🎯 법적 근거: **농어업재해보험법 제11조** — 손해평가는 장관이 고시하는 **손해평가요령**에 따라 공정·객관적으로 수행, 고의로 진실을 숨기거나 거짓 평가 금지. 요령 고시 전 **금융위원회 협의** 의무.
- 손해평가 주체: 농림축산식품부장관과 사업약정을 체결한 **재해보험사업자**(법 제8조).
- ⭐ 조사자 3유형 + 보조: **손해평가인**(시행령 제12조 요건 충족, 사업자 위촉) / **손해평가사**(자격시험 합격, 시행은 산업인력공단 위탁 가능) / **손해사정사**(보험개발원 시험+실무수습+금감원 등록) / **손해평가보조인**(위탁받은 자가 운용).
- 업무 위탁(법 제14조·시행령 제13조): 지역농협·지역축협·품목별·업종별 협동조합, 지역산림조합, 지구별·업종별 수협·수협은행, 손해사정업자, 민법 제32조 비영리법인.
- 🧠 **교차손해평가**: 동일 시·군·자치구 내 손해평가인 상호 간 담당지역 교차 평가 (법 제11조제3항) / 손해평가인 정기교육 **연 1회 이상**.

## Chapter 02. 손해평가 절차와 현지조사

### 2-1. 손해평가 기본단계 (사고접수 → 전산입력)

1. **사고 발생 통지**: 가입자는 사고 발생 시 가입 대리점·사업자에 지체 없이 통보.
2. **사고 발생 보고 전산입력**: 기상청 자료·현지 방문으로 보험사고 여부 판단 → 사고접수대장 + 전산 입력.
3. **손해평가반 구성**: 생육시기·품목·재해종류에 따라 조사내용 결정 후 지체없이 구성 — 손해평가인·손해평가사·손해사정사, **5인 이내**, 부족 시 손해평가보조인 위촉 (요령 제8조) 🎯
4. **현지조사 실시**: 손해평가 단위별로 실시.
5. **현지조사 결과 전산 입력**: 전산 또는 모바일 기기로 입력.

### 2-2. 손해평가 단위와 현지조사 절차

- ⭐ **손해평가 단위** (요령 제12조): 농작물 **농지별** / 가축 **개별가축별**(벌은 벌통 단위) / 농업시설물 **보험가입 목적물별**.
- 🧠 "농지" = 하나의 보험가입금액에 해당하는 토지 — 필지(지번)와 무관하며 방풍림·돌담·도로(농로 제외)·울타리·시설 등으로 구획된 하나의 경작지.
- 현지조사 5단계: 영업점 도착 → 계약·기본서류 검토·현지조사서 수령 → 피해현장 방문해 **보장재해 여부 심사** → 상황별 관련조사 선택 실시 → 결과 안내·서명확인 → 전산입력 또는 대리점 제출.
- 조사방법: **전수조사** 또는 품목별 표본주수·구간표에 따른 **표본조사** — 피해사실이 명백한 경우 피해사실확인조사 생략 가능.

### 2-3. 핵심 용어

- **손해평가인** 🎯 중요: 시행령 제12조 자격요건을 충족해 재해보험사업자가 위촉한 조사자
- **손해평가반** 🎯 중요: 손해평가인·손해평가사·손해사정사로 구성, 5인 이내 (요령 제8조)
- **손해평가 단위** 🎯 중요: 농작물=농지별, 가축=개별가축별, 시설물=목적물별 조사 기준 (요령 제12조)
- **교차손해평가** 🎯 중요: 동일 시·군·구 내 손해평가인의 담당지역 교차 평가 (법 제11조제3항)
- **피해사실확인조사** 🎯 중요: 사고접수 후 지체없이 보장재해 피해 여부를 조사 (명백 시 생략)

## Chapter 03. 작물별 손해평가 — 과수·논작물·밭작물

### 3-1. 과수작물 — 적과전종합위험 조사 순서

- 대상 품목: **사과·배·단감·떫은감**. 조사 순서: 피해사실 확인조사(사고접수 후 지체없이) → 유과타박률(우박, 5종한정특약) → 낙엽률(단감·떫은감, 6월 1일 이후~적과 전) → **적과후 착과수 조사**(피해 유무 무관, 전 과수원) → 낙과피해조사(접수 후 지체없이, 전수 또는 표본) → 착과피해조사(수확 직전, 우박·일소·가을동상해) → 고사나무조사(수확완료 후~보험종기 전, 전수) 🎯
- 종합위험 보장 유형: 수확감소보장·과실손해보장·나무손해보장·해가림/비가림시설(인삼)·농업시설물·농업수입보장.
- 낙과·착과피해 조사 시 보험약관의 **과실피해분류기준**으로 피해과실 구분.

### 3-2. 과수원 조사 산식

- 🎯 **유과타박률** = 피해유과수 ÷ (정상유과수 + 피해유과수) — 표본주 동서남북 4개 가지에서 각 5개 이상 유과 조사.
- **낙엽률** = 낙엽수 ÷ (착엽수 + 낙엽수) — 단감·떫은감, 6.1 이후 적과종료 이전 낙엽 피해.
- **침수주수** = 침수피해 나무수 × 과실침수율 — 과실침수율 = 침수 착과(화)수 ÷ 전체 착과(화)수.
- **미보상감수량** = (평년수확량 − 수확량) × 미보상비율.
- ⭐ **조사대상나무수** = 실제결과나무수 − (고사 + 미보상 + 수확완료 + 수확불능)나무수.

### 3-3. 논작물(벼·맥류) — 시기별 조사

- 대상품목: 벼·조사료용 벼·밀·보리·귀리.

| 조사 종류 | 조사 시기 |
| --- | --- |
| 예찰조사 | 사고접수 전 |
| 피해사실확인조사 | 사고접수 직후 |
| 이앙·직파불능 조사 (벼만) | 이앙한계일(**7월 31일**) 이후 |
| 재이앙·재직파 조사 (벼만) | 사고접수 후 ~ 재이앙 직후 |
| 경작불능조사 | 사고접수 후 ~ 수확 개시 시점 |
| 수확불능확인조사 (벼만) | 수확포기 확인 시점 |
| 수확량조사 — 수량요소(벼만, 표본) | 수확 전 14일 전후 |
| 수확량조사 — 표본조사 | 알곡이 여물어 수확 가능한 시기 |
| 수확량조사 — 전수조사 | 수확 시 |

- ⭐ 판정 기준: **경작불능** = 식물체 피해율 65% 이상 + 계약자 신청 → 경작불능보험금 지급, 계약 소멸(수확감소보험금 미지급) / **수확불능** = 제현율 65% 미만(분질미 70%) + 신청 / **수확포기** = 11월 30일까지 미수확·미수확 상태 갈아엎기·수확물 전량 미유통 중 하나 🎯
- 실제경작면적이 가입면적과 **10% 이상** 차이 → 계약사항 변경.

### 3-4. 밭작물 — 조사 종류별 품목

- 보장방식 3종: 종합위험 수확감소보장 / 생산비보장 / 작물특정 및 시설종합위험.
- 수확감소보장 대상품목: 고구마·옥수수·콩·양배추·양파·마늘·차·감자·팥·수박·단호박·참깨·당근·녹두·생강·가을무·가을배추(병충해보장형 포함).
- 🎯 조사 종류별 품목: 피해사실확인=전 품목 / **재파종**=마늘·당근·가을무·가을재배 감자 / **재정식**=양배추·단호박·가을배추·양파 / 경작불능=전 품목(차 제외) / 수확량조사=수확직전 표본 또는 전수(**차만 수확 중 전수**).
- 병해충 인정비율(감자): 1급(역병·모자이크병) 90% / 2급(홍색부패병·시들음병) 70% / 3급(반쪽시들음병·탄저병) 50% ⭐
- 콩·팥 전수조사 수확량 = 전체 종실중량 × (1 − 함수율) ÷ 0.86.
- **조사대상면적** = 실제경작면적 − (고사 + 타작물 및 미보상 + 기수확)면적.

## Chapter 04. 시설물·농업수입감소보장 손해평가

### 4-1. 농업용 시설물 감가율

### 4-2. 농업수입감소보장방식

- 🧠 농업수입안정보험: 농작물재해보험에 **가격하락 손해**까지 합산 보상 — 산출 가격은 **기준가격과 수확기가격 중 낮은 가격** (수확기가격 상승 시 기준가격 적용) 🎯
- 과수 대상: 포도(비가림시설보장)·복숭아·감귤(만감류)·단감.
- 피해사실확인조사 대상재해: 자연재해·조수해·화재·**가격하락**·병충해(복숭아만) ⭐
- 손해액: 기준가격 ≥ 수확기가격 → (기준가격 − 수확기가격) × (평년수확량 − 피해수확량) + 기준가격 × 피해수확량 / 기준가격 < 수확기가격 → 기준가격 × 피해수확량.
- **피해율** = (기준수입 − 실제수입) ÷ 기준수입 (100% 상한), 기준수입 = 평년수확량 × 기준가격.

## Chapter 05. 가축재해보험 손해평가

### 5-1. 손해의 평가와 특약 체계

- 평가 흐름: 손해발생 사실 확인 → 손해액·보험가액 평가 → 지급보험금 산정. 축종별 손해액 확정 방식 상이.
- 🎯 특별약관 **총 22개** = 일반조항 9 + 부문별 13(소 1, 돼지 2, 돼지가금공통 2, 말 4, 기타가축 3, 축사 1).
- 협정보험가액 특약 대상: 종빈우·종모돈·종빈돈·자돈(포유·이유)·종가금·유량검정젖소.
- ⭐ 유량검정젖소 요건: 농가 — 직전월 305일 평균유량 10,000kg 이상 + 평균체세포수 30만 이하 / 개체 — 최근 산차 305일 유량 11,000kg 이상 + 체세포수 20만/ml 이하 → 시가와 무관하게 가입 가능.

### 5-2. 알릴의무

- 계약 전: 청약서 질문사항 사실대로 고지 — 위반 시 보험자는 **안 날로부터 1개월 내 + 계약체결일로부터 3년 내** 해지 가능 (보험자가 알았거나 중과실로 몰랐으면 해지 불가) 🎯
- 계약 후(전 축종): 타 보험 체결, 반경 10km 이내 가축전염병 발생, 30일 이상 휴업 등 → 위반 시 안 날로부터 1개월 내 해지 가능.

### 5-3. 특약 손해평가 — 소도체결함보장

- 보험가액 = 정상도체 해당등급(사고소 등급)의 1두가격 / 손해액 = 정상도체 해당등급 1두가격 − 사고소 1두 경락가격 🎯
- 1두가격 = 사고 전월 전국지육경매평균가격(원/지육kg, 축산물품질평가원 고시) × 도체중(kg).
- 도체 결함: 근출혈·수종·근염·외상·근육제거·기타 (축산물품질평가사 판정) / 폐기처분 시 보통약관 방식.

## Chapter 06. 보험금 산정·지급 및 심사

### 6-1. 보험금 산정 골격 (농작물)

- 수확감소보장(옥수수 제외): 보험금 = 보험가입금액 × (피해율 − 자기부담비율), 피해율 = (평년수확량 − 수확량 − 미보상감수량) ÷ 평년수확량 🎯
- 나무손해보장: 보험금 = 보험가입금액 × (피해율 − 자기부담비율), 피해율 = 피해주수 ÷ 실제결과주수.
- 농업시설물·버섯재배사·부대시설: 재조달가액(특약 미가입 시 시가) 기준 손해액 − 자기부담금, 가입금액 한도.

### 6-2. 보험가액과 지급 심사 (가축)

- 🧠 **이득금지원칙**: 보험으로 이득을 보아서는 안 된다는 손해보험 원칙 — 보험가액(피보험이익의 평가액)이 그 판정기준 ⭐
- 보험 유형: **전부보험**(가입금액=가액 → 손해액 전액) / **초과보험**(가입>가액 → 가액 한도) / **일부보험**(가입<가액 → 손해액 × 가입금액÷가액, 비례보상) / **중복보험**(동일방식=가입금액 비례분담, 상이방식=독립책임액분담) 🎯
- 특약 지급: 가입금액 ≥ 가액 → 손해액 전액(가액 한도) / 가입금액 < 가액 → 손해액 × (가입금액 ÷ 가액).

### 6-3. 핵심 용어

- **보험가액** 🎯 중요: 피보험이익의 평가액 — 이득금지 판정·보상한도 기준
- **미보상감수량** 🎯 중요: (평년수확량 − 수확량) × 미보상비율
- **조사대상나무수** 🎯 중요: 실제결과나무수 − (고사+미보상+수확완료+수확불능)주수
- **유량검정젖소** 🎯 중요: 305일 유량·체세포수 기준 충족 시 협정보험가액 특약 대상
- **일부보험** 🎯 중요: 가입금액<가액 시 손해액 × 가입금액÷가액 비례보상
