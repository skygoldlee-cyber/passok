# 미용사(일반) 학습안내서 — Passhair

## 시험 개요

- **종목**: 미용사(일반) 국가기술자격 (한국산업인력공단, 종목코드 7937)
- **필기**: 객관식 4지택일 통합 60문항/60분 — 60점(36문) 이상 합격, 과락 없음
- **실기**: 미용실무 작업형 약 2시간 25분 — 60점 이상 합격
- **출제기준**: 2027.1.1~2031.12.31 적용 — 본 팩은 신기준 기준 자체 제작

## 과목 구성 (필기 5과목 + 실기)

| 과목 | 범위 | 비중 추정 |
|---|---|---|
| 피부학 | 표피·진피 구조, 부속기관, 유형, 기능 | ~23% (14문) |
| 모발학 | 큐티클/코르텍스/메둘라, 모근·모낭, 결합·성장주기 | ~30% (18문) |
| 화장품학 | 정의·기능성·유화·계면활성제·전성분 표시 | ~13% (8문) |
| 공중위생관리학 | 공중위생관리법 체계 — 신고·위생교육·감시·처분 | ~17% (10문) |
| 소독학 | 기구별 소독기준·소독제·안전 | ~17% (10문) |
| 미용실무 | 실기 작업형 — 샴푸·커트·펌·컬러·위생 수기 | 실기 대비 |

## 학습 경로

1. **개념 투입**: 카드(플래시카드)로 핵심 용어 암기 → 교재 해당 챕터 본문 읽기
2. **문제 적용**: 과목별 문제은행 — 발문→정답 인용(📖 교재 근거) 확인
3. **통합 훈련**: 통합 모의고사(60문/60분) — 시간 관리 + 과목 편중 확인
4. **실기 준비**: writtenPractice 주관식 연습 — 수기 순서 서술 후 모범답안 대조

## 수치 암기 포인트 (number-drills 대상 후보)

- 두피 모발 수: 약 10만~15만 개 · 성장기: 2~6년 · 휴지기 탈락: 50~100개/일
- 위생교육: 매년 1회 · 과태료 상한: 300만 원 이하
- 차아염소산나트륨 희석: 유효염소 1000ppm (타올·가운) · 침지: 10분 이상
- 스팀타올 보관: 80℃ 이상 · 패치테스트 관찰: 48시간

## 참조자료 활용

- 📚 **공중위생관리법·시행령·시행규칙** (과목4) — 신고·의무·처분의 원문
- 📚 **이용·미용기구별 소독기준 및 방법** (과목5) — 소독법의 고시 원문
- 📚 **화장품법·화장품 안전기준** (과목3) — 정의·분류·표시의 원문
