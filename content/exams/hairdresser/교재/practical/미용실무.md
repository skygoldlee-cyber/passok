# 미용실무 — 미용사(일반) 실기 2027 교재

> **시험 형식**: 작업형 약 2시간 25분 (100점 만점 60점 합격) — 본 자료는 필답·서술 연습용
> **출제기준**: 2027.1.1~2031.12.31 기준 자체 제작 교재

## Chapter 01. 실기 과제 구성

- 🎯 실기 평가는 **두피·모발 관리 + 헤어 기술 과제**로 구성되며 샴푸·두피 마사지·커트·펌·컬러링·드라이·세팅 등이 주요 항목이다.
- **평가 요소**: 위생·안전(도구 소독·가운 착용), 기술 정확성(각도·섹션·로딩), 시간 준수, 마무리 정리.
- 🎯 **작업 준비 절차**: 고객 상담·분석 → 도구·재료 소독·정리 → 가운·타올 착용 → 작업 실시 → 마무리·평가.

## Chapter 02. 주요 수기 순서

- 🎯 **샴푸**: 온수(체온 정도)로 적시기 → 샴푸 도포 → 두피 마사지(지문면 사용, 손톱 금지) → 헹굼 → 타올 드라이.
- **커트**: 섹션 분할 → 가이드라인 설정 → 각도별 커트(0도·45도·90도·180도 레이어) → 크로스체크 확인.
- **펌**: 모발 진단 → 전처리 → 로드 와인딩(섹션·각도·텐션) → 1제 도포 → 중간 테스트 → 헹굼·타올 드라이 → 2제(중화) → 최종 헹굼.
- 🎯 **컬러링(염색)**: 패치테스트(48시간 전 권장) → 두피 보호(바셀린 등) → 모발 도포(뿌리→끝 또는 끝→뿌리) → 발색 시간 → 헹굼·후처리.

## Chapter 03. 안전·위생 필수사항

- **패치테스트**: 염색약(PPD 등)에 대한 알레르기 확인 — 팔 안쪽에 소량 도포 후 48시간 반응 관찰.
- 🎯 **도구 소독은 작업 전후 필수** — 가위·커트기·브러쉬는 고시된 소독기준으로 소독 후 사용한다.
- **화학제 주의**: 펌제·염색제는 두피·눈 접촉 방지, 환기 유지, 사용 후 잔여물은 버린다.
