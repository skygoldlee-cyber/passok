# 실기 주관식 연습 — 미용사(일반) 작업형 필답 총 5제

> 본 파일은 실기 작업형 대비 자체 제작 연습 문항입니다 (`### S` 주관식 포맷 — manifest `written[]` 등록).
> 모범답안·채점기준 대조 자기채점 방식.

---

### S1. 샴푸 시술 순서

- **유형**: 서술형 · **근거**: 실기 작업형 (샴푸)

**문제**: 샴푸 시술의 작업 순서를 5단계로 서술하시오.

**모범답안**: 온수(체온 정도) 적시기 → 샴푸 도포 → 두피 마사지(지문면 사용, 손톱 금지) → 헹굼 → 타올 드라이

**채점기준**:
- [ ] 순서 5단계 모두 정확히 서술 시 만점, 단계 누락·순서 오류 시 감점

---

### S2. 패치테스트

- **유형**: 서술형 · **근거**: 실기 작업형 (염색)

**문제**: 염색 시술 전 패치테스트의 방법과 이유를 서술하시오.

**모범답안**: 염색약(PPD 등) 알레르기 확인 목적 — 팔 안쪽에 소량 도포 후 48시간 반응 관찰. 홍반·가려움 시 시술 금지

**채점기준**:
- [ ] 목적 + 방법(도포 부위·관찰 시간) 명시 시 만점

---

### S3. 펌 시술 순서

- **유형**: 서술형 · **근거**: 실기 작업형 (펌)

**문제**: 펌(파마) 시술의 전체 순서를 서술하시오.

**모범답안**: 모발 진단 → 전처리 → 로드 와인딩(섹션·각도·텐션) → 1제 도포 → 중간 테스트 → 헹굼·타올 드라이 → 2제 중화 → 최종 헹굼

**채점기준**:
- [ ] 1제 환원·2제 산화 중화 개념 포함 서술 시 만점

---

### S4. 기구 소독

- **유형**: 서술형 · **근거**: 실기 작업형 (소독)

**문제**: 가위·바리캉의 소독 방법을 고시 기준으로 서술하시오.

**모범답안**: 이물질 제거 → 소독액 묻은 천/거즈로 날을 중심으로 표면 닦기 → 마른 천으로 물기 제거 (높은 위험도 기구)

**채점기준**:
- [ ] 전처리 + 소독 방법 + 보관(분리보관) 언급 시 만점

---

### S5. 고객 상담 확인사항

- **유형**: 서술형 · **근거**: 실기 작업형 (고객 상담)

**문제**: 작업 전 고객 상담에서 반드시 확인해야 할 사항을 3가지 서술하시오.

**모범답안**: ① 두피·모발 상태(손상도·이상) ② 알레르기·과거 부작용 여부 ③ 원하는 시술·길이·스타일 — 이상 발견 시 시술 제한·전문가 안내

**채점기준**:
- [ ] 위생·안전 관점 확인사항 3가지 서술 시 만점
