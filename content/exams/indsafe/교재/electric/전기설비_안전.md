## Chapter 01. 감전 메커니즘 ⭐빈출

### 1-1. 감전 영향 ⭐

- 🎯 **전류 크기별 인체 영향**(mA 단위 — AC 60Hz 기준, 대표값):
  | 전류 | 반응 |
  | --- | --- |
  | 약 **1mA** | 지각전류 — 감전 느낌 시작 |
  | 약 5mA | 통증·근육 수축 |
  | 약 **10~15mA** | 이완전류(let-go) — 자력으로 전극 이탈 한계, 근육 경련 |
  | 약 20~50mA | 호흡곤란·혈압 상승 |
  | 약 **50~100mA** | **심실세동** 역치 — 치사 가능 |
  | 100mA 이상 | 심장 마비·화상 |

- 🎯 **감전 결정 요인**: 통전전류 크기·**통전 시간**·**통전 경로**(심장 경유 — 좌수↔우발 위험)·주파수(50·60Hz 위험 최대)·신체 상태·피부 저항(건조 약 2,000~5,000Ω, 습윤 급감).
- **통전 경로**: 손↔손 / 손↔발 / 발↔발 — 심장 통과 비율(좌수→발 > 우수→발) 순 위험.

### 1-2. 전기화재·안전전압

- 🎯 **안전한계전압**: 건조 장소 **50V** / 습기·물기 장소 **25V**(기준규칙 기준치) — 접촉전압 한계.
- **전기화재 원인**: 과부하·접촉불량·단락·누전·아크 — 스파크·과열로 발화.

## Chapter 02. 감전 방지 시설 ⭐빈출

### 2-1. 접지 ⭐

- 🎯 **접지공사 종류·저항(전기설비기술기준)**:
  | 종별 | 대상 | 접지저항값 |
  | --- | --- | --- |
  | **특별제3종** | 특고압 계통 변압기 저압측 | 10Ω 이하 |
  | **제3종** | 저압용 전기기계기구 철대·금속제 | 100Ω 이하 |
  | **제1종** | 고압·특고압용 전기기계기구 | 10Ω 이하 |
  | **제2종** | 고압·특고압 계통과 저압 결합용 변압기 저압측(혼촉 방지) | 변압기 1선 지락전류로 계산 |
  | **중성점 접지** | 저압 2선식 중성선 | — |

- 🎯 **접지 목적**: 고장 시 대지전압 저하(접촉전압 감소) + 누전차단기 동작 보장 — 등전위 본딩과 병용.
- **절연저항 기준**: 저압 전로 0.1MΩ 이상(대지전압 150V 이하), 0.2MΩ(150V 초과 300V 이하), 0.4MΩ(300V 초과) — 전로 분기별 측정.

### 2-2. 누전차단기·기타

- 🎯 **누전차단기(ELB)**: 누설전류로 지락 감지·차단 — 정격감도전류(감전 방지용 **30mA 이하**·0.03초 이내 동작), 화재방지용 별도.
- **절연·격리**: 절연피복·절연물로 대전체 피복 — 정기 절연저항 측정.
- **감전방지 보호구**: 절연장갑·절연화·절연대 — 정기 성능 시험.

## Chapter 03. 정전기 ⭐

### 3-1. 정전기 발생·피해

- **발생**: 마찰·박리·흐름(액체 유동)·충돌 대전 — 두 도체 접촉 후 분리 시 대전(대전열 순서).
- 🎯 **피해**: 방전 불꽃 → 인화성 물질 **화재·폭발** / 감전 쇼크·오작동(정밀기기)·분체 부착.
- **최소착화에너지**: 정전기 방전 에너지가 물질 착화에너지 초과 시 점화 — 인화성 액체 취급 시 위험.

### 3-2. 방전·대책 ⭐

- **방전 형태**: 스파크 방전·코로나 방전·브러시 방전 — 스파크 방전 에너지 최대.
- 🎯 **대책 4축**: ① **접지·본딩**(도체 연결 등전위화) ② **가습**(습도 65% 이상 — 표면전도도↑) ③ **제전기·이온화**(방전 전하 중화) ④ **유속 제한·낮은 전기전도도 재료 사용** — 비도체는 접지 효과 없음(이온화 필요).

## Chapter 04. 방폭구조·위험장소 ⭐빈출

### 4-1. 방폭구조 종류 ⭐

| 기호 | 명칭 | 원리 |
| --- | --- | --- |
| **d** | **내압방폭** | 내부 폭발을 용기가 견딤 — 화염 외부 전파 차단 |
| **e** | **안전증** | 점화원 발생 부품을 구조적으로 안전 증강 — 과불·과전압 여유 |
| **i** | **본질안전** | 회로 에너지를 착화 불가 수준으로 제한(ia·ib·ic) — 계측·제어 |
| **o** | **유입** | 점화 부품을 기름에 침지 |
| **p** | **압력(유입)방폭** | 내부 청정공기·불연성 가스 가압으로 위험가스 차단 |
| **m** | **몰드** | 점화원을 수지로 봉입 |
| **n** | **비점화** | 정상운전 중 점화원 발생 없는 구조 |

- 🎯 **그룹·등급**: 가스 군(Ⅰ=갱내용 / ⅡA·B·C=공장용) · 온도등급 T1~T6(표면온도 한계 — T6=85°C 이하).
- **인증**: 방폭 인증 없는 기기 위험장소 설치 금지.

### 4-2. 위험장소 분류 ⭐

- 🎯 **구역 분류(0·1·2종)**: 0종=지속·장시간 위험 분위기 존재 / 1종=정상 운전 중 발생 가능 / 2종=비정상 시에만 발생 가능.
- **방폭등급 결합**: Zone 0=본질안전(ia) 필수 수준 — 구역별 적합 방폭구조 선택.

## Chapter 05. 전선로·작업 안전

### 5-1. 전선로·이격거리 ⭐

- **전선 종류**: 절연전선(O.W·가교·고무)— 옥외·수직전선로 별도 규정.
- 🎯 **활선·근접 작업**: 충전부 근접 한계 — 특고압은 이격거리 표(전압별 m 단위). 작업 전 **검전·접지·절연** 3단계 + 작업 허가.
- **개폐기·차단기**: 부하 차단 기능 있는 차단기로 단로 — 퓨즈 교체는 정전 후.

### 5-2. 자동제어·비상정지

- **비상정지·인터록**: 위험 발생 시 급정지 + 방호물 개방 시 동작 차단 — 안전 인터록 회로.
- **자동제어 안전**: 시퀀스 제어 오작동 방지 — 페일세이프(고장 시 안전측 동작)·풀프루프 설계.
- **스마트팩토리·협동로봇**: 자동화 설비의 위험 — 안전 PLC·안전 릴레이·안전 레이저 스캐너.

## 🔑 핵심 용어

- **이완전류** 🎯 중요: 10~15mA — 자력 이탈 한계, 근육 경련
- **심실세동** 🎯 중요: 50~100mA 역치 — 감전 치사 원인
- **방폭구조 d·e·i·p** 🎯 중요: 내압·안전증·본질안전·압력 — 구역·그룹·온도등급
