## kocw_c_a_12

### 연산자의 개요 및 산술연산자
연산식은 연산을 지시하는 연산자와 연산의 대상이 되는 피연산자(operand)로 구성된다. 피연산자의 요구 개수에 따라 1개의 피연산자를 요구하는 연산자를 단항연산자, 2개의 피연산자를 요구하는 연산자를 이항연산자로 구분한다. 산술연산자는 이항연산자로서 사칙연산을 수행하는 덧셈(+), 뺄셈(-), 곱셈(*), 나눗셈(/)과 나머지를 구하는 모듈로(%) 연산자가 있다. 뺄셈(-) 기호는 단항으로 사용되어 부호를 바꾸는 역할을 하기도 한다. 나눗셈(/) 연산은 실수형 결과를 산출할 수 있으며, 모듈로(%) 연산자는 정수형 연산에 적용되어 정수형 결과만을 산출한다.

### 증감연산자
증감연산자는 변수의 값을 1씩 증가시키거나 감소시키는 연산자로, 증가연산자(++)와 감소연산자(--)가 있다. 증감연산자는 1을 더하거나 빼는 일반적인 치환문보다 빠른 기계어 코드를 생성하여 컴파일 속도가 빠르다는 특징을 갖는다. 증감연산자는 위치에 따라 전위형(PREFIX)과 후위형(POSTFIX)으로 구분된다. 전위형(++변수, --변수)은 변수의 값에 대해 먼저 증감연산을 수행한 후 변화된 값을 포함된 수식에 적용한다. 반면 후위형(변수++, 변수--)은 현재 변수의 값을 수식에 먼저 적용하여 연산식을 처리한 후 나중에 증감연산을 처리한다.

### 관계연산자 및 논리연산자
관계연산자는 두 변수나 수식 간의 대소 비교 및 상등 관계를 판별하는 이항연산자로 주로 조건 처리에 사용된다. 대소 관계를 판별하는 연산자에는 작다(<), 작거나 같다(<=), 크다(>), 크거나 같다(>=)가 있으며, 상등 관계를 판별하는 연산자에는 같다(==)와 같지 않다(!=)가 있다. 논리연산자는 참 또는 거짓의 논리값을 사용하여 연산을 수행하고 그 결과 또한 논리값으로 산출한다. 두 피연산자 중 하나만 참(1)이어도 참이 되는 논리합(||, OR), 두 피연산자가 모두 참(1)일 때만 참이 되는 논리곱(&&, AND), 1인 경우 0으로 0인 경우 1로 변환하는 단항 부정(!(NOT)) 연산자로 구성된다.

### 연산자 우선순위
하나의 수식 내에 여러 종류의 연산자가 혼재되어 있을 경우, 연산은 산술연산자, 관계연산자, 논리연산자의 순서로 처리된다. 세부 우선순위는 단항연산자인 !, ++, --가 가장 높고, 그 다음으로 산술연산자인 *, /, %가 뒤따른다. 이후 덧셈과 뺄셈(+, -), 대소 관계연산자(>=, >, <=, <), 상등 관계연산자(==, !=) 순으로 연산이 진행된다. 논리연산자 사이에서는 논리곱(&&) 연산자가 논리합(||) 연산자보다 높은 우선순위를 갖는다.

### 비트연산자
비트연산자는 정수형이나 문자자료형의 피연산자를 대상으로 대응되는 비트(0, 1) 단위의 연산을 수행하는 연산자이다. 메모리의 특정 비트를 조작하거나 하드웨어에 비트 단위로 접근하여 제어하고자 할 때 필수적으로 사용된다. 비트연산자의 종류로는 두 비트가 모두 참일 때 참이 되는 AND(&), 하나라도 참일 때 참이 되는 OR(|), 두 값이 배타적으로 다를 때 참이 되는 XOR(^)이 있다. 또한 비트를 부정하여 1은 0으로, 0은 1로 변환하는 단항 1의 보수 연산자(~)와 비트를 각각 지정한 수만큼 좌우로 이동시키는 왼쪽 이동 연산자(<<), 오른쪽 이동 연산자(>>)가 제공된다.

### 조건(3항) 연산자 및 복합대입연산자
조건 연산자는 3개의 피연산자를 취하는 3항 연산자로 `조건식 ? 식1 : 식2`의 형식으로 사용된다. 첫 번째 피연산자인 조건식을 판별하여 조건이 참이면 두 번째 피연산자인 식1을 결과로 취하고, 거짓이면 세 번째 피연산자인 식2를 결과로 취한다. 복합대입연산자는 일반 산술연산과 대입연산을 결합하여 식을 간결하게 표현할 수 있도록 제공되는 연산자이다. 복합대입연산자의 종류에는 +=, -=, *=, /=, %=뿐만 아니라 비트 이동을 결합한 >>=, <<= 등이 있으며, 예를 들어 `x = x + y`는 `x += y`로 축약하여 표현할 수 있다.

## kocw_c_a_18

### 변수 선언과 초기화
변수는 선언 시 일반적으로 메모리의 스택(stack) 영역에 할당된다. 메모리는 계속해서 재활용되는 구조이므로 선언된 영역이 자동으로 0으로 채워지지 않으며, 초기화하지 않은 영역에는 원하지 않는 값인 쓰레기 값(Garbage)이 남게 된다. 따라서 변수 초기화는 사용자의 책임이며, 선언과 동시에 값을 할당하는 방식을 통해 원하지 않는 값이 들어가는 것을 방지할 수 있다. 특히 자신의 값과 다른 값을 더하여 저장하는 누적 변수의 경우 선언 시 반드시 0으로 초기화해야 연산 결과의 오류를 막을 수 있다.

### 주소 연산자(&)와 입출력 함수
변수가 선언되어 메모리에 할당되면 모든 변수는 메모리 주소에 의해 구분되어 저장된다. 주소 연산자 `&`는 변수가 메모리의 어느 주소에 할당받았는지 확인하기 위해 사용하며, `printf` 함수의 `%p` 지정자를 통해 변수가 할당된 메모리의 시작 주소를 16진수로 출력할 수 있다. 키보드로 데이터를 입력받는 `scanf()` 함수는 `scanf("형식지정자", &변수명)` 형식으로 작성하여 입력값을 변수의 주소에 직접 저장한다. `printf()` 함수는 `%c`(한 문자), `%s`(문자열), `%d`(부호 있는 10진수), `%f`(float형 부동소수점), `%lf`(double형 부동소수점) 등의 형식 지정자를 사용하여 다양한 형태의 데이터를 출력한다.

### 크기 관련 자료형 수정자(short, long)
void를 제외한 기본 자료형에는 형 수정자를 적용하여 크기와 표현 방식을 세부 조정할 수 있다. `short`와 `long` 수정자는 운영체제 플랫폼의 비트 환경에 따라 실제 메모리 크기와 값의 표현 범위가 달라진다. 16bit 환경에서 크기는 `short` 2바이트, `int` 2바이트, `long` 4바이트이다. 32bit 환경에서는 `short` 2바이트, `int` 4바이트, `long` 4바이트가 할당된다. 64bit 환경에서는 `short` 2바이트, `int` 4바이트, `long` 8바이트로 처리되므로 실행 환경에 따른 자료형 크기 차이를 유의해야 한다.

### 부호 관련 자료형 수정자(signed, unsigned)
`signed` 수정자는 양수와 음수를 모두 표현할 수 있는 부호 있는 정수를 나타내며, 선언 시 `unsigned`가 붙지 않으면 기본적으로 `signed`가 선언된 것으로 간주한다. `signed` 형식은 최상위 1비트(가장 왼쪽 비트)를 MSB(most significant bit) 부호 비트로 사용하며, MSB가 0이면 양수, 1이면 음수를 나타낸다. 예를 들어 `signed char`(또는 `char`)는 8비트 중 최상위 비트를 부호로 사용하여 $2^7$ 기준인 -128부터 127까지의 범위를 갖는다.

반면 `unsigned` 수정자는 부호 비트가 필요 없으므로 최상위 비트까지 데이터 표현에 활용하여 부호 없는 정수를 선언할 때 쓰인다. `unsigned char`는 8비트 전체를 데이터 표현 비트로 사용하여 0부터 255($2^8-1$)까지의 범위를 표현할 수 있어 양의 정수 표현 범위가 2배로 확장된다. 16비트 정수의 경우 `short`는 -32,768 ~ 32,767 범위를 표현하지만 `unsigned short`는 0 ~ 65,535 범위를 갖는다. 32비트 정수 환경에서 `int` 및 `long`은 -2,147,483,648 ~ 2,147,483,647을 표현하고, `unsigned int` 및 `unsigned long`은 0 ~ 4,294,967,295 범위를 표현한다. 64비트 정수 환경에서 `long`은 -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 범위이며, `unsigned long`은 0 ~ 18,446,744,073,709,551,615 범위를 갖는다.

## kocw_c_a_67

### 기본 문자열 처리 함수와 수치 변환 함수
문자열의 길이를 측정하거나 복사, 연결, 비교 등을 수행하기 위해 다양한 표준 문자열 처리 함수가 사용된다. 문자열의 길이를 반환하는 `strlen`의 함수 원형은 `size_t strlen(const char *s)`이다. 대상 버퍼에 문자열을 복사하는 `strcpy`의 원형은 `char *strcpy(char *dest, const char *src)`이며, 문자열을 덧붙이는 `strcat`의 원형 역시 매개변수 구조상 대상을 지정하는 방식으로 정의된다. 두 문자열을 비교하는 `strcmp`는 `char *strcmp(const char *s1, const char *s2)` 원형을 가지며, `s1`이 `s2`보다 크면 양수(+), 작으면 음수(-), 두 문자열이 같으면 0을 반환한다. 문자열 형태의 숫자를 정수형으로 변환하는 `atoi`의 원형은 `int atoi(const char *str);`이다. "1"과 "2"를 그대로 더하면 문자열 결합에 의해 "12"가 되므로, 정상적인 수식 연산을 수행하기 위해서는 `atoi("1") + atoi("2") = 3`과 같이 변환 후 계산해야 한다.

### 문자 및 문자열 탐색·변환 함수
문자열 내에서 특정 문자열을 검색하거나 대소문자 변환 및 임시 복사를 수행하는 함수들이 제공된다. `strstr`의 함수 원형은 `char *strstr(const char *str1, const *str2);`로, 검색 대상 문자열 `str1`에서 찾을 문자열 `str2`가 최초로 발견된 이후의 문자열을 반환하며, 원래 문자열과 검색된 문자열을 활용해 위치를 계산할 수 있다. 문자열 전체의 대소문자를 변환하는 함수로 `char *strupr(char *string);`(대문자 변환)과 `char *strlwr(char *string);`(소문자 변환)이 있다. 개별 문자 단위 변환에는 `int toupper(int c);`(대문자 변환)와 `int tolower(int c);`(소문자 변환)가 사용된다. `strdup`의 원형은 `char *strdup(const char *string);`으로, 문자열 처리 시 메모리에 임시 저장 장소를 만들어 복사해 둠으로써 원본 값의 변형을 방지한다. 아울러 중요 데이터 처리 시에는 `memset(버퍼, set할값, 크기)` 함수를 활용하여 버퍼를 초기화하는 것이 바람직하다.

### 배열과 포인터를 이용한 문자열 선언 및 특성 비교
C 언어에서 문자열을 선언하고 초기화하는 방식은 배열을 이용하는 방법과 포인터를 이용하는 방법의 두 가지로 나뉜다. `char str1[] = "My String";`과 같이 배열로 선언한 문자열은 변수 형태의 문자열이며, `char *str2 = "Your String";`과 같이 포인터로 선언한 문자열은 상수 형태의 문자열이다. 변수 형태인 배열 선언 문자열은 `str1[1] = 'k';`처럼 내부의 특정 요소를 수정할 수 있으나, 배열 자체의 참조 위치는 변경할 수 없다. 반면 상수 형태인 포인터 선언 문자열은 포인터 변수가 가리키는 대상의 위치(주소)를 변경할 수 있지만, `*(++str2) = 'k'`와 같이 포인터가 가리키는 문자열 내용 자체를 수정하는 것은 불가능하다.

## kocw_c_c_07

### 전처리기와 주요 지시자
전처리기(Preprocessor)는 컴파일러가 프로그램을 기계어로 번역하기 전에 소스 프로그램을 가공하고 처리하는 프로그램이다. 전처리기 지시자(Preprocessor Directive)는 전처리기에게 특정 작업을 수행하도록 지시하는 유사 명령어로, 런타임(실행 시간)에 수행되는 명령어가 아니며 반드시 `#` 기호로 시작한다. 주요 지시자인 `#include`는 다른 파일의 내용을 현재 파일의 해당 위치에 그대로 포함시키는 역할을 한다. 또 다른 지시자인 `#define`은 특정 단어(매크로; Macro)를 지정한 다른 문자열로 대치하도록 정의하며, 끝에 세미콜론(;)을 붙이면 세미콜론까지 치환 대상에 포함되는 문법 오류가 발생할 수 있어 주의해야 한다. 매크로는 인수를 전달받는 함수 형태(매크로 함수)로도 정의할 수 있으며, 이는 실제 함수 호출이 아닌 텍스트 치환 방식으로 전처리 단계에서 처리된다.

### 헤더 파일의 종류와 참조 방식
헤더 파일(Header File)은 다른 소스 파일에 포함시킬 목적으로 작성된 파일로, 통상 `.h` 확장자를 가지며 인클루드 파일(Include File)이라고도 부른다. C 언어에서 헤더 파일은 포함 표기법에 따라 탐색 위치가 달라진다. `<표준헤더파일>` 형태는 개발 환경이나 시스템 컴파일러에 미리 설정된 표준 시스템 경로에서 헤더 파일을 찾는다. 반면 `"일반헤더파일"` 형태는 소스 파일이 위치한 현재 작업 디렉터리를 우선적으로 탐색한다. 헤더 파일에는 주로 다른 파일에서 공유하여 호출할 함수의 선언과 매크로 정의 등이 정리된다.

### 함수의 원형(선언)과 정의
함수의 선언(Declaration) 또는 함수 원형(Prototype)은 함수의 정의(Definition)에서 본체(Body) 부분을 제외하고 반환형, 함수명, 매개변수 목록으로 구성된 인터페이스만 명시한 것이다. C 언어에서는 변수와 함수 모두 실제로 사용하기 전에 명시적으로 선언(Explicit Declaration)하는 절차가 바람직하며, 선언이 누락될 경우 암시적 선언(Implicit Declaration) 문제가 발생할 수 있다. 함수를 호출하는 입장에서는 제공되는 기능과 사용법만 알고 있다면 함수의 세부 구현 내용까지 파악할 필요가 없다. 따라서 함수 원형을 상단에 미리 선언해 두면 함수의 실제 구현부인 Definition을 소스 코드의 다른 위치나 별도의 파일로 분리하여 배치할 수 있다.

### 모듈러 프로그래밍과 분할 컴파일
모듈러 프로그래밍(Modular Programming)은 복잡하고 큰 프로그램을 다루기 쉬운 작은 단위로 분할하여 해결하는 분할 정복(Divide & Conquer) 기법에 기반한다. 프로그램의 기능에 따라 소스 파일(`.c`)을 여러 개로 분리하여 작성하면 대규모 소프트웨어를 체계적으로 관리할 수 있다. 각 소스 파일은 개별 컴파일 과정을 거쳐 목적 파일(Object File, `.o`)로 독립적으로 변환된다. 이후 링커(Linker)가 생성된 목적 파일들을 서로 연결하는 링킹(Linking) 작업을 수행하여 최종 단일 실행 파일(`.exe`)을 완성한다. 공통으로 필요한 함수 원형은 별도의 사용자 정의 헤더 파일에 선언해 두고, 소스 파일에서 이를 포함하여 참조하도록 구성한다.

### 인터페이스와 구현의 분리 및 추상화
컴퓨터 과학에서 추상화(Abstraction)는 프로그램과 데이터에서 불필요한 구현 세부 사항을 숨기고 특정 목적에 관련된 핵심 정보만을 남기는 일반화 과정을 의미한다. C 언어 체계에서 헤더 파일(`.h`)은 외부 모듈과의 접점 규격인 인터페이스(Interface) 역할을 담당하고, 소스 파일(`.c`)은 실제 동작을 작성한 구현(Implementation) 역할을 담당한다. 함수나 서비스를 호출하는 사용자는 인터페이스만 알면 세부 동작을 알 필요가 없는 블랙박스(Black Box) 원리가 적용된다. 따라서 컴파일 단계에서는 서비스 소스 파일 원본이 없더라도 함수 선언이 담긴 헤더 파일만 존재하면 정상적으로 컴파일이 완료된다. 최종 실행 파일을 생성하는 링킹 단계에서는 소스 파일 대신 컴파일 완료된 목적 파일이나 라이브러리 파일이 결합된다.

### C 표준 라이브러리와 라이브러리 파일
`printf()`나 `scanf()`와 같은 표준 입출력 함수는 C 언어의 표준 라이브러리(C Standard Library)에서 기본으로 제공하는 함수이다. 표준 라이브러리 함수의 원형 선언은 개발 환경이 제공하는 표준 헤더 파일(예: `stdio.h`) 내에 수록되어 있다. 표준 함수의 실제 정의(구현 내용)는 프로그램 작성 시마다 매번 컴파일할 필요가 없도록 미리 컴파일하여 목적 파일 형태로 묶어둔 라이브러리 파일에 저장되어 있다. 라이브러리 파일은 빌드 툴체인에 따라 확장자가 상이하게 관리된다. MinGW 환경에서는 `.a` 확장자를 사용하며, Microsoft Visual C++ 환경에서는 `.lib` 확장자를 갖는다.

### C 표준 라이브러리(Standard Library)와 레퍼런스 활용
C 표준 라이브러리는 C 언어에서 기본적으로 제공하는 서비스 함수들의 모음입니다. 개발자는 각 함수의 기능과 이용 방법을 레퍼런스(Reference)를 통해 확인하며 프로그래밍을 수행합니다. 대표적으로 Microsoft는 1990년대 초반부터 MSDN(Microsoft Developer Network)이라는 레퍼런스 DB를 구축하여 통합개발환경(IDE)에서 충실한 C 레퍼런스를 제공하고 있습니다. Visual Studio는 Visual C++ 기반 IDE를 기원으로 삼고 있어 C 언어 지원 기능이 우수한 반면, Eclipse는 Java 기반 개발 환경이므로 C 레퍼런스 지원이 상대적으로 부실합니다. 표준 함수를 모두 암기할 수는 없으므로 C 표준 라이브러리 위키북스, cppreference 등의 온라인 레퍼런스를 상시 활용하는 능력이 필수적입니다.

### 주요 표준 헤더 파일 분류 및 기능
표준 라이브러리 함수를 사용하기 위해서는 기능별로 정의된 해당 헤더 파일을 포함해야 합니다. 입출력을 담당하는 `<stdio.h>`(printf 함수 등)와 수학 함수를 연산하는 `<math.h>` 외에도 프로그램 제어 및 데이터 처리를 위한 다양한 헤더가 존재합니다. 대표적으로 의사 난수 생성, 동적 메모리 할당, 변환, 정렬 등을 지원하는 `<stdlib.h>`가 있으며, 날짜 및 시간 형식 변환은 `<time.h>`를 통해 수행합니다. 또한 오류 검출용 매크로를 제공하는 `<assert.h>`, 문자 분류 및 대소문자 변환 함수가 포함된 `<ctype.h>`, 정수 및 부동소수점의 구현 특성 상수를 정의한 `<limits.h>`와 `<float.h>`, 문자열 처리용 `<string.h>` 등이 표준 헤더로 규정되어 있습니다.

### 헤더 파일의 구성 요소와 매크로 상수
헤더 파일에는 서비스 함수의 원형(Function Prototype)뿐만 아니라, 함수의 이용과 연산에 필요한 매크로(Macro) 및 구조체 등이 정의되어 있습니다. 예를 들어 MinGW 환경의 `<math.h>`에는 원주율 값을 의미하는 `M_PI`(3.14159265358979323846)를 비롯하여 자연상수 `M_E`, 로그 및 제곱근 관련 상수들이 매크로 형태로 선언되어 있습니다. `log()`나 `exp()`와 같은 수학 표준 함수를 프로그램에서 정상적으로 호출하려면 소스 코드 상단에 반드시 `#include <math.h>` 지시자를 선언하여 함수 원형을 참조할 수 있도록 해야 하며, 누락 시 문법 에러(Syntax Error)나 경고(Warning)가 발생합니다.

### 난수 생성(rand, srand)과 균등 분포(Uniform Distribution)
의사 난수(Pseudo-random number)를 생성할 때는 `<stdlib.h>`의 `rand()` 함수를 사용하며, 이 함수는 0부터 매크로 상수 `RAND_MAX` 사이의 정수를 반환합니다. 실행 시마다 동일한 난수 순열이 반복되는 것을 방지하기 위해 시드(Seed) 값을 초기화하는 `srand()` 함수를 호출해야 하며, 통상 `<time.h>`의 `time(0)`을 인자로 전달하여 매 실행 시점마다 다른 난수열이 생성되도록 설정합니다. 0과 1 사이의 실수 값을 동일한 확률로 가지는 균등 난수 변수(Uniform Random Variable, X~Uniform[0,1])를 생성하기 위해서는 `rand()` 함수로 구한 반환값을 변환하여 0.0 이상 1.0 이하의 실수 범위로 대응시키는 연산 처리가 필요합니다.

### 타입 변환(Type Casting)의 개념과 구분
타입 변환(Type Casting)은 값의 데이터 타입을 다른 타입으로 변경시키는 것을 의미합니다. 타입 변환 방식은 컴파일러에 의해 자동으로 변환되는 묵시적(Implicit) 타입 변환과, 프로그래머가 변환 연산자를 사용하여 의도적으로 변환을 지정하는 명시적(Explicit) 타입 변환의 두 가지로 분류됩니다. 타입 변환을 통해 산술 연산 과정에서 발생할 수 있는 자료형 간 불일치나 정수 나눗셈에 따른 오차를 방지하고 요구되는 연산 결과 타입을 명확히 얻을 수 있습니다.

### 형변환 연산자(Type Casting Operator)
형변환 연산자는 명시적(Explicit)이자 강제적으로 값의 데이터 타입을 변경하는 연산자이며, `(type) expression` 형태로 작성한다. 대입 연산 과정에서 정수형 변수를 실수형 변수에 대입하거나 실수형 변수를 정수형 변수에 대입할 때 묵시적 변환이 발생할 수 있으며, 특히 실수 값을 정수 변수에 묵시적으로 변환하는 것은 바람직하지 않아 컴파일러 경고(Warning)가 발생하기도 한다. 정수 간의 나눗셈인 `a / b`는 소수점 이하가 버려진 정수 몫을 산출하지만, 피연산자 앞에 `(double)`과 같이 명시적 캐스팅을 적용하면 연산 결과가 실수 형태로 올바르게 계산된다.

### 배열의 정의와 초기화
C 언어에서 배열은 동일한 자료형의 데이터 여러 개를 연속된 메모리 공간에 저장하는 자료구조이다. 크기가 3인 정수형 배열 `a[3]`을 선언하면 각 요소는 인덱스 `a[0]`, `a[1]`, `a[2]`로 개별 접근하여 값을 대입할 수 있다. 또는 선언과 동시에 중괄호를 사용하여 `int a[3] = {2, 9, 8};`과 같이 한 번에 초기화하는 것도 가능하다. 주사위 눈의 발생 빈도와 같은 다수의 카운트 데이터를 다룰 때는 `int N[6] = {0, 0, 0, 0, 0, 0};` 형태로 모든 요소를 0으로 초기화하여 사용한다.

### 난수 생성 함수와 확률 시뮬레이션
난수 기반 시뮬레이션을 구현할 때 `urand()` 함수는 `(double)rand() / (RAND_MAX + 1)` 형태로 정의하여 [0, 1) 범위의 균일 의사 난수(Uniform Pseudo Random Number)를 실수 형태로 생성한다. 이때 나누는 분모를 `RAND_MAX + 1`로 명시적 형변환을 적용하여 나눔으로써 생성 결과가 1.0이 되지 않도록 처리한다. 주사위 던지기 시뮬레이션에서는 각 눈(1~6)의 결과 빈도를 배열의 인덱스에 매핑하여 누적 계수한다. 특정 눈의 누적 횟수를 전체 시뮬레이션 횟수(`N_DICE`)로 나누면 해당 눈이 나올 확률이 계산되며, 시행 횟수를 100, 1000, 10000 등으로 증가시킬수록 결과는 이론적 확률인 1/6(약 0.166667)에 수렴한다.

### 몬테카를로 시뮬레이션(Monte-Carlo Simulation)을 이용한 원주율 추정
몬테카를로 방법은 다수의 무작위 표본(Sample) 및 반복 실험을 통해 실제 참값을 추정하는 기법이다. 단위원의 직각부채꼴 영역에 대해 각각 [0, 1] 범위의 균일 분포를 따르는 두 난수 좌표 쌍 $(X, Y)$를 생성하여 표본을 추출한다. 정사각형 면적 대비 부채꼴의 면적비는 $\pi / 4$가 되므로, 전체 샘플 수 대비 부채꼴 내부에 존재하는 샘플 수의 비율은 $\pi / 4$에 근사한다. 판정 시 경계 위의 점도 내부로 포함하며, 내부 점의 개수와 전체 표본 수를 이용하여 원주율 값을 유도할 수 있다.

### 사용자 라이브러리(User Library)와 링커(Linker) 설정

### 부동소수점 수의 표현 원리와 IEEE 754 표준
컴퓨터는 아주 크거나 작은 실수를 다루기 위해 과학적 기수법을 응용한 $F \times 2^E$ 형태의 부동소수점(Floating Point) 표현 방식을 사용한다. 지수부($E$)의 값에 따라 소수점의 위치가 이동하며, 데이터는 부호($S$), 지수부($E$), 소수부($F$)로 나누어 비트에 배치된다. 32비트 단정밀도 IEEE 754 표준에서는 부호 1비트, 지수부 8비트, 소수부 23비트를 할당한다. 수치 계산 공식은 지수부 $E$가 $1 \le E \le 254$ 범위일 때 $(-1)^S \times 1.F \times 2^{E-127}$을 적용하며, $E = 0$일 때는 $(-1)^S \times 0.F \times 2^{-126}$을 적용한다.

### 실수형 자료형의 특징과 제약점

### 변수의 유효범위(Scope)와 지역변수
유효범위(Scope)는 프로그램 코드 내에서 변수의 식별자를 정상적으로 인식하고 사용할 수 있는 범위를 의미한다. 함수 내부에서 선언된 변수는 선언된 해당 함수 내에서만 유효한 지역변수(Local Variable)가 되며, 다른 함수에 동일한 식별자를 가진 변수가 있더라도 상호 간에 간섭하지 않는다. 지역변수는 중첩 블록(Nested Block)의 시작점에서도 선언이 가능하며, 해당 변수의 유효범위는 자신이 선언된 블록 내부로 엄격히 제한된다. 블록 밖에서 내부 블록의 지역변수를 참조하려 하면 문법 오류가 발생하며, 외부 변수와 내부 블록 변수의 이름이 동일할 경우에는 블록 내부에서 선언된 지역변수가 우선적으로 적용된다.

### 부호 있는 정수 표현 방식과 부호-절댓값 및 1의 보수

### 2의 보수 표현법의 원리와 특징

### 2의 보수와 10진수 간의 상호 변환

### 배열의 선언과 초기화
배열은 선언과 동시에 초기화 목록(initializer)을 사용하여 초기값을 지정할 수 있습니다. 배열 크기보다 적은 개수의 원소로 초기화하는 경우, 지정된 원소 이후의 나머지 요소들은 자동으로 0으로 초기화됩니다(예: `int a[3]={2,9};`는 `a[0]=2, a[1]=9, a[2]=0`이 됨). 또한 `int a[3]={0,};`과 같이 선언하면 배열의 모든 원소를 0으로 초기화할 수 있습니다. 초기화 목록이 제공되는 경우에는 배열 길이를 생략하여 `int a[]={2,9,8};`과 같이 선언할 수 있으며, 이때 배열의 크기는 원소의 개수에 맞추어 자동으로 결정됩니다. 반면 초기화 목록이 존재하지 않을 때 배열의 길이를 생략하면 컴파일러가 크기를 결정할 수 없어 구문 오류(Syntax Error)가 발생합니다.

### 배열 초기화 및 인덱스 참조 시 오류의 유형
배열을 다룰 때 발생하는 오류는 컴파일 시점의 구문 오류(Syntax Error)와 프로그램 실행 시점의 런타임 오류(Run-Time Error)로 구분됩니다. 초기화 목록(initializer)의 값 개수가 선언된 배열의 길이를 초과하는 경우(예: `int a[3]={2,9,8,7};`), 컴파일러가 오류를 사전에 인지하여 Syntax Error가 발생합니다. 반면 선언된 배열의 크기를 초과하는 인덱스를 참조하는 코드(예: 크기가 3인 배열에 대해 `a[3]` 접근)는 컴파일러가 유효 범위를 벗어난 사실을 파악하지 못해 Syntax Error가 발생하지 않으며, 허용되지 않은 메모리에 접근함에 따라 실행 중 Run-Time Error(Memory Access Violation 등)가 발생할 수 있습니다.

### 배열의 크기와 메모리 구조
`sizeof` 연산자를 적용할 때 배열 전체의 크기는 자료형의 크기와 원소 개수의 곱으로 계산됩니다. 예를 들어 크기가 3인 `double` 배열은 24바이트(8바이트 × 3), 크기가 3인 `int` 배열은 12바이트(4바이트 × 3), 원소가 5개인 `char` 배열은 5바이트(1바이트 × 5)를 차지합니다. 반면 각 요소(`a[0]`, `b[0]`, `c[0]`)에 `sizeof`를 적용하면 각 자료형의 기본 단위 크기(double: 8바이트, int: 4바이트, char: 1바이트)가 반환됩니다. 배열의 각 요소는 메모리 상에 연속적으로 배치되며, 인덱스가 1씩 증가할 때마다 참조 자료형의 크기 단위만큼 주소 값이 증가합니다.

### 배열과 포인터의 관계 및 포인터 연산
배열의 이름은 배열의 첫 번째 원소의 주소(`&a[0]`)를 가리키는 상수 포인터입니다. 따라서 주소값을 저장하는 포인터 변수에 배열의 이름을 직접 대입할 수 있습니다(`p = a;`). 포인터 변수에 대한 덧셈 및 뺄셈 연산은 정수 값의 단순 가감이 아니라 가리키는 자료형(Reference Type)의 크기 단위로 주소값이 증감합니다(예: `double` 포인터에 1을 더하면 주소값은 8 증가). 또한 포인터 연산을 이용하여 배열 요소에 접근할 수 있으며, 배열의 인덱스 표현식 `a[i]`는 포인터 역참조 표현식인 `*(a + i)` 또는 `*(p + i)`와 완벽히 호환됩니다. 포인터 변수 자체를 배열 이름처럼 `p[i]` 형태로 사용하는 것도 가능합니다.

### 증감 연산자의 동작 방식
증감 연산자(`++`, `--`)는 피연산자로 반드시 변수를 취하는 단항 연산자이며, 일반적인 덧셈이나 뺄셈 연산보다 연산 처리 속도가 빠른 장점이 있습니다. 연산자가 피연산자의 앞에 위치하는 전치(Prefix) 방식(`++X`, `--X`)은 변수의 값을 먼저 1 증가 또는 감소시킨 후 그 변경된 값을 수식의 결과값으로 반환합니다. 반면 연산자가 뒤에 위치하는 후치(Postfix) 방식(`X++`, `X--`)은 현재 변수의 값을 수식의 결과값으로 먼저 사용한 뒤 변수의 값을 1 증가 또는 감소시킵니다. 연산자의 위치에 따라 연산 결과 및 프로그램 로직에 영향을 주어 버그 유발 가능성이 있으므로, 소프트웨어 공학 관점에서 일부 개발 환경은 사용을 제한하기도 합니다.

### 함수의 배열 인자 전달과 크기 정보 전달 방법
함수의 매개변수로 배열을 전달할 때 실제로는 전체 배열이 복사되는 것이 아니라 배열의 시작 주소값(포인터)만 복사되어 전달됩니다. 따라서 함수 매개변수 선언 시 명시된 배열 크기(`int sum(int n[10])`)는 컴파일러에 의해 무시되며, 이는 `int sum(int n[])` 또는 포인터 표기법인 `int sum(int *n)`과 완전히 동일합니다. 함수 내부에서 매개변수로 전달받은 배열 요소를 수정하면 원본 배열의 데이터가 직접 변경됩니다. 이때 호출된 함수는 배열의 전체 크기를 자동으로 알 수 없으므로, 크기 정보를 전달하기 위한 추가 정수 매개변수(`int nlen`)를 함께 넘기거나 배열의 마지막 요소에 특정 종료값(센티널 값, 예: `-1`)을 배치하여 크기를 판별하는 절차가 요구됩니다.

### C 언어에서의 문자열(String) 표현
문자열은 0개 이상의 연속적으로 나열된 문자들의 집합이며, 문자의 배열로 취급됩니다. 개별 문자를 작은따옴표로 하나씩 초기화하는 방식(`char aMsg1[] = {'H','e','l','l','o'};`)의 불편함을 해소하기 위해 큰따옴표(`" "`)를 사용하는 문자열 리터럴 초기화 방식(`char aMsg2[] = "Hello";`)이 제공됩니다. 또한 문자열은 문자 배열 외에도 메모리 주소를 직접 다루는 문자 포인터 변수(`char *p = "Hello";`)를 선언하여 가리키도록 설정할 수 있습니다.

### C 언어 문자열의 정의 및 포인터의 크기
C 언어에서 일반적인 문자열은 마지막에 널 문자(`'\0'`)를 포함하고 있는 문자 배열(Null Terminated String)을 의미하며, `printf`를 통해 문자열을 출력할 때는 서식 지정자 `%s`가 사용된다. 예를 들어 큰따옴표를 이용해 선언된 `char aMsg2[] = "Hello";`는 실제 메모리에 `{'H', 'e', 'l', 'l', 'o', '\0'}` 형태로 저장되므로, 널 문자가 없는 단순 문자 배열 `char aMsg1[] = {'H', 'e', 'l', 'l', 'o'};`보다 배열의 크기(`sizeof`)가 더 크다. 포인터 변수의 경우 참조하는 타입(Reference Type)에 관계없이 주소값을 저장하는 데 필요한 메모리 크기가 동일하므로, `sizeof(char *)`, `sizeof(short *)`, `sizeof(int *)`, `sizeof(double *)`의 결과는 모두 같다. 문자열 출력 함수 등에서 `putchar(*str++)` 구문은 현재 포인터가 가리키는 문자를 출력한 뒤 포인터를 1 증가시키는 연산인 `putchar(*str); str = str + 1;`과 본질적으로 동일하게 동작한다.

### 문자열 초기화 방식과 메모리 저장
배열 형태로 선언된 `char aMsg1[]`이나 `char aMsg2[]`의 우측에 사용된 문자열은 해당 배열 변수의 초기화(Initializer) 역할을 수행한다. 반면 `char *p = "Hello";`와 같이 선언할 때 우측에 쓰인 문자열은 별도의 상수(문자열 상수)로 메모리에 저장되며, 포인터 변수 `p`에는 그 문자열 상수의 주소값이 저장되어 초기화된다. 만약 `char *p = aMsg2;` 형태로 수정하면 포인터 변수 `p`는 배열 `aMsg2`의 시작 주소를 가리키게 된다.

### C 언어 배열 대입 연산의 제한과 문자열 복사

### 자바 패키지와 JAR
자바 패키지는 기능이 비슷한 라이브러리 클래스나 인터페이스들을 하나의 집단으로 묶어놓은 것을 의미한다. 작성자는 자바 프로그래밍 언어 자체이거나 사용자일 수 있으며, 기본 패키지 디렉토리는 `C:\jdk1.5.0\jre\lib`, 사용자 정의 패키지 디렉토리는 `C:\jdk1.5.0\jre\lib`의 서브디렉토리에 위치한다. 여러 개의 클래스(`.class` 파일)를 효과적으로 관리하기 위해 모든 패키지 내용을 파일 하나로 묶어 압축하는 방법을 JAR(Java Archive)라고 한다. JAR 압축파일 유틸리티를 사용할 때는 압축이 필요한 패키지 디렉토리의 상위 디렉토리로 이동한 후 유틸리티를 이용해 압축을 수행한다.

### 주요 표준 패키지의 종류
자바 표준 라이브러리는 역할에 따라 다양한 기본 패키지를 제공한다. `java.lang`은 자바의 기본적인 클래스(Object, String 등)를 포함하며 import 문 없이도 자동으로 사용할 수 있다. `java.util`은 데이터 수집, 날짜 및 시간 정보 접근, 문자열 분석 등 표준 작업을 지원하고, `java.io`는 입출력 작업을, `java.net`은 네트워크 관련 기능을 지원한다. GUI 환경과 관련해서는 기본 그래픽 컴포넌트를 지원하는 `java.awt` 및 그 이벤트 처리를 위한 `java.awt.event`, 그리고 AWT보다 다루기 쉽고 유연한 Swing 컴포넌트를 제공하는 `javax.swing` 및 `javax.swing.event`가 있다. 이외에도 웹 애플릿 작성을 위한 `java.applet`과 표준 SQL을 사용한 데이터베이스 접근을 돕는 `java.sql`이 있다.

### 패키지의 선언과 import 문
패키지 선언은 사용자가 유사한 기능을 가진 클래스들을 하나의 패키지로 묶을 때 사용하며, 소스 코드 상단에 `package 패키지이름;` 형태로 명시한다. 사용자 정의 패키지는 기본 라이브러리 경로(`C:\jdk1.5.0\jre\lib`)의 하위 디렉토리에 계층 구조에 맞추어 배치한다. 반대로 프로그램에서 특정 패키지에 속한 라이브러리 클래스를 불러와 사용하려면 `import 패키지이름.읽을클래스이름;` 또는 와일드카드(`*`)를 적용한 `import 패키지이름.*;` 형식의 import 문을 선언해야 한다.

### java.lang.Object 클래스
`java.lang` 패키지에 속한 `Object` 클래스는 자바의 최상위 클래스로, 모든 객체가 상속받는 주요 공통 메서드를 제공한다. `equals(Object obj)`는 호출 객체와 매개변수 객체가 같은지를 비교하여 boolean 값을 반환하며, `clone()`은 객체를 복사하고 `getClass()`는 객체의 클래스명을 Class 형의 객체로 반환한다. 객체의 고유 해시코드 값을 정수로 계산하는 `hashCode()`, 객체가 가진 문자열을 반환하는 `toString()`, 쓰레기 수집(Garbage Collection) 전에 호출되어 점유한 자원을 해제하는 `finalize()`가 포함된다. 또한 멀티스레드 제어를 위해 스레드 실행을 중지하고 대기시키는 `wait()`, 대기 중인 스레드를 깨우는 `notify()` 및 `notifyAll()` 메서드를 지원한다.

### 래퍼(Wrapper) 클래스와 수치형 클래스
래퍼 클래스는 기본 자료형(Primitive Type)을 객체 형태로 표현하는 클래스이다. 수치형 래퍼 클래스의 상위 추상 클래스인 `Number`는 `intValue()`, `longValue()`, `floatValue()`, `doubleValue()`와 같이 기본형 수치 자료형으로 변환하는 추상 메서드를 정의한다. 32비트 정수를 다루는 `Integer` 클래스는 문자열을 int 기본형으로 변환하는 `parseInt(String str)`, 2진법 문자열로 변환하는 `toBinaryString(int num)`, 문자열로부터 객체를 생성하는 `valueOf(String str)` 등의 정적 메서드를 지원한다. 정수형 클래스로는 크기별로 `Byte`(8bit), `Short`(16bit), `Integer`(32bit), `Long`(64bit)이 있고, 실수형 클래스로는 `Float`(32bit), `Double`(64bit)이 있다. 실수 클래스에는 객체의 값이 무한대인지 판별하는 `isInfinite()`, 인자 값이 숫자가 아닌지(NaN) 판별하는 `isNaN(float num)` 메서드 등이 제공된다.

### Character 클래스와 문자열(String, StringBuffer) 클래스
`Character` 클래스는 단일 문자를 다루며, 문자의 속성을 검사하는 `isDigit(char ch)`, `isLetter(char ch)`, `isLowerCase(char ch)`, `isUpperCase(char ch)`, `isSpace(char ch)` 및 대소문자 변환 메서드인 `toLowerCase(char ch)` 등을 제공한다. `String` 클래스는 크기가 변하지 않는 불변(immutable) 문자열을 처리하며, 문자열 비교(`compareTo`), 특정 문자의 위치 검색(`indexOf`, `lastIndexOf`), 길이 반환(`length`), 접두사 확인(`startsWith`), 문자열 연결(`concat`), 부분 문자열 추출(`substring`), 문자 치환(`replace`) 기능을 수행한다. 반면 `StringBuffer`는 가변(mutable) 길이를 지원하는 문자열 클래스로, 내부 버퍼 크기를 조회하는 `capacity()`, 끝에 데이터를 추가하는 `append()`, 특정 인덱스 위치에 내용을 삽입하는 `insert()`, 문자열을 역순으로 뒤집는 `reverse()`, 특정 인덱스의 문자를 바꾸는 `setCharAt()` 등을 제공한다.

### System 클래스의 시스템 제어 메서드
System 클래스는 운영체제 및 시스템 환경과 상호작용하기 위한 정적 메서드를 제공합니다. currentTimeMillis()는 1970년 1월 1일 자정부터 현재까지의 시간을 밀리초 단위로 반환하며, exit(int exitcode)는 현재 실행 중인 응용프로그램을 강제 종료하되 매개변수로 0을 지정하면 일반적인 정상 종료를 수행합니다. gc() 메서드는 쓰레기 수집(garbage collection) 작업을 명시적으로 시작시키는 역할을 합니다. 또한 getProperties()는 현재의 시스템 속성 집합을 조회하고, getProperty(String key)는 특정 키에 지정된 시스템 속성 문자열을 반환합니다. loadLibrary(String libname)는 지정된 라이브러리 이름을 갖는 동적 라이브러리를 메모리에 로드하는 기능을 수행합니다.

### Math 클래스
Math 클래스는 수학적 연산에 필요한 다양한 메서드와 상수를 제공하며, 포함된 모든 메서드와 상수는 static으로 선언되어 객체 생성 없이 클래스명을 통해 직접 호출합니다. abs(int i)는 주어진 매개변수 i의 절댓값을 int 형으로 반환하며, max()와 min() 메서드는 두 인자 중 각각 큰 값과 작은 값을 구합니다. 삼각함수 및 지수 계산을 위해 cos(double x), atan(double x), exp(double x)를 제공하여 cos 값, arctangent 값, e^x 값을 double 형식으로 얻을 수 있습니다. 올림과 내림을 처리할 때는 ceil(double x)을 통해 x보다 크거나 같은 가장 작은 실수를, floor(double x)를 통해 x보다 작거나 같은 가장 큰 실수를 산출합니다.

### Class 클래스
Class 클래스는 특정 객체와 관련된 클래스 또는 인터페이스에 대한 메타 정보를 제공합니다. 사용자 프로그램이 메모리에 로드될 때 자바 가상 기계(JVM)에 의하여 자동으로 인스턴스가 생성됩니다. getSuperclass()는 해당 클래스의 상위 클래스 객체를 반환하고, isInterface()를 통해 인터페이스 여부를 boolean 값으로 판별합니다. newInstance() 메서드는 해당 클래스의 새로운 객체를 직접 동적으로 생성하여 반환하며, getName()은 클래스나 인터페이스의 이름을 문자열로 반환합니다. 외부 문자열을 이용해 클래스를 동적으로 로드할 때는 정적 메서드인 forName(String classname)을 호출하며, 대상 클래스를 찾을 수 없으면 ClassNotFoundException 예외를 발생시킵니다.

### StringTokenizer 클래스
java.util 패키지에 포함된 StringTokenizer 클래스는 하나의 문자열을 구분자를 기준으로 분리하여 토큰화할 때 사용합니다. 생성자 StringTokenizer(String str, String delimeters)를 통해 대상 문자열과 분리자 문자열을 설정하여 객체를 생성합니다. countTokens() 메서드는 분리 작업 후 문자열 내에 존재하는 잔여 토큰의 개수를 반환합니다. 토큰을 순차적으로 탐색할 때는 hasMoreTokens()를 호출하여 파싱할 문자열이 남아 있는지 여부를 true 또는 false로 확인합니다. 이후 nextToken() 메서드로 다음 순서의 토큰을 읽어 들이며, 필요에 따라 인자로 새 구분자를 넘겨 다음 토큰 추출 시 분리자를 변경할 수도 있습니다.

### Vector 클래스와 Enumeration 인터페이스
Vector 클래스는 서로 다른 종류의 객체 데이터를 저장할 수 있는 가변 크기 배열 구조로, 저장 공간이 가득 차면 자동으로 크기가 확장됩니다. 객체 생성 시 기본 크기 10으로 초기화하거나, Vector(int size, int increment)와 같이 초기 크기와 공간 초과 시 늘어날 증가분을 명시할 수 있습니다. addElement(Object obj)는 객체를 벡터의 맨 마지막에 추가하고, insertElementAt(Object obj, int index)은 특정 위치에 삽입하며 범위 밖인 경우 ArrayIndexOutOfBoundsException을 발생시킵니다. 데이터 조회 및 검색을 위해 elementAt(int index), contains(Object obj), indexOf(Object obj)를 사용하고, 전체 요소 수 파악은 size(), 비어 있는지 판별은 isEmpty()를 이용합니다. 또한 elements() 메서드는 벡터에 저장된 객체들을 순회할 수 있는 Enumeration 객체를 반환하며, 이를 통해 hasMoreElements()와 nextElement() 메서드로 요소를 하나씩 추출할 수 있습니다.

### Stack 클래스
Stack 클래스는 Vector 클래스의 하위 클래스로 설계되어 후입선출(LIFO, Last-In First-Out) 방식의 자료구조를 지원합니다. push(Object item) 메서드는 스택의 최상단에 새로운 객체를 추가하고 추가된 해당 객체를 반환합니다. 반대로 최상단 객체를 꺼낼 때는 pop()을 사용하여 맨 위의 객체를 반환하는 동시에 스택에서 완전히 삭제합니다. 최상단 객체를 제거하지 않고 단순히 값만 확인하고자 할 때는 peek() 메서드를 호출합니다. 현재 스택이 비어 있는지 검사할 때는 empty()를 사용하여 boolean 값을 얻으며, search(Object item)는 스택에서 지정된 객체의 위치를 정수로 반환하되 맨 위 위치를 1로 지정하고 찾지 못하면 -1을 반환합니다.

### Hashtable 클래스
Hashtable 클래스는 고유한 키(key)와 그에 대응하는 값(value)을 쌍으로 묶어서 저장하는 자료구조입니다. 해시테이블에 사용되는 모든 키는 고유성을 가지므로 서로 다른 값을 유지해야 합니다. put(Object key, Object value) 메서드로 원소를 저장하며, 키 또는 값 중 하나라도 null인 경우 NullPointerException이 발생합니다. 키나 값을 검색할 때는 각각 containsKey(Object key)와 contains(Object value) 메서드를 사용하여 포함 여부를 확인하고, get(Object key)을 통해 특정 키에 매핑된 값을 가져옵니다. 저장된 특정 키 쌍을 지우려면 remove(Object key)를, 전체 원소를 삭제하려면 clear()를 사용하며, keys() 메서드로 모든 키를 순회할 수 있는 Enumeration 객체를 획득합니다.

### Random 클래스
Random 클래스는 정수 및 실수 등 임의의 난수를 생성할 수 있는 유틸리티 클래스입니다. 기본 생성자인 Random()을 호출하면 현재 시간을 초기 시드(seed) 값으로 사용하여 난수 발생기를 초기화합니다. 난수 발생 과정을 제어하거나 재현하고자 할 때는 특정 시작 값을 받는 Random(long seed) 생성자를 이용하며, setSeed(long newseed)를 통해 실행 중에도 시드 값을 변경할 수 있습니다. nextInt() 메서드는 int 자료형 난수를 반환하고, nextDouble()은 double 자료형 난수를 반환합니다. 통계적 정규분포가 필요한 경우에는 nextGaussian() 메서드를 호출하여 Gaussian 형태의 난수를 double 값으로 획득합니다.

### Date 클래스
Date 클래스는 날짜와 시간 정보를 생성하고 조작하는 기능을 제공합니다. 기본 생성자인 Date()는 현재 시스템의 날짜와 시간을 기준으로 객체를 생성하며, Date(long msec)는 GMT 기준 1970년 1월 1일 자정부터 지정된 밀리초(msec)만큼 경과한 시점을 표현합니다. 년, 월, 일 및 시, 분, 초 정보를 명시하여 객체를 초기화하는 다양한 생성자 오버로딩을 지원합니다. getTime() 메서드는 1970년 1월 1일 이후 현재까지 경과한 시간을 밀리초 단위로 반환합니다. getMonth()는 해당 월을, getDate()는 1과 31 사이의 날짜를 반환하며, getDay()는 해당 요일을 반환하되 일요일은 0, 토요일은 6의 정수 값으로 나타냅니다. 시간 세부 정보는 getHours()(0~23), getMinutes()(0~59), getSeconds()(0~59)를 통해 각각 얻을 수 있습니다.
