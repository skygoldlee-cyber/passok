# 중개실무

> 공인중개사 2차 과목 — 중개대상물 조사·계약서·보수 계산·거래신고 핵심 골격

## 1. 중개대상물의 확인·설명

개업공인중개사는 중개 완성 전 중개대상물에 관한 사항을 **중개의뢰인에게 확인·설명**할 의무가 있다. 설명 대상은 권리관계·법적 제한·물건 현황·인근 환경·관리비·교통·교육시설 등 중개 결정에 영향을 미치는 사항이다.

- 확인 자료: 등기부등본·토지대장·건축물대장·토지이용계획확인서·지적도
- 중개대상물 확인·설명서는 계약서와 별도로 작성·교부하며 서명·날인을 받는다
- 설명하지 않은 사항으로 손해가 발생하면 개업공인중개사가 배상 책임을 진다
- 권리분석 시 주의: 저당권·전세권·근저당 설정액·경매 진행·가압류·임차권 존재 여부

## 2. 계약서 작성 실무

- 매매계약서: 당사자 인적사항·목적물 표시·매매대금·계약금·중도금·잔금 일정·소유권이전 시기·인도 시기·특약
- 임대차계약서: 임대차기간·차임·보증금·관리비·용도·수선 의무·특약
- 계약서 서명날인과 보관: 당사자 각자 계약서를 보관하고 개업공인중개사는 사본 보존 (보존기간 5년)
- 특약 주의: 공과금 정산·기존 담보 승계·하자담보책임·매매대금 조정 조항

## 3. 중개보수·실비

- 중개보수(수수료): 시·도 조례로 정한 요율 상한 내에서 당사자 합의로 정한다 — 매매·교환·임대차별 요율 차등
- 실비: 권리조사비·정보제공비·교통비 등 실비는 중개보수와 별도로 청구 가능
- 거래가액 기준: 임대차는 보증금+차임 환산액(월차임×100)을 거래가로 계산
- 부가세: 중개보수에는 별도로 부가가치세가 과세된다
- 보수 청구 시기: 중개대상물의 거래가 성립된 때 — 계약 불성립 시 청구 불가(실비는 가능)

## 4. 거래신고·실무 절차

- 실거래 신고: 거래계약 체결일부터 **30일 이내**에 중개업자 또는 거래당사자가 관할 시·군·구에 신고
- 신고 방법: 부동산거래관리시스템(rtms.molit.go.kr) 전자신고 또는 방문 신고
- 신고 내용: 거래당사자·목적물·거래가격·중개업소·계약일자 — 해제·취소 시에도 신고
- 허위신고·축소신고: 과태료 대상이며 탈세 의심으로 국세청 통보 대상이 된다

## 5. 중개 보조·안전

- 중개보조원: 소속공인중개사가 아닌 보조업무자 — 직접 중개행위 불가
- 중개행위 제한: 자기 계약·쌍방 대리·확인 미설명·허위 광고 금지
- 개업공인중개사의 보증책임: 소속공인중개사·중개보조원의 중개행위 손해에 대해서도 배상 책임
- 광고 실무: 표시광고의 규정 준수, 허위 과장 광고 금지

## 6. 기타 실무 포인트

- 등기부등본 확인: 갑구(소유)·을구(권리)의 설정·말소 상태 확인
- 토지이용계획확인서: 지역·지구의 용도·행위제한 확인
- 임차권 분석: 대항력 요건(점유·주민등록) 존재 여부와 보증금 우선변제 여부 확인
- 가압류·가등기·예고등기는 소유권 이전 장해 요인으로 반드시 확인
