# 7과목 중개실무

> **학습 안내**
>
> 공인중개사 2차 과목 — 출제비율 **공인중개사법+거래신고법 70% + 중개실무 30%**. 중개실무 30%는 **서식 작성·계약 절차·보수 계산·전자계약**이 핵심입니다. 시행규칙 별지서식과 전자계약시스템 절차가 정본 근거입니다.

## 🎯 최우선 암기 축

① **확인설명서 종류** → Ⅰ주거용·Ⅱ비주거용·Ⅲ토지·Ⅳ입목광업공장재단 — 용도별 적용
② **계약서 3종** → 일반중개계약서·전속중개계약서·거래계약서(매매·임대차)
③ **보수 vs 실비** → 보수=조례 요율 한도 / 실비=확인설명 소요 실제비용
④ **전자계약 절차** → 공인중개사 작성→당사자 서명→공인중개사 확정→자동신고→공전소 보관
⑤ **손해배상** → 보증보험/공제 가입 의무·보증금액·설명·증서 교부
⑥ **중개보조원** → 확인설명서 서명은 개업공인중개사·소속공인중개사만 — 보조원 불가

### 1.1 확인·설명서 서식 ⭐
- **중개대상물 확인·설명서**: 중개의뢰인에게 서면 작성·설명·서명날인 의무
- 서식 4종: **Ⅰ 주거용건축물 · Ⅱ 비주거용건축물(업무·상업·공업용) · Ⅲ 토지 · Ⅳ 입목·광업재단·공장재단**
- ⚠️ 2026.8.28 개정 — 신탁등기·공동담보·공동관리비 확인란 신설

### 1.2 확인·설명 항목 🧠
- **권리관계**: 등기부 표제부+갑구+을구 — 소유권·저당권·전세권·임차권·가등기·압류
- **물건 현황**: 소재·지번·지목·면적·용도·구조·연수·현재 이용 상태
- **공법상 제한**: 용도지역·용도지구·용도구역·개발제한·농지전용·건축법 규제
- **세금·부담**: 공과금·관리비·공동담보·신탁등기 여부
- **실물 확인**: 현장 조사 — 경계·무허가·용도 실태·하자

### 1.3 서명 날인 의무 ⚠️
- 확인·설명서 서명은 **개업공인중개사 또는 소속공인중개사**만 가능 — 중개보조원은 불가
- 서명·날인 의무 위반 시 **과태료 100만원** + 업무정지 대상

## 2. 계약서 작성 — 일반·전속 계약서·매매·임대차

> 📌 **출처**: 시행규칙 제26조 + 별지 16·17호| **참조 자료**: [시행규칙 별지서식(일반중개계약서)](<../../참조자료/ref_md/과목7/시행규칙 별지서식(일반중개계약서)/시행규칙 별지서식(일반중개계약서).md>) · [시행규칙 별지서식(전속중개계약서)](<../../참조자료/ref_md/과목7/시행규칙 별지서식(전속중개계약서)/시행규칙 별지서식(전속중개계약서).md>)| **시행일**: 2026. 8. 28.

### 2.1 중개계약서 2종 ⭐
- **일반중개계약서**: 중개의뢰인과 개업공인중개사 간 — 중개대상물·기간·보수율·실비 합의
- **전속중개계약서**: 특정 개업공인중개사에게 **전속 중개** 위임 — 전속 기간·독점권·보수 약정
- 기재사항: 중개대상물 표시·계약기간·중개보수율·실비·성립 조건·손해배상·특약

### 2.2 매매·임대차 계약서 🧠
- **매매계약서**: 매도인·매수인·공인중개사 기재 — 거래대금·중도금·잔금·인도·소유권이전·중개보수
- **임대차계약서**: 임대인·임차인 기재 — 보증금·차임·기간·관리비·용도·특약
- 거래계약서 작성 후 **거래계약서명부** 기재·보관 의무 — 이중계약·거짓 기재 금지

### 2.3 계약서 기재 함정 ⚠️
- 매매대금을 실제와 다르게 기재(업·다운 계약서) → **금지행위·형사처벌 + 과태료**
- 중개보수율·실비를 사전 합의 없이 청구 → 분쟁 원인
- 전속계약 기간 중 다른 중개업자 이용 제한 — 위반 시 계약위반

> **확인문제:** 전속중개계약서와 일반중개계약서의 차이는? (전속은 특정 중개사에게 독점 위임)

## 3. 중개보수·실비

> 📌 **출처**: 공인중개사법 제20조 + 시행규칙 제20조·별표| **참조 자료**: [시행규칙 별표(주택 중개보수 상한요율)](<../../참조자료/ref_md/과목7/시행규칙 별표(주택 중개보수 상한요율)/시행규칙 별표(주택 중개보수 상한요율).md>) · [시행규칙 별표(오피스텔 중개보수 요율)](<../../참조자료/ref_md/과목7/시행규칙 별표(오피스텔 중개보수 요율)/시행규칙 별표(오피스텔 중개보수 요율).md>)| **시행일**: 2026. 8. 28.

### 3.1 중개보수 상한요율 🎯
- **시·도 조례**로 정한 요율의 범위 내 — 초과 수수 시 **형사처벌 + 업무정지**
- 주택 매매: 0.4~0.7% / 주택 임대: 0.3~0.6% / 오피스텔 매매 0.5%·임대 0.4% — 물건별 상이
- 보수 + 실비 = **거래금액 × 요율** + 확인설명 소요 실비(실제 비용 한도)

### 3.2 실비 🧠
- **실비**: 확인설명서 작성에 소요된 **실제 비용** — 보수와 별도로 청구 가능
- 사례·증여·기대이익 등 **부당한 이익 금지** — 금지행위로 형사처벌

### 3.3 보수 청구 순서 ⚠️
- 계약 성립 시 중개보수 확정 → 잔금 지급 시 수령 관행
- 중개보수의 청구 근거는 중개계약서 기재율 — 사전 합의 없으면 조례 요율 적용

> **확인문제:** 중개보수의 상한 규정은? (시·도 조례 요율 — 초과 수수 시 형사처벌)

## 4. 거래신고·전자계약

> 📌 **출처**: 거래신고법 제3조 + 전자계약시스템| **참조 자료**: [부동산거래 전자계약시스템 사용자매뉴얼(한국부동산원)](<../../참조자료/ref_md/과목7/부동산거래 전자계약시스템 사용자매뉴얼(한국부동산원)/부동산거래 전자계약시스템 사용자매뉴얼(한국부동산원).md>)| **출처**: 한국부동산원

### 4.1 실거래 신고 ⭐
- **30일 이내** 거래당사자·중개업자가 시·군·구에 신고 — 허위신고·미신고 과태료
- 신고필증 발급 → 소유권 이전등기 시 필수 서류
- 거래계약서명부: 계약서 작성·보관 의무 — 매매·임대차·교환 등 전 건

### 4.2 전자계약시스템 (irts) 🧠
- **5단계 절차**: ①공인중개사 계약서 작성 → ②계약당사자 확인·서명(공동인증/휴대폰 본인인증+수기서명) → ③공인중개사 계약확정(전자서명) → ④전자계약시스템이 실거래가/확정일자/임대차신고 **자동 신청** → ⑤공인전자문서센터 보관
- **전자계약 이점**: 신고 자동화·확정일자 자동 부여·계약서 분실 방지
- 매매: 실거래가 자동신고 / 임대차: 주택임대차·확정일자 자동신청

### 4.3 서식 기재 순서 ⚠️
- 계약서 작성 순서: 중개대상물 확인서 기본 → 확인서 세부 → 계약서 본문 → 당사자·공인중개사 서명
- 신고와 계약서 기재 일치 의무 — 거짓 기재 시 처벌

> **확인문제:** 전자계약의 자동신고 항목은? (실거래가·확정일자·임대차신고)

## 5. 손해배상책임 — 보증설정·공제·설명의무

> 📌 **출처**: 공인중개사법 제30조·제42조 + 시행령 제26조| **참조 자료**: [시행규칙 별지서식(손해배상책임보증설정신고서)](<../../참조자료/ref_md/과목7/시행규칙 별지서식(손해배상책임보증설정신고서)/시행규칙 별지서식(손해배상책임보증설정신고서).md>)| **시행일**: 2026. 8. 28.

### 5.1 보증설정 의무 ⭐
- 개업공인중개사는 업무 개시 전 **보증보험 가입·공제 가입 또는 공탁** 의무 — 미가입 시 등록 취소
- **보증설정금액**: 개인 **2억원** · 법인 **4억원** (분사무소당 2억원 추가)
- 업무보증 설정서를 중개사무소에 게시 — 손해배상보증설정신고서 제출

### 5.2 공제(한국공인중개사협회) 🧠
- 협회 공제사업: 공제기금 조성·공제금 지급 — 공제료율 **0.22%** (공제금액 대비)
- 보상범위: 개업공인중개사의 중개행위로 인한 손해 — 과실 비율에 해당하는 금액
- 공제금 지급: 중개사고 발생 → 신고 → 조사 → 배상 확정 → 공제금 지급 → 개업공인중개사 구상

### 5.3 손해배상책임의 설명 🔢
- 중개 완성 시 거래당사자에게 손해배상책임 보장 사항 설명: **보증금액·보증기관(공제)·보장기간**
- 관계 증서(공제증서·보증서) 사본 교부 또는 전자문서 제공 의무
- 공탁금은 폐업·사망 후 **3년 이내 회수 불가**

### 6.1 중개보조원의 범위 ⭐
- **중개보조원**: 공인중개사 자격 없이 **현장안내·일반서무·연락·홍보물 배포** 등 단순 보조 업무
- 금지: **확인·설명서 서명·계약서 작성·중개 상담·보수 청구** — 보조원이 수행 시 **형사처벌**

### 6.2 고용·감독 🧠
- 고용 시 등록관청에 **고용신고** — 이직·해고 시 변경 신고
- 개업공인중개사는 보조원의 업무를 **지도·감독** — 보조원 위반 시 양벌규정(개업공인중개사에 과태료)
