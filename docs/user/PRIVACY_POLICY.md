# 개인정보 처리방침

> **시행일**: 2026-10-30
> **문서 ID**: DOC-USR-18
> **범위**: platform · 판본: none
> **관련 SPEC ID**: UX-MET-05~08, AU-08~09, PAY-03~07, AI-25~28

PassOK(이하 "서비스")는 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 등 관련 법령을 준수합니다. 이 문서는 서비스가 어떤 정보를 수집·이용·보관하는지, 이용자가 어떤 권리를 가지는지를 설명합니다.

## 1. 수집하는 정보

### 1.1 기기에만 저장되는 정보 (서버 미전송)

학습 진도·오답·중요 표시·메모·설정 등 **모든 학습 데이터는 이용자의 기기(브라우저 저장소)에만 보관**됩니다. 계정 없이 모든 기능을 사용할 수 있으며, 로그인하지 않으면 이 데이터가 서버로 전송되지 않습니다.

### 1.2 서버에 수집되는 정보

| 구분 | 수집 항목 | 수집 조건 |
|------|-----------|-----------|
| 계정 | 이메일 주소 | 로그인 시 (이메일 OTP·비밀번호·소셜 OAuth) — 소셜 로그인은 공급자(Google 등) 계정 연동 정보만 인증 서비스를 통해 처리 |
| 클라우드 동기화 | 학습 진행 스냅샷 | 로그인 상태에서 자동 동기화 — 본인 계정으로만 조회 가능(행 단위 보안 적용) |
| 익명 사용 통계 | 기능 사용 이벤트 종류·횟수, 익명 기기 식별 ID(난수), 페이지 로드당 임시 세션 ID, 화면 경로, 앱 버전, 브라우저 종류 | 기본 수집 — 설정에서 언제든 차단 가능(§4) |
| 오류 로그 | 오류 메시지·발생 화면·앱 버전·브라우저 종류·임시 세션 ID | 오류 발생 시 자동 — 사용 통계와 동일하게 차단 가능 |
| 의견 보내기 | 이용자가 직접 입력한 내용·평점·선택적 계정 연결 | 이용자가 제출할 때만 |
| Pro 라이선스 | 코드 사용 이력·계정의 플랜 상태 | 코드 활성화 시 |
| AI 해설·주간 코칭 기능 | 문항 본문·이용자가 고른 오답·정답·교재 근거(오답 해설) / 주간 학습 집계 수치(풀이·오답·정답률·페이스 — 문항 내용 미포함, 주간 코칭) | 로그인 상태에서 "AI 해설"·"AI 주간 코칭" 버튼을 누를 때만 — 서비스 서버를 경유해 AI 제공사로 전달되며, 서버는 내용을 기록·저장하지 않고 일일 사용 횟수(카운터)만 저장합니다 |

## 2. 수집하지 않는 정보

- 학습 내용(어떤 문제를 풀었는지의 세부 답안), 메모, 검색어
- 이름, 전화번호, 주소
- 결제 수단 정보 — 현재 결제는 외부 안내(오픈채팅 상담·계좌이체/카카오페이)로 처리되며 서비스가 카드번호 등을 수집·저장하지 않습니다
- 광고 식별자·광고 추적 — 광고·분석용 외부 서비스(Google Analytics 등)를 사용하지 않습니다

## 3. 이용 목적

수집한 정보는 다음 목적으로만 사용합니다:

- **서비스 제공**: 로그인·기기 간 학습 데이터 동기화·Pro 권한 관리
- **품질 개선**: 어떤 기능이 실제로 도움이 되는지 집계 수준에서 파악, 오류 수정
- **문의 대응**: 의견 접수·처리

## 4. 이용자의 권리와 행사 방법

| 권리 | 방법 |
|------|------|
| 수집 거부 (동의 철회) | ⚙️ 설정 → **사용 통계 전송** → 꺼짐 — 익명 통계·오류 로그 전송이 즉시 중단되며, 앱의 모든 기능은 그대로 사용할 수 있습니다 |
| 내 정보 열람 | 도움말 → **내 사용 통계**(기기 내 카운터) · 설정 → **데이터 백업**(학습 데이터 JSON 내보내기) |
| 기기 데이터 삭제 | 설정 → 초기화 기능 또는 브라우저 사이트 데이터 삭제 |
| 계정·서버 데이터 삭제 | §7 문의 채널로 삭제 요청 — 요청 접수 후 계정 및 동기화 데이터를 삭제합니다 |
| 로그아웃·동기화 중단 | ⚙️ 설정 → 계정 / 로그인 → 로그아웃 — 기기 내 데이터는 유지됩니다 |

## 5. 제3자 서비스

서비스는 아래 외부 서비스를 이용하며, 각 사의 개인정보 처리방침이 함께 적용됩니다.

| 서비스 | 역할 | 전송되는 정보 |
|--------|------|---------------|
| Supabase | 로그인 인증·계정 데이터·동기화 저장소 | 이메일·계정 데이터(해외 리전 서버에 저장될 수 있음) |

| 법령·출처 사이트 (law.go.kr 등) | 법령 원문 조회 | 링크 접속 시 해당 사이트의 정책 적용 |

## 6. 보관 기간과 안전 조치

- **기기 저장 데이터**: 이용자가 직접 삭제할 때까지 기기에 보관됩니다.
- **서버 데이터**: 계정 유지 기간 동안 보관하며, 삭제 요청 시 지체 없이 파기합니다.
- **안전 조치**: 계정 데이터는 행 단위 접근 제어(Row Level Security)로 본인만 조회되며, 익명 사용자는 타인 데이터에 접근할 수 없도록 서버 수준에서 강제됩니다. 익명 통계는 수집 항목을 미리 정해진 목록으로 제한합니다.
- 미성년자: 이 서비스는 자격시험 학습용으로, 만 14세 미만 아동의 개인정보를 고의로 수집하지 않습니다.
