## 1. 매핑 원칙

1. **참조자료가 근거의 원천**: 교재·문제은행의 근본 소스는 ref_md이며, 도출 순서는 `참조자료 → 교재 → 문제은행` (`CONTENT_WORKFLOW.md` §3.3-2).
2. **다대다 매핑**: 교재 챕터는 복수의 ref 문서를 근거로 삼고, 하나의 ref 문서가 여러 챕터·과목에 인용된다. 1:1 파일 대응이 아니다.
3. **매핑의 실체는 `📌출처` 링크**: 교재 본문의 출처 블록이 `ref_md/과목N/<문서>/`로의 링크를 포함한다 — 본 표는 그 링크의 실측 추출이다.
4. **과목 귀속 ≠ 인용 범위**: ref 문서의 과목 귀속(`references.json.docSubjectRules`)과 교재의 인용 과목은 다를 수 있다 — 과목1·2의 법령·고시를 과목3·4 교재가 인용하는 것은 정상 (§6.4 추적성 계약).
5. **섹션 번호체계 준수**: 교재는 `NUMBERING_SYSTEM.md`의 십진법 체계를 따른다.

### 표기 규칙

- 문서명은 꼬리(`(기관)(제N호)(시행일)`)를 뺀 정식 명칭 — 실제 파일명은 `ref_md/과목N/<문서명(꼬리포함)>/`
- `(과N)` 표기는 ref_md 귀속 과목 — 교재 과목과 다른 경우 교차 인용

## 3. 관찰 — 과목 경계 구조

- **과목3 교재의 출처는 전량 타 과목 ref** — 과목3 귀속 ref(시행규칙 별표2·4·5·6·안전기준 별표4)는 교재 📌출처가 아닌 **문제은행 인용·백매터** 층에서 소비된다. 과목3 학습 지식의 법적 근거가 CGMP·안전기준(과목2 귀속)에 있기 때문.
- **과목1은 모법 성격** — 화장품법·시행규칙(과1 귀속)이 전 과목 교재의 공통 근거.
- **은행 인용은 교재 인용과 별개의 층** — 은행의 교재 교차 인용 약 4~8% + ref 직접 인용(`ref:`)까지 합산하면 ref 소비 범위는 본 표보다 넓다.
