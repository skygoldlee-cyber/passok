# 위험물산업기사 실무도구(Practice Tool) 설계 — 시험→안전관리 실무 전환

> **문서 ID**: DOC-DSN-55
> **범위**: exam:hazmat · 판본: none
> **관련 SPEC ID**: UM-01~04 (학습/실무 모드 전환·실무 랜딩) · PAY-01~08 (Pro 게이팅) · DA-13 (시험 격리) · DA-15 (콘텐츠 독립) · CO-13 (생성 문서 공유) · CS-13 (이야기형 정본 문서)
> **목적**: hazmat 팩에 "시험 합격 후 현장에서 매일 쓰는" 안전관리자 실무 피처를 추가하는 설계 — carework DOC-DSN-42(현장도구 6단계)·cosmetic Formula OS와 동형 패턴
> **최종 업데이트**: 2026-11-18

## 1. 배경·문제

- 위험물산업기사 합격자의 실무는 **위험물안전관리자** — 저장·취급 수량 판정, 시설기준 점검, 혼재·소화 판단, 점검 기록 작성이 일상 업무
- 시험 과목3(위험물 성질·취급·행정)은 실무와 거의 1:1 대응 — 지정수량·혼재표·시설기준 수치가 그대로 현장 판정 기준
- 법적 근거 데이터는 이미 확보 — 위험물안전관리법(법률)·시행령·시행규칙·세부기준 고시가 `참조자료/ref_md`에 편입됨
- SAFECHEM 서사(신입 안전관리자 도현)와 자연 결합 — 서사 장면이 곧 도구 사용 상황

## 3. 기능 스펙 — 6단계 도구

### 3.1 Phase 1 — 지정수량·배수 판정기 (`hzQty`)

**가장 작고 즉효** — 시험 최다 출제 영역이자 실무 최빈도 판정.

- 입력: 물질 선택(류·품명) × 저장량·취급량 → 복수 물질은 배수 합산
- 출력: 합산 배수 → **소량 위험물 / 신고 대상 / 허가 대상** 판정 + 근거 조문 링크
- 근거: 위험물안전관리법 시행령 별표1(지정수량)·시행규칙(배수 합산 규정)
- 함정 반영: `<`·`≤` 경계 — 경계값 카드(MEMORIZATION_AIDS B-2)의 실무형

### 3.2 Phase 2 — 혼재 판정표 (`hzMix`)

- 입력: 두 물질(또는 류 조합) 선택
- 출력: **혼재 가능 / 혼재 금지 / 조건부(격리·칸막이)** + 위반 시 유형
- 근거: 세부기준 고시 혼재 기준표 — 데이터를 `hz-mix-data.js` 상수로

### 3.3 Phase 3 — 소화약제 적응 매트릭스 (`hzExt`)

- 입력: 위험물 류·품명 (또는 화재 유형)
- 출력: **적응 소화약제 / 금수성·금지 수단 / 살수 가능 여부** + 주의(연소 확대 위험 등)
- 근거: 시행규칙 소화 기준 + 과목2 교재 소화 원리 — 시험 소화기 선택 문제의 실무형

### 3.4 Phase 4 — 탱크·저장소 계산기 (`hzTank`)

- 입력: 옥외저장탱크 지름·높이, 저장 유(인화점), 방유제 형태
- 출력: **공지면적·보유공지 산정**, 방유제 설치 면적·저장용량 상한(탱크 최대 2만 kL 등), 옥내저장소 적합 여부
- 근거: 시행규칙·세부기준 고시 탱크 기준 — 서사 "탱크 공식→점검 검산" 복선의 실무형

### 3.5 Phase 5 — 시설기준 점검표 (`hzAudit`)

- 시설 유형별 체크리스트: 제조소·옥내저장소·옥외저장소·옥내탱크·옥외탱크·주유취급소·이송취급소
- 항목별 적합/부적합 + 부적합 시 근거 조문·시정 기한 안내
- 남 소방위 점검 장면(서사)의 실무 대응물 — 점검 결과 저장은 Pro(Phase 6 기록부와 통합)

### 3.6 Phase 6 — 안전관리자 기록부 (`hzLog`)

- 생성 문서: **정기점검일지·위험물 입출고대장·소화훈련 기록·시정조치 보고**
- 저장: `hz-log-store` 로컬 우선·로그인 시 클라우드 (care-log-store 패턴)
- 공유: 인쇄·PDF·복사 (CO-13 생성 문서 공유 인프라)
- Pro 게이팅: 생성·미리보기 무료, **저장·PDF·내보내기 Pro**

## 5. 데이터 출처 (ref_md 인용 — 학습 콘텐츠 동일 패턴)

| 도구 | 근거 문서 |
|---|---|
| hzQty | 위험물안전관리법 시행령 별표1(지정수량) · 시행규칙(배수 합산) |
| hzMix | 세부기준 고시 혼재 기준표 |
| hzExt | 시행규칙 소화 기준 · 교재 과목2 소화 원리 · 세부기준 고시 |
| hzTank | 시행규칙·세부기준 고시 탱크 시설기준 (공지면적·방유제·용량 상한) |
| hzAudit | 세부기준 고시 시설기준 전반 (제조소~취급소별) |
| hzLog | 시행규칙 점검·기록 의무 조항 + 자체 서식 |

**법령 변경 추적**: `ai:stale` 패턴 — ref_md 갱신 시 영향 상수(지정수량·배수·공지면적 계수) 스모크 항목 나열

## 7. 서사·학습 연동

- SAFECHEM 서사 장면 ↔ 도구 연결: 도현의 점검 장면에 "실무에서도 같은 판정 — 도구 열기" 링크 (LEARNING_MEDIA_LINK 패턴)
- 인물 설정표(CS-13) 해설 톤 규칙에 "도구 결과 화면 멘토 코멘트" 추가 가능 — 백 선임의 "근거가 뭐지?" 되묻기가 조문 링크 톤으로
- 함정 커버리지: 각 도구의 함정 항목은 문제은행 시나리오 문항과 공유 데이터로 이원화 금지 — `hz-*-data.js`가 정본

## 8. 로드맵·미결 사항

- 착수 순서: hzQty(Phase 1) → hzMix → hzExt → hzTank → hzAudit → hzLog — 각 Phase 독립 배포 가능
- 미결: ① 물질 마스터 범위 — 출제 빈출 ~40종 우선 vs 별표1 전체(수백 종) ② 시설기준 체크리스트 항목수 목표(유형당 ~30?) ③ hzAudit 이력 저장을 hzLog와 통합 vs 분리 ④ 모바일 입력 UX — 수량 단위(kg·L·kL) 변환 자동화 여부
