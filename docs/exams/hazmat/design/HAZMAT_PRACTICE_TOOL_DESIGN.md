# 위험물산업기사 실무도구(Practice Tool) 설계 — 시험→안전관리 실무 전환

> **문서 ID**: DOC-DSN-55
> **범위**: exam:hazmat · 판본: none
> **관련 SPEC ID**: UM-01~04 (학습/실무 모드 전환·실무 랜딩) · PAY-01~08 (Pro 게이팅) · DA-13 (시험 격리) · DA-15 (콘텐츠 독립) · CO-13 (생성 문서 공유) · CS-13 (이야기형 정본 문서)
> **목적**: hazmat 팩에 "시험 합격 후 현장에서 매일 쓰는" 안전관리자 실무 피처를 추가하는 설계 — carework DOC-DSN-42(현장도구 6단계)·cosmetic Formula OS와 동형 패턴
> **최종 업데이트**: 2026-11-18 (법령 2차 검토 — 운반 기준·별표18/19 분리·방유제 지름 기준·점검 의무 대상·서식 라벨 3단계·정본 체인)

## 1. 배경·문제

- 위험물산업기사 합격자의 실무는 **위험물안전관리자** — 저장·취급 수량 판정, 시설기준 점검, 혼재·소화 판단, 점검 기록 작성이 일상 업무
- 시험 과목3(위험물 성질·취급·행정)은 실무와 거의 1:1 대응 — 지정수량·혼재표·시설기준 수치가 그대로 현장 판정 기준
- 법적 근거 데이터는 이미 확보 — 위험물안전관리법(법률)·시행령·시행규칙·세부기준 고시가 `참조자료/ref_md`에 편입됨
- SAFECHEM 서사(신입 안전관리자 도현)와 자연 결합 — 서사 장면이 곧 도구 사용 상황

### 1.1 정확성·면책 원칙 (최우선)

- **판정 오류는 형사 리스크** — "지정수량 이상"을 잘못 판정하면 사용자가 무허가 저장을 하게 되고, 이는 형사처벌 대상. 모든 판정 화면에 **"참고용 — 최종 판단은 관할 소방서"** 고지를 상시 표시한다.
- **법령 근거는 법령만** — 판정 근거 칸에는 법률·시행령·시행규칙·고시·조례만 표기한다. 교재는 해설 링크로 분리하고 판정 근거에 섞지 않는다.
- **상수에 시행일 부기** — `hz-*-data.js`의 법정 상수는 근거 조문 + 시행일을 함께 기록한다. `ai:stale` 추적과 연결해 법 개정 시 영향 항목을 나열한다.
- **법정 서식과 자체 서식 구분** — 법이 정한 기록·점검표는 고시 서식을 그대로 쓰고, 자체 작성물은 [자체 서식]으로 표시한다. 법에 없는 기한·수치는 지어내지 않는다.

## 3. 기능 스펙 — 6단계 도구

### 3.1 Phase 1 — 지정수량·배수 판정기 (`hzQty`)

**가장 작고 즉효** — 시험 최다 출제 영역이자 실무 최빈도 판정.

- 입력: **품명 선택**(시행령 별표1 + 시행규칙 제3조 세부 품목 — 판정 정본) × 저장량·취급량 → 복수 품목은 배수 합산
  - 정본 범위: 별표1의 "그 밖에 행정안전부령으로 정하는 것"은 시행규칙 제3조에서 품목별 지정수량으로 갈린다 (예: 제1류 차아염소산염류 50kg·나머지 300kg). 지정수량이 "50·300·1,000kg"처럼 복수이거나 "~를 함유한 것"이면 위험성이 가장 비슷한 품명을 고르는 분기 입력이 필요하다
  - 물질 검색은 보조 — "물질 → 품명 추천" 용도로 빈출 ~40종만 유지. 지정수량은 물질이 아니라 품명으로 정해진다:
    - 제4류 석유류: 수용성/비수용성에 따라 지정수량 2배 차이 → 입력 필드 필수
    - 제2류 황(순도 60%)·금속분(입도)·철분·마그네슘: 판정기준 미달 시 위험물 자체가 아님 → "위험물 해당 없음" 출력 가능
    - 제5류: 자기반응시험 결과로 제1종(10kg)/제2종(100kg) 갈림 → 시험 결과 입력 분기
- 판정 출력 (법률 기준 구분):
  - **소량위험물 기준 대상 아님** (1/5 미만 — 경계값은 시·도 조례가 정한다) — 단, **운반 기준(법 제20조)은 양과 무관하게 적용**되므로 용기·적재·표시 의무는 그대로
  - **소량위험물** (1/5 이상 ~ 지정수량 미만) — 저장·취급 기준은 **시·도 조례** 적용 (법 제4조) → 결과에 **"관할 시·도 조례 확인 필요"** 고지 상시 표시
  - **지정수량 이상** — 제조소등 허가 대상
  - **특례** — 관할소방서장 승인 90일 이내 임시 저장·취급(승인 제도, 신고 아님) / 법 제6조제3항 허가 면제(주택 난방용·농어업용 지정수량 20배 이하 등)
- 배수 합산 근거: **법률 제5조** — 같은 장소 2종 이상 위험물, 각 수량/지정수량 합계 ≥1이면 지정수량 이상으로 본다 (시행규칙 아님)
- 함정 반영: `<`·`≤` 경계 — 경계값 카드(MEMORIZATION_AIDS B-2)의 실무형

### 3.2 Phase 2 — 혼재 판정표 (`hzMix`)

- 입력: **[운반 / 저장] 모드 선택** + 두 물질(또는 류 조합) + **저장 모드 시 시설 유형**(옥내/옥외저장소) — 별표18 Ⅲ의 예외 조합(유별 집합·1m 간격)은 옥내·옥외저장소에 적용되는 규정이라 시설 유형을 받지 않으면 판정 범위가 모호하다
- **운반 모드**: 시행규칙 별표19(운반 기준) 부표2 혼재표 → 혼재 가능/금지
  - 예외: 지정수량의 1/10 이하로 운반하는 경우 혼재 기준 적용 제외
- **저장 모드**: 시행규칙 별표18 Ⅲ — 원칙 **금지**, 별표가 정한 조합에 한해 **1m 이상 간격**을 두고 허용 (칸막이·격리는 별도 기준이 아니라 해당 조합의 조건)
- 출력: 모드별 판정 + 근거 표기 (운반=별표19 부표2 / 저장=별표18 Ⅲ) — 두 기준을 섞은 "조건부" 단일 판정은 하지 않는다

### 3.3 Phase 3 — 소화약제 적응 매트릭스 (`hzExt`)

- 입력: 위험물 류·품명 (또는 화재 유형)
- 출력: **적응 소화약제 / 금수성·금지 수단 / 살수 가능 여부** + 주의(연소 확대 위험 등)
- 근거: **시행규칙 별표17(소화설비 적응성)** — 판정 근거는 법령만, 교재 과목2는 해설 링크로 분리
- 확장(실무 빈도 높음·시험 계산 출제):
  - **소요단위 계산** — 면적·용량별 소화설비 능력단위 산정
  - **소화난이도 등급 판정** — 설비 구분(소화난이도 Ⅰ~Ⅲ) 판정 결과 표시

### 3.4 Phase 4 — 탱크·저장소 계산기 (`hzTank`)

> ⚠ **입출력 재정의 (법령 검토 — 2026-11-18)**: 보유공지는 탱크 크기가 아니라 **지정수량 배수**로 정한다. `hzQty`의 배수 결과가 입력 의존이다.

- 입력: hzQty 배수 결과(또는 배수 직접 입력) + 탱크 형상(원통·구형 등)·지름·높이·저장 유(인화점) + 동일 부지 탱크 수·유별(제6류 여부)
- 출력:
  - **보유공지 너비(m)** — 지정수량 배수 구간으로 산정, 4,000배 초과 시에만 탱크 지름·높이로 계산 (법령 개념은 "보유공지 너비"이지 "공지면적"이 아님)
    - 감축 규정: 제6류 저장 옥외탱크 → 너비의 1/3(최소 1.5m) · 동일 부지에 탱크 2기 이상 인접 설치 → 1/3(최소 3m)
  - **탱크 용량** — 내용적 − 공간용적, 형상별 내용적 공식(교재 6차 원고의 탱크 공식과 동일 정본)
  - **방유제 산정** — 용량 → 거리 → 높이 순서로:
    - 용량: **인화성액체** 탱크는 최대 탱크 용량의 **110%**, 비인화성(제6류 등)은 **100%** — 탱크가 2기 이상이면 가장 큰 탱크 기준. 실제 필요 용량은 방유제 안 **다른 탱크 기초 체적 + 방유제 높이 이하 부분 체적을 차감**해 산정 (차감 과정이 없으면 현장 검산 불일치)
    - 방유제-탱크 거리: **탱크 지름** 기준 — 15m 미만이면 높이의 1/3 이상, 15m 이상이면 1/2 이상 (인화점 200℃ 이상 위험물 탱크는 거리 규정 제외)
    - 높이: 0.5~3m 범위
    - 상한: 안쪽 면적 8만㎡ 이하·탱크 수 10기 이하 — **20기 허용 = 모든 탱크 20만L 이하이면서 인화점 70~200℃ · 제한 없음 = 인화점 200℃ 이상**
- 비대상: 옥내저장소는 용기를 저장하는 창고로 탱크 계산기 범위 아님 — 옥내탱크저장소는 hzAudit의 시설 유형 판정에서 다룬다 (참고: 옥내탱크저장소의 탱크 용량 상한은 지정수량 40배 이하·제4석유류와 동식물유류를 제외한 제4류는 20,000L 이하 — 시설 구분 기준이 아니라 용량 상한 규정)
- 근거: 시행규칙·세부기준 고시 탱크 시설기준 — 서사 "탱크 공식→점검 검산" 복선의 실무형

### 3.5 Phase 5 — 시설기준 점검표 (`hzAudit`)

- 시설 유형 전체 (시행령 별표3 기준): 제조소·옥내저장소·옥외저장소·옥내탱크저장소·옥외탱크저장소·**지하탱크저장소·간이탱크저장소·이동탱크저장소·암반탱크저장소**·주유취급소·일반취급소(충전하는 일반취급소 포함 — "충전취급소"라는 별도 유형은 법령에 없음)·판매취급소·이송취급소 — 이동탱크·지하탱크는 그 자체가 정기점검 대상이라 실무 최빈도
- **정기점검 의무 대상 판정**을 점검 첫 화면에 둔다 — 시행령 제16조 기준: 예방규정 대상 시설·지하탱크저장소·이동탱크저장소·땅에 묻힌 탱크가 있는 제조소·주유취급소·일반취급소가 의무 대상. 간이탱크저장소·판매취급소 등 비대상은 같은 점검표를 써도 **"자율점검"**으로 표시해 법정 기록과 구분한다
- **체크리스트 정본 = 세부기준 고시의 법정 정기점검표 서식** — 자체 항목을 만들지 않는다. 항목 수·순서·근거 조문이 고시에서 자동 결정되고 개정 추적도 ref_md로 이어진다
- 항목별 적합/부적합 + 부적합 시 **근거 조문 표시만** — "시정 기한 안내"는 넣지 않는다 (법정 시정 기한이 없는 항목에 기한을 지어내면 사용자가 법정 기한으로 오인)
- 남 소방위 점검 장면(서사)의 실무 대응물 — 점검 결과 저장은 Pro(Phase 6 기록부와 통합)

### 3.6 Phase 6 — 안전관리자 기록부 (`hzLog`)

- 생성 문서 — 라벨 3단계 **[법정 서식 / 법정 의무·서식 자유 / 자체 서식]**:
  - **[법정 의무·서식 자유]** 위험물 취급 일지 — 시행규칙 제55조 제5호는 일지 작성·기록 의무만 정하고 별지 서식은 없다 (ref_md 본문 확인 완료) → 자체 서식으로 생성하되 법정 의무 기록임을 표시
  - **[법정 서식]** 정기점검 기록 — 세부기준 고시 정기점검표 서식. 보존 기간 의무: 정기점검 3년·옥외탱크 구조안전점검 **25년(연장 신청 시 30년)** → 저장 설계에 보존 기간 메타 반영 (만료 임박 안내는 선택)
  - **[자체]** 소화훈련 기록·시정조치·점검 보완 메모 등 — [자체 서식] 표기
  - "위험물 입출고대장"은 법정 의무 서식이 아니므로 넣지 않는다 (필요 시 [자체 서식]로 별도 표기)
- 저장: `hz-log-store` 로컬 우선·로그인 시 클라우드 (care-log-store 패턴)
- 공유: 인쇄·복사는 **무료**(법정 보존 기록을 종이로라도 남길 수 있어야 함), PDF 파일·공유·내보내기는 Pro
- Pro 게이팅: 생성·미리보기·인쇄·복사 무료, **저장·PDF·공유·클라우드 동기화 Pro**

## 7. 서사·학습 연동 + 정본 일원화

- SAFECHEM 서사 장면 ↔ 도구 연결: 도현의 점검 장면에 "실무에서도 같은 판정 — 도구 열기" 링크 (LEARNING_MEDIA_LINK 패턴)
- 인물 설정표(CS-13) 해설 톤 규칙에 "도구 결과 화면 멘토 코멘트" 추가 가능 — 백 선임의 "근거가 뭐지?" 되묻기가 조문 링크 톤으로
- **정본 체인 (수치 불일치 원천 차단)**: `ref_md 원문 → hz-*-data.js (사본) → 교재 표·도구` 순으로 흐른다. 법령의 정본은 ref_md 원문이고 데이터는 그 사본 — 데이터↔원문 일치를 검증하는 **스모크 테스트**를 둬 법 개정 시 상수 노후를 자동 감지하고, 교재 📊 법정 수치 표는 다시 data.js에서 **자동 생성**한다. 문제은행 함정·도구 판정도 같은 상수를 참조한다. 교재·문제은행·도구 3곳 분산 시 수치 드리프트 발생 (교재 리뷰 반복 지적 사안)
- 함정 커버리지: 각 도구의 함정 항목은 문제은행 시나리오 문항과 공유 데이터로 이원화 금지

## 8. 로드맵·의존·미결 사항

- 착수 순서: **hzQty → hzTank → hzMix → hzExt → hzAudit → hzLog** — 각 Phase 독립 배포 가능
  - 의존: hzTank는 hzQty의 배수 결과를 입력으로 받되, **배수 직접 입력도 허용하므로 단독 배포 가능 — 연동(배수 결과 자동 이관)은 hzQty 이후**
- 해결된 미결: ① 물질 마스터 범위 → 별표1 + 시행규칙 제3조 품명이 판정 정본, 빈출 ~40종은 추천용 ② hzAudit 항목 수 → 법정 정기점검표 서식 정본으로 자동 결정 ④ 단위 변환 → 같은 단위 안 변환(kL↔L)만 자동, 무게↔부피는 법정 단위(제4류 L·그 외 kg) 우선 + 비중 직접 입력
- 잔여 미결: ③ hzAudit 이력 저장을 hzLog와 통합 vs 분리 ⑤ 소량위험물 조례 데이터 — 17개 시·도 조례 전수 수집 vs "관할 확인" 고지만(권장: 고지만). 고지만 선택 시 1/5 경계는 "대부분 시·도 공통"이라는 **가정에 기대는 값**임을 결과에 함께 표시한다
