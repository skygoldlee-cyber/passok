## 1. 매핑 원칙

1. **참조자료가 근거의 원천**: 교재·문제은행의 근본 소스는 ref_md이며, 도출 순서는 `참조자료 → 교재 → 문제은행`이다.
2. **다대다 매핑**: 교재 챕터는 복수의 ref 문서를 근거로 삼고, 하나의 ref 문서가 여러 챕터·과목에 인용된다. 1:1 파일 대응이 아니다.
3. **매핑의 실체는 `📌출처` 링크**: 교재 본문의 출처 블록이 `ref_md/과목N/<문서>/`(과목 귀속 문서) 또는 `ref_md/<문서>.md`(출제기준 등 공통 평탄 문서)로의 링크를 포함한다 — 본 표는 그 링크의 실측 추출이다.
4. **과목 귀속 ≠ 인용 범위**: ref 문서의 과목 귀속(`references.json.docSubjectRules`)과 교재의 인용 과목은 다를 수 있다 — 과목3 귀속의 시행령·세부기준을 과목1 교재가 인용하는 것은 정상이다.

### 표기 규칙

- 문서명은 꼬리(`(기관)(제N호)(시행일)`)를 뺀 정식 명칭 — 실제 파일명은 `ref_md/과목N/<문서명(꼬리포함)>/`
- `(과N)` 표기는 ref_md 귀속 과목 — 교재 과목과 다른 경우 교차 인용, `(공통)`은 평탄 문서(출제기준)
