# PassOK(PassCare) 이용자 관점 평가 보고서 — 요양보호사 시험 대비 기능과 유료 이용 가능성

> **문서 ID**: DOC-BIZ-10
> **범위**: exam:carework · 판본: none
> **관련 SPEC ID**: ROAD-P5 (Pro 안내·무료/유료 경계 — 평가 대상)
> **성격**: 외부 평가 보고서 등재 — 평가자 추정 기반, 사용자·결제 데이터 없음. 원문 보존, 말미 §A에 코드 대조 검증 부기 (2026-11-13)
> **연계**: DOC-BIZ-06 §7-2 수익 가설의 검증 입력 · DOC-BIZ-07 인터뷰의 지불 의사(Q12·Q12c) 검증 항목과 대응

## 1. 요약

시험 대비 기능만 놓고 보면, 수험생이 이미 가진 무료·저가 자료로 상당 부분 대체됩니다. 지금 구성 그대로는 수험생이 유료 결제까지 할 가능성이 낮다고 판단합니다(평가자 추정).

- 요양보호사 시험은 규모가 작고(필기 35문항, 실기 45문항) 합격선이 60%이며, 응시자는 교육원에서 320시간 교육을 마친 상태입니다. 장기 학습 관리·정밀 진단 기능이 필요한 시험이 아닙니다.
- 문제집, 모의고사 교재, 국시원 CBT 체험 등 대체재가 이미 많습니다.
- 대체하기 어려운 가치는 오답 개인화 복습, 읽기 쉬운 교재 형식(이야기형·웹툰형·글자 크게), 그리고 시험 이후에도 쓰는 실무 도구입니다.
- 가장 앞에 내세운 유료 기능(학습진단, 통합 모의고사, ㄱㄴㄷ 훈련)이 이 시험 수험생의 필요와 어긋날 수 있습니다.

## 2. 평가 관점과 근거

이 보고서는 수험생(이용자)이 "이 앱에 돈을 낼 이유가 있는가"를 기준으로 작성했습니다. 사이트의 공개된 기능 안내와 메뉴 구성, 그리고 요양보호사 시험에 관한 외부 공개 자료(말미 참고 자료)를 근거로 했습니다. 사용자 수나 결제 데이터는 없으므로 이용 가능성에 대한 판단은 평가자의 추정입니다.

## 3. 요양보호사 시험의 특성

| 항목 | 내용 |
|---|---|
| 시험 구성 | 필기 35문항(5지선다, 요양보호론), 실기 45문항 |
| 합격 기준 | 필기·실기 각각 60% 이상 |
| 응시 전제 | 지정 교육기관에서 320시간(이론 126, 실기 114, 현장실습 80) 이수 |
| 시험 방식 | 2024년부터 필기·실기 모두 CBT |
| 응시료 | 32,000원 수준(감면 대상자는 전액 감면) |
| 기출문제 | 별도로 공개되지 않는 시험이라는 출판사 설명이 있음 |

이 특성이 의미하는 바는 다음과 같습니다.

- 준비 기간이 길지 않고 교육원 수업이 이미 학습의 중심이라, 캘린더·주간 배분·4회독 전략 같은 장기 학습 관리 기능의 필요가 크지 않습니다.
- 필기는 단일 과목 구성이라 과목별 과락 진단, 과목별 히트맵 같은 설계가 맞지 않는 부분이 많습니다. 합격까지 몇 문제가 남았는지 보여주는 단순한 지표가 더 어울립니다.
- 모의고사에서 확인된 "100문항 / 120분" 기본값은 이 시험(필기 35문항)과 규모가 다릅니다. 시험별로 올바르게 바뀌는지 점검이 필요합니다.

## 4. 이용자가 이미 가진 대체재

- 서점 문제집과 모의고사 교재: 모의고사 3회분이 들어간 문제집, 모의고사 10회분 교재 등이 전자책으로도 판매됩니다.
- 국시원 CBT 체험하기: 시험 화면 조작 연습을 무료로 할 수 있습니다.
- 교육원 자료와 수업: 응시 자격 조건 자체가 교육 이수이므로 모든 응시자가 교육원 자료를 가집니다.
- 커뮤니티와 블로그 정리 자료: 시험 일정, 합격 기준, 학습 요령은 무료로 쉽게 찾을 수 있습니다.

준비 기간이 짧고 응시료가 3만 원대인 시험에서, 수험생이 준비 도구에 지불할 수 있는 금액의 상한은 낮은 편입니다.

## 5. 강점은 사라지는가

| 기능 | 대체 가능성 | 판단 |
|---|---|---|
| 문제·해설 자체 | 높음 (문제집, 모의고사 교재) | 차별성이 거의 없음 |
| 플래시카드, 퀴즈, 모의고사 기본 형태 | 높음 | 차별성이 거의 없음 |
| 학습 캘린더, 주간 배분, 4회독 전략 | 중간 | 짧은 준비 기간에는 과한 기능 |
| 학습진단, 합격 갭 분석 | 낮음 (종이 교재가 못 함) | 가치는 있으나 시험 규모에 비해 과함. 단순화하면 유효 |
| 오답·진술 단위 개인화 복습 | 낮음 | 남는 핵심 강점 |
| 이야기형·웹툰형 교재, 글자 크게 보기 | 낮음 | 중장년·읽기 어려운 학습자에게 실질 가치 |
| 시험 이후 실무 도구(일지, 근무표 등) | 중간 (기관 방식과 겹침) | 시험 이후까지 쓰게 만드는 차별점 |

정리하면 "문제를 제공한다"는 가치는 사라지지만, "내가 틀린 것을 모아서 다시 보여준다", "읽기 쉽게 보여준다", "시험 이후에도 쓴다"는 가치는 남습니다.

## 6. 이용자 유형별 이용 가능성 (평가자 추정)

| 이용자 유형 | 필요 | 이용 가능성 |
|---|---|---|
| 교육원 수료생 다수 | 시험 전 복습, 모의고사 | 무료 체험 후 이탈 가능성이 높음. 결제 전환은 소수 |
| 읽기·암기가 어려운 분, 재응시자 | 쉬운 교재, 오답 복습 | 지불 의사가 있을 수 있는 가장 현실적인 유료 후보 |
| 외국인 학습자 | 모국어 교재와 용어 학습 | 다국어가 없으면 어려움. 다국어 전용 앱이 이미 있음 |
| 현직 요양보호사 | 일지, 인수인계, 서식 | 오래 쓸 가능성은 있으나 입력 부담과 개인정보 신뢰가 해결되어야 결제로 이어짐 |

## 7. 유료 기능에 대한 이용자 관점 평가

- 학습진단: 가장 큰 강점으로 내세우지만 유료이고, 시험 규모에 비해 과합니다. 무료로 일부(예: 오답 요약)를 경험하게 하고 정밀 분석만 유료로 두는 편이 설득력이 높습니다.
- 통합 모의고사: 서점 교재와 국시원 CBT 체험으로 대체됩니다. 기본 모의고사를 무료로 열고, 오답 연동과 해설을 유료로 구분하는 구성이 자연스럽습니다.
- ㄱㄴㄷ 조합 훈련: 요양보호사 시험이 5지선다 중심이라는 점에서, 이 시험 수험생에게 필요한 훈련인지부터 불분명합니다.
- 웹툰형 교재, 클라우드 동기화: 읽기 어려운 분과 여러 기기를 쓰는 분에게는 이해되는 유료 요소입니다. 다만 중장년 사용자는 계정 구조(로그인 수단마다 별도 계정, 유료 코드는 같은 계정에서만 사용)에서 혼란이 생기기 쉽습니다.

준비 기간이 짧은 시험이므로, 월 구독보다 "시험일까지 기간제 이용권"이나 1회 결제가 이용자에게 더 납득되는 구조입니다.

## 8. 이용자 관점 개선 제안

- 수험 기능은 대부분 무료로 열고, 유료는 개인화 복습, 쉬운 교재 형식, 동기화처럼 대체재가 없는 부분에 집중합니다.
- 요양보호사 선택 시 시험 규모(필기 35문항, 실기 45문항)와 60% 합격 기준에 맞는 모의고사 설정과 진단 지표로 바꿉니다.
- "기출"이라는 표현을 쓴다면 출처를 밝힙니다. 이 시험은 기출문제가 별도로 공개되지 않는다는 설명이 있어, 문제 출처가 불분명하면 신뢰에 영향을 줍니다.
- 교육원과 제휴해 수료생에게 제공하는 방식을 검토합니다. 응시자가 모이는 곳이 교육원이므로 개인 결제보다 전환과 홍보에 유리할 수 있습니다.
- 카카오 로그인을 가장 앞에 두고, 로그인 수단이 달라도 유료 권한이 이어지는 계정 연결을 제공합니다.
- 시험 이후까지 이용하게 하려면 실무 도구에서 대상자 개인정보 취급 원칙과 제도 기준일·출처 표시를 갖춥니다.

## 9. 종합 판단

이용자 관점에서 PassOK의 시험 대비 기능은 "있으면 편하지만 꼭 돈을 낼 이유는 아닌" 수준으로 보입니다. 문제와 모의고사는 무료·저가 대체재로 충분하고, 시험 규모가 작아 정밀 진단과 장기 관리 기능의 필요도 낮기 때문입니다.

반면 오답 개인화 복습, 읽기 쉬운 교재, 시험 이후 실무 도구는 대체재가 적어 유료 가치가 될 수 있습니다. 이 세 가지를 중심으로 무료·유료 경계를 다시 설계하고, 시험 규모에 맞게 기능을 단순화하며, 교육원 제휴를 병행하면 이용과 결제 가능성이 높아질 것으로 판단합니다.

## §A. 코드 대조 검증 (등재 시 확인 — 2026-11-13)

보고서 주장을 실제 구현과 대조한 결과. 원문은 위 그대로 보존하고 판정만 별기한다.

| 보고서 주장 | 대조 결과 | 판정 |
|---|---|---|
| 모의고사 "100문항/120분" 기본값이 시험 규모와 다름 | carework `manifest.json`의 `integratedExam`은 이미 **35+45문항·90분·60% 과락**으로 정확히 설정됨. 100/120은 cosmetic 시험 설정값이자 코드 폴백 주석 — 단 `exam-sim-session.js`에 `|| 120` 폴백이 있어 registry 미로드 시 오표시 여지 | ✅ 설정 정확 (폴백 경로만 잔여 리스크) |
| 유료는 "대체재 없는 부분"(개인화·쉬운 교재·동기화)에 집중해야 | `feature-plan.json` 현행: `mock_exam`·`combo_*` **free**, `story_textbook`(이야기형)·`personal_analysis`·`cloud_sync`·`care_*_save/share/export` **pro** — 권고 방향과 이미 대체로 정합 | ✅ 구조 정합 (오답 연동 유료 세분화는 미적용) |
| "기출" 표기는 출처를 밝혀야 | carework 교재·문제은행에 `🔖기출` 마커 실재 — 기출 비공개 시험에서 출처 미표기 시 신뢰 리스크 유효 | ⚠️ 실제 갭 — 표기 정정 또는 출처 주석 필요 |
| 카카오 로그인 전면·계정 연결 | google·kakao OAuth + 이메일 OTP 이미 지원(`OAUTH_PROVIDERS`). **로그인 수단 간 유료 권한 이어짐(계정 연결)은 미구현** — 중장년 혼란 지적 유효 | ⚠️ 계정 연결 갭 |
| ㄱㄴㄷ 조합 훈련이 이 시험에 맞는가 | carework의 해당 기능은 `number-drills`(숫자 암기 드릴) — 보고서 지칭 기능과 명칭 상이 가능. 5지선다 시험 적합성 재검토는 유효 | 🔍 명칭 확인 필요 |
| 신규 입력 (기간제 이용권·교육원 제휴·수험 기능 무료 개방) | 현 로드맵(DOC-BIZ-06)에 없는 가설 — §7-2 수익 가설·채널 검토 입력으로 유효. 교육원 제휴는 DOC-BIZ-07 Q2b(취업 경로)와 검증 경로 공유 | 📌 §7-2 검토 대상 |

**보고서와 기존 전략의 접점**: "시험 이후 실무 도구가 차별점" 판정은 DOC-BIZ-06의 P0~P2 실무 도구 로드맵과 수렴 — 수험→종사자 전환(P2-10)의 해자 논리를 외부에서 재확인한 형태. 단 보고서는 "수험 기능 무료 개방"을 권고해 현행 pro 분할(진단·이야기형)과 긴장이 있으므로 인터뷰(DOC-BIZ-07) 지불 의사 결과와 함께 판정할 것.
