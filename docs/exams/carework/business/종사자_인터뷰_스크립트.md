# 종사자 인터뷰 스크립트 — Care OS §6-0 단계

> 목적: `CareOS_경쟁전략.md`(DOC-BIZ-06) §5-0 세그먼트×채널 가설과 §6 로드맵 착수 여부를 판단하는 데이터를 수집한다. 결과가 아니라 **인터뷰 전에 기준을 확정**한 문서다 — 인터뷰 후 기준을 바꾸면 확증 편향.
> 원칙: 기능 소개 ❌ / 현재 업무 관찰 ⭕. "필요하세요?"가 아니라 **"어떻게 하세요? 보여주실 수 있어요?"**로 묻는다 — 지도점검·감사처럼 들리면 방어적 "다 하고 있어요"가 나와 수요가 과소 측정된다.
> 소요: ~30분 (거절 대비 **핵심 15분 버전**은 §7)
> **문서 ID**: DOC-BIZ-07
> **범위**: exam:carework · 판본: none
> **관련 SPEC ID**: ROAD-P5, DA-18 (수요 검증 인터뷰 — DOC-BIZ-06 §6-0)

## 0. 판단 기준 (인터뷰 전 확정)

| 항목 | 기준 |
|---|---|
| 표본 | **시설급여(요양원·주야간) 종사자 5명 + 방문요양 종사자 5명** — 두 그룹은 채널·기능 가설이 달라 **분모를 분리**해서 집계한다. 시설장·사회복지사는 질문에 답하되 요양보호사 분모와 별도 기록 (의사결정권자 정보는 B2B 검증에 유용) |
| 중단 기준 ① | 이중 입력 회피 불가 확인 — "개인 도구에 따로 기록할 이유가 없다"가 **두 그룹 합산 6/10 이상**이면 P0 전면 재검토 (DOC-BIZ-06 §7-1 1순위 리스크) |
| 중단 기준 ② | 개인 기기 사용 금지 일반화 — 근무 중 개인 폰 사용 불가가 **시설 그룹 4/5 이상**이면 개인 채널 전략 재수립 (시설 B2B 전용으로 전환 검토) |
| 진행 기준 | ①이중 입력 회피 경로 존재(가져오기·붙여넣기 수용)가 그룹별 3/5 이상 **그리고** ②시설 그룹에서 기관 도입 의향 또는 디자인 파트너 신청 **1곳 이상** — 말만으로는 판단 안 함, 행동 신호 결합 |
| 분기 | 방문요양 그룹 지불 의사가 낮아도 무료 사용 의향(Q11)이 높으면 **유입 채널 가치 확정**(개인 Pro 기대 하향 유지) / 시설에서 관리자(시설장) 지불 의사 확인되면 **기관 Pro 가설 보강** |
| 가격 앵커 | 개인 Pro **월 3~5천원** · 기관 Pro **월 5만원** — 기준가와 동일하게 확정 (인터뷰 중 임의 변경 금지) |

## 시작 전 (30초)

> "요양 현장 도구 방향을 정하기 위해 실제로 어떻게 일하시는지 여쭤보러 왔습니다. 정답이 있는 게 아니라 지금 방식 그대로가 가장 좋은 답입니다. 오늘 내용은 제품 방향 판단에만 쓰입니다. 메모(또는 녹음)해도 괜찮을까요?"

## 2. 현재 기록 방식 (10분) — 인터뷰 항목 ① (이중 입력 실태)

| # | 질문 | 확인할 것 |
|---|---|---|
| Q3 | 근무 중 기록은 뭘로 하세요? 공단 앱(스마트장기요양) / 기관 프로그램(이지케어·케어포·엔젤 등) / 수기 / 카톡 메모? | 기록 도구 분포 — 공단 앱 vs ERP vs 수기 실제 비율 |
| Q4 | 같은 내용을 **두 군데 이상** 적는 일이 있으세요? 예를 들어 수기로 썼다가 프로그램에 다시 옮기거나, 앱 입력 후 별도 보고서를 쓰거나. | **이중 입력 실태 직접 확인 — 중단 기준①의 핵심**. "없다"면 어디서 끝나는지까지 추적 |
| Q5 | 프로그램이나 앱에 입력한 내용을 나중에 다시 꺼내 쓰신 적 있으세요? 엑셀이나 출력으로 빼본 적 있으세요? | 데이터 반출 경험 — CSV 가져오기(P1-4)의 실수요 |
| Q6 | 기록하면서 "이건 내가 따로 갖고 있으면 좋겠다" 싶은 게 있으세요? 없으면 왜 없으세요? | 개인 기록 자산 수요 — 공백 주장의 직접 검증 |

## 3. 인수인계·교대 실태 (시설 그룹 5분 / 방문요양은 §3b로)

| # | 질문 | 확인할 것 |

| Q8 | 전달이 빠지거나 잘못 전달돼서 문제 생긴 적 있으세요? 어떤 일이었어요? | 인수인계 실패 경험 — 문제 강도의 직접 증거 |

## 4. 개인 기기·업무 부담 (5분) — 인터뷰 항목 ②④
