PassOK의 차별점은 "딱딱하고 암기하기 어려운 내용을 쉽게 만드는 도구"다. 이 문서는
이야기형을 포함한 각인 장치의 확장 방안을 우선순위와 함께 정리한다 — 상태: **제안 검토 단계**.

## 1. 원칙

- **사실 무결성 우선**: 수치·법령·표·공식은 어떤 각인 장치도 바꾸지 않는다. 장치는 사실을 감싸는 기억 고리에만 붙는다.
- **기존 자산 재활용 우선**: 이미 검증된 구조(서사 슬롯·두음법·웹툰 뷰·FSRS/BKT)를 확장해 새 인프라를 최소화한다.
- **판본 영향 없음**: 학습 도구는 읽기 판본을 가리지 않고 동일 데이터 소스에서 파생한다.

## 2. 방안 A — 기존 자산의 팩간 확장 (비용 대비 효과 최상)

| 방안 | 내용 | 근거·선행 자산 |
|---|---|---|
| A-1 웹툰 버블 뷰 팩 공용화 | carework `care-webtoon.html`(서사 슬롯→말풍선 컷)을 hazmat·cosmetic 서사에 적용 | 뷰 인프라 완비 — 서사 슬롯만 공급 |
| A-2 hazmat 서사 패치 | SAFECHEM Series Bible(교재/docs/) 기준으로 과목3부터 `story/*_서사.md` 작성 | 뼈대 완성 — 최대 미착수 항목 |
| A-3 시나리오 문항 팩 확장 | carework 상황별 대처카드·시나리오 단계를 다른 팩에 적용 — 수치 문제를 "이 상황에서 무엇을 선택?" 장면으로 | carework Phase 2 검증됨 — 암기→판단 연습 전환 |

## 3. 방안 B — 기억술 도구 (수치·나열의 각인)

| 방안 | 내용 | 각인 원리 |
|---|---|---|
| B-1 두음법 개인화 | 고정 64개 목록에 사용자 자작 연상 문장 등록 → 복습 스케줄 탑재 | 생성 효과(generation effect) — 직접 만든 두음은 기억 강도가 큼 |
| B-2 경계값 카드 | hazmat류 "2만 kL·24시간·지정수량" 경계값 + `<·≤` 함정을 두 값 비교 카드로 자동 생성 | 함정 자체를 학습 장치로 전용 — 오답 경험이 각인 |
| B-3 빈칸 인출(cloze) 자동 생성 | 교재 표·정의문의 핵심 수치·용어를 `___`으로 가린 카드를 build 시점 생성 — 숫자암기표의 정적 목록을 교재 전체로 확장 | 인출 연습(retrieval practice) — 교재 구조(📌체크포인트·수치 표)가 이미 마킹돼 생성 규칙 명확 |
| B-4 설명하기(Feynman) 슬롯 | 챕터 말미 "멘토에게 설명해 보라" 프롬프트 + 키워드 체크리스트 자가채점 | 설명 효과 — 서사 장치(선임 되묻기)와 결합 시 퀴즈가 스토리 안에 녹음 |

## 4. 방안 C — 서사와 복습의 결합 (차별화 포인트)

| 방안 | 내용 | 연결 지점 |
|---|---|---|
| C-1 복선 회수 훅 | 오답 카드 뒷면에 "수첩의 그 장면" 한 줄 — 카드가 교재 장면으로 역링크 | 오답 → 챕터 앵커(AN-10) 이동 |
| C-2 에피소드 앵커 복습 | BKT 취약 단원을 "그 단원이 나온 장면"으로 묶어 복습 세션에 서사 제목 표시 ("8화 — 탱크 점검일") | BKT(D-22) × 서사 맵 |
| C-3 캐릭터 해설 톤 | 정답 해설을 선임 멘토의 되묻는 말투로 | 인물 설정표(CS-13 정본)에 해설 톤 규칙 추가 필요 |

## 5. 추천 실행 순서

1. **hazmat 과목3 서사 패치** (A-2) — 뼈대 완성, 표준형 유지하며 슬롯만 추가
2. **cloze 자동 생성기** (B-3) — 교재 구조화 마커 기반이라 전 팩 즉시 적용
3. **웹툰 뷰 공용화** (A-1) — carework 검증 후 이식
4. B-1·A-3·C 계열은 팩별 차등 도입

## 6. 미결 사항

- cloze 생성 대상 마킹 규약 — 교재 본문에 잠재 카드 영역을 어떻게 선언할지 (파서 규칙 필요)
- 경계값 카드의 함정 추출 방식 — 수동 큐레이션 vs 수치 표 자동 추출
- 서사 슬롯 ↔ BKT 단원 매핑 테이블 관리 위치 (manifest vs 서사 패치 헤더)
