## 0. 전제

- Discord 계정은 기존 운영 서버용 계정을 재사용해도 된다
- 서버는 **신규 1개**를 만든다 — `passok-ops`(비공개 운영: 배포 알림·조회 봇)와 절대 공유하지 않는다. 운영 webhook·`admin-bot`은 ops 서버에 그대로 둔다

## 1. 서버 생성 + Community 활성화

1. Discord 왼쪽 서버 목록 맨 아래 **「+」(서버 추가)** → **「직접 만들기」** → **「커뮤니티를 위한 서버」** → 이름 `PassOK`
   - "나와 친구들을 위한 서버"로 만들어도 되지만, 커뮤니티 템플릿은 규칙 채널이 미리 생성된다
2. 서버명 우클릭 → **서버 설정 → 커뮤니티 활성화(Enable Community)** → **시작하기**
   - Safety checks: "인증된 이메일 필요" + "미디어 콘텐츠 스캔" 체크 → 설정 완료
3. 활성화되면 서버 설정에 **Onboarding·인사이트** 메뉴가 생기고 `#rules`·`#moderator-only` 채널이 자동 생성된다

## 2. 채널·카테고리 트리

설계 §1 트리를 그대로 만든다. 카테고리 생성: 채널 목록 빈 곳 우클릭 → **카테고리 만들기**.

| 카테고리 | 채널 | 종류 |
|---|---|---|
| 👋 허브 | `#환영·규칙` · `#전체-공지` · `#시험-관심등록` · `#자유-수다` · `#버그·기능제보` | 텍스트 (`#전체-공지`=공지 채널) |
| 💄 조제관리사 | `#조제-공지` · `조제-질문포럼` · `#조제-오류제보` · `#조제-스터디` · `🔊조제-음성룸` | 텍스트+포럼+음성 |
| 파일럿 ×4 | `#<시험>-알림신청` · `#<시험>-질문` | 텍스트 (축소 세트) |
| 🔒 운영 | `#트리아지` · `#자동화-로그` | 텍스트 (staff 전용) |

- **Announcement(공지) 채널**: 채널 생성 후 → 채널명 우클릭 → **채널 편집 → 공지 채널** 토글 — Community 서버에서만 보이는 옵션이다. 타 서버가 팔로우 가능
- **포럼 채널**: 채널 생성 시 종류를 **포럼**으로 선택 → 채널 설정 → **태그**에 과목 추가 — 조제는 `화장품법`·`제조`·`품질관리`·`안전관리` (manifest `subjects`와 동일 명칭으로 맞춘다)
- **파일럿 표기**: 카테고리명에 "(준비중)"을 붙여 오픈 상태를 구분 — 승격 시 제거 + 풀 세트로 확장 (PILOT_EXAM_PROMOTION §9)
- 파일럿 채널명 예시: `#손평-알림신청`·`#손평-질문`(lossadj) / `#손사-`·`#안기-`·`#행사-` (insadj·indsafe·admagent — 접두는 짧게, 명칭은 자유)

## 3. 역할 + 권한 게이트

1. **서버 설정 → 역할 → 역할 만들기**:
   - `@수험생-조제관리사` — 역할 색을 시험 테마색(`#06b6d4`)으로 지정하면 구분이 쉽다
   - `@관심-손해평가사` · `@관심-손해사정사` · `@관심-산업안전기사` · `@관심-행정사`
   - `@운영팀` · `@모더레이터`
2. **카테고리 권한** — 카테고리 우클릭 → **카테고리 편집 → 권한** (채널은 카테고리 권한을 상속):
   - 시험 카테고리: `@everyone`의 "채널 보기" **OFF** → 해당 `@수험생-*`/`@관심-*` 역할과 `@운영팀` **ON**
   - 허브 카테고리: `@everyone` 보기 ON 유지 — 단 `#환영·규칙`·`#전체-공지`·`#시험-관심등록`은 "메시지 보내기" **OFF** (읽기 전용 — 관심등록은 반응으로 받는다)
   - 운영 카테고리: `@everyone` OFF + `@운영팀`·`@모더레이터` ON

## 4. Onboarding — 자가 역할 부여

**서버 설정 → Onboarding** 에서 질문을 등록한다 (Community 내장 기능 — 별도 봇 불필요):

- 질문: "어떤 시험을 준비하고 있나요?" — **복수 선택 허용**
- 답변 옵션 → 역할 매핑: 조제관리사→`@수험생-조제관리사`, 손해평가사→`@관심-손해평가사`, 손해사정사→`@관심-손해사정사`, 산업안전기사→`@관심-산업안전기사`, 행정사→`@관심-행정사`
- "기본 채널"은 허브 채널을 지정 — 역할 미선택 멤버도 볼 수 있는 채널

## 5. 규칙 + AutoMod + 검증 수준

1. `#환영·규칙`(또는 자동 생성된 `#rules`)에 규칙을 고정한다. 최소 항목:
   - 교재·문제은행 스크린샷·복사 공유 금지 (저작권 — 앱 내 링크로 유도)
   - 타 수험앱·강의·상품 광고 금지
   - 오류 제보는 해당 시험 `#*-오류제보` 채널로
2. **서버 설정 → AutoMod**: "의심스러운 스팸 콘텐츠 차단" ON + 키워드 필터(광고·욕설) + 멘션 스팸 차단 ON
3. **서버 설정 → 안전 설정**: 인증 레벨 **중간**(가입 후 5분 경과해야 발언) + 멤버 검증(Rules Screening) ON

## 6. 초대 링크 → 앱 연결 (ES-08)

### 6.1 초대 URL 발급

1. 서버를 열고 **초기 진입점으로 쓸 채널**을 고른다 — 보통 `#환영·규칙` 또는 `#전체-공지` (새 멤버가 처음 도착하는 채널)
2. 채널명 **우클릭 → 「사람 초대하기」** (또는 서버명 우클릭 → 사람 초대하기)
3. 팝업 하단 **「초대 링크 편집(Edit invite link)」** 클릭:
   - 만료: **만료 없음(Never)** — 앱에 박히는 링크라 만료되면 버튼이 죽은 링크가 된다
   - 최대 사용 횟수: **제한 없음**
   - 임시 멤버십 부여: **OFF**
4. **「새 링크 생성」→ 복사** → `https://discord.gg/xxxxxxxx` 형태

> **시험별 유입 추적(선택)**: 시험마다 다른 채널에서 각각 링크를 만들면(`#조제-공지`·`#손평-알림신청` 등) 서버 설정 → 초대(Invites)에서 링크별 사용 수를 추적할 수 있다.

### 6.2 exams.json 기입·반영

1. `content/exams.json` 해당 엔트리에 기입:

   ```json
   "discordInvite": "https://discord.gg/xxxxxxxx"
   ```

2. 반영 후 배포:

   ```powershell
   npm.cmd run build:data
   ```

   → 도움말 메뉴에 'Discord 커뮤니티' 버튼 노출 (ES-08, `community-btn`)
3. 파일럿 시험은 `discordInvite` 기입 전이라도 `#시험-관심등록` 고정 메시지로 서버 초대 + 관심 반응 지시를 안내한다

### 6.3 오프라인 QR 자산 (인쇄물·전단용)

앱 내 노출은 클릭 링크가 정본 — QR은 같은 기기에서 스캔 불가라 화면 배치 가치가 없다.
인쇄물·스터디카페 전단 등 오프라인 배포 시 아래 생성물을 사용한다 (영구 링크 기반이라 스테일 없음 — 초대 URL 교체 시 재생성 필요):

- `docs/assets/discord-invite-qr.svg` — 벡터 (인쇄 확대 무손실)
- `docs/assets/discord-invite-qr.png` — 1024px 래스터 (슬라이드·문서 삽입)

재생성: `npx qrcode "<초대URL>" -t svg -o docs/assets/discord-invite-qr.svg` (PNG는 `-t png -w 1024 -m 4`)
전체 QR 자산 인덱스: [docs/assets/README.md](../../assets/README.md)

## 7. 검증 — 외부 계정 시점

별도 계정 또는 시크릿 창으로 확인:

- [ ] 초대 링크 진입 → 규칙 동의(Member Screening) → Onboarding 질문 표시
- [ ] 역할 미선택 멤버는 허브만 보이고 시험 카테고리 비표시
- [ ] 역할 선택 시 해당 카테고리만 추가 노출
- [ ] `#전체-공지`·`#환영·규칙`에 일반 멤버 발언 불가
- [ ] 배포된 앱 도움말 메뉴에 'Discord 커뮤니티' 버튼 노출 + 클릭 시 초대 페이지로 이동

## 8. 다음 단계

- **Phase 3 — 공지 자동발송 (AD-12, 구현됨 · ✅ 2026-10-24 설정·발송 테스트 완료)**: 각 `#<시험>-공지`·`#전체-공지` 채널 → 채널 설정 → 연동 → 웹후크 생성 → URL을 `.env`에 선언:
