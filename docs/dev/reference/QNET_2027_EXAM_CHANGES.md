## 4. 기타 2027 관련 공지

- 변리사 제64회 시행계획 공고 (2026.11.19 등록, 공고 제2026-166호)
- 정수시설운영관리사 제41~43회 시행계획 공고 (공고 제2026-187호)
- 국가유산수리기능자 시험일정 사전 안내 (2026.10.14) — 전문자격 사전 시행일정 공고 11월 말 예정
- 사회복지사 1급 제25회 필기 확정: 접수 12.7~12.11 → 시험 2027.1.16 → 발표 3.24
- 기상기후기사 출제기준 변경 안내 (적용 2027.1.1~2031.12.31)
- 국가자격검정 인정신분증 범위 조정 (2026.10.27~ 적용 중)

## 5. 작업 시사점

- `indsafe`는 active 팩이며 2027년 1회 필기(2.12~)부터 5과목 체제 적용 — manifest 과목 구성·교재/문제은행 재편 필요. 세부 범위는 Q-Net 자료실의 2027~2029 출제기준 원문으로 확정할 것 (과목명 통합 ≠ 범위 축소 단정 불가)
- `indsafeind`·`iteng`은 draft 단계라 과목 구조를 2027 개편 기준으로 처음부터 잡는 것이 유리
- 변경 적용일은 2027.1.1 — 2026년 잔여 회차 콘텐츠는 현행 과목 구성 유지가 정답. 팩별로 "구년도판/신년도판" 병행 여부는 별도 결정 사항
