## 한 줄 정의

**PassOK** — 한국 자격시험 대비 **멀티시험 학습 PWA**. 시험은 콘텐츠 팩 단위로 온보딩되며, 기본 팩은 맞춤형화장품 조제관리사(`cosmetic`, 앱명 Passmula + Formula OS 실무 배합).

> **명칭 위계**: PassOK = 플랫폼 · Passmula = cosmetic 수험 앱 브랜드 · Formula OS = cosmetic 실무 도구 (브랜드 분리 여부 미정)

- 프로덕션: https://passok.vercel.app
- 저장소: github.com/skygoldlee-cyber/passok

## 기술 스택 원칙

- **Vanilla ES Modules** — 프레임워크 없음, 런타임 의존성 0개 (공급망 공격면 최소화, vendor는 해시 매니페스트 검증)
- **Local-First** — localStorage가 1차 저장소, Supabase는 opt-in 증강
- **콘텐츠=SSOT** — `content/*.md`가 정본, `data/` 번들은 전부 빌드 산출물 (수동 편집 금지, 신선도 게이트가 차단)
- **시험 독립** — 플랫폼 코드에 시험 id·과목 키 하드코딩 금지 (`check:contentind`, DA-15)

## 기존 인강·교재 대비 강점 분석

### 구조적으로 우위에 설 수 있는 지점

| 강점 | 기존 매체의 한계 | 이 플랫폼의 근거 |
|------|------------------|------------------|
| 개인화 스케줄링 | 인강·교재는 "누구나 같은 순서·같은 속도" | FSRS-6이 카드별 망각 곡선을 추적해 "잊기 직전 시점"에만 복습 배정 — 같은 시간 대비 회수 효율이 높을 것으로 기대 **(가설 — 일반 연구 근거, 제품 실측 전)** |
| 약점 측정의 정밀도 | 교재는 스스로 약한 부분을 '느낌'으로 판단 | BKT가 단원별 숙달 확률 P(L)을 정오답 시퀀스로 추정 → "모르는 것을 모른다"는 메타인지 갭을 데이터로 해소 |
| 능동 회수 강제 | 인강은 수동 시청, 교재는 수동 독해 — '이해했음 착각'에 취약 | 모든 루프가 회수(플래시카드·OX·복수정답·모의고사) 중심 — 테스트 효과는 학습 효율에서 가장 잘 입증된 기제 **중 하나** |
| 법령 개정 추적 | 종이 교재는 개정되면 폐기/증보판 | ref_md 원문 해시·인용 라인 추적 — 법령 고시가 바뀌면 영향받는 문항·교재 문단을 기계적으로 추적 (`ai:stale`) |
| 오프라인·세션 조각화 | 인강은 스트리밍·40분 단위 | PWA 완전 오프라인 — 출퇴근 10분 단위 세션으로 쪼개짐. 학습 앱의 실사용 패턴과 정합 |
| 콘텐츠 증산 비용 | 인강 제작은 강사·스튜디오 비용 | `ai:draft` 파이프라인으로 문항 초안을 저비용 생산 → 리뷰 게이트 후 확장. 교재 제작 대비 증산 비용이 낮을 것으로 기대 **(가설 — lossadj 파일럿에서 실측)** |

### 정직한 한계

- **설명의 깊이** — 인강 강사의 직관적 비유·맥락 설명은 텍스트+카드가 대체 못 함. 이 플랫폼은 "개념 이해" 단계가 아니라 "기억·적용" 단계에 강함
- **동기부여 구조** — 인강의 진도율·학습 조언 같은 강제력 있는 커리큘럼은 없음. 자기주도 학습 의존
- **콘텐츠 신뢰** — 기존 교재는 출판 검증 프로세스가 있고, AI 생성 문항은 리뷰 게이트가 있으나 검증 이력이 얕음
- **완성 시험 1개** — cosmetic만 성숙(active), 나머지 18개는 pilot/draft. 멀티시험 가치는 아직 구조 수준

### 실질 포지셔닝

"인강/교재의 대체재가 아니라 **보완재**" — 개념은 교재·인강으로 배우고, **암기·약점 교정·복습 스케줄링**을 이 플랫폼에 맡기는 구조. 차별화 축은 **법령 개정 ↔ 문항 추적성 + 개인 망각 모델** — 둘 다 종이 교재와 영상 강의로는 **구조적으로 비용이 큰** 영역이다.
