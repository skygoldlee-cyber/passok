# 자격시험 학습 매체 경쟁 분석 — 교재·인강·CBT

> **문서 ID**: DOC-BIZ-13
> **범위**: platform · 판본: none
> **성격**: 사내 전략 분석 등재 — §3 표에 구현 현황 열 부기(2026-11-16 코드 대조), 나머지 원문 유지
> **범위**: 전 시험 팩 공통 — 본문의 요양보호사 사례는 대표 예시이며 매체 구조 분석은 팩 무관
> **연계**: CE-06 (가독성·밀도 규약 — "가독성 중심 교재" 요구와 직결) · DOC-BIZ-06 (Care OS 경쟁전략 — "합격 후 단절" 대응의 carework 사례) · DOC-BIZ-01 (Formula OS 경쟁전략 — cosmetic 사례)


Nov 16, 2026 · @coteleaf

기존 교재·인강·CBT는 모두 정보 공급에 집중하고, 학습자가 기억하고 꺼내 쓰는 과정은 설계하지 않는다. 세 매체가 서로 끊겨 있다는 점이 신규 진입자에게 가장 큰 기회다.

## 1. 매체별 약점 비교

세 매체 모두 ‘기억을 꺼내는 연습’과 ‘매체 간 연결’이 약하다. 판정은 공개 자료와 필자 분석에 따른 것이며, 수험생 설문으로 검증하지 않았다.

| 평가 항목 | 시중 교재 | 인강 | CBT·문제풀이 앱 |
| --- | --- | --- | --- |
| 가독성·시인성 | 약함 — 작은 글자, 빽빽한 쪽 | 보통 | 약함 — 작은 글자, 광고 |
| 출제 우선순위 제시 | 약함 | 강사에 따라 다름 | 보통 — 빈출 문제는 있음 |
| 인출(떠올리기) 연습 | 약함 — 단원 끝 문제만 | 없음 — 듣기만 | 강함, 단 정답 위치 암기로 흐름 |

| 중장년층 배려 | 약함 | 보통 | 약함 — 복잡한 메뉴 |

## 2. 매체별 상세 약점

### 시중 교재

- **분량 경쟁:** ‘표준교재 완벽 반영’이 ‘더 많이 담기’가 된다. 요양보호사 표준교재(2026판)는 694쪽이고, 시중 수험서는 이를 176\~364쪽에 압축하면서 글자·여백을 줄인다 — 다른 시험도 표준교재·법령 원전 대비 동일한 압축 구조다.
- **강약 없음:** 자주 나오는 내용과 드물게 나오는 내용이 같은 무게로 실린다.
- **기출 근거 약함:** 요양보호사처럼 기출 비공개 시험은 교재마다 예상문제의 질이 크게 다르고, 공개 시험(위험물 등)도 기출 해설의 깊이가 천차만별이다.
- **복습 동선 없음:** 한 번 읽고 끝나는 선형 구조다. 종이 문제는 한 번밖에 못 풀고 채점·오답 정리에 시간이 든다.

### 인강

- **시간 효율 낮음:** 교재를 읽어 주는 강의가 많다. 글로 10분이면 될 내용을 60분 듣는다.
- **수동 학습:** 듣는 동안 이해한 느낌은 들지만, 스스로 떠올리는 연습이 없다.
- **검색 불가:** ‘그 개념이 몇 강 몇 분’인지 찾을 수 없다.
- **개정 반영 느림:** 재촬영 비용 때문에 구버전 강의가 남는다 — 법 개정 주기가 짧은 시험(화장품법·노인장기요양 등)에서 특히 치명적이다.
- **상황 제약:** 출퇴근길·짧은 휴식 시간에 소리를 켜고 오래 보기 어렵다.

### CBT·문제풀이 앱

- **문제 편중:** ‘문제은행에서 나오니 많이 푸세요’가 핵심 메시지다. 그 결과 정답 위치를 외우게 되고, 문제를 조금 바꾸면 틀린다.
- **오답 진단 없음:** 오답노트는 틀린 문제 모음일 뿐, 어떤 개념이 약한지는 알려주지 않는다.
- **이론과 단절:** 해설에서 해당 이론으로 바로 갈 수 없다.
- **문항 품질 편차:** 기출 비공개 시험은 복원·자체 문항의 정확도를 확인하기 어렵고, 신설 시험(맞춤형화장품 조제관리사 등)은 기출 자체가 없어 문항 설계 역량이 곧 품질이다.
- **중장년층 UI 미흡:** 작은 글자, 광고, 복잡한 메뉴.
- **운영 안정성:** 소규모 앱은 서버 장애로 답 저장·해설 보기가 막히는 사례가 있다(모두CBT, 2026년 8월).

## 3. 기회와 대응 방향

경쟁 매체의 약점은 하나의 제품 안에서 교재·문제·복습을 연결하면 대부분 대응할 수 있다.

| 경쟁 매체의 약점 | 우리의 대응 | 구현 수단 | 구현 현황 (2026-11-16 코드 대조) |
| --- | --- | --- | --- |
| 정보 과잉, 낮은 가독성 | 펼침면 하나에 주제 하나, 핵심 3\~5개 | 교재 샘플 제작 가이드 기준 적용 | **구현됨** — CE-06 가독성·밀도 규약 + `audit:ce06` 상시 감사(인쇄 펼침면은 유보) |
| 수동 학습(읽기·듣기) | 짧은 이론 → 바로 떠올리기 문제 → 간격 반복 | 주제별 확인 문제 + 앱의 복습 일정 알림 | **구현됨** — carework 4단계 학습 흐름(미리풀기→이야기→요약→시나리오) + 전 팩 FSRS-6 복습 스케줄(`src/study/fsrs.js`). 단 복습 **알림(push)은 미구현** |
| 정답 위치 암기 | 같은 개념을 O/X·빈칸·상황형으로 반복 출제 | 개념 단위 문항 은행, 보기 순서 랜덤 | **구현됨** — 이야기형·시나리오·OX·복수정답(combo) 드릴, 보기 셔플(carework·hazmat 적용, 전 팩 확장 가능). 단 우리 은행도 위치암기 위험 동일 — 변형 효과 검증 가설 필요 |

| 긴 인강 | 개념당 3\~5분 짧은 영상, 자막 기본 | 소리 없이도 볼 수 있는 형식 | **미구현** — 영상 없음. 이야기형·웹툰 컷으로 부분 대체 중 |
| 문항 품질 편차 | 모든 문항에 근거 쪽수·개정 기준일 표시 | 개정 시 문항 일괄 점검 프로세스 | **구현됨** — 문항별 📌출처 + 교재 라인 인용(6884건)·`sync:citations` 자동 동기·표준교재 대조 검증(VALIDATION). "쪽수"보다 강한 라인 근거. 개정 기준일 표기는 부분 |

## 4. 우선순위와 검증할 가설

먼저 만들 것은 ‘가독성 좋은 교재 + 확인 문제 + 앱 연결’이다. 개발 비용이 낮고, 세 매체의 단절을 한 번에 보여줄 수 있다.

**추진 순서**

1. 가독성 중심 교재 샘플(과목당 펼침면 3개) + 주제별 확인 문제
2. 교재 QR → 앱 문제 연결, 문항마다 개념 태그·근거 쪽수
3. 개념별 약점 지도와 간격 반복 복습
4. 개념당 3\~5분 짧은 영상
5. 합격 후 실무 도구 연계

**검증할 가설** (샘플 단계에서 확인)

- [ ] 40\~50대 수험생은 분량보다 가독성을 보고 교재를 고른다 — 기존 교재와 샘플을 나란히 보여주고 선택 이유를 물어본다
- [ ] 종이 교재 사용자도 QR로 앱에 들어온다 — QR 스캔율과 앱 재방문율을 잰다
- [ ] 개념 태그 기반 약점 지도가 오답노트보다 점수를 더 올린다 — 소규모 비교 테스트
- [ ] 수험생이 길게 느끼는 인강 길이 — 학습자 인터뷰 3\~5명

이 문서의 매체 판정은 공개 자료와 필자 분석에 기반한다. 위 가설을 검증한 뒤 1장 표를 수정한다.

## 부록 A. 코드 대조 갭 분석 (2026-11-16 등재 시 부기)

**실제 신규 투자 갭은 4개** — 나머지 행은 이미 구현돼 있어 "진입 전략"이 아니라 "차별점의 시장 언어화"로 읽어야 한다.

| 순위 | 미구현 갭 | 선결 조건·진입 비용 |
| --- | --- | --- |
| 1 | 문항별 개념·함정 태그 (과목·장 → 개념 단위 세분화) | 은행 스키마 확장 — 약점 지도 정밀도의 전제 |
| 2 | 종이 교재 QR → 앱 개념 문제 진입 | `src/content/qr.js` 재사용 + 교재 ↔ 콘텐츠 ID 매핑. **인쇄 교재 유보(CE-06) 해소가 전제** — 전 팩 공통 인프라 |
| 3 | 개념당 3~5분 짧은 영상 | 제작 파이프라인 신설 — 숏츠 제작의뢰(DOC-BIZ-08) 채널 활용 가능 |
| 4 | 복습 알림(push)·대형글자 모드 | PWA 알림 권한 + 글자크기 설정 UI |

**원문 판정 보정**: 표준교재 694쪽 인용은 2024본 — **2026본(4부 15장, 2025.7.1 개정법 반영)이 최신**(carework 소재에 확보). §1~2 매체 판정에는 영향 없으나 출처 갱신 권고.

**분석 공백(후속 조사 과제)**: ① 실명 경쟁자(에듀윌·해커스 무료 앱, 유튜브 무료 강의) 부재 — 매체 유형 비교만 있음 ② 가격 축 없음 — 무료 구조가 최대 차별점인데 표에 미반영 ③ 시험별 이질성 — 기출 공개 여부(위험물 공개 vs 요양보호사 비공개)·신설 시험(cosmetic, 기출 자체 부재) 등 팩별 경쟁 구도가 상이하므로 본 분석은 공통 뼈대로만 사용 ④ "QR 스캔율" 가설은 인쇄 교재 선행이 전제.
